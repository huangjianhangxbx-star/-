- Q1 用户采用：硬直0.6秒；期间命中照常扣HP，不叠加/刷新硬直；结束恢复50%最大架势并重新等待1.5秒。架势自然恢复为每秒最大值25%。
- Q2 用户采用：实际HP损失100%形成虚血，最后受伤后保留4秒，再按最大HP每秒10%衰减。有效敌方HP伤害的50%可夺回；普攻每次上限自身最大HP5%，技能整次施放共享最大HP10%预算。
- 普通影庭冻结架势/虚血计时；菲奥蕾影庭推进并将虚血限制在实际缺血量内。离开节点、死亡/濒死清虚血并重置架势，不转换为治疗。复制体出生满架势、无虚血，独立结算。敌人不启用虚血夺回。
- 参数均为首版可调值；普通治疗后立即夹紧虚血。已生成领域/延迟效果不因后续硬直消失。箭雨窗口继续流逝但不补射；无限模式保留开关。
