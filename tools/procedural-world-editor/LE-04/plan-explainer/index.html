程序需要知道什么

“融合”包含四件不同的事

轮廓

先有一段完整岩体

笔画的宽度、高度和加减方式形成目标形体。重复覆盖同一处不会机械加高；开始落笔时先冻结参考表面。

关系

相邻部分各有职责

中段继续延伸，末端需要收口，弯折需要转角，较低台面要有支撑。规则先确定关系，再决定放哪一种构件。

表面

边界允许受控适配

去掉埋入内部的面，处理小范围接合；被覆盖的雪转成岩石，露出的台面保留雪。连接成功还需要检查实际几何。

更新

修改会带动附近结构

端部被接长后，原端部可以换成中段。改变之处及必要连接带重算，远处结构、手动锁定和独立摆件保持。

每种构件必须说明三个边界

  1. 外观保留区：岩面、雪帽和主要轮廓，保持作者设计。
  2. 可重复中段：只有被认证的区域才允许延伸或重复。
  3. 允许接合带：仅在明确宽度内裁切、填接或替换。

缺少适配信息的单件继续用于手动摆放或先做认证。没有合适连接件时应明确报告缺口，不能偷偷拉伸整个模型。

用途专属的参数化生成器

配方负责尺寸、用途与条件

更准确的理解是：专用生成器＋源模型／剖面／端口＋条件规则。模型本身没有AI。风格配方要声明允许编辑哪些参数、尺寸或曲率范围，以及何时换款、启用支撑或拒绝操作。

这只是智能Tilemap吗？
邻接选件只是其中一层。生成器还要根据长度、宽度、高程和曲线路径重新生成结构，并根据离地、跨度和接触关系启用不同职责。
程序生成几何是在补漏洞吗？
配方可以明确生成主体内部、台阶、转角或地基衔接。这些是有意的结构输出；生成范围、材质和接合方式都必须预先声明，保护区保持不变。
遇到无法适配的情况怎么办？
在声明范围内换用兼容款式或派生合法支撑；超界就明确提示并保留原提交。不能在无解处任意塞方块，也不能裁坏受保护的设计面。

下面的屋顶与楼梯是解释用的假想我方方案。不表示已经复原Tiny Glade，也不加入本轮LE-04的实现范围；本轮仍只做规则岩体。

同一原则用于不同用途时，参数与派生条件不同
用途用户控制配方怎样联动明确授权的几何
屋顶
假想示例		声明范围内的长、宽、坡度或曲率。重算屋脊、坡面、两端及檐口。尺寸超出该款式能力时，按条件换款或提示，不能任意拉伸整块导入模型。按剖面生成的屋面和檐口、允许重复的中段；保留指定端部和外观设计。
楼梯
假想示例		上下高差、宽度、跨度、离地距离与走向。重算踏步与转折。贴地可启用侧墙；架空时按声明条件启用梁、柱或桥式支撑。跨度或支撑无合法方案时拒绝。配方定义的踏步、侧墙及支撑结构；保护区与外部独立物件不受随意改动。
岩体
LE-04拟建		笔画路径、宽度、顶底高度和局部高度带的增减。更新连通体轮廓，安排主体、端部、转角、肩部和雪帽，并检查接地与支撑。目标实体及已声明的台阶、转角和地基接合区域；保留源设计保护区与手动锁。

连续修改，也要可控

邻域重组不等于全场洗牌

从稳定结构确定变化

同一笔画、同一套原料和同一种子应得到同样结果。构件分段和选择不能跟鼠标事件数量走，也不能每拖一帧随机挑一遍。

手修与独立物件有保护

锁定的形体、单独摆的装饰以及明确保留的外观面，不随自动重组被覆盖。连接无法满足保护约束时，应给出冲突提示。

薄厚调整作用于指定高度

想瘦身或加粗中腰，控制的是这一段岩体的目标范围。附近连接需要重算，不等于允许在笔画范围之外增删体积；构件额外外扩也必须先显示在实际作用预览里。

削减后可检查原连通岩体的支撑，发现悬空或保护冲突时明确处理；这不要求全场重新生成网格。实际显示更新仍应局限于必要的附近。这是一套确定性的编辑规则，不需要让大模型逐帧决定怎么摆。

完成标准

用一段连续操作判断工具是否会搭建

  1. 拖出一段岩壁中段连续，端部完整，不是一排独立副本。
  2. 转弯并接上原岩壁弯角、交汇与新旧连接协调改变。
  3. 再补画，加宽或削减邻近角色随形体变化，手修和远处保持。
  4. 撤销、保存、重开形体、来源、颜色与保护意图都可复现。

实施先用主体与端部打通一条真实笔画的完整流程，不等待全部原料制作完成才验证拖画。最终仍须覆盖转角、交汇、肩部等全部职责，并检查自然岩体的轮廓、疏密和阶梯层次。连续操作通过，不能代替美术判断；截图美观，也不能代替真实编辑与性能测量。
