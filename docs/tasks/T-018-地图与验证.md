# T-018 独立探索：地图、操作和验证

2026-10-05。入口：出发账册选择「暗牢探索」，设置敌人布局种子，确认携入后直接进入。无需先打塔防。旧塔防远征与雾钟庭院支路保留。

## 操作

- WASD 或鼠标移动；队友沿用探索跟随和自治。H 召回，B 集结，Shift 瞬影，Q 收纳。
- 三处篝火位于第1、10、15房间。可见并靠近1.2米后，点击右侧「篝火休息」。每处每次探索只能用一次；交战或敌人仍在追踪时拒绝使用。
- 恢复适用存活本体：最大生命的50%、压力减40、已有技能冷却清零、满架势、清虚血/硬直与普通负面。死亡、濒死及复生中的角色不恢复；不修武器、不重置怪物、不解除普通获救限制。菲奥蕾的特殊获救限制可由篝火解除。
- 成功休息记录最近检查点，猎人复生优先选附近合法空地。出口在第20房间；猎人进入1.2米且其他在场本体靠近3米或已入影庭、脱战且无附近威胁时自动胜利并安全结算。濒死队员仍需救援或逐个明确放弃，自动流程不会代为放弃。
- 战术手牌默认收起；Tab固定开关、底边悬停临时展开、离开300ms收起，选牌或拖牌期间保持展开。同行者栏保留。猎人操作区仅选中猎人时出现于左侧详情下方。相机投影不因抽屉改变。
- 可见敌人发现目标显示红色「!」，随后红圈追踪，失视宽限内黄色「?」；不可见敌人不显示标记。

## 地图来源与转换

源工程：`E:/WORLDCREATOR/new/Project_ANKALUTE`。
保存场景：`Assets/Scenes/XingHaiHuiLang/SC_DarkDungeon_Exploration.unity`。
模型源：`art/体素渲染验证/暗牢材质家族-v1/exports/assets/`。

复用37份原GLB（嵌入贴图，合计2,076,896字节）与3275个保存实例；地图144×120米，20房间。没有重搭房间、削墙或修改源场景。MCP只读取得FBX根变换/包围盒，37资产轴向校验误差小于0.0001米；源场景SHA256未变。编辑器处于另一任务的未保存2D场景，没有切换或保存它。禁读的Assets/Script与Assets/Scripts未读取。

`game/public/assets/dark-dungeon/manifest.json`保留资产SHA与源场景SHA；`geometry.json`为实例矩阵。坐标1米=1游戏单位，游戏x=UnityX−10.5、y=UnityZ−8.5；网页场景再减地图中心。原GLB与FBX轴向不同：X反射烘入几何并反转三角绕序，实例矩阵去除反射，按资产网格InstancedMesh绘制。迷雾使用实例世界坐标，避免整批模型共享错误遮罩。

导航不是原生NavMesh转换。按保存实例中2904个MeshCollider对应的GLB三角形，在角色体高0.32–1.8米范围和0.3米半径保守栅格化；1624个2米地板合计6496平方米，主连通分量5519个1米格。20个房间中心、三篝火与出口均在该分量；2个孤立近似格被排除。所有游戏移动、敌人视线仍由现有核心规则消费此网格。复杂家具边缘与原生连续碰撞可能存在差异。

渲染采用网页原生材质、猎人局部暖光、篝火与探索遮罩；没有将Unity RealToon/URP实验室Shader、SSAO、后处理逐项移植，也不声称画面与团结一致。源实例和模型复用，渲染方案属于网页适配。

## 可重跑与证据

导出脚本位于`game/tools/dark-dungeon/`。先通过项目MCP只读执行`ReadModels.cs`，保存回执为`work/T-018/map/native-models.json`（本轮快照另存于记录目录）；使用带NumPy的Python运行`export.py`与`package.py`。脚本只读源Unity文件，输出本仓库网格及模型副本；源路径在脚本顶部显式声明。`package.py`会更新本任务的派生地图文件，不对源工程写入。

证据目录：`记录/验证/T-018/`。`validation.json`为原生bounds/源哈希/连通核验；`navigation-preview.png`为离线导航总览；`entry-campfire.png`、`hand-1280.png`、`room-02.png`为真实浏览器画面。测试中的远距离移动按已求得路线逐段发出正常移动命令，未绕过探索未知区命令限制。

自动测试覆盖独立入口/出口唯一结算、三个事件点、重复/危险/远距离篝火拒绝、耐久与死亡边界、普通获救及菲奥蕾例外、检查点复生、种子复现与变化、安全距离、20房间连通、警戒可见性、濒死不自动放弃；浏览器覆盖抽屉固定/悬停/锁定、投影不变、猎人操作位置、实际恢复/结算及跨走廊移动。测试最终计数见同目录summary.json。

未做完整地图人工通关、目标设备GPU基准或全部旧浏览器套件。已有UI默认展开的历史断言需随新抽屉规范逐项维护。构建仍有大chunk提示；资源加载检查排除浏览器favicon.ico的既有404，地图、角色资源与脚本没有加载错误。
