# 材质与轴向交换样本
axis-color 为不对称灰/R/G/B原生资产，含可编辑母版、GLB、FBX与材质旁车；assembled 包含共享实例、事件预览和PNG贴花。

Blender可直接打开GLB。团结导入FBX时必须一起复制同名 .xhmaterials.json，并完整保留 assembled.xhtextures 目录。使用随包M1.2插件，地图注册表保持本配方 Blender Fbx Axes 开启，不额外对模型重复旋转180度。比例参考PNG不会进入模型。

此目录用于验证方向、尺寸、颜色和贴图，不是最终美术。正式地图逻辑仍以地图JSON及注册表为准。详细接入见 ../../docs/团结接收器-M1.2.md。
