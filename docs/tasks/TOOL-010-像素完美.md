## 当前有效设计
1. 物体模式每个新体素独立；同画布 Ctrl+J；跨画布须先合并相同精度、网格对齐的画布。内部编辑只修改所选物体，新体素归入该物体。
2. 像素完美默认关，本机记忆；只在编辑模式提供入口。单格、单层、volume/stack连续添加笔画适用；矩形、填充、擦除、大画笔与物体模式沿用旧路径。悬停提示适用范围。
3. 本笔原始样本与旧模型分开；局部单格折角形成对角连续线。旧格、重复交叉点、明确长直角保留；跨面/层变化拆分处理。
4. GPU预览只构建本笔新增格，不修改原模型。鼠标抬起经原操作事务一次提交；Esc/pointercancel/blur/保存/切换模式均安全取消。
5. B 的自动UV、Base Color、可编辑源、FBX+PNG目标保留，但不在本轮提前实现。
