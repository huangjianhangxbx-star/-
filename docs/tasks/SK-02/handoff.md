# SK-02 试玩与交接

普通探索出发前，两名角色的固定实验被动可只读预览。进入当前世界以 Level0 开始，击杀继续按既有规则获得4生命力；按 **V** 或点击右下 V 槽打开面板，点击“激活”支付当前级的一份费用，同时为猎人、阿尔各开启一个被动。三级共支付24，费用4/8/12均为SAMPLE。

Level1调息提高空闲体力恢复；Level2提高右手Q/R样板架势；Level3提高Q/R样板HP。技能加成在新接受动作时缓存，原生E/普攻/左手不改变。三个被动仍是固定实验候选，不是完整技能树或永久数值。

升级界面暂停模拟，Esc关闭；Tab/Enter/Space可键盘操作，开关清持键，不在战斗动作未结束时取消动作来开窗。死亡返场、篝火、同世界离开继续保留级别；开始新测试须原二次确认，保留出征选择但下一世界归零。刷新页面不存档。
