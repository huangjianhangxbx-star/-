# 战斗原型设计基线 v1

日期：2026-09-27。状态：历史设计基线，包含后来已被覆盖的规则；复查当前生效规则请先看 [CurrentRules.md](CurrentRules.md)。可玩原型的实现与限制见 Delivery.md。
优先级：用户最新明确决定 > 本文已确认条目 > 口语版原始意图 > 原型计划 > 参考视频。本文不修改原始资料。

## 目标与范围

验证低操作负担的即时战棋：角色在战场上频繁调位、智能攻击，猎人负责救援与影庭，角色损耗跨战斗保留。以能操作、重现规则并统计纠正操作的战斗切片为交付，不以静态 UI 或自动播放动画代替玩法。
沿用原计划 P0–P8：一张完整斜视角防御地图起步，随后扩展两场战斗与一个休息节点、技能卡牌道具装备、黑暗精神和真实 Spine 接入。不在本版实现横版探索、完整肉鸽、永久养成与剧情。

## 已确认的交互与战斗规则

| 主题 | 当前规则 |
|---|---|
| 移动成本 | 所有己方角色无移动 CD，可连续移动与改道 |
| 完整移动 | 点选角色，再点击目标格，松手进入方向选择，点击确认后提交 |
| 快捷移动 | 按住角色拖到目标格，松手提交，沿用默认方向 |
| 取消与时间 | 右键取消当前操作；选中、定向、背包交互为 0.1 倍速，完成或取消恢复正常 |
| 友方占位 | 途中可穿过友方，终点不能与友方重叠 |
| 敌方阻挡 | 移动被敌人阻挡则暂停并恢复合法普攻；解除阻挡自动续行，可随时改道 |
| 拦截敌人 | 角色按阻挡数拦截；超额敌人继续前进；濒死及离场不阻挡 |
| 跨台 | 过渡期间归属出发格，结束切到目标格并淡入；不无敌，状态照算 |
| 自动朝向 | 默认方向优先；无策略时选最近合法目标，无目标回默认方向；自动朝向不覆盖默认方向 |
| 跨层攻击 | 使用远程概念；非远程仅同层；地面远程受高台遮挡，高台远程可跨高度 |
| 技能 | 每人一个，战中不切换；开始移动打断技能并进入 CD，释放技能取消移动 |
| 敌人路线 | 优先原路线；被迫偏离后接回尚未走过部分中最近可达位置 |
| 路障 | 不得封死敌人抵达目标点的全部通路；非法放置提示且不消耗 |
| 部署范围 | 普通测试图全图合法格；猎人测试图为猎人动态范围与静态区域并集 |
| 道具范围 | 始终受猎人周围范围限制，不随全图部署扩大 |

普通同层移动按进入的逻辑格确定归属。高台与地面没有职业部署硬限制，不匹配时仅提示。移动中不执行普攻；手动换武器取消未出手普攻、继承攻击周期，不赠送立即攻击。自动转向不打断已开始的攻击。四向而非八向朝向。

## 救援、撤离与节点结算

- 一键救援：点击濒死角色救援按钮，猎人自动前往有效范围、到达即救援；显示路线与预计时间，无二次确认，可中途重新指挥。
- 获救角色本场禁用，下一节点 1 HP。胜利或失败退出时，尚未超时的濒死角色自动救回并保留 1 HP；已死亡不复活。
- 角色栏提供进入影庭、前往撤离点；自动移动到达后离场。途中仍受击和阻挡；实际离场后才冻结状态且不受击、不阻挡。
- 影庭目标跟随猎人移动；猎人死亡或离场时取消前往影庭指令并提示。
- 离场后生命与 Buff/Debuff 冻结；技能进入 CD 后按基础速度计算，不受增益。正常成功撤离者始动量条完成后可再部署。
- 猎人不能进影庭；经撤离点离场后本场不能返回，撤离前提示失去救援、影庭及周围部署能力。主动离场不触发死亡重生。
- 水晶击破：本场失败，退出节点；重新进入才重新开战，新战斗水晶满血。角色损耗不回退，不创建用于回退的战前记录。
- 水晶重试次数决定能否继续留在副本，不是角色回档次数。
- 当前原型没有战斗中主动退出节点，只能胜利或失败离开；角色个体撤离不是整场撤退。
- 战斗结束清除临时效果、投射物、延迟伤害和临场牌；生命、精神、耐久、死亡与专属牌等远征状态按原设计保留。持久化的是当前远征状态，不提供失败回滚。

## 卡牌、装备与黑暗

卡槽顺序为临场、背包、角色专属；只有多类型同时存在时显示分隔。刷新只替换背包牌并抽出新 4 张，其他两类保留。成功使用移除当前手牌，不删除背包配置，非法目标不消耗。

普攻实际出手扣一次耐久，取消未出手攻击不扣；范围普攻不按命中人数重复扣。当前版技能暂不扣耐久，影武器无耐久消耗。双武器、损坏切换和职业约束沿用原设计；具体耐久消耗量可配置。

光照只控制可见性，不改武器范围模板。任意己方有效光源揭示的敌人对全队可见，各角色仍单独检查范围、层级、遮挡；预览与实际判定一致。近距离受击发现例外保留，详见 OpenRules。精神与逻辑光照等级解绑。

## 技术方案（待整体评审）

沿用 Vite + TypeScript + Three.js + 原生 DOM/CSS。纯逻辑状态是唯一战斗数据源。地图、寻路、范围、伤害、生命周期与远征状态不依赖 Three.js 对象；渲染层消费状态与事件。Sprite 和 Spine 实现同一个视觉接口，动画缺失须显式降级提示，不伪造已接入。

划分六个职责：
1. 世界查询：地格、层级、占位、可通行与路线接回。
2. 战斗模拟：行动、伤害、技能、状态、阻挡、生命周期。
3. 战斗指令：部署、移动、定向、救援、撤离、用牌与用物；提交时统一校验。
4. 远征：当前节点、重试资格、角色持续状态及节点结算。
5. 表现：场景、角色视觉、范围与路径；同一合法目标查询同时服务预览、索敌和命中。
6. 交互与 HUD：完整/快捷操作状态、时间控制、反馈、统计与调试。

时间以可缩放的模拟时钟推进，失焦停止累积大时间差；动画与伤害事件通过可取消的攻击实例关联，防止取消后幽灵伤害。暂停优先于慢速，多个交互慢速来源需成组释放，避免一个面板关闭就错误解除另一个交互。离場技能 CD 例外独立处理。

三条可选路线：直接依赖 Spine 搭玩法会把资产兼容与规则调试绑在一起；先用纯色几何人形难以验证 Q 版比例；推荐原计划的 Q 版 Sprite 闭环加独立 Spine 技术核验，验证后替换视觉适配器。不得用球体代表已完成角色表现。

## UI 方向（frontend-design 方案，待整体评审）

场景是画面主体。上方窄状态带；下方中央卡牌，右下角色栏与上方技能键；角色详情只在选中时出现，调试面板默认折叠。部署与范围反馈附着在地格，使用轮廓与填充差异，不能只靠颜色。

色板：煤墨 #171C20、雾石 #747E80、旧骨白 #D8D4C7、暗铜 #A98C60、血红 #B65559、灯青 #74B9C7。暗铜只用于框线与焦点细节；灯青服务部署和安全路径，血红服务威胁与无效目标。世界为冷暗石构、铁艺、少量暖灯；UI 背景比场景略不透明以确保可读。

字体：标题用宋体类衬线（SimSun/serif）表现旧时代档案感；操作正文用 Microsoft YaHei/sans-serif，数字用 Consolas/monospace。全中文短标签，正文不使用装饰字体。

辨识特征：底部角色栏像旧铜框身份牌，HP、始动与技能分别占固定边带；只在焦点角色上出现细小哥特拱形轮廓，避免每个按钮都装饰。此为建议视觉方向，不冒充用户已确认的最终画面。

桌面横屏优先，检查 1280×720、1440×900、1920×1080；窗口变窄时底栏重排，不遮住水晶、猎人及主要线路。按键焦点清晰，减少动效偏好不影响战斗反馈。

## 参数与资产分配草案

可逆参数：首图 14×8 格；两条路线、两个高台区、两个出生点、一个水晶与撤离点；救援倒计时先 45 秒，跨台 0.75 秒，转向微冷却 0.5 秒。它们是试玩初值，不是新永久规则。移动 CD 恒为无，不重新引入参数开关改变本版规则。

猎人逻辑绑定用户指定的 Galore0，实际资产候选 Galore；普攻前 5 格，技能前 5×3 格。dustin、verlaine_bot 是敌方；其他己方由 agent 配置职责。菲奥蕾视觉映射先保留可替换 assetId，不把文件夹名称冒充角色身份。全部初始移速一致且较慢，不由 run 动画名称决定。

## 验收

每阶段均可启动、构建、回归。A–G 场景沿用原计划：基础防守、移动、遮挡、救援、撤离再部署、黑暗、真实 Spine。

必须验证：预览与命中一致；取消不扣资源；无移动 CD；自动转向不打断攻击；友方不能终点重叠；路线受阻后续行；路障不封死；濒死结算与已死亡区分；失败不回档；重入水晶满血；猎人撤离不重生；离场状态冻结但技能 CD 正常；背包刷新保留其他牌；全队光照与各自射程分离。

Vitest 验证纯逻辑，浏览器验证真实操作路径与多分辨率；统计移动、手动/自动朝向、救援、取消、非法操作、纠正移动和慢速时间。首版不编造性能达标数字，取得实测后再下结论。

## 2026-09-27 第二轮规则覆盖（高于本文旧条目）

1. 取消角色手动方向选择。点击/拖动移动及部署直接提交；攻击范围预览显示四向并集。非攻击时默认背向己方水晶。
2. 点击头像或模型进入0.1倍慢速，右键任意位置或左键空放取消。慢速动画按每帧小步采样，不再累积到1/30模拟秒才画一帧。
3. 敌人按轨迹分波，每波出现前预告行动路线；波间隔可变化并可重叠。
4. 地面刷新的敌人仅规划地面路径。地面通路由高墙/不可通行区约束；高台与地面需明确区分。路障可受敌方攻击并损坏。
5. 水晶只在地面；当前撤离点仅水晶。角色移动指向水晶时显示就地撤离按钮，玩家选择后执行撤离。当前关闭影庭撤离入口。
6. 同卡时限效果不叠加，重复使用拒绝且不耗牌；不同效果分别显示头顶倒计时读条。
7. 守卫厚血，菲奥蕾有队友治疗技能；头像区与左侧立绘右边都有可点击技能图标、填色进度、三位小数秒显示。
8. 下层卡牌与角色区域增大，卡牌从偏中央的手牌槽向两侧排列。

以上来自用户本轮明确要求；生命值、治疗量、波次时间为实现中的可配置初值，见PrototypeParameters.md。

## 第四轮战斗规则覆盖
- 普攻范围和技能范围独立配置；左侧角色详情技能按钮悬停时切换技能预览，底部技能按钮不切换。预览四向潜在范围，实际方向性技能单次仍选一个方向释放；治疗为队友周围区域。
- 技能执行期间停止普攻。猎人旧强化普攻改为独立技能射击，独立伤害/节奏，不消耗普攻耐久。
- 同层敌我重合仍可互相攻击，不能因零格距离而让敌人停手。
- 守卫保留厚血并增加被动与技能减伤；具体数值是试玩配置。
- 优先使用角色原配Spine特效，击杀事件从敌人位置发出碎片飞向统计。飞行是反馈，不重复或延迟逻辑入账。
