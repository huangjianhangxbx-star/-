# 参考、朝向、取景与保存修正版

2026-11-01。适用于便携版模型制作和场景搭建；保存当前内容后重开程序加载更新。

## 使用

- 建模命令 → 辅助与参考：`导入比例参考` 可一次选择多张 PNG，下一次从上次目录打开。逐张选择后调整高度、位置、可见性或移除。高度按世界米保存，不随画布格尺寸变动。
- `导入建模参考` 是底层背景图，随视图缩放，几何始终在其上方；与比例参考分开管理。场景搭建也有独立的比例参考入口，随场景保存，不生成游戏物体或进入模型导出。
- 编辑、当前模型预览、搭建场景分别保存显示设置。默认建模开启结构边线和体素格线；需要时可自行关闭。同步模型双视口是主动可选项。
- `Ctrl+U` 调整颜色，实时同步模型及场景引用预览。搭建中选中同一种原生资产的实例也可直接调用；调的是共用资产，所有引用同步。取消恢复，应用后再正常保存。`Q` 吸色成功自动回到画笔；`T` 画笔、`E` 擦除。
- 绘制平面面板明确选择上 +Z、下 −Z、右 +X、左 −X、后 +Y、前 −Y，每个方向记住自己的工作层。转视角不会改变绘制平面；表面搭积木仍沿已有起笔面，空白处使用选定平面。
- 物体模式 Ctrl+C / Ctrl+V 或 Ctrl+D 显示复制预览；鼠标锁定最近 X/Y/Z 轴，左键落地，Esc 原地落地并选中新件，不再自动向右偏移。原位重叠副本用独立画布表达，保持独立可编辑和可撤销。
- 左侧物体右键可删除单件或已选多件。集合右键的“删除集合及内容”与“解散集合”分开：前者删除成员，后者仅移除分类。可整体撤销；锁定内容不可删除。
- `F` 聚焦所选内容，未选时聚焦当前画布；`Shift+F` 全部取景。聚焦后绕所选几何中心旋转，参考图与网格不再撑大取景。远处杂物可在树中删除，或用 F 排除。
- 根设置单选时默认“同时移动当前物体操作轴”，可取消勾选仅设置资产根。多选保留各物体独立轴；自由根不在操作轴可表达的格点时保留根的精确坐标并提示轴未同步，不偷偷取整。

## 保存修复

项目中旧资产源缺失或未成功加载时，仍保存正常模型和场景，缺失资产登记及其源文件保留。捕获保存队列、生成预览及写入都处于错误清理范围；失败后可以重试，重复保存共用当前请求，不再卡成“保存正在进行”。
