# EN06 实战接缝合同

任务输入：EN04—EN06连续计划v0.1，用户批准推荐参数。父版本C2 `99b4596a7c949c3806a5056cf3bf342a36194e44`；C1 `ede865653a4b1fea634a5219c3ea695b9ebce9f2`。本轮不关机，不联系Gitee，不新增怪物/角色/二进制素材。玩家黄金四段、Hit/Break/End、取消/扣费、伤害/装弹、动作窗口和音色参数保持既有合同。

## 单一权威

沿主GameState、模拟时钟、combatIdentity代次和HP接触。EnemyActionRuntime接受动作后产生主上下文；EnemyAttackEntity独立存放已经提交的运输与落地危险。EN04架势在该主接触内只处理一次；EN06只读观察，没有旁路伤害、全局出手队列或额外随机数。

`enemy-observation.ts` 读取玩家当前可见的僵尸准备扇形和已提交实体落点，使用现有`areaHits/areaFootprint`地形几何。预警到Hit结束即移除；实体按自己的代次/寿命消失。第三箭已提交但尚未出生时仍是同一真实实体；施法者死亡、移动或移出世界不改变落点风险。不可见落点不供给离手AI；不能用观察输出宣称全知或保证闪避成功。

每条观察键含代次和Action/Entity身份，两弓同帧六箭不会压成一个反应时间。离手伙伴保留原反应延迟和步行避险/站位。具名新场不调用Legacy闪现/规避执行器代替原动作包，也不自动启动RMB/E技能；离手普攻仍合法。该限制只在新架势World生效，旧场景闪现托管原分支保留。

## 参数与隔离

新架势：即时归零控制0.6模拟秒、结束恢复最大值50%、真攻击后等待1.5秒、满速25%最大值/秒、正面挡盾架势损失系数0.5；攻击/闪避暂停、副手架盾半速、静止/步行满速，DOT不反复刷新延迟。这些是用户批准的本游戏SAMPLE，非原作动态观察结论。Reference开发对照只关闭新增架势层。

EN05六组共用原地形：单僵尸、单弓、混合1+1、三怪2+1、四怪2+2、五怪3+2。各怪有独立身份、动作与知识；身体扫掠、合法侧路和后撤避免穿体，不设同时出手名额。五怪标为开发压力场，不承诺正式关卡平衡。

UI新增低透明细虚线扇形，采用主几何裁剪；沿用三箭轨迹、落点圈、架势/受控提示。诊断默认收起。新场架势提示明确“归零立即失衡”；普通场仍保留原第二击语义。没有因读招调整模型、命中窗口或玩家黄金参数。
