# XC09 技能输入与确认契约

仅 Standalone 探索启用。原技能执行、消耗、伤害、时钟与 Auto 条件保留。依据原始 v0.1 计划和 T029–T033 控制契约。

Command 三技能按钮绑定 CommandFocus；点击准备，不提升 Direct，不消费资源，不取消旧 MoveOrder。会话保存在 explorationControl.aim，绑定 actorId/source/startedAt、唯一 sessionId、slot、skillId、profession 和 target。Path/Skill 共用唯一 owner；换技能或 F 替换当前会话。

纯查询返回实际角色中心、解析后的技能范围、痛印、模式意图和当前可确认原因。身体尚忙、冷却或痛印暂缺可以先准备；确认不排队。确认重新读取当前身份、槽位、职业、资源、实际动作和目标条件。可恢复失败保留会话；身份失效退出。重复或过期 token 无法提交。

成功确认在 command 内转换成一次既有 skill 请求，统一进入原 applyCommand 与一次后处理。只取消施法者的订单和 Basic 缓冲，清 Aim，保留 CommandFocus 与原 Direct。原 Direct 有限防御继续；Reservation 只属于离控 AimActor。

| 技能 | Command | Direct 热键 |
| --- | --- | --- |
| Prayer/Ward/Bell/Pain/Sanctuary | 自身真实范围预览，LMB 确认 | 原即时请求 |
| Snipe/Poison | 预览开启或关闭，确认切换自身模式 | 原即时切换 |
| Dance | 自动进入；已开启时确认退出 | 原退出请求 |
| Rain/Reap | Auto 状态，不提供手动入口 | 原拒绝手动请求 |
| Hunt | 说明沿既有索敌，确认激活 | 原即时激活 |

Target Type 与 InputStyle 分离。Direction/Point/Unit 是框架校验能力，用受控测试定义核对格式、真实范围、LOS、可见性和唯一候选。没有新增正式定向/地面/单体技能，也不把 Hunt 改成鼠标定向攻击。

SkillAim 的 LMB 独占确认，RMB 只取消当前 Aim，Escape 逐层退出；F 替换选路，W/Shift/E/R/T 沿旧同键接管规则。Direct 技能条只显示状态与快捷键，点击不再形成额外施放入口。明确其他功能、暂停和失焦取消会话；只读 Debug 保留。

普攻展示：每个合法 Basic Release 有独立 basicRelease 序号与原 pending 身份，用于一次挥击声和保留动画余段。真正取消仍清动画；展示序号不增加伤害、CombatEvent、命中统计或 Reap 次数。命中效果带展示身份避免声音双播。

本契约不代表 XC08 手感研究、XC10 机动 UI 或人工体验验收完成。

## T-035 单一实控切换（2026-10-07）

用户批准以 controlledBodyId / DirectActor 为唯一实控身份。C 两位本体切换，1/2 绝对选择，头像及场内友方点击立即切人；有效持有 WASD 转交，新技能和机动只操作当前角色。当前角色选择 no-op，无效对象先拒绝。旧 Focus/Promote/CommandAim 与 CommandDefense 正常流程停用；离手交正常 AI，切回撤销普通 AI 路线。新 Aim 只属于 Direct，F 选路保留；切走作废未确认 Aim/token，但保留双方已确认订单和原子动作。成功身体动作只取消自身订单。主 HUD、技能和机动同绑 Direct；复制体查看只读，默认切人不自动慢速，其他模态规则保持。

此块替代历史 T029–T034 的双身份控制要求；资源、碰撞、订单、合法 Release/Hit 与真取消安全契约仍有效。专项入口：docs/tasks/T-035-单一实控输入与交接契约.md；执行与验证：docs/tasks/T-035-单一实控切换与控制简化.md、T-035-验证记录.md。用户试玩通过后直接回 EC10 战术轮盘；XC08/XC12/13 研究与演出不冒充完成，旧 XC10 Command UI 退出。发布仅 GitHub main，禁止 Gitee。
