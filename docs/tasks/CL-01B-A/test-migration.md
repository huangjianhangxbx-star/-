## A5 补充诊断与资源修复

首轮9项自然浏览器检查6通过、3失败，两档完整地图闭环均通过。三项失败没有删掉：

3. 第二次新世界在原生僵尸可见时卡住。诊断确认所有模态关闭、移动仍提交，但原生资源未就绪导致模拟暂停；第二次纹理请求未完成。最小自然两世界重载仍复现。直接连续 load/dispose 的资源探针通过，不能把它称为自然场景问题的 RED。
