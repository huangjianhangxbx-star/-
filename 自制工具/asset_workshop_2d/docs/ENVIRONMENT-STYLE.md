# 2DW-05B 场景风格规范（已批准增量版）

2026-10-10 用户批准 M0 并授权实施 M1–M8。本文件是工坊维护说明；任务内唯一权威仍是 `spec/asset-spec.json`，这里不能覆盖输出硬规格。M0 原稿及当时“待审”记录保留作为历史来源，当前审批以本文件和规则注册表为准。

## 已批准范围与三项修订

L0 场景总纲、L1 通用表现、石材 L2 正式接入。木材两条仅为实验候选，默认不强制；土壤、金属、植被只预留身份，未编造材质细则。

- ENV-COM-10：暗部/亮部各最多3阶是主要明暗块面层级，不限制整张图的颜色数量；允许极弱、整体化材质色差。
- ENV-COM-06：材质变化按需保留，结构已成立时不为表现材质而额外填充纹理。
- V1 作为持久正向参考，代表成熟手绘环境美术的质感方向，不要求其他材质同色、同裂缝、同构图。

低饱和、赛璐璐组织与约6:3:1只按用途解释，不是全局像素公式。普通高亮不等于发光，色彩服从材质及任务，不强制灰绿色。不触发重复/联通时不加入 ENV-COM-08。

## 操作与审批

在桌面“场景风格继承”选择场景环境和材质家族。概览只读显示正式、候选、人工判错及来源；现有本次任务偏移照常使用。新建恢复普通任务，复制保留场景选择并生成新ID，改选择会使旧预览失效。

长期修订从“提出长期规则修订”另存 `2dw-environment-proposal/1` JSON，固定 candidate 状态，不改本次 ZIP、批准注册表或项目默认。人工审阅确认后才由维护者接入新目录版本。原有 05A 项目风格默认保存仍保留，其语义不扩展到批准场景库。

V1 文件：[approved-stone-v1.png](../resources/style-references/approved-stone-v1.png)，来源与适用范围见同目录 provenance.json。通过现有“添加 PNG”选择它，再把角色设为“风格”；没有明确选择的图片不自动塞进 ZIP。外部执行端仍须看图并引用 refId，工坊只验证字节和元数据。

原项目契约 → 已批准适用场景规则 → 本次偏移，偏移不可静默覆盖上层。硬输出规格始终优先。已有暗部停刻和明暗预算的继承来源会标注，场景文本只补充含义；不复制整套旧提示词。结构化预算差异给出冲突；自由文本及视觉矛盾仍由外部 AI/人工判定，未检测到不代表没有冲突。

`environmentStyle` 快照含选择、批准规则、候选、判错、来源、触发原因、继承来源和参考锚点。每条规则保留 id/version/layer/domain/materialScope/type/status/origin/checkMode。规格是唯一权威，四个 Markdown 是镜像；v4 重读核对批准目录及镜像，不能只重算 manifest 就提升候选或改掉规则。今后目录变更须保留旧版本解析器以维持 v4 存量兼容，本轮冻结目录1。

新增镜像为 scene-style-charter.md、environment-common-rules.md、material-family.md、failure-signals.md，位于 ZIP 的 style/。无目标 PNG，无已完成的分析/制作报告。木材任务只含通用正式规则与两条候选，不携带石材规则或 V1 锚点。

## 人工美术验收仍待完成

三份样包是待执行任务，不是三张完成素材。看真实生成结果后再判定大中小形主次、普通高亮克制、暗部停刻、材质是否过密/塑料化、重复标记、石墙与地砖区分，以及木材候选是否值得正式接入。工坊不自动分析图像或计算所谓“3色/6:3:1通过率”。无缝拼接、图像生成、Unity 导入、其他材质细则与3D工坊均不属于本轮。
