# 新画布继续使用表面搭积木

2026-11-01；基线 392e15e。用户要求新建画布后仍能贴着已有模型进行表面搭建。保持后台工作，不操作当前窗口或用户资产。

## 行为与范围

- 当前画布为空或已有内容时，表面搭积木的画笔和矩形都可借用其他可见画布的模型表面。新体素只写入当前画布，按其单位和原点对齐，不切换来源画布或物体。
- 优先采用视线上最近的可见表面；当前画布使用实时体素数据，避免显示网格重建延迟影响连续堆高。来源画布可锁定，隐藏、透明度为零或已剖切掉的表面不作为支撑。
- 一笔沿起笔面绘制，矩形可拖出原支撑面的范围；继续保留当前工具、建模模式、对称、归属保护及整笔撤销/重做。擦除、重染和填充继续限定当前可编辑内容。
- 不自动合并画布或对象，不改来源的体素、颜色、贴图原稿。不同单位不共格时，沿法线向外对齐当前网格，避免新格侵入支撑体，可能留下不足一格的间隙；不缩放或移动原模型。
- 本轮只扩展表面搭积木，创造模式及贴图绘画的既有来源/物体范围校验保持。

## 根因与实现

原 `paintHit` 的 DDA 只查当前可编辑体素，新空画布因此直接退回工作平面。现在复用 `CanvasView` 已缓存的几何拾取查询外部画布，把命中点及世界法线转换到当前画布格坐标，再与实时 DDA 的距离比较。外部命中不携带可编辑的 source cell，提交继续走既有当前画布事务；不按鼠标移动重新构造每体素包围盒。

## 验证

- 先在原 build 的真实隐藏工坊复现 RED：来源世界顶面为 0.5 m，新 0.125 m 画布原点 0.125 m，结果错误落在本地 Z0，正确应为 Z3。
- 组件检查覆盖三种粗细关系、偏移原点、六向法线、负面向外对齐、非均匀缩放法线、剖切、显隐/透明度和缓存；旧活动网格不能遮住有效外部支撑。
- 真实工坊临时项目验证 0.25/0.125 m 新画布、画笔/矩形、单笔撤销、已存在自有体素时的最近表面选择；来源完整序列化及绘画原稿哈希保持。补查连续自有表面堆高与擦除/重染范围。
- 类型检查、构建与既有表面/创造矩形流程通过。最终核心回归、便携 EXE 检查、程序资源备份/哈希与 GitHub 回执记录于当日日志。

## 使用

选择或新建目标画布，保持“表面搭积木”，直接在其他已显示画布的模型表面绘制；R 切矩形、T 回画笔。当前画布没有体素也可以起笔，按当前画布单位生成，Ctrl+Z 可整笔撤销。
