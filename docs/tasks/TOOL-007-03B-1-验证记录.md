日期：2026-10-06。基线 `main@8c77b24`；依据用户指向的最新对话中已确定的 03B-1 范围执行。保留共享工作区其他任务的修改。

## 实现

- 复制的是 03A 的精确 Selection Set，不扩为 Bounds；从当前几何读取颜色与 owner 快照。底层中心附近的真实选中格作为整数锚点，维持 0.25 米网格相位。Clipboard 只在应用会话中保存，不写系统剪贴板，也不持久化。
- Ctrl+V 仅进入 Paste 预览。整块半透明 Ghost 随鼠标贴到已有体素外侧相邻格或空白工作网格；左键/确认按钮才提交，Esc 取消零改动。相同体素为 No-op，不同颜色或 owner 的占用为整块冲突，冲突格红色提示；每次粘贴后退出预览并选中新位置。
- “移动选区”共用同一个放置预览状态和 EditOperationPlan/Session，源位置在预览时保留并淡化；提交时先删除源再添加目标，允许与选区自身重叠，外部冲突整次拒绝。X/Y/Z 的 ± 按钮在普通选择状态下逐次提交，每次各一条 Undo；在预览状态下只调整目标，确认时作为一条 Undo。
- Paste/Move 后 Selection 跟随目标；几何 Undo/Redo 同步恢复对应 Selection，普通选择手势不进入历史。Clipboard 在 Undo 后仍可再次粘贴。切换模块后拒绝旧 Clipboard 跨模块粘贴；Move 遇到缺失或变化的源格明确拒绝。
- 未修改 Workshop 文档 schema、发布格式、Blender/FBX 或 Unity 契约。未做 Cut、旋转、镜像、跨模块色板映射、连续印章。
