# 工坊重构计划术语

本文件只统一 TOOL-005 设计和实施计划的词汇。既有地图术语仍以 `自制工具/map_editor/docs/CONTEXT.md` 为准；这里的新文档名称是规划名称。

**模块资产（Asset）**：具有稳定身份、局部空间和Root的独立环境资源，例如地面、洞壁、高台或道具。

**资产源（AssetDocument）**：可再次编辑的模块内容。与交换模型和已发布版本分开。

**场景源（SceneDocument）**：场景私有资产登记及其放置实例、分组和美术贴花的组合关系。

**项目入口（ProjectDocument）**：可打开场景的登记集合，不承载另一份几何或Gameplay。

**场景草稿（Local Draft）**：归某个场景所有的可编辑资产，不要求正式名称、缩略图或发布。

**公共库（Library）**：可跨场景取用的资产源集合；独立副本拥有自己的身份与内容。

**放置实例（Instance）**：某份场景私有资产的一次放置，具有独立实例身份与世界变换。

**根锚点（Root）**：模块局部空间中用于放置与替换的稳定基准点。旧文件字段anchor和新方案anchorM表达同一概念，不是两次偏移。

**源修订（Revision）**：可变源完成事务后的计数，不等同于发布身份。

**发布快照（Publish Snapshot）**：冻结目标、依赖与输出配方的一次不可变版本。

**生成资源（Generated Assets）**：由引擎接收器从发布版本生成的网格、材质与视觉Prefab。

**用户包装（User Wrapper）**：在生成视觉资源之外保存功能与人工修改的Prefab或场景对象。

**旧地图路线（Legacy）**：保留旧地图、表面逻辑、事件和原MapBaker能力的兼容入口。
