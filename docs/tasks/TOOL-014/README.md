# TOOL-014 首轮实施与交接

用户授权：U0–U7；依据任务包和指定对话较新决定，第三方参考图未提交。P1–P3保留为后续需求。原始计划/START_HERE/验收表仍为输入文档；验收表的用户勾选不由自动测试代填。

## 实现
- 模型制作文档栏含建模、自动上色、贴图绘制、保存/导出与资产更多。默认单视口，左树与画布分页，窄工具条和右属性；宽度、显隐为本机偏好。1000宽层级改为主动打开的抽屉。
- 自动上色/岩体塑形沿用原计划器，参数停靠右栏，应用/取消与滚动参数分开。布局/相机/显示不丢草稿，保存和切换有三选一确认。
- 独立绘画子窗复用MapView/CanvasView/SurfacePaintTools；主CanvasSession保留唯一源/历史/保存责任。显式目标选择，无需隐藏模式前置。菜单按窗口/文本焦点路由；子窗只暴露ready/受限command/return/通知接口，无workbench或fs。
- 主/子主框架身份+本地URL校验；租约、修订、所有者、像素预算、命令去重、一笔在途和32MiB消息限界。关闭、崩溃、重载失效；已确认笔触留在主会话。子窗撤销限于本次进入后的笔触，返回主窗可继续旧历史。
- 数据协议、画布原点、Root、体素归属、paintSource/faceTone和导出器未改；Legacy未加载新外壳样式。

## 验证证据
- 新增paint-lease核心测试覆盖目标/过期/去重/越界、写保护、保存历史、旧几何重做拒绝、排队时释放。全核心结果与最终EXE指纹见最终回执。
- tests/workshop-shell-ui.mjs：真实布局、四屏幕尺寸/DPI、冻结预览、保存返回/放弃、真实上色应用/撤销；布局前后原文件和GLB（内嵌PNG）字节一致。撤销后规范化revision再比导出内容，避免把合法历史序号误判为几何变化。
- tests/paint-window-ui.mjs：v2与v1真实子窗，六面×三精度、填充/连续笔画/擦除、历史、保存故障恢复、主关闭取消、项目切换取消、子渲染进程崩溃恢复、五次开关、完整进程退出重开；主建模恢复后的笔画/撤销；不动生产资产。
- tests/workshop-shell-performance.mjs：原创1万/4万格，进程启动到模型打开1269/1661ms，30帧rAF平均16.67ms；这是本机隐藏窗口短时观测，不是GPU性能承诺。五次开关Tab渲染进程回到1个，工作集短时缓存有波动，不能据此声称不存在长期泄漏。
- tests/workshop-shell-legacy-ui.mjs：Legacy启动/视口/保存入口烟测；tests/workshop-appearance-export.test.cjs：实际Blender5.1.2回读GLB/FBX几何、UV、材质、PNG，1项通过。

## 试玩
1. 重启新EXE，打开资产副本；文档栏直接进入建模/自动上色/贴图绘制。
2. 自动上色和塑形在右栏调整，改变相机或折叠布局保留预览；保存时选择应用/放弃/返回。
3. 贴图窗口中选画笔/擦除/两种吸色/填充；保存项目或返回建模。未保存但已确认的笔画仍留主窗。
4. 左层级页切画布，资产更多找改名、另存、Root；顶部双视口/资产抽屉按需启用。

## 已知边界与未执行
单笔仍裁切在一个体素面；没有P1–P3、UV或图层栈。32MiB以上快照明确拒绝；累计4096命令需保存重开。绘画期间该主窗口限制其他写操作，不能作为多资产并行协作系统。菜单文本焦点实现有防护，但系统菜单逐组合人工操作、显示器拔插、主窗重载、长时间内存稳定性未逐项故障注入；不能把本机五次开关当作完整多窗口压力验收。迁移表标出了没有逐按钮重跑的既有能力。用户手感/审美验收待试玩；技术实现完成不代表已获得用户认可。
