## 必修闭环

- **R1 已解决**：start() 使用 Profile.dialoguePoolId 查 DialogueCatalog，resolveDialoguePool 复制并绑定池内 actor/speaker 别名到 targetId；context.actorId 使用实际 id。未知池明确报错。独立池和适配层测试覆盖对应边界。
- **R2 已解决**：Presenter 的姓名与投影均使用 game.speakerId；适配层验证说话者，新增真实浏览器内容 fixture 将第二句切到 hunter，并核对姓名和位置。截图中尾部位于银蓝发猎人上方，未继续指向橙发伙伴。
- GameState 引用替换后会话失效，降低新世界/读档过程中旧会话误用的风险。

## 已声明且接受的样板边界

- SAMPLE、GameState 内存 flags/history、once 在成功开始计次、暂未接 AVG/任务/传送，交付记录已如实说明。
- 现有短句和两选项是验收范围，不等同于长篇排版或大型剧情工具完成。
