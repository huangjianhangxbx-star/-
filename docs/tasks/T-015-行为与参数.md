# T-015 行为与参数

2026-10-04。依据 T-014 计划输入第2.1、2.5—2.8及第5节；用户在 T-014 交付后明确继续实施。参数均为首版可调值，自动验证与人工试玩/平衡验收分开。

## 移动和软阵型

| 项目 | 实现 |
|---|---|
| 玩家基础速度 | 1.70，塔防与探索相同，不再附加非战斗1.25倍。手动控制保留该本体的负重/减速。 |
| 塔防/探索敌人 | 分别独立配置1.275，旧0.85的1.5倍；不读取玩家速度。 |
| 跟随 | 使用猎人当前负重/减速后的步速，实际跟随且离猎人超过2.2时额外1.15倍；手动/战斗移动不加赶队倍数。 |
| 软槽位 | 猎人领队，本体数组中的稳定同行次序；两列，后距0.85起、每两名增加0.7，侧距±0.7；期望方向每模拟秒最多偏转1.8弧度。 |
| 柔性停留 | 距期望点0.65内、软分离合格且不远离猎人时保持原位置；候选点在期望点周围0.35—1.05搜索。不是每帧强制排队。 |
| 软分离 | 候选评分惩罚贴近他人当前位置/目的地；友军互穿只取消探索本体之间实体阻挡，不能穿墙或敌人。影体、塔防部署与落位保持原间距。 |
| 重叠排序 | 场内深度差小于0.02时，以稳定队伍次序辅助排序；普通深度排序继续用于其他位置。 |

## 仲裁和锚点

优先级：玩家选中/直接控制/明确命令 > 生命与技能落位等生命周期 > 战斗局部AI > 非战斗软跟随。所有权由引擎状态判断，并非只检查UI有没有选中。

- 选中本体立即停止其自主路径/跟随；正在跨层的物理转换先完成，随后停止余下跟随，不强行取消转换。
- 成功接受移动、直接控制、技能、换装、收纳、救援、疾行等命令后让权；失败命令不删除原自主目标。单体命令只影响对应对象，H/B逐个执行并沿用资格拒绝/重复请求规则。
- 命令接受后0.5秒缓冲；动作仍执行时持续让权。鼠标移动抵达或受阻结束后更新当前位置为锚点，再留0.5秒缓冲；WASD每累计实际路程0.75更新锚点，松开后保留最终位置。疾行/瞬影和全队集结完成也提交新位置，避免走回旧点。
- 塔防初始在场/部署时建立锚点；探索首次入战为所有在场本体快照当前位置。AI路径不更新锚点。
- 活动半径塔防1.0、探索战斗2.0；候选、路径路点与运行中重规划均受同层/半径限制。保留现有跨层、硬直、回镰落位及影庭优先级。
- 普攻前摇、正在执行的技能、回收/救援/换装/集结期间不启动AI移动。复制体固定位置，不参与本体自治。
- 探索真正脱战清AI锚点，保留玩家已提交路径，自然恢复跟随；不瞬移、不重置价格/技能/影体。

## 职业与倾向

固定每0.35秒评估，重新移动至少间隔0.6秒；评分改善至少0.3才微调。锚点周围0.5间隔、每环16候选，使用合法地形/占位/实际视线与武器射程；优先附近可见目标，少量候选评分先算后排序，路径只对改善候选求解。

| 职业 | 位置处理 |
|---|---|
| 近战/镰舞 | 附近差少量距离时进入合法攻击距离，不追出半径；能直接攻击时默认守住位置。 |
| 远程/猎人 | 尝试局部合法射击点解决轻度超射程/遮挡；没有合法改善就留原地。 |
| 盾卫 | 更重锚点距离成本、偏局部接敌；不会追远。 |
| 治疗/冰系支援 | 为受伤/承压队友提高局部覆盖评分；移动不会替玩家释放关键主动技能。 |
| 没有任务目标 | 返回合法锚点；被占用或没有半径内合法路径时等待，不传送/扩大半径。 |

默认倾向能攻击时尽量站定；保势按自身架势缺口增加已知敌方攻击危险的惩罚；规避进一步提高危险惩罚；救护加大危险队友覆盖权重；进攻提高有效命中权重。五种只改评分，不增加半径/资源/新技能。整备或探索非战斗配置页选择，战斗期间锁定。

## 第一击入战

唯一首次入口 `attackCommit`：猎人本体普攻建立前摇，猎人攻击型主动技能接受施放，或敌人对本体普攻建立前摇时进入交战。在伤害、闪避和护盾之前发生，不要求扣HP。单纯发现/追击不首次入战。

非战斗同行本体不自动普攻或开始箭雨/回镰；纯治疗和已生成支援领域可继续。复制体攻击、纯治疗、瞄准、环境伤害与延迟伤害单独不首次入战。已经交战后的真实本体/敌人对本体伤害（含本体持续/延迟效果）续计活动；影体来源始终不续计。敌人报复/感知仍沿原规则和来源判定。

交战后，没有敌人追击本体且满3模拟秒没有有效活动才脱战；追击可保持已交战状态。入战快照位置、停跟随；脱战不做节点清理。猎人无目标仍可主动提交攻击技能，因此这样的主动行为也会入战；正常回放脚本仅在有可攻击敌人时施放，避免在出口无限重复发起战斗。

## 表现与验证边界

构筑页只增加首要倾向一行，选中详情显示倾向；开发验证开关可查看锚点/半径/软槽位及当前意图、入战原因。调试环与线使用既有覆盖层生命周期，关闭清理，普通游戏不出现调试图形。

没有改架势/虚血底层、AI关键技能消费、活动半径规则、塔防碰撞或引入复杂行为树。速度改变会影响旧攻略时序，完整回放记录实际结果；自动通过不等于最终平衡或长期性能证明。
