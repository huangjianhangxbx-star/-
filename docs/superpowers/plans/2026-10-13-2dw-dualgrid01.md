# 2DW Dual Grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. 当前两个子技能不可用；按用户已批准详细计划在当前会话分阶段执行与自检，不冒称调用或额外派遣代理。

**Goal:** 一个获批单样品驱动连续A/B绘画与双网格16态，真实涂画、源像素/接缝/重复分别诊断，保留旧v1–v8和47态。

**Tech Stack:** 当前Node24/Electron44/TypeScript7/PNGjs/fflate，无新依赖或在线API。

**Spec:** ../../tasks/2DW-DUALGRID-01/plan.md；固定外部研究与坐标选择见tech-decision.md。

## Global Constraints

TL1/TR2/BL4/BR8，图像Y向下；6/9分离；W×H数据→(W+1)×(H+1)显示；一格仅更新四格。默认c128/PPU100/K4，精确源图4c×4c。保留原PNG；人工艺术和Unity实机均不能由技术通过替代。不改开发细则/用户维护/游戏/3D/原作资源；真实AI及密钥ignored，只选择性GitHub main，不Gitee/force。
