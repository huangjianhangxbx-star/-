# T-027 / EC09 Encounter Domain 与 AI 参数

依据：[用户批准的原始计划](T-027-EC09-原始计划.md)。仅 Standalone 的 explorationBattle 启用 Companion AI 2.0；作用对象为当前离手的猎人或本次选择的同行原本体。复制体、Tower 和旧庭院继续原自治；非战斗继续 EC02 的 DirectActor 领队软阵型。不增加手动技能 AI、指令轮盘或新遭遇。

## 遭遇边界与控制权

生成的 Encounter 保存 center 和 tacticalRadius=6.5U；每个运行时敌人保存 encounterRoom/encounterId，不解析显示名称。活动组由当前存活且不在 return 的敌人的追击、接敌、AttackIntent、Reaction 或未过期的己方挑衅形成。多个活动组取圆形域并集；死亡/回归失去活动依据，不因过去看见过敌人而常驻活动。

攻击位与普通自主路线都在并集内。路线按不超过 .15U 的间距检查全段，拒绝进入未活动敌人的探测距离加 .2U 余量且具有 LOS 的位置。自动/背景索敌也限制为活动组内可见或已交战目标，自动回镰还检查整段出击路径。敌人已提交的 AttackArea 仍按原命中通道结算，没有给离手本体额外免疫。

明确 mouse move 在切人后先完成，完成后自由决策；旧兼容字段可能仍记录 anchor，但 AI2 不使用它。DirectActor、玩家移动/操作宽限、H/B、收纳救援、跨层、技能落点、装备切换、强制位移、Broken/stagger/stun、真实闪避和已有技能运行时都优先于自主走位。接管立即撤销 AI2 普通移动；前台技能不被 AI 的避险取消。受到强制位移后不续旧路线，从新位置重评估。

| 普通决策间隔 | .20 秒 |
| 普通移动承诺 | .35 秒；危险、失效目标/路线、玩家接管立即重评估 |
| 最小收益 | 安全且在理想射程时，新点收益不足 .45 留在原处 |
| 集结迟滞 | 距 DirectActor >5.5U 启动，≤3.5U 结束；可离开战斗域，仍避开未交战探测区 |

| 战术候选 | 当前点 + 三圈射程、每圈 16 个方向；合法地形/路线、可命中、领队距离共同筛选 |

站位代价综合路径时间、射程偏差、危险、领队距离、方向收益和保护收益。Hunter/Ranger 使用远程武器时更偏向具有背部弱点敌人的 Side/Back；近战方向收益较弱，支援职业优先安全；Shieldguard 优先 Frontline/Peel，不使用 Standalone 旧 Anchor Brace。

## 预警与应急机动

只观察可见或已交战敌人的实时 AttackIntent。首次看到每个 cast 后等待 .18 秒；不读取原始玩家输入，不预知隐藏未交战预警。对所有当前已知且尚未 Resolve 的 Area 保守检查安全终点，包括约一秒内即将命中的多重危险；超过一秒但已经显示的预警也不会被忽略。这里没有预测尚未出现的能力。

在 .5/1/1.5U 三圈各采样 24 个避险点，按全路径长度/当前真实移速估算到达时间。如果早于当前威胁 Resolve 的剩余时间减 .06 秒，优先普通行走。否则才尝试真实同行 Evade 或猎人 Blink，提前检查完整位移的合法终点及遭遇边界，正常消耗 charge、使用原动画/冷却/命中窗口。Blink 只用于应急，不用于赶路。

候选安全性会检查全部已知危险的终点重叠；没有做未来 Tracking 方向变化或沿路多个 Resolve 时点的完整轨迹预测。前台、Break、太晚、无路或无机动次数都可能导致真实受击，不给予额外无敌。普通普攻起手允许因避险取消；手动三技能不主动施放。Rain/Dance/Reap/Poison 保持原触发与冷却。

## 代码与诊断

encounter-domain.ts 负责身份、活动域和路线边界；companion-combat.ts 负责离手状态、候选评分、稳定性与危险决策。autonomy.ts 只做模式分流；engine、技能查询、移动、交接、强制位移和真实机动入口接入共享状态。

既有 Debug 开关显示 intent、目标、活动房间、期望点、range band、hazard、risk、拒绝原因与 walk/evade/blink 选择，绘制域圆、目标连线和期望点。普通界面不新增操作。
