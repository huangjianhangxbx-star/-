# AUDIO-01 本轮交付与验收状态（2026-10-17）

## 基准与边界

从 `3b54460` 的干净 `scene2d-validation` 工作树实施。附件计划 v1.0 与仓库基础细则均已核对；外部 ChatGPT 对话链接重定向登录，未用作需求证据。原作音频、银行切片、解码 WAV、录音和工具留在 ignored `work/AUDIO-01/`，不提交也不进入 Vite 构建产物。未修改 `design/用户维护/` 和 `design/开发细则.md`，不推 Gitee。

## 交付行为

- 正式游戏的 BattleAudio、Hunter、芙蕾茜娅与敌人参考音频共用一套 `GameAudio` / `AudioContext`、主输出、总线与缓存。行动音效由非 trace 的即时事件流触发；未解锁、过期、错世界的短音不延迟补播。
- 总线含音乐、玩家、同伴、敌人、交互、环境、语音与 UI；用户音量/静音持久，solo、条件覆盖和对话 snapshot 临时。声部预算包含过渡中的旧音乐节点和 stinger；循环环境声离开听域停止节点，重新进入按从头播放策略恢复。
- 条件音乐覆盖标题、探索、远室、交战、对话和诊断 Boss。原创三层 `ENGINE_DIAGNOSTIC_ONLY` 共用音频时钟，按已知 100 BPM 的小节换段；三首从原作银行解码的**本机候选**按未知节拍的秒级淡变播放，不宣称其原场景绑定、BPM、循环点或编曲分轨。为避免候选播放结束后长期静音，本机评估采用明确标识的**整段重播**，不是原作 loop 点复刻。离线本机 Vite 服务可访问受限白名单；公开构建因没有原作媒体回落到诊断层。
- 空间声使用世界坐标距离/声像、墙体查询低通和共享环境混响。F10 默认监控父正式会话，显示真实声部、缓存、规则、混音状态、丢弃原因；可改总线、solo、来源停止、事件试听、音乐和区域诊断覆盖。旧隔离预览仍可进入且默认会话静音。

## 素材来源及核验

七个现有参考 WAV 的格式/哈希与来源见 ignored `work/AUDIO-01/audit.md`，不以旧文件名声称听感。`音乐.bank` 内 FSB5 子块为 50 样本；本机 FFmpeg 9.0.1 不支持其 FSB5 版本，官方 vgmstream CLI `r2117-323-gdb77f98f` 可解码编号 23 `Cind_Title1`（148.728s）、41 `CIND_Home2_Loop`（99s）、26 `Chapter1_V4_4`（318.192s）。编号、时长和格式只证明银行内有可解码流；绑定仅为本轮评估候选。工具 ZIP、FSB/WAV 与探针都在忽略目录；HTTP 提供器只接受本机回环地址和三个固定文件名。

## 验证证据

- `npm run build`：TypeScript 与 Vite 构建通过；构建资产列表无原作音频。
- Vitest：音频策略/即时事件/旧音效接口 6 项通过，本机资源白名单 4 项通过。
- Playwright：音频 10 项、真实输入故事 4 项、TITLE-01 回归 4 项，合计 **18/18** 通过。包括单 Context、重复解锁不重排、标题进入探索、F10 父世界与 snapshot 清理、环境循环声远近虚拟化/停止恢复、原作候选本机解码、同主输出采集。候选缓存按 128 MiB 逐出旧文件，F10 暴露当前 PCM 字节量。
- 四条自然键鼠故事及主输出录音位于 ignored `work/AUDIO-01/stories/`：挥空/开包（1.08s，无命中音）、既有僵尸遭遇（12.72s，有主角与敌人命中/受击）、同伴对话（3.54s，快照获取/释放）和余额不足购买（1.56s，一次拒绝音、零成功音）。JSON 同录音保存事件/状态时间线。四段最高峰约 -19.2/-13.7/-21.2/-18.9 dBFS，证明样段无削波；没有人耳试听。
- 180 个低/高优先请求压力测试曾复现 187 个节点；现以软预算 44、硬预算 48 保留淡出/关键声空间，含旧音乐与 stinger，复测不超 48。隐藏事件模拟证明循环源停止并在恢复可见后重建。
- `work/AUDIO-01/stem-pcm.json` 对实时诊断 buffer 和 transport 偏移做测试专用离线 PCM 渲染：三层 onset 均为样本 481、循环对照误差低于 5e-14；反复强度切换保持节点及 epoch。不是原作分轨或设备延迟的证明。
