# SUR-01-LITE｜试玩交接

使用最终回复的带提交版本链接。从正常入口出征，起点往东至通道，再沿南侧支廊走到约(10,17)。这是南廊局部暗区，原调查委托仍在前厅。

1. 未点灯时，南廊远处的有效可见性会收紧；原探索目标折叠区显示暗区提示。
2. Tab背包选“实验便携灯”，点击“点亮照明·消耗1”。团队初始2盏，成功变1，灯固定在当前身体位置，半径4/持续20模拟秒。
3. Tab或Space暂停，寿命冻结。关闭面板/继续运行，到期灯消失，暗区限制恢复。记忆地形可能保留低亮轮廓，不应把它误认为仍看得到实时敌人。
4. 灯仍有效时不能重复消耗；区外不能点。交给阿尔的灯她不会自动使用，须先撤回团队。合法离区清灯不退款，继续同世界不重建旧灯；新世界团队重置2。

这些位置/数值/外观为SAMPLE，尚无用户认可本轮观感的记录。技术结果和实际未试边界见validation.md；仅一个浅层环境样板，停试玩Gate。
