# UIX-ROLE-01 角色交互交付

日期：2026-10-16。接手基准 `53c8dda`，原工作区干净。来源：用户提供的《系统讲解.ppt》两页和 UIX-ROLE-01 计划。外部 ChatGPT 对话跳转登录页，未声称读到其较新内容。

## 实现

- V 改为寻路；原技能配置/升级保留屏幕按钮。F 使用角色交互入口，交易中继续执行选中物品的买卖，编辑数量时不触发。
- 近距离 F 或点击角色展开四入口半环。默认在左侧，左边缘空间不足时翻到右侧，名称单独跟随目标。图标为代码原生 SVG，不新增位图依赖。
- 商人只允许商店，其余灰显；芙蕾茜娅四入口可选，商店是独立空库存，另三项反馈“后续开放”，没有实现好感、送礼或角色装备事务。
- 主控芙蕾茜娅时在角色旁显示 Z 切换；她仍可以 F 与商人交互。猎人不提供 NPC 交互菜单。
- 菜单开关释放输入并取消旧移动订单；菜单锁主控移动/战斗按键，不暂停世界。Esc、空白、超距、目标失效、控制身份变化、窗口失焦关闭。
- 移除商人的旧场景文字直达交易入口。所有角色交易先经菜单商店动作。原独立库存、买卖原子事务、刷新、背包容量规则保留。

## 架构与扩展

`core/role-interaction.ts` 集中角色 Profile、动作能力、同层/视线/容器同等3单位范围、会话世界/访问批次/控制者/epoch 校验。`RoleInteractionPanel` 只呈现能力并路由动作；商店复用同一访问判断，`merchant-shop.ts` 按 Profile 选择样板货架或空货架。

后续新角色需登记 Profile 与身份映射，不在 UI 中复制角色条件。对话、礼物和角色装备目前仅保留动作入口；实际系统接入 `act` 对应路由即可。未加入通用对话树、好感或装备编辑架构。

F 的无菜单上下文优先级建议落实为：附近角色 → 附近手动掉落 → 附近容器；开包时优先地面拾取，交易时优先选中交易。范围参数复用 `INVENTORY_INTERACTION_RADIUS`。
