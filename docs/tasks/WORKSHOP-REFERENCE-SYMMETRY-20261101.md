## 已确认行为与分工

1. 建模参考始终在几何底层，不挡模型/选区/操作轴/画笔；逐张透明度 0–100%，建模图默认 50%、比例图默认 100%。不能只靠 renderOrder，因为凹槽合成会在最后重画辅助图。
2. 建模的比例/建模参考由同一项目共用，切资产/画布不丢失；新图只保存到 project.editor，旧资产/画布中的参考兼容汇总并保留原稿。项目已有 editor（即使空对象）为权威，删除后不从旧资产复活；身份冲突保留不同图，完全相同的图去重。参考独立撤销/重做，不修改模型几何历史。
3. 场景比例参考仍归所属场景；建模右侧搭建预览显示该场景的同批参考，世界坐标、身高、显隐及透明度一致，不参与取景包围盒、拾取或游戏导出。
4. 对称中心增加独立 XYZ 米坐标、半格/整格步进、模型/选区中心、三轴拖动；拖动只改镜像中心，保持模型原位，Esc 完成位置调整。继续保留旧坐标/吸附和模型选点入口。
5. 改工作层/朝向保留矩形、擦除等当前工具。表面搭积木与创造模式支持固定起笔面的矩形，包括拖出起笔支撑面的连续区域、阻止其它物体覆盖、预算预检与整笔撤销。R 为矩形快捷键，输入控件与组合键不抢键。
