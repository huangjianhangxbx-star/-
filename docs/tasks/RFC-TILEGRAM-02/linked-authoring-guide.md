# 单画布绘制→47片→地图：实际联动工作台

入口：http://127.0.0.1:5294/gallery/artist-workflow.html#linked-authoring

## 用法

1. 在右边预览点一片墙。左边直接放大它所用的母版源窗；橙框是结构区，蓝框是前板区。下方是按窗口真正合成的墙片，右边所有相同输出片的位置同时高亮。
2. 下载单画布ZIP。里面包含6144×4608px示范稿、同尺寸透明底板、独立刀线层、cut-map和绘制说明。画布左半画连续结构，右半画前板；这是同一张PNG内的两个绘画区。请把刀线作为独立辅助层，不要在正式输出中保留框线。
3. 参照示范稿确定大形与区域，在底板绘制，或以示范稿为底稿修改。对照网页的局部橙/蓝窗口，确认要画的位置。全图中的重复草稿只辅助构图；只有固定源窗参与输出，不会自动同步所有看似相同的形状。
4. 保存为同尺寸PNG并载入页面。页面只在浏览器本地读取，实际按47份记录重切；37个预览（14通用形状＋23设计/补角区）即时使用新切片。全部47态至少在一个预览有真实落格。
5. 点断线/错位处，回到对应绘画窗修母版，再载入检查。导出当前47片ZIP，其中包括47个PNG和cut-map；母版原件由你另行保存。当前示范输出为96×144px、100PPU，不能拿这个规格改写原作数据。

## 已验证

- 单画布切47片与原A双层逐RGBA相同。编辑固定源窗像素，目标输出确实改变。
- 47态全部具备绘画窗和预览落格；预览点片、下拉选片、母版窗反查使用同一cut-map。
- 浏览器载入一张改过指定像素的6144×4608 PNG，目标切片保留该像素；实际下载的ZIP通过CRC与47PNG数量检查，改动像素也在ZIP中。
- 错尺寸PNG拒绝，既有作品预览保持不变；PNG签名检查拒绝伪装格式。原作保护153输入SHA未变，旧12项浏览器检查通过。
- 全部模块测试12项通过。技术验证不代表用户美术认可。

## 限制

这是一张包含23连续设计区的原创母版提案，尚未优化为最小画板；不是随意画一幅完整H图就能自动推导全部47种连接。端头、内凹、交汇有明确补角设计区，仍需人工绘制与接边校对。示范稿仍为简化结构，不代表成熟画风。

A的结构底稿部分包含前板的预留/示意内容；实际需要前板的片会按蓝窗覆盖合成，页面显示实际取图顺序。更改局部不能保证所有不同mask的共边同时正确，应检查H/T/L/孔洞/补角区。

全套联动、像素裁切和导出请使用localhost HTTP入口。file冷启动保留旧观察页浏览，但新画布若受浏览器跨文件像素读取限制可能无法裁切或导出。用户PNG不上传服务器、不自动覆盖磁盘、不进入GitHub。尚未接入工坊或Unity，原作PSD未恢复。
