# TOOL-015 三步入门

1. 打开 project 文件夹，在场景选择门洞练习，点击编辑模块，再打开“贴图绘制”。顶部直接选择画笔/直线/折线/矩形/椭圆；右边切换色轮与色板。按“一体素大小”恢复16/8/4 px。原色检查用于核对作者色。
2. 画笔默认沿可见表面，内部共面体素接缝可以跨过。形状锁定起笔平面；折线逐点点击，Enter完成，Esc取消。选区工具拖框，Shift加选、Ctrl减选；“共面连通面”选择当前鼠标所在连通区域。填充范围可切换小面、共面或当前选区。Delete只擦贴图选区笔触。
3. 在右边展开对称，设置固定中心（米），勾选作者空间X/Y/Z。中心不跟Root或镜头移动；非法位置可显式吸附半格。贴图可选镜像至不可见外表面；没有真实对应表面则跳过。返回建模，选择三维/表面搭积木/创造画笔后可在右侧配置同一目标的对称，支持添加/擦除/重染。保存项目后再关闭。

方圆硬边笔头；[ / ]调尺寸；B/E/L/R/O/G/M切工具；Alt临时吸色。1px自由画笔才适用贴图像素完美。选区限制所有输出，包括镜像；只选择左边时不会自动扩大到右边。

排队最多4笔；满时明确拒绝新手势。等待确认期间可以选色和继续落笔。失败显示重试/放弃；重试同一命令，放弃不会抹掉已确认的主会话修改。保存/撤销/返回等顺序等待队列。尚未确认的活动形状先Enter完成或Esc取消。

样例为原创隔离练习：门洞与后墙（0.25m）、平板/L角（0.125m）、对称柱（0.0625m），各有少量原始手绘与美术暗面。没有用户生产资产。

当前不含真正多层/alpha、图案复制、自动结构边带、压感/防抖或任意曲面展开；见任务包后续N1–N4。首次版本的造型与手感由用户试玩确认。
