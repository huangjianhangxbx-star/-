# T-007 角色技能重制：当前原型内容表

更新：2026-09-30。依据[任务输入](T-007-计划输入.md)及用户采用的 G1—G4；已实现的可迭代原型内容，不是正式平衡定稿。任务及证据见[执行记录](T-007-角色技能重制.md)、[验证记录](T-007-验证记录.md)。原始设计、开发细则与用户维护区不回填。

## 阵容、职业与操作

| 身份 | 本轮职业／默认技能 | 保留内容 |
|---|---|---|
| 猎人 | 猎人／猎杀时刻 | 普攻、瞬影、影庭、救援及原技能不重制。 |
| 菲奥蕾 | 默认镰舞者／永夜镰舞；另可选离魂回镰 | 治愈职业的生命祷告、伤势守护，冰系的霜镜钟声，特殊影庭身份均保留。 |
| 伊内丝 | 盾卫／折痛回响；另可选静钟庇护 | 占原守卫出战槽位；旧守卫身份、毒刃定义及源资产仍保留，未改名冒充新角色。 |
| 阿尔 | 弓手／狙击姿态；另可选连珠箭雨 | 原 ranger 身份与狙击基础倍率、攻击节奏及射程保留。 |

战前整备、节点地图或探索非战斗验证入口可选技能；同职业战斗中不能换技能／改选分支，只能培养已有选择。菲奥蕾换职业会切到该职业已配置技能与构筑；后台技能冻结。复制体保存出生构筑，不能独立培养／换职业，不随本体后续升级。

时间以模拟时间计：暂停不推进，0.1×与2×相应变化。头顶技能按钮负责操作和状态，侧栏负责介绍；自动技能不会因为按 E 额外发动。痛印显示数量与预计治疗，回镰显示普攻次数，箭雨显示当前窗口和实发箭数，镰舞显示充能或“模式中／退出”。就绪状态沿用高亮。

| 技能 | 开局／节点重入 | 发动与退出 | 执行期间 |
|---|---|---|---|
| 折痛回响 | 0/8 痛印，无时间 CD | 至少一印时 E／头顶按钮手动释放，全部清零 | 瞬时治疗；已发出的回声独立完成。 |
| 静钟庇护 | 36秒空充能 | 满充手动开启，持续12秒 | 停止普攻，定点维持；移动、换装、回收等中断后完整冷却。 |
| 狙击姿态 | 关闭，无充能 | E／按钮开关 | 普攻伤害3.5倍、间隔2.5倍、射程7；移动暂停攻击但不关闭。 |
| 连珠箭雨 | 24秒空充能 | 满充自动进入6秒窗口，空场也进入 | 独立替代普攻；普通移动／眩晕期间窗口继续、丢弃发射时隙；跨层／回收／换装等中断。 |
| 永夜镰舞 | 18秒空充能 | 满充自动开启；E退出重新空充能 | 无限时强化普攻；普通移动不退出；死亡或换不同职业关闭。 |
| 离魂回镰 | 0/5真实普攻出手 | 满条且存在合法命敌路线才自动发动 | 本体滑行往返，复制体身体不动、发出镰影；中断不补刀、不退计数。 |

下表 A 为施放／出手时攻击强度，M 为施法者最大生命；目标生命上限会另行写明。所有分支在 T0/T1/T2 都可生效，每技能三选二，每分支二级；二级替换一级。两次进阶暂收费24、40碎片；分支两级暂收费12、20。与抽卡、20碎片召影共用余额，是获准经济过渡，未实现正式金币／生命力兑换。

## 伊内丝

折痛回响：有效敌方直接命中获得一印，上限8；护盾或固定防御承接仍计，闪避不计，毒伤／派生效果不自行产印。同一逻辑命中不可重复计，真实多段各计。释放位置半径2.8内在场友方（含自身与复制体）各治疗 `印数×2%M`。不治疗影庭对象，不复活濒死者。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 0.7秒后原位置35%治疗回声 | 保留首回声，1.4秒再产生25%回声；印数、位置与构筑用此次快照。 |
| A 合契护纹 | 各波给予4秒护纹，下一次直接受击抵消20%，上限目标最大生命5% | 抵消35%，上限8%；同来源刷新，不同来源同次只消耗最强一层。 |
| B 觅伤回声 | 每波治疗后最低生命比例者额外获该波基础治疗35% | 最低者55%，第二低者25%；同一人不重复领取两份。 |
| C 余愈结晶 | 本技能过量治疗50%转4秒盾，同来源累计上限目标最大生命8% | 转75%、5秒、上限12%；不转换其他来源治疗。 |

静钟庇护：施放位置半径3.2，每0.5秒治疗 `0.5%M`；敌人减速30%、对应有效固定防御削减25%。敌方受实际层级和墙体遮挡限制；友方治疗按平面半径，可跨层、不受墙阻挡。多来源减速／削防取最强；削防上限70%，不把低伤箭聚合后只扣一次防御。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 敌人离场后基础减速／削防残留2秒 | 核心半径1.6额外削防15个百分点，每3秒核心友方再获一次基础治疗；离场／领域结束只残留基础值。 |
| A 迟滞涟漪 | 每敌人本次领域首次覆盖时65%减速1秒 | 80%、1.5秒；反复出入不重触发。 |
| B 剥鳞印记 | 连续覆盖每2秒额外削防6个百分点，最多3层；离场清层 | 每层10个百分点；含基础／核心总量最多70%。 |
| C 接力烛火 | 友方离场后每秒恢复1%M，3秒；重入停止同来源尾随 | 5秒；离场时附近1单位内另一最低生命比例友方额外治疗2%M，不递归传递。 |

## 阿尔

狙击姿态的下列培养只在模式开启的狙击原始出手中生效，关闭后普攻不获得这些效果。每次主箭只扣一次普攻耐久，派生不会递归生出新出手。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 主目标后方沿原射线最多1名合法敌人受主箭防御前威力35% | 保留贯线，0.35秒后原位置／方向迟响，最多2名各25%；不穿墙／超射程。 |
| A 破甲锥 | 主箭、贯线和迟响忽略对应有效固定防御35% | 忽略55%。 |
| B 钉影 | 主箭命中减速65%、1秒，同目标3秒间隔 | 80%、1.5秒，间隔不变；派生不重新施加。 |
| C 猎线接力 | 主箭击杀后死点2单位内最近合法目标，45%威力接力一次 | 搜索2.8、70%威力；仍需阿尔射程和视线，不递归接力。 |

连珠箭雨：每0.008秒一支 `0.025A` 微箭，逐箭防御，没有最低1伤害保底。首个时隙在窗口起点，右边界不含；静态合法靶1秒125支、6秒750支主箭。空场／移动／受控时丢弃时隙，不能后来补射；下一发重新索敌。每10个主箭时隙抽样画面／声音，逻辑射数不减，沿用有上限的素材对象。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 每16支实发主箭附1支60%普通微箭威力侧箭 | 替换为每12支附最多2支；不并行运行旧频率。 |
| A 破缝楔矢 | 每24支主箭替换一支 `0.25A` 楔矢，忽略50%固定防御 | 每16支替换 `0.35A`；侧箭不继承该倍率和破甲。 |
| B 织网 | 同目标主箭有效命中20次，减速25%、1秒并清局部计数 | 12次、40%；派生不累计。 |
| C 回旋箭痕 | 每0.4秒确有主箭才留半径0.6、1秒箭痕；每目标首次承受4支独立微箭，最多2处 | 半径0.9、1.5秒、6支、最多3处；不重新触发楔矢／织网／侧箭。 |

## 菲奥蕾

永夜镰舞：按圆形索敌确定朝向，主刀对半径1.8、正面120°内满足同层／遮挡的全部目标造成 `1.15A`，无人数上限。一刀一次耐久；移动不攻击但不退模式，入影庭不产生场内攻击。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 0.2秒后原位置／方向35%主横扫威力回锋，人数不限 | 回锋额外覆盖背后90°；每目标一次。 |
| A 裂帛 | 主刀留下3秒裂纹；下一主刀命中已有裂纹者额外 `0.2A` | 4秒、额外 `0.35A`；派生不种／刷新裂纹。 |
| B 众生回潮 | 主刀实际命中每人治疗自身1%M，每刀最多计3人 | 每人1.25%M、最多5人；只限制回血人数，不限制伤害人数。 |
| C 余月留痕 | 外沿0.3宽弧带残痕0.6秒，首次覆盖 `0.25A`，每来源只保留最新 | 1秒、`0.4A`；同层、不穿墙，不接敌。 |

离魂回镰：5次真实普攻出手蓄满；每出手只记一次，不按目标数／派生／动画计。路线候选取敌人方向和16个补采样方向，优先合法命敌人数，再比较长度，最后稳定破同分。身体扫掠后最长3、最短0.4单位，速度6单位/秒，转折停0.08秒，路径步长0.04。敌人可穿，墙、窄缝、高差不可穿；无无敌。

去程每敌人一次 `2A`，回程每敌人一次 `1.4A`。回程重新检查动态障碍，原位非法时搜索其周围1.5范围内可达合法点；移动命令中断后先以真实速度就近合法落位再续新命令，不瞬移、不补伤害。完全封堵会结束动作并提示，不能保证被封死的空间存在合法出口。

| 培养 | 一级／T1 | 二级／T2 |
|---|---|---|
| 进阶 | 终点半径1转折斩 `0.8A` | 保留转折斩；正常完成合法归位后半径1.2收锋 `0.8A`；中断不收锋。 |
| A 往返契印 | 本次去程命中过者回程威力额外40% | 额外65%；标记只属于本次来源。 |
| B 归途缝合 | 回程首次经过其他在场友方0.9内，治疗3%M，每人一次 | 范围1.2、5%M；含友方复制体，不含影庭对象。 |
| C 留席月轮 | 起步原位半径0.9，至结束／最长2秒；首次 `0.5A` 并25%减速0.6秒 | `0.8A`、40%减速1秒；没有身体／接敌容量。 |

复制体发出相同合法路径的镰影，身体及占地始终在原位，可被攻击。出生空计数，不继承本体正在滑行的动作引用。

## 生命周期、素材与起始参数

有限施放保存构筑、位置、方向、攻击与生命快照；持续模式培养对下一次出手即时生效。普通影庭冻结；菲奥蕾只推进当前装备技能的时间状态，不在影庭自动开启新攻击或发出场内效果；正负buff冻结无效。节点进入重置时间充能、计数与动作，保留培养；新副本清培养并保留默认偏好和解锁上限。冷却牌不凭空填痛印／普攻计数。

伊内丝临时基础：800生命、35攻击、近战1.2、1.4秒普攻、阻挡3、impact固定防御8、基础减伤35%、始动10秒、容量10。菲奥蕾真实／影镰刀：35／23攻击、1.8射程、1.1秒间隔、物理slash、重量3／1；兼容focus和blade，容量14、总携重12。其他旧技能与波次未为本任务重平衡。

伊内丝用 `Rina_F_Summer`，菲奥蕾三职业统一用 `Charlotte`，均为指定来源的工程副本；原始骨架不修改。全部新骨架的待机／移动／攻击／技能／死亡与原生攻击／技能特效有运行时像素证据。Charlotte素材本身带枪主题，本轮用已有动作近似镰刀／施法，范围与时序用几何反馈补足，未声称素材有定制镰刀动画。详情见[素材清单](../AssetManifest.md)。

本轮不实现正式经济、刷新持久存档、完整探索生命周期、全队命令或第四轮内容。自动验证不代替用户试玩与平衡评价。
