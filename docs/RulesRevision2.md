# 第二轮规则修订 · 2026-09-27

用户本轮明确要求优先于此前设计；本计划使用writing-plans分配可独立验证的核心、场景、UI与启动任务。

- 启动：验证端口拒绝连接，改为独立后台服务，等待HTTP成功后打开浏览器，项目目录记录PID和日志。
- 核心：按轨迹拆波次、非等间隔预告；地面敌人仅地面寻路；路障可破坏；同卡增益拒绝叠加；守卫厚血与菲奥蕾群疗；水晶即地面撤离点；非战斗朝水晶反方向。
- 场景：预告箭头沿路线掠过；头顶增益倒计时条；Spine每渲染帧采样解决慢动作阶梯；明确墙/地面/高台。
- 输入：取消方向流程，点击或拖动立即提交；选择显示四向攻击范围；指向水晶显示就地撤离确认；右键/空放释放慢速。
- HUD：底部卡牌居中向外铺开并扩大，角色技能为填色图标及三位小数秒；左侧立绘右侧同技能按钮。毫秒数值是模拟时间展示，并非声称屏幕每毫秒刷新。
- 验证：先修改冲突规则测试并观察红测试；核心、交互、浏览器、构建与三尺寸截图；更新持久项目记忆。

暂定同卡buff重复使用拒绝、不耗牌；不同卡效果可并存。当前仅调整可配置试玩生命和治疗值，不宣称最终平衡。
