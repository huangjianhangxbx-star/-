## 已实现

- `core/voxel-selection.ts`：精确坐标集合与选择时的颜色/owner 快照；Bounds/Count 派生；集合替换、追加、减去、清空。只属编辑会话，不写入资产 schema。
- `desktop/selection-query.ts`：冻结相机及可见体素映射；中心投影进入屏幕矩形（含边界）才候选；从候选中心向相机方向 DDA 计数实体格，空气不计层，恰好擦过棱角的零长度格不计层。正交相机用平行视线。缓存投影与深度，分片让出执行时间，支持取消。
- `desktop/selection-controller.ts`：点/刷选、空白起笔屏幕框选、Shift 加选、Ctrl 减选；确认后的集合保持，相机旋转不改变集合。框选后调深度沿用框选时冻结的相机，几何或剖切改变后失效旧查询，需重新框选。
- 区域 Fill/Clear/Replace 通过 `EditOperationPlan / EditOperationSession` 执行同一预览计划，一次操作一次几何历史；保留当前 owner，缺失格填充恢复选择快照 owner。预算预检、分片执行、异常和取消复用原事务。
- 清除体素后选择掩码仍显示；选区操作不进入 Undo；换资产和关闭项目清空选区。
- 既有“复制选区为模块”按 exact keys 过滤，不再按包围盒扩大。
- 选区显示为一个 InstancedMesh 填色与一个实例化线段对象，真实立方体边缘，无逐格 Three Object。预览色较浅，减选预览为橙色；不改变源色。
- 原三维/地台/矩形/创造模式及 Legacy 框选流程保留。隐藏 Workshop 的旧 Z Min/Max 主控件，不修改存储/发布/Blender/Unity 契约。

## 实际操作

| 操作 | 键位/入口 |
| --- | --- |
| 点选、连续刷选 | 体素选区 → 点选/刷选；左键，起笔替换原选择 |
| 屏幕框选 | 框选体素；可从空白处起笔；松开仍留在选择模式 |
| 加选 / 减选 | 起笔按 Shift / Ctrl（本笔固定） |
| 穿透 | 可见/1、−、+、全部；或 Alt+滚轮，向上增加 |
| 相机 | 普通滚轮缩放，右键旋转，中键平移 |
| 取消预览 | Esc、pointercancel、失焦，保留确认集合 |
| 区域操作 | 填充、清除、替换颜色；使用当前色板 |
| 撤销 | Ctrl+Z / Ctrl+Shift+Z，只针对几何，不撤销选择 |
