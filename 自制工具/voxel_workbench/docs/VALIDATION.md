# 实测与待验收（2026-10-01，持续更新）

状态：开发验证版，**原计划尚未整体完成**。Blender 5.1.2 / Python 3.13.9，Windows 11。未安装用户插件配置、未注册全局Skill、未推送。

## 已执行

- test_model.py：8项纯逻辑测试；负半格、补点、脚底锚点、体积接触、尺寸间距、sRGB、非法字段、超量阵列。
- integration.py：真实mesh、请求重试、旧修订拒绝、失败不留半笔、局部面写时复制、原生顶点编辑识别、保存重开。
- collision_test.py：重叠实体拒绝、失败原资产不变、边界接触允许。
- presets_test.py：显式保存固定版本、另一资产调用、路径穿越拒绝。
- profile_test.py：新默认不改变旧资产步长，非法步长拒绝。
- export_test.py：两种GLB结构、PNG真实sRGB数值、最近采样、源模型保持、FBX新场景重导入贴图。修复过图片缓冲误写线性值导致色板偏暗。
- preview_test.py：实际中性PNG、原场景恢复。
- ui_test.py：注册、按钮建块、卸载、重复注册。
- gui_smoke.py：独立工厂配置Blender进程，真实事件模拟拖笔5块→undo0→redo5→Esc取消仍5；非人工手感评审。
- verify_viewer.cjs：独立Three.js/Edge查看两种GLB，30对象/360三角面，尺寸6×2.25×0.75米（Y up）；截图与数值在artifacts/wall。
- benchmark.py：1000块约0.126秒，10000块约1.409秒，均共享1个mesh。仅后台创建时间，不是视口FPS。

每个行为测试先观察缺失行为失败，再实现。GUI通过不等于全部笔刷模式通过。
