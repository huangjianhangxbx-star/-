# TOOL-008 交接

## A 包已实施

- 项目、场景、资产可在项目页重命名；新资产有可识别的默认名称。
- 保存资产和场景使用带哈希校验的回收区；被实例引用的资产先提示引用数量，可显式移除实例；可恢复，永久删除有二次确认。旧发布目录不参与回收。
- 最近成功打开的项目保存在本机 Electron 用户数据中；支持一键重开、路径失效提示、重新定位、忘记记录。切项目时处理未保存修改。
- 项目页提供卡片/列表、搜索、排序与资产缩略图；在三种桌面窗口尺寸做了截图检查。

原有模块笔刷、场景装配、发布历史、Blender/Unity 交换代码保留。本包新增 UI 不改变 v1 文档 schema；回收区属于受管项目文件。新建项目/场景/资产尚沿用 v1 场景私有资产结构，不能误称资产优先模型已经完成。回退时可通过本包提交回退应用代码；已有 `.workshop-trash` 必须先经 UI 恢复或另行备份，不能仅回退代码后直接丢弃回收文件。

技术验证见 [validation.md](validation.md)。用户对 A 包的实际手感尚未验收。下一包按 [plan.md](plan.md) B/C 实施项目级原生资产、实时引用、旧工程副本迁移、单资产 FBX 出口和试摆降级。
