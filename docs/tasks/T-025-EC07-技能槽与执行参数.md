# T-025 / EC07 技能槽与执行参数

仅 Standalone 暗牢使用三槽；Tower/旧庭院保留原单技能。E/R/T 对应 0/1/2，F 不占用，自动箭雨/回镰按原规则自动发动。空槽拒绝施放，无占位新技能。

| 职业 | 首次默认三槽 |
| --- | --- |
| 猎人 | hunt / 空 / 空 |
| 守夜司祭 | prayer / ward / 空 |
| 霜镜使 | bell / 空 / 空 |
| 守卫 | poison / 空 / 空 |
| 弓手 | snipe / rain / 空 |
| 盾卫 | pain / sanctuary / 空 |
| 镰舞者 | dance / reap / 空 |

已保存 legacy default 优先迁入槽1，同职业另一个现有技能放槽2；槽1非空、同职业且不重复。未改技能倍率、射程、持续时间、CD、分支价格和上限。SkillState 以 ID 持有 progression/CD/time/pulse/counter/enabled/run；legacy 镜像仅投影槽1，显式 resolveSkill/skillState 用于多槽。

所有已装备技能充能各自推进；未装备技能冻结，重新装备恢复，首次装备冷启动。普通影庭冻结、菲奥蕾按原特殊规则继续。一个 Foreground 占角色施法/专属位移；Snipe/Poison/Dance 是背景模式。自动技能需本体可用且没有其他 Foreground；遍历按槽序，先开始的动作阻止后续抢占。当前每个合法职业至多一个自动 Foreground，双自动同 tick 的设计暂没有现有内容实例。

临时 battle 配置只改 Unit.professionSlots，不改 Profile；account/briefing/nodes 配置保存 Profile.loadouts（按角色/职业）。新探索从 Profile 复制并重置培养/时钟。职业换装保存本次职业槽并恢复对应职业，既有换装 .8s/移动取消保留。不能卸下正在执行的 Foreground，卸下背景模式安全关闭而保留其状态。已成立延迟效果按自身生命周期继续。

篝火 restoreSkillAtCampfire 按已装备技能类型恢复 timed/auto/chargedMode 充能，Pain/Reap 不增加计数，toggle 不改开关，未装备技能不借休息刷新。旧模式保留既有恢复逻辑。

复制体出生复制三槽、培养、分支、计数、模式和剩余充能，独立推进；不会随本体后续换槽/培养变化。正在执行的本体动作不复制到新位置：清除 run/time/瞬时快照并按其完整CD开始，避免复制正在成立的世界效果。原有复制体召唤资格/费用/不可移动/不可主控保留。

HUD 按 DirectActor 展示 E/R/T 与各自状态，空槽弱化。查看影体不改主控，详情列出生槽及每个技能的培养分支；Build 先选择槽，再显式 skillId 培养；同职业战中允许安全换槽，保持原 0.1×慢速。悬停查询该槽的范围，空槽无范围。暂停和模态沿用输入阻断，不新增 AI2/技能指令轮盘。
