# 规则对账

## T-002：连续空间与交战基础（2026-09-30）

有效依据：新设计 v0.2 第 2、3 节、用户“执行”授权及随后采用的 B1—B4。原稿和开发细则未改写。设计确认、实现、测试和用户试玩分开登记，完整执行记录见 [T-002](tasks/T-002-连续空间与交战基础.md)。

| 主题 | 本轮已确认规则 | 实现与过渡 |
|---|---|---|
| B1 占地与停留 | 圆形脚底完整占地；濒死友方保留间距；可经过友方，不能抢占停留位置与预留终点；失效停合法处 | 连续坐标、圆形占地、目标预留；单位中心不再吸附格心。路径以网格辅助，狭窄通道必要时细查 |
| B2 跨层 | 合法相邻边界渐隐后切换逻辑侧再渐入；新移动只替换后续目的地；拒绝技能；濒死按当前逻辑侧恢复可见；切换前落点失效留原侧 | 普通跨层状态机；无无敌；地面敌人不跨层。猎人瞬影不在本轮 |
| B3 塔防接敌失效 | 死亡、濒死、撤离、不可接近和超距统一返程；途中可受伤、受控，不主动攻击或重新接敌；返回路线才恢复判断 | 唯一关系与容量、固定追击锚点；退回未走路线节点；无伤害仇恨排行 |
| B4 起始参数 | 允许记录并调整；普攻先单目标，技能保留原群体效果；独立墙与实体高台按高度遮挡 | 默认脚底半径 0.18、停留间隙 0.08、接敌半径 1.5、追击半径 3；均是可调测试值 |
| 探索差异 | 复制体不作为敌方主动索敌或报复目标，不计为本体队伍遭遇；容量溢出敌人仍可攻击本体 | 独立策略与真实开发场景、参与者事件契约。未实施全队入战／脱战状态机、视野或探索结算 |

### 获准保留的过渡入口

| 入口 | 本轮适配 | 尚不等于 |
|---|---|---|
| 疾行 | 选单位身份与方向；沿连续坐标位移 1 单位，校验占地与整段路径 | 新卡牌能力设计、猎人瞬影 |
| 路障 | 仍是格网建筑；检查连续身体、出生点、水晶及敌人路径；敌人仍可破坏 | 连续自由建筑系统 |
| 救援 | 猎人寻路到按中心距离判断的救援范围；保留按钮 | 新影庭收纳与保护时点 |
| 水晶撤离 | 指向水晶、点击本地确认、抵达后撤离；复制体仍可立即销毁 | 新安全点／完整影庭界面 |
| 卡牌与道具 | 单位身份与连续距离判定，不使用浮点坐标相等来查找目标 | 生命力经济、变卖／销毁 UI |
| 技能与装备 | 旧技能、充能、耐久继续运行；普攻和技能互斥 | 职业切换、子技能树、等级成长 |
| 波次与结算 | 旧地图波次、资源、胜败、重入过渡保留 | 新波次批次、重试跨战斗奖励去重 |
| 黑暗 | 旧光源／局部受击发现采用连续中心距离 | 新探索视野设计 |

### 参数来源与单位

地格边长为 1 逻辑单位。空间配置位于 game/src/core/spatial.ts 的 SPACE：半径 0.18、间隙 0.08、接敌 1.5、追击 3、探索部署 3、跨层 0.75 秒、平台高度 0.58、射线眼高 0.45、墙遮挡高度 2.5。跨层中点是渐隐完成和逻辑切换点。
角色射程保留获准旧测试用途：猎人／守卫 5、游侠 7、菲奥蕾 1；敌方普通近战／重甲射程 1、远程射程 4（本轮试玩修正，原近战误用 4）。射程如今是圆形中心距离，不是前方格数。近战仍只同层，远程允许跨层但受实体遮挡。基础速度 0.85（另受既有负重倍率）；容量沿用 block，普通敌人占 1、重甲占 2。普攻一次最多命中 1 目标，与技能群体范围独立。
