# TOOL-010 B0–B2 implementation plan

> Agentic workers: execute in parallel by owned modules; test first. User explicitly authorized B after reviewing the existing v0.1 plan, 2026-10-24. Stop at Gate B user playtest once B2 is usable; B3/B4 formal Unity reception remains after that gate. B0 export proof is mandatory before declaring painting usable.

**Goal:** Direct 3D opaque Base Color painting, auto UV, editable native source, compatible model actions and real FBX+PNG proof.
**Architecture:** Stable per-canvas face keys `x,y,z,face` (face follows surface.ts: even positive, odd negative) and local UV axes ascending model axes excluding normal. Versioned bounded sparse texels; density64/m SAMPLE. Inline source within native JSON is chosen for initial implementation: existing atomic native writes, full-source SHA/checksum and portable lifecycle cover all bytes without introducing dangling blob dependencies. Record this deliberate implementation adjustment; no arbitrary paths or unbounded source. Painted visible faces get separate textured quads; unpainted geometry stays greedy, exported atlas padded/nearest with white factors and inherited opaque material properties.
**Constraints:** .25/.125/.0625 steps; right rotate/middle pan; Edit selected object only; hidden/locked no paint; geometry unchanged; one stroke one undo; Esc/blur/save/switch cancels; opaque source only; no silent loss on unsupported geometry transforms/resampling/scene merge. Budget262144 covered texels/asset and bounded face count/source bytes. Preserve old fast path and documents.
