# 工坊原位副本与轴向移动设计

用户决定：Ctrl+C/V 后允许与源体素完全重叠，按 Esc 完成原位副本；副本仍可独立沿 X/Y/Z 移动。工坊源保留每份副本，FBX 只导出重叠合成后的可见表面。

现有编辑文档、网格和 FBX 使用每坐标一个体素的 `cells`。保持该合成视图，新增可选的 `baseCells` 与 `voxelCopies`：前者是常规绘制层，后者是有 ID 的独立体素组。加载旧源时 `cells` 即 base；首次创建副本时才写扩展字段。合成按 base、复制创建顺序覆盖同坐标颜色；预算约束同时考虑独立源格数和合成格数。验证时重算合成并拒绝不一致文件。

Ctrl+V 从源位置进入放置预览；按 Esc 在源位置提交独立副本，左键可在目标处提交。副本提交后保持选中，视口显示 X/Y/Z 轴手柄；拖动按 0.25 米吸附，松手形成一次可撤销操作。保存和重开保留副本身份及位置；副本列表可重新选择。常规体素绘制仍作用于 base，避免悄悄改写独立副本；输出端只读取 `cells` 合成结果，不产生重复面。

场景试摆、项目索引、Unity/FBX 交换协议及 Legacy 语义不变。旧版本程序不能读取带扩展字段的新源，项目保存不做降级或静默丢弃。
