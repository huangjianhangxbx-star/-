1. **实际地板比参考更橙、更均匀，家具局部遮光带有格状边缘。** 家园暖色已读出，厨房、桌椅与阅读区仍可分辨；但参考的木板更灰棕、局部照明更集中，炉/槽周围的低分辨率阻光边缘显得技术化。本项扣材质/表现分，不能用后期再美化抵销错误拓扑。本图没有因此遮住结构。
2. **阅读长椅与规整三畦仍是最明显的造型适配。** 它们与概念的单人座和连片菜园不同；但实际阅读角确实在右上同组、菜园确实在建筑之外，后门门槛接石路，已消除用户此前否决的核心布局问题。
3. **储物与边缘生活细节较概念克制，右下增加了实际商人/箱子/HUD。** 原型所需对象和前门提示集中在右下，画面略拥挤；厨房、阅读书架仍可见，未再用关闭HUD缩小实机来隐藏差异。南侧储物组面积较小但已靠墙聚组。限制保留，不要求新增装饰量产。
