## 规模基线

样本是16格分区台阶、3种顶色与固定侧色，**不等同于同体素数的碎石、复杂洞穴或成千上万模型**。全部地形纳入镜头，两幅真实WebGL视口。单位ms，单轮测量非统计保证。

|---|---:|---:|---:|---:|---:|---:|---:|
|小|512|4|24 / 48|1.94|0.82|0.25|169|
|中|25,600|44|222 / 444|34.97|28.80|5.96|528|
|较大|184,320|184|878 / 1,756|268.27|225.68|51.96|3,231|

桌面首次打开三档229/190/1082ms；后台网格时间见desktop-scale.json。Electron离屏GPU模式90帧采样约60fps，这证明当前样本预览可持续绘制，不等于用户前台输入延迟或游戏帧率。

6次小/中/大/小/大/小切换：每视口已上传几何回到5，大图185（含网格辅助对象）；强制GC后页面堆约4.7–5.5MiB/36.6–36.8MiB。**整个Electron多进程工作集约448–905MiB，回到小图未立即回落**，包含保留堆/缓存；不能据此承诺无长期内存增长。原始进程分项保留在desktop-scale.json，尚未做数小时压力测试。大文档的全量撤销快照是下一轮明确优化候选。
