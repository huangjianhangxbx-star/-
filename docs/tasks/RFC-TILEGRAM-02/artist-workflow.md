# 画师操作一页版

打开本地画师页，点击“母版”即可看到A/B/C；优先B，再用A的H/T草稿校对。

1. 在连续H/T草稿确定墙体宽度、大明暗块、墙沿走向，别先填碎纹理。
2. 顶形与前面板分层绘制；前板竖缝一次安排，检查各交汇位置。
3. 四个自然方向的五种接角分别校对，不能把原作未证明的镜像当事实。
4. 打开独立annotation核刀线；正式输出隐藏辅助层。blank为透明编辑层，demo是原创结构教学，不是定稿风格。
5. 使用cut-map整数矩形切47片；在H/L/T/U/孔洞/端点回拼中检查断线、双墨线和面板遮挡。
6. 需要特殊修正的片在C中受控替换；记录适用mask，不把手绘修补藏进通用裁切器。

每套下载ZIP含画板、辅助层、规则与阶段图。供技术验证的100PPU不改变源研究数据；默认模板是简化结构示范，不能直接当成熟环境资产。

## 2026-10-14 可读性补充

首页增加真实木墙的完整片、观察分区与原坐标合回三栏；先理解上沿/前板，再看端头/直段/转向。分区线不是已恢复的作者图层。PPU模式支持同时打开边界索引，标注不改变图像宽高。用户理解度与美术认可仍未作为程序测试结论。

## 实际素材职能表对照

原创B部件表旁增加原木墙四方向×五类观察窗及实际前板；20格均以登记原片整数裁切，无镜像/调色/补画，HTTP下逐RGBA核对。点格子显示源索引/mask/矩形并打开完整源图。含前板或黑内部的窗口不等于可复用顶形部件；未证明这20观察窗可无损还原全部47态。原图片与浏览截图只保留本机。
