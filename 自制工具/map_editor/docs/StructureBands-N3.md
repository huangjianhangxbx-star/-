# 自动结构描边与台阶边带

1. 打开模型的「贴图绘制」窗口，在顶部「绘画目标」旁点「自动处理 · 结构描边」。右栏成为参数页，模型视口保留。
2. 选择侧面上沿、顶面内描边、顶面+侧面或通用凸棱；设置颜色、宽度。按「结果 / 原始 / 识别边与覆盖范围」比较。右键旋转、中键平移，不改变计算结果。
3. 点击「应用到独立图层」，关闭参数页后可在普通图层列表显隐、擦除、排序，保存项目或正常导出。一次应用一次撤销。

默认手绘下方生成：原有手绘盖在色带上方，状态会提示遮盖像素；需要覆盖显示时选「置顶生成」。组合预设生成侧边与顶面两个独立层。指定色初值取打开工具时的画笔色，可解除颜色联动；相对底色压暗以原生色板底色计算，不采样视口受光色。

宽度是64px/m的整数像素（1–64px），不是体素数量。各画布精度下2px都是0.03125m。接收面方向和当前贴图选区只裁写入，不产生假边。空选区不回退整个模型。结构描边不重复应用画笔对称。

「完整资产」包括其他物体以及隐藏/锁定画布的几何，只读判断接合；只写当前绘画目标。不同精度与非零原点的简单拼接可识别。非流形对角接触、重合归属不唯一或超出分析/原稿预算会明确拒绝，不静默补缝。

应用后调整本次宽度/颜色再点「替换本次结果」，缩窄会移除旧的多余像素。相同参数不重复创建层。「新建一组」才追加另一组。手修、重排或锁定过的结果不能被静默覆盖；关闭再打开工具默认新建，不按层名认领旧内容。

这是生成普通像素的作者工具。造型变动后需要重新生成。原稿、隐藏层、普通复制/旋转/移动与便携源都沿用现有保存规则；GLB/FBX使用可见合成。视口黑边、诊断蓝线都不是导出结果。

Esc取消未发送草稿；切目标、保存、历史、返回建模和关闭主窗口会先让你选择应用、放弃或返回调整。已发送的操作需要等确认后撤销。

原创练习：便携包「示例/结构描边与台阶边带/project」，有三级岩台、门洞与后墙、混合精度手绘、环形平台四个资产。
