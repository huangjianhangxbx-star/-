# TOOL-015 选取复制粘贴性能与落地修正

用户要求：选取/复制/粘贴减轻卡顿；左键单击直接落地，不再额外Enter；减少操作冗余。沿用现有独立绘图窗口布局。

实现：选区以有限掩码解析并复用像素缓存，复制/擦除不遍历整模型平面；复制单次扫描计算边界并仅存有色像素。贴片变换按有色像素生成最近邻结果，缓存最近一次比例/旋转；透明像素不覆盖目标。框选和粘贴高频输入按帧合并，相同命中跳过重复预览，点击或释放时处理最终输入。左键直接提交一次，Enter仍可用于方向键微移后的键盘落地；Esc取消；重复粘贴保留比例/旋转。黄色预览描边尊重开关，选区轮廓保留。

验证先于修改：单击落地测试失败（1次提交而非2次），小选区复制触发全平面扫描测试失败。修复后通过。补充每帧合并、最终点击位置、取消、缩放最近邻及所有旋转方向对照。

测量（本机独立生成测试工程，不修改用户资产）：
- 662有色像素、512×512含透明范围，50次平面贴片定位：中位11.87ms → 0.227ms，结果总像素32762一致。仅核心定位算法，非整体帧率。
- 1024体素画布真实窗口，大选区含50个绘制像素：复制35.6ms → 2.5ms；移动事件中位0.3ms → 0.1ms；两帧等待29.8ms → 29.1ms。未声称整体显示帧率大幅提高。
- 性能脚本：tests/paint-paste-benchmark.mts、tests/paint-paste-performance-ui.mjs。
- 实际窗口：跨画布缩放旋转单击落地、取消、撤销/重做、图层合并/隐藏、进程重启回读通过；800ms确认延迟笔迹连续显示通过。

沿表面延展仍需沿真实相邻面行走；非常大的连续满色贴片仍受像素预算与渲染成本影响，本轮没有改变预算或静默降低质量。
