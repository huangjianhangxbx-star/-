# Scene Ctrl+J merge implementation plan

Approved design: 2026-10-24 conversation. Selected editable voxel scene instances become one new independent asset and one scene instance. Source assets stay unchanged. World geometry/colors and precision retained; same aligned resolution canvases consolidate, different precisions remain distinct. No remeshing. Undo restores original instances in one command; redo returns same merged instance. New asset is retained in the project/library on undo, avoiding deletion of subsequently edited or reused assets. Compact More menu + Ctrl+J.

- Add pure `mergeSceneInstances(scene, assets:ReadonlyMap<string,AssetDocument>, ids:readonly string[], assetId:string, instanceId:string)` -> `{asset:AssetDocument,instance:SceneInstance,scene:SceneDocument}`. Validate >=2 voxel instances, budget, transforms, palettes and grid representability before mutations. Bake world-space transforms relative to a grid-aligned local origin, preserve voxel colors incl sideColor, retain precision groups <=32. One joined model object per consolidated canvas, source PNG references excluded. Later selected instance wins overlapping same-grid cells; no input mutation. Tests cover rotation including negative corners, free roots, offsets, palettes, mixed precision, overlap and failures.
- Wire WorkshopSession/controller to register/open independent asset then install replacement scene once; new asset persists through undo for safety. V1 uses scene-private asset row; V2 project row + standard save pipeline, no auto-disk writes or forced save. Selection changes to replacement, history leaves sources available. Unsupported GLB/PNG selections abort atomically.
- Add assembly Context.join(ids):Promise<string>, More menu `assembly-join`, Ctrl+J; disabled if <2 or unsupported assets. Preserve compact layout.
- Verify core, types/build, Electron V1/V2 merge/copy/edit/undo/redo/save/reopen; package and test executable. Update rules/log, selective commit, safe GitHub baseline/push if reachable.
