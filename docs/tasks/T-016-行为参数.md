# T-016 行为与参数

2026-10-04。首版参数，自动验证不代替用户体感与平衡验收。依据[原计划](T-016-计划输入.md)，覆盖 T-015 的“靠近也算收益”和精确回锚点行为，保留活动半径、玩家控制、架势/虚血与探索首击入战。

## 三层与生命周期

查询层 autonomy-query.ts 只产生真实贡献点/合法路径/TTC/窗口及覆盖查询；autonomy.ts 持有任务和运动；autonomy-config.ts 是单一可调参数入口。AIState 显式记录 phase、task kind/target/startedAt/contributed/point、settleUntil、贡献点/TTC/window/coverage/rejectReason，不从 intent/path 猜任务。

Hold守位→Commit接任务→Approach取得贡献点→Engage当前可贡献；目标/需求失效立即清自主剩余路径并进入Settle，低优先Return在观察后才回舒适区。Commit为接受动作的瞬时阶段，下一运动决策进入Approach/Engage。Player由成功命令/选中进入，立即释放原任务；失败命令保留原路径。原地正常普攻不限响应覆盖。

每模拟步验证任务生命、当前资格与需求，不能因仍有路径就跳过。目标死亡、离场、不可见/无合法贡献、已被满足且自己未贡献时结束；实际有效命中标记攻击贡献，包括护盾承接的命中；任务目标若可命中则在正常普攻排序中优先普通更近目标，既有直接接敌优先保留。紧急自卫与可达、生命低于25%的真实支援对象可打断普通攻击任务。

## 硬门槛与窗口

候选包含当前位置、锚点和每0.5环16点，塔防半径1、探索2。同层、合法占地、真实canHit（武器兼容/可见/视线/高低层/射程）、可走路径均通过才有攻击任务。仅更近、到位仍打不到不可驱动移动。路径及引擎重规划继续保持半径边界；不扩大索敌规则或AI权限。

TTC=真实路径长度/实际含负重减速步速+0.25秒前摇；余量0.2。静止/已接敌目标窗口视为稳定。沿现有路径或路线以当前速度做匀速位置预测，0.1秒采样合法攻击包络，检查预测出手时贡献点仍可命中；预测范围通常4秒、必要时延至8秒。预测不模拟未来碰撞/转身/随机改目标；超出稳定模型的判断不声称精确未来模拟。被硬直的敌人仍是可攻击目标，不把“不能行动”等同“不能攻击它”。

普通移动需求1，heavy2；原地可命中本体与有效Commit/Approach/Engage任务计覆盖，排除自己、复制体和不可行动/读条等对象；本人被直接攻击可额外响应。已有覆盖只禁止多余移动，不禁集火。

## 职业、支援与倾向

盾卫增加离锚成本；进攻提高可行任务优先级但不绕硬门槛；保势按实际架势缺口增加危险成本，规避提高危险权重。当前位置已可攻击通常守住；保势/规避只有仍能贡献且确实更安全时做任务内微调，避免纯躲避造成无贡献乱走。

支援使用当前实际已装技能的治疗/护盾/恢复效果、真实半径和可用冷却/持续模式状态，要求受伤的健康在场本体与到位覆盖改善。没有相关效果的镰舞/盾卫不因“救护优先”虚构治疗；技能仍在冷却时不为潜在覆盖走动。现有祷告/守护效果按真实半径覆盖，沿用其不要求LOS的结算；AI只取得位置，不替用户施放关键技能。已生成、固定于起点的领域不因本体移动扩大效果。
