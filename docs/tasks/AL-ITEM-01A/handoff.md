# AL-ITEM-01A 试玩交接

打开最新提交版本的主探索入口（最终回复提供带版本链接），出征后按 Tab。新世界团队有两瓶“实验缓回药”。

1. 左栏选药→“交给阿尔 ×1”，或“交给阿尔并设优先 ×1”。也可拖到右侧后备/原位自由槽。
2. 右栏选实际持有项→“设为优先”或“收回团队 ×1”；后备拖自由槽只设优先。
3. 右键原自由槽清空意图，持有数量保留。优先不代表立刻用；种子/农具不自动使用。
4. Z 控制阿尔时停自动用药。控制猎人时，阿尔可在安全时机为3米内低血量同伴或自己缓回；不会特意追赶投递。实际身上显示持续恢复。
