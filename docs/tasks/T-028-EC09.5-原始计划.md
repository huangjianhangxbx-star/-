# 3. 战外同行 Catch-up

当前 Standalone 玩家基础移动约 2.40，而 follower 远距离只有 ×1.15 追赶，转角和寻路后容易落后一个房间。

建议仅对：

```text
Standalone + explorationIdle + follower
```

使用分级追赶：

```text
距离领队 <= 2.2U
→ 正常速度

2.2 ～ 3.5U
→ ×1.20

3.5 ～ 5.5U
→ ×1.45

> 5.5U
→ ×1.70
```

当距离 >3.5U：

> 优先“赶到领队附近”，不再严格追回不断移动的 formation slot。

重新进入约 <=2.5U 后恢复软阵型。

Far Catch-up 时路径重评估建议约 0.15～0.20s。

本轮不做战外瞬移。

验收：
- 猎人连续通过走廊和转角；
- 阿尔不再常态性落后一整个房间；
- 转角落后后数秒内追近；
- Tower follow 不受影响。

# 4. 普通怪追击：从驻守半径改成持续追击

当前：

```text
detect = 5U
lost = 1.5s
leash = 8U
```

且 target / enemy 都受 home 距离约束。

这会让普通敌人过于容易放弃。

建立：

```ts
type PursuitPolicy =
  | 'chaser'
  | 'territorial'
```

当前 Standalone 普通 melee/ranged/heavy 使用：

```text
chaser
```

未来精英/Boss才使用：

```text
territorial
```

---

## 4.1 Chaser

真实进入追击后：

> 不再因为离 home >8U 立即放弃。

建议放弃条件：

### 极远
与目标持续拉开到约 16～18U。

### 长期丢失
LOS丢失后：
```text
追 lastSeen
→ 搜索 / 尝试重获
→ 约4～5s仍找不到Party Body
→ 才 return
```

home 继续用于：
- 初始巡逻；
- 真正脱战后的 return；
- 未来 territorial 敌人。

---

## 4.2 Dynamic Combat Domain

普通怪追出原房间后，EC-09 AI2 不能还被旧 Encounter 圆困住。

Active Combat Domain 增加动态扩展：

```text
原 Active Encounter Domain
+
正在追击的 active enemy 周围小战术泡
+
DirectActor 周围小战术泡
```

但 AI 战术路径仍必须拒绝主动进入 Inactive Encounter 感知区。

因此：
- 玩家把已激活怪拉出来 → AI能继续参战；
- AI不会自己去开下一组怪。

# 6. Basic Attack 加快

当前基础攻击时序偏慢，是早期为了 Telegraph 可读性设的。

建议首轮：

```text
melee basic
total ≈ 0.22s
lock ≈ 0.10s

ranged basic
total ≈ 0.30s
lock ≈ 0.14s

heavy basic
total ≈ 0.36s
lock ≈ 0.18s
```

Basic 主要靠：
- 敌人朝向；
- 动作动画；
- 距离；
- 追击节奏

来读。

不是每次平A都画红区。

# 7. Melee / Heavy Approach Tempo

普通敌人不再永远直线匀速靠近。

新增轻量状态：

```text
Pursue
→ 可选 Probe
→ Burst
→ Basic
```

Probe：
- 目标距离约1.8～3.2U；
- 横向短移动约0.20～0.45s；
- 保持面向目标。

Burst：
- 速度约 ×1.45～1.70；
- 持续约0.20～0.40s；
- 快速压进到Basic范围。

不是每次都Probe。

使用：

```text
enemy identity + attack serial
```

确定性决定：
- 是否Probe；
- 左/右；
- 时长；
- Burst倍率。

不用裸 Math.random。

Ranged保持控距，不强行冲脸。

# 8. Ability Telegraph 进度表达

Ability 开始后：

> 低强度显示最终完整 Area 边界。

同时内部填充表示时间进度：

```text
progress =
(time - startedAt)
/
(resolveAt - startedAt)
```

### Circle
从中心半径0逐渐扩展到完整radius。

### Sector
从origin向外逐渐扩展range。

### Capsule
从source沿射线逐渐填充到终点。

同时：
- opacity；
- saturation；
- red intensity

随 progress 增强。

Tracking：
- 边界可转向；
- 虚线；
- 内部填充继续。

Locked：
- 边界冻结；
- 实线；
- 填充继续逼近Resolve。

不只靠颜色表达。

Basic完全不进入Telegraph Renderer。

# 9. AI 闪避：只对 Ability 做紧急规避

当前 Companion AI Hazard 会读取所有 AttackIntent。

改成：

> Emergency Hazard 只处理 `kind === 'ability'`。

Basic：
- 不触发 Evade；
- 不触发 Blink；
- 只通过普通战术站位处理。

---

## 9.1 Ability Threat Score

即使是 Ability，也不是“看到就必闪”。

ThreatScore至少考虑：
- HP Damage；
- Posture Damage；
- 是否会直接 Broken；
- 当前HP比例；
- 当前Posture比例；
- 多Area重叠；
- AITendency；
- 是否能普通走出去。

流程：

```text
Ability预测会命中
↓
等待真实reaction delay
↓
能走出去
→ Walk Avoid

走不及
↓
ThreatScore达到阈值
→ Evade / Blink

否则
→ 接受命中
```

---

## 9.2 AITendency

### avoid
更容易花机动。

### preserve
Posture低时更愿意躲高架势技能。

### aggressive
更愿意吃低威胁技能换输出。

### default
中间。

### rescue
正在Peel时仍会躲真正高威胁技能。

不使用随机闪避概率。

# 10. 默认显示实际 HP Damage

原型阶段默认显示：

> **真实 HP Loss。**

不是理论 Power。

例如：
```text
Power 50
→ 防御后37
→ Shield吸收17
→ HP实际掉20
```

显示：
```text
20
```

0 HP Loss / Miss / Active Evade：
> 不弹普通“0”。

---

## 10.1 多段伤害聚合

Rain等多段不能每次弹数字。

建议：

```text
同 target + source/cast
约0.10～0.15s窗口
聚合成一个 Damage Float
```

表现：
- 目标上方；
- 轻微上浮；
- 约0.55～0.75s淡出；
- Reduced Motion只淡出。

Weakpoint提示继续独立。

# 11. 主动切人 Tactical Focus

只有玩家主动：

- C；
- 1 / 2；
- 点击另一名本体；

成功改变 DirectActor 时触发。

不触发：
- 点击当前角色；
- downed自动handoff；
- 系统fallback；
- Hunter复生；
- Tower。

---

## 11.1 首轮参数

建议：

```text
真实时间：1.5s
初始Time Scale：0.20
平滑恢复到1.00
```

不是固定1.5秒0.1×。

建议使用 smooth easing。

必须按 real time 计时，不能按 simulation time。

---

## 11.2 主动位移立即取消

以下成功动作立即结束 Focus：

```text
WASD / direct
mouse move
Blink
Evade
```

马上回 1×。

E / R / T：
> 本轮不自动取消 Focus。

理由是以后技能可能采用：

```text
激活
→ 鼠标选方向
→ 点击确认
```

Switch Focus正好提供判断窗口。

---

## 11.3 与现有 Slow 合并

当前 Build / Card Aim 等使用0.1×。

建议把：

```text
simulationDelta(... slow:boolean ...)
```

升级为明确：

```text
timeScale:number
```

最终多个慢速来源取更慢值。

不能互相覆盖成加速。

Camera继续使用 real/visual dt，不跟着 Simulation Slow 慢到卡住。

# 13. 用户试玩重点

### 同行
阿尔是否还会掉到上一个房间。

### 追击
普通怪是否终于像“真的在追你”，而不是稍远就回家。

### Basic
是否变成快、靠动作读、有压力，而不是等地面红区。

### Ability
是否只有值得认真躲的技能才画范围，并且填充能直觉表达“快要结算”。

### 变速接近
Probe/Burst是否增加压迫感，但仍可学习。

### AI闪避
是否从“见红就滚”变成“知道什么值得花闪”。

### Damage Number
是否更容易调数值，而没有严重遮挡。

### 切人
是否形成：
```text
切人
→ 短判断窗口
→ 观察/准备技能
→ 一移动马上回正常速度
```
