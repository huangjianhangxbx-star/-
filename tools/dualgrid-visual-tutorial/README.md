# 双网格手绘课

双击本目录的 **index.html**，用 Edge / Chrome 打开。不需要安装、启动服务器或登录，图片只在本机处理。

1. 母版教学默认 **400×400 PNG**，兼容旧的384×384且保留原尺寸。查看原图和右边3×3平铺；切到100% / 200%检查接缝。其他尺寸会提示，不会拉伸。没有母版时先用标明的几何演示图。
2. 默认 **M07：右下角要挖空**。点画廊其他组合，再点四个步骤，看四角占用、白色保留/黑色挖空、真实透明结果和手绘位置。红点是这一张需要经过的边中点。
3. 在地图左边点/拖画石砖，右键或“擦空地”擦除。右边实时拼接；橙框标出四张关联渲染块，点击查看其四角来源。试试 L 形、凹口和斜向接触。
4. 下载“当前蒙版 PNG”和“当前示范 PNG”。蒙版的白色保留区不透明，挖空区真正透明。黑白查看图只供看，不要当透明成品使用。
5. **Photoshop**：母版置底，导入透明蒙版并载入不透明区域为选区，给母版添加图层蒙版；新建透明细节层补画断边。**SAI2**：保留母版，在副本中按参考选区删除外部区域，再新建透明层补画；各版本选区方法可能不同，可手动沿轮廓选取。页面里的折叠步骤可照着做。

石砖始终保持原坐标，内部纹理继续贯通。只在真实空地交界画断边；接缝不只对齐中点，还要统一整条边的透明度与颜色。棋盘只是透明查看底，不会出现在下载图片里。

网页新增“整版模板”：按用户截图的排列重建绿色占用图。粗线是4×4素材切格，细虚线是每格的四角。点击模板格与下方单张教学双向联动；第2行第4列是默认M07。右侧先按直角模板套入母版，可切换平滑轮廓作对照。下载按钮提供该排列的1536×1536透明绿色模板、同排列母版图集和CSV。模板下载不含棋盘/切格线/编号。

截图槽位从上到下为 `04 10 13 12 / 09 14 15 07 / 02 03 11 05 / 00 08 06 01`，数字为本教材M编号。它与原有M00→M15顺排图集不同；需要哪个排列，就用该区域对应的下载按钮。

母版示范的对角两片断开，载入手绘图集时则完全保留你画的形状。M00–M15是教学编号；原有顺排图集按当前母版大小导出（400格为1600×1600，384格为1536×1536）。Unity插件的槽位映射需另行核对。本工具提供结构范例，最终石砖崩口、排布和明暗仍需手绘。

## 正式400格：从SAI2手绘到整图集试画

1. 在“整版模板”下载 **绿色模板：每格400 / 整版1600 PNG**。它采用你确认的截图槽位顺序，绿色不透明，空地真正透明，不带棋盘、格线或编号。旧384格模板仍可下载。
2. 在SAI2打开这张1600×1600模板，作为参考层；另建绘画图层，逐格完成16种素材。每格400×400，中线200。导出前隐藏绿色参考层，保留空区透明，导出同尺寸PNG。
3. 在新增“载入你的整张手绘图集”选择/拖入这张1600×1600 PNG。工具直接按400格裁切，没有重套蒙版、转动、缩放或重新生成纹理。选择任意格可看400原像素。
4. 地图自动切到手绘图集。左侧点/拖涂画，右键擦除，或用六种示例检查实际拼接；“地图素材”可切回原有母版示范，已导入图集仍保留。

截图顺序与顺排图集不是同一排列，正式手绘载入须用上方截图布局的绿色模板。完整图集尺寸错误会显示具体尺寸并保留上次有效图片。图片均本地处理，不改原文件；刷新页面后需要重新导入。

画图参考可下载“400格绿色模板＋网格＋编号”：1600×1600，400实线切格、200虚线中线，各格标注M00–M15。另有“独立网格编号参考层”透明PNG，便于在SAI2单独叠加、隐藏。无标记版仍保留。最终图集导出前隐藏参考层，避免把编号与格线一起导入地图。

另提供“400格模板＋网格编号＋接缝带”和独立接缝带参考层。橙色带宽14px，只覆盖每格外框附近的绿色区域，透明区与内部断边不填橙色。它提醒检查共边，并不意味着整条带都不能画；接缝处须让邻图的透明度和颜色分布一致。网页可切换显示，最终绘画导出时隐藏提示层。

地图现在按素材原像素绘制：400格的11×9地图为4400×3600，384格为4224×3456。“适应窗口”看全图；50% / 100% / 200%在滚动视窗里检查砖纹和接缝。“大窗口查看地图”提供更宽的查看区域。原像素地图PNG下载保持透明，且不含棋盘、选中框或辅助网格。

## 完整母版变体随机平铺（独立功能）

在“母版变体随机平铺”一次选择原母版和3张变体，或追加任意数量的PNG。每组统一400×400（兼容统一384×384），每格等概率选择一张，默认不旋转、不翻转。可移除单张、清空重载；范围可选4×4、8×6、12×8。点“重新随机”看另一种排列，输入同一个种子可复现同组图片的排列。

可勾选“随机90°旋转”：每格独立等概率选择0° / 90° / 180° / 270°，不翻转。勾选“显示变体编号 / 角度”可看每格来源及顺时针角度。关闭旋转恢复固定0°，且不改变每格选中的变体；同一组图片/种子/开关状态可复现。下载PNG保留实际旋转，不含查看文字和线。

默认固定方向；自身四向无缝并不自动保证90°随机混铺无缝，旋转后的边纹/颜色/透明度也要相容，可用接缝线检查。

默认适应视窗显示整图；100% / 200%检查原像素接缝。接缝线和变体编号只用于查看，不改变排列、不烘焙到下载PNG。所有变体之间也要能互相接缝。这个区域与双网格16态、母版教学和手绘图集完全独立，不修改它们或原文件。刷新后需要重新载入图片。
