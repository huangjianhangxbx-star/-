## 当前：接续恢复与弯道可走面修复（2026-11-04）

本轮继续处理“经常续不上、快拖失败、红线后回不来”。输入现在只累计已经接受的笔迹；暂时不合法的尾段单独显示，回到有效端点附近再向前延伸即可重新求解，不会把一次偏航永久留在整笔里。松手采用已接受部分；若整笔还没有有效部分，则保留原桥。

**操作看颜色：**进入“连续绘制路线”，在首尾端面出现绿色接续提示后按住左键向外拖。黄色表示初段不足0.5m，继续向外画；此时松手会明确提示未新增，不会显示“已采用”；青色表示已接受、松手可采用；红色只表示当前尾段未采用。红线时可保持按住，回到青色末端附近，再向前延伸、留出转弯空间。无需靠猜拖动速度来判断是否成功；右键、中键仍用于视图导航，Esc取消本笔。

旧的50°转角与估算半径硬拒会把正常接缝的采样弦误当成不可行结构。本轮改为80°单折角上限，并检查实际桥面每个截面的两个三角形均保持正面积，继续保留自交、边界交叠和走廊间距检查。只放宽角度会误放内侧折叠，因此实际桥面检查是同时加入的必要保护。

另修复了跨转角铺面切角：原来一个铺面片段跨过作者转角、源件又没有该处断面时，会用直弦切掉外侧可走面。现在片段在作者截面处分开适配，保留原源件拓扑、UV与配色。45°接续的慢采样原漏2/327、快采样原漏3/327，现均为0；四组实际网格、碰撞与撤销检查已通过。

本轮共变更四份源码：输入、曲线安全检查、结构片段布局，以及`ReplicaSession.Rebuild`。重建时会刷新派生来源映射，但不改作者`DocumentJson`或`Revision`；三项原本全部失败的映射回归现全部通过。更新采用原工程后台增量方式，保留当前试玩场景；不改GUID、套件或场景文件，不关闭编辑器或取得桌面控制。

用户试玩指出普通拖画经常只剩小节，续画又变成独立桥段。本轮已在同一工程修复输入与连接代码。此前理想U/S采样的后台通过未覆盖这类操作，不能据旧报告推断实际绘制可靠。

- 弯道边界先按作者角点求交，再沿真正的两侧边界采样，修复正常弯道被误判自交。

1. 先点“U 弯样例”或“S 弯样例”查看自由路线；再选“连续绘制路线”，按住左键缓缓画出斜向、C/U/S 路线。桥体会随有效采样更新，松手采用最后有效候选。真实鼠标 T3 由用户延后（deferred_by_user）。
2. 选中作者，在场景中用圆柄自由移动单个节点，用黄色方柄调整该节点标高。也可在节点列表输入坐标；预览后“采用候选”，Esc 取消。
3. 进入“连续绘制路线”或点击“从首尾接着画”，移到附近自由桥任一首尾端面；看到绿色接续端面后直接向外拖，按实际鼠标相对移动量延伸。新增部分接入同一作者，不要求先选中该桥。保留“沿末段续接4米”和“删除最后一段”。
4. 在足够长的水平直段启用“此路段开洞”；弯曲段复杂拱洞、急转、自交和自由三维扭转不在本轮承诺中。非法候选应说明原因并保留有效作品。
5. “素材套件”切换原创 A/B，预览后采用或取消。“登记工坊套件…”仍读取现有九角色登记文件。结构模板可沿弧适配，立柱与拱圈造型件保持刚性。
6. 保存原生场景或路线文件，之后继续编辑；采用、取消、Undo 与保存重开使用同一作者数据。v0.2 生命周期与独立重开已有后台通过报告，真实鼠标仍单独留待之后。

右键、中键和 Alt 属于视图导航；Esc 取消未采用候选。旧 schema1 作者按旧求解器保留原形；“保留旧作，另建自由版”显式创建新版本，不静默改变旧作品。

## v2 母件使用约定

- tread/deck 沿实际中心线与横向车道适配；coping/rail 沿左右两侧各自弧长分配。结构模板保留源拓扑、UV0 与颜色，生成法线按形变重算；没有把全部模型统一禁止变形或无差别拉伸。

- 支撑由扫掠配方生成，洞口与可见面共用边界；它不是母件，也不自动挖开基础地形。
