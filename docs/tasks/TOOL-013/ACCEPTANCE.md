# 用户试玩检查单 · 区域色差与美术暗面

这里是待验证清单，不代表功能已实现或已通过。

## 区域色差

打开一面深灰墙。固定同一个观察角度与原色显示，对比原始纯色、旧逐格随机、新区域色差。

- 按砖块变化时，同一块砖内部不再形成小格棋盘；能看出砖之间的轻微差别。
- 成片色斑有大小可调的大中区域，不是整面均匀撒点；比例降低后有大量干净区域。
- 调幅度只改变色差，不打乱区域；同一个seed返回相同结果。
- 门洞不被填上，金属/门框等非目标不变。出现固定侧色时有解释，工具不擅自全局改色。
- 调参、取消、确认、一次撤销/重做正确；保存后关闭整个程序，再打开仍相同。

## 美术暗面

先用一个灰色方块，不用复杂模型掩盖问题。

- “上亮下暗”：顶面保持，侧面轻压，底面略深；不是整个方块一起变黑。
- “指定光向”：更换参考方向可以改变面分档；旋转相机不改变已保存配色。
- 相同设置重复应用不会越来越黑；清除暗面能恢复原底色。
- 一半画白色标记、一半不画：默认保护标记；显式开启影响手绘后标记也受暗面作用，但关闭/清除后原笔触恢复。
- 完全涂满的面在保护手绘时底色效果不可见，界面能解释，而不是悄悄改变标记。
- 两个同向面，其中一个被拱顶挡住：首版不应声称能区分真实遮挡阴影。

## 综合

- 正常受光模式可能叠加实时阴影；用原色模式确认作者颜色本身没有过暗，再判断受光效果。
- 复制、移动、旋转、分离、合并后的颜色/暗面仍跟着对应表面；没有跑位或旧数据复活。
- 换显示预设不改资产、不取消上色预览、不重新抽种子。
- 导出FBX与贴图后在Blender实际打开；方向、底色、手绘、暗面一致。修改工坊源需要重新导出成品。

最终美术标准：远看整体色调统一，近看才有克制变化；暗面帮助读形，不是为了做暗而黑成一片。
