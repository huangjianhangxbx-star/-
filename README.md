## 游戏原型

第三轮试玩：打开“战前配置”选择菲奥蕾的技能或武器；进入战斗后用下方“职业与构筑”提升技能、三选二分支或请求换装。面板0.1×，需紧急操作时右键关闭。内容、价格和边界见[第三轮内容表](docs/tasks/T-006-内容与界面方案.md)，验证见[第三轮记录](docs/tasks/T-006-验证记录.md)。

Three.js + TypeScript 原型位于 `game/`，包含源码、角色动画及特效资源、测试和锁定的 npm 依赖清单。安装 Node.js 22.12 或兼容版本后：

```powershell
cd game
npm ci
npm run dev
```

生产构建：`npm run build`。原型依赖 `game/public/assets/` 下的角色、动画和音效资源。

## 架势与虚血（T-014）

战斗中青绿条为真实生命，灰白尾段为可夺回虚血，黄铜细条为架势。架势归零进入破势，再次受到架势攻击才硬直；选中角色可查看数值。攻击造成实际敌方生命损失可夺回虚血，多段技能共享整次施放上限。参数、影庭及技能中断规则见 [T-014](docs/tasks/T-014-架势与虚血.md) 和 [参数表](docs/tasks/T-014-参数与生命周期.md)。用户随后授权继续实施队友自治与移速改造，见下方T-015。
