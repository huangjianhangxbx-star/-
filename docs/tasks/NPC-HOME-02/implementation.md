## 单一控制链

成员关系仍由 home-resident 管理；home-goals 提供纯评分与步骤数据；home-schedule 只适配日相位；home-routine 从原执行器迁移，持有同一个 activity 状态。home-activity 保留原 API 的兼容转发，未增加第二移动器。移动仍调用原 navigate 和 engine 共享移动，路径清除须数组引用属于本控制器。

评分分解为基础分、完成记忆、禁止立即重复、区域/距离偏好、日相位。固定输入排序稳定，缺少活动点的目标不可选；当前合法承诺不因另一个分数略高或切相位而抢占。评分只查询元数据和可站性，不逐个目标寻路。

## 三条无产出步骤链

| 目标 | 顺序（停留为模拟秒） |
|---|---|
| prepare-meal | prepare → 5–8 秒 → dine → 3–5 秒 |
| quiet-reading | read → 2–3 秒 → rest → 8–12 秒 |
| garden-care | garden-water → 3–5 秒 → garden → 5–8 秒 |

步行经过真实后门与家具碰撞。坐标只取布局活动点；布局仅给现有水点增加 garden-water 语义 tag，没有重画或移动已验收布局。停留表现仍为 stand-placeholder，不冒充烹饪、阅读或浇水专用动画。

## 恢复与失败

菜单、对话等复用原 hold 租约，保留目标、stepIndex 与剩余停留；恢复重验当前步骤，不重跑已完成步骤。活动点不可用时尝试同 tag 等价点；无可用点、布局失效或长危险中断可有限退出。阻塞间隔 1 秒，最多 3 次，单次路径预算 1600，失败目标短冷却 8 秒。有效目标完成冷却 20 秒。

离图冻结，返家仍同一 Unit、伤势和装备。成功组队同步取消生活控制，旧 release 不能清除伙伴新路径。危险暂停超过 30 模拟秒可放弃；对话和旅行不按此超时放弃。无后台生活、自动返家或解散。

## 日相位与诊断

HomeScheduleContext 支持 morning/daytime/evening/night、可选 dayIndex 和来源。正式日历尚不存在，默认明确为 prototype-phase/daytime；适配器可接未来权威来源。F10 的“原型日相位（仅本会话）”只改变后续评分，不强制目标、不存档。

F10 显示目标、前三评分各部分、步骤、活动点、路径 token/长度及中断原因。最近六条目标转换使用独立环，避免频繁对话挤掉转换记录。
