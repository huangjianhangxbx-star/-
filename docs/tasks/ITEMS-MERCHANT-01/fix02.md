# 待售区与地面交互修正


## 待售投放与地面交互修正（2026-10-16）
待售区空态采用明确虚线投放框，仍仅由玩家手动加入，不自动罗列库存；无报价物品明确拒收。丢弃按鼠标反投影位置落地，必须是同层可见合法地面，否则原物品不动。F 在附近有手动掉落物时优先拾取最近一项，空间不足给文字提示且保留掉落；无掉落仍保留原选路用途。开包可将附近地面物品拖进指定背包格，也可 WASD 移动，输入框编辑时不移动；开包仍不触发战斗输入。场景卸载/刷新清理手动掉落规则不变。

验证：11 项核心测试通过；浏览器实际出售、丢弃、地面拖入指定格、满包 F 拾取拒绝、腾出空间后 F 拾取、开包移动流程通过；TypeScript 检查及 Vite 构建通过。查看 merchant.png 确认右侧虚线投放框。浏览器测试为设定位置/满包夹具后执行真实鼠标键盘交互；未覆盖所有地图边界。Vite 保留已有大包体警告。
