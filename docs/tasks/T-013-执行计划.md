# 第七轮探索状态与生命周期 Implementation Plan

> 本机未提供 writing-plans 引用的 superpowers 执行子技能；按用户当前执行授权在本会话逐项实现。采用复用现有战斗、导航、账本和渲染的方案，独立保存探索访问与节点记忆，不复制塔防终结逻辑。

**Goal:** 正常支路形成探索→遇敌→脱战→队伍命令→提前退出→重入→目标完成→合法退出→副本安全结算的闭环。

**Architecture:** 内容定义与副本内节点记忆分开，探索感知/战斗活动不依赖渲染；队伍任务逐人执行，迷雾统一被核心查询与表现消费。塔防继续使用原波次调度。

**Tech Stack:** 现有 TypeScript、Three.js、Vitest、Edge Playwright，不升级依赖。

**Spec:** [第七轮输入计划](T-013-第七轮输入计划.md)及[任务批准记录](T-013-探索状态与生命周期.md)。
