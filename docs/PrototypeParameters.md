# 原型可调规则清单

以下是本次实现的候选初值，不冒充用户逐项确认的永久规则。数据见 game/src/core/combat-config.ts 与 engine.ts。

- 副本开始有2次重置机会；有机会时水晶击破消耗一次并退出节点，仍可重入；已无机会时再次失败结束本轮。
- 同步结算时先处理濒死超时，再判胜败。
- 猎人生命归零直接等待重生，16秒后以60%生命返回；菲奥蕾本场禁用，下节点1HP；普通角色救援窗口45秒。
- 私有受击发现持续2秒，只让被攻击角色识别攻击者；光源正常揭示全队共享。
- 开场始动：守卫6秒、菲奥蕾4秒、游侠3秒；成功撤离后6秒再部署。无移动CD。
- 猎人强化普攻8秒，5×3范围、增伤；守卫恢复技能、游侠范围攻击、菲奥蕾范围治疗，均为单技能原型配置。
- 菲奥蕾暂用Livia视觉，守卫Arina，游侠Cynthia；怪物用Dustin与Verlaine_bot的四种配置，未称其为原剧情身份。
- 手动/自动刷新消耗20碎片并抽4张背包牌；次数、伤害、HP、精神、负重和光源均为试玩初值。
- 第1战斗完成可使用一次休息节点，再进入第3节点（黑暗战斗）；可重入已开放战斗节点。
- 当前页面内维持远征状态；刷新页面为新测试。尚无磁盘自动存档。

- 全部单位基础移速统一0.85格/秒；负重/状态修正另算。水晶初值10HP，每场12敌人，属于平衡试值。
- 猎人个人击杀每3个触发专属牌，最多持有1张；使用后可再次获得。
- 猎人优先在存活菲奥蕾附近合法空格重生，否则在起点附近重生。


## 第二轮试玩改动
- 当前生命：猎人260、菲奥蕾200、守卫600、游侠180；菲奥蕾周围治疗120，水晶保持10。
- 首场4波，每波3敌，开始时间7/15/20/35秒，各波内部出怪间隔3/4/2/2.5秒；各提前5秒预告，允许波次重叠。
- 路障80生命，地面敌人可攻击摧毁；仍保留不能封死所有合法通路的放置检查。
- 同来源增益不能叠加，不刷新时长，重复拒绝不耗牌。
- 当前技能读条显示0.001秒精度，实际随渲染帧刷新，不宣称1kHz显示。

## 第四轮参数覆盖
守卫常驻减伤25%；主动额外减伤50%持续8秒，两者乘算（承受37.5%伤害），施法阶段2秒，恢复120。猎人技能持续8秒，独立射击40伤害/秒，首次0.25秒。技能范围：猎人定向5×3、射手定向4×3、菲奥蕾曼哈顿距离3、守卫自身；攻击型技能预览展示四方向候选范围，实际执行按目标方向。击杀每敌4碎片，视觉3颗飞行光点不重复记账。

## 第五轮数值初稿
战斗45敌人、8波：开波18/45/65/85/105/125/145/165秒，敌数2/3/4/5/6/7/8/10；HP倍率0.45递增0.15至1.5，伤害倍率0.45递增0.11至1.22。角色参数详见`game/src/core/combat-config.ts`；始动时间Hunter0/Fiorre8/Guard10/Ranger6秒。技能18秒空条充能（Hunter持续技8秒），复制体20碎片，本体与复制体共用单个敌人的毒素计量。
