# EN00｜来源证据与单点缺口

基准与授权见[任务](../EN-00-参考敌人体系对账与覆盖合同.md)。本机证据指纹/回读结果见 [EN00-evidence.json](EN00-evidence.json)。原作 Steam Build24935935；本轮复看保存证据，不启动原作、执行目标 DLL 或扩展全敌库逆向。22 份定向输入登记 SHA；CR04 审阅包按清单逐文件复算。6 个敌人导出资产按 AL01/AL03 manifest 校验一致。

## 状态的准确含义

| 状态 | 本轮用法 |
|---|---|
| SOURCE | 原表/模板/保存 IL/原骨架具体字段，限定构建及条件 |
| ORIGINAL OBS | 原作正常运行结果；本轮与父研究都没有取得，不填 Lab 结果 |
| LAB SAMPLE | 原有获批技术样板值；并非所有后续主探索数值自动获批 |
| LAB VERIFIED | 同版本夹具或自然输入已验证；指向测试和日志，不等于用户验收 |
| MAIN IMPLEMENTED | 当前主探索实际代码；旧体系仍在，新的僵尸/弓手尚未迁移 |
| USER ACCEPTED | 用户限定体验认可；小蓝角色手感、Hunter G01 和 Al RMB，不外推完整敌人原作保真 |
| PENDING | 指定模板、动态消费者、OBS、后续阶段/人工子项，不以模糊“基本还原”关闭 |

## N1：单位、模型与根动作不能混名

CR04 Unit 原表161 的 `僵尸`，UnitMove=`僵尸1`，选中根 `僵尸_攻击`。AL01 实际视觉来自模型 bundle `僵尸1`，Lab 执行名 `僵尸攻击` 是适配名，不能把 bundle 名当所有单位类型的同义词。CR04-N1-D01/D02/C02 证明根模板 data/loadData 和源行匹配，N1-C06/C07/C08 证明候选 Ready(true) 与最终 Ready(false)/CanAttack 两道资格。

原所选攻击骨架本机回读：Flash、Lock 的 time 缺省为0；Dash、Hit 为 .5667。`attack` **无 Break/End 事件**。AL01 提取清单 unit.json SHA `d2b889e14591e6dedf6679f996b81e2668a5fb4e7c86190b3b9f1a46396f340d` 本轮匹配，4.1.23。因此父 CR04 的“未取得所选事件表”只是历史时点，本轮不重复提取；2秒恢复仍是 Lab 最大时间轴/结束策略 SAMPLE，不是原 OnAnimFinish 实测。

静态根 dash=.7/.2、CD初始2.5/后续1.5、基数范围0..1.8有来源，但受实例属性/随机初始CD/充能/攻速等修改；Lab 固定值不能称原作绝对周期。Lab HP110、伤害5、速度1.2、转向3、最终角35°、危险扇区1.6/半角.8/寿命.1、硬直.24、击退.3、声音绑定为 SAMPLE/适配。无 casting/阶段修正条件下 incoming硬度1 > defensive0 的严格比较有保存证据，不保证每次玩家攻击必先命中。

## 保存研究的适用边界

- CR02：输入/Break与End权限/严格硬度/伤害过滤/技能结束与既有实体清理分开；不会把玩家 a1–a4 的 Break/End 直接安在怪物 attack 上。
- CR03A：主动支付在 Attack，成长回复在有效首次命中；原 Character.Inst 消费者与原型 caster适配分开。它为身份/费用/成长不可合并提供反例，不为新怪物补造相同资源规则。
- CR04：N1近战/N2远程差异与唤醒、局部避让静态证据；没有证明共享进攻名额。所有8个原观察协议 `not_performed`，result空；CR02/03A也是空结果，准确状态见机器证据。不是整款游戏不存在导演。
- AL01/AL03：复用契约与测试摘要。AL01 T09/T10/T11/T12覆盖裁剪根资格、取消/硬度、几何/低帧；AL03 87逻辑/25浏览器为历史验证，不冒充本轮重跑。原作栏保持 null。

## 优先补证清单（不阻止 EN-01 纯运行时夹具）

1. P1｜N2 两子/爆炸实际模板、Son owner/index、Bullet渲染挂接：只追选中链，禁止展开全技能库；允许编码阶段沿用显式 Lab契约，但不得宣称原作消费者闭合。
2. P1｜N1/N2普通地图精确ID出现与原作自然动作/打断/发射后死亡 OBS：事件表无需重取；未自然遇到保持未执行，不造地图/改存档证明。
3. P1｜各怪 AttackReady/MoveReady 的原消费者与动态速率/结束节点：骨架没有这两个事件，先沿显式 SAMPLE结束策略，不补造原事件。
4. P2｜敌人原声音/粒子实际调用：优先原资源已有映射，缺者标适配，不能直接用“有音效文件”关闭同步。
5. EN-05前｜具名差异候选的实际 Unit/模型/根模板/事件/反应；见覆盖矩阵。普通组存在证明不足以声称重型/防御型机制已取证。
