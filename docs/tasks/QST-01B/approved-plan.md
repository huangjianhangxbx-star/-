## 0. 为什么轮到 QST-01B

已核对的 `QST-01A` 主要完成普通探索入口、合法离开、继续同一世界和新世界二次确认，并非完整的任务玩法。当前正式地图在 `game/src/core/dark-dungeon-map.json`，为 144×120、20 房间，入口 `01_守门人前厅` 与相邻的 `02_失火储藏室` 已有；正式入口 `standaloneDefinition` 现有事件点主要是篝火，`victoryCondition:'exit'`，不应把旧 `探索/静钟` 逻辑冒充现行任务系统。

本轮只补**一个有接取、有进度、有真实完成效果的小任务**。它要能与现有世界生命周期及地图探索共存，但**不能演变成任务编辑器、复杂 NPC 或完整主线剧情系统**。

## 1. 玩家可见的最小体验

建议任务名（**SAMPLE，可换**）：**《失火储藏室调查》**。

1. 玩家从正常入口开始新测试世界。进入前厅后，可在一个**已确认可到达、且不与篝火/两田/角色重叠**的简易事件点查看“调查委托”；点击/靠近交互后接受任务。任务从 `未接取 → 进行中`，现有“探索目标”折叠区增加一行任务名和 `调查失火储藏室（0/1）`。
2. 玩家正常走路探索到相邻的 `02_失火储藏室`，在一个经过实际地图合法性校验的位置，点击/靠近“调查记录”事件点。成功后从 `进行中 → 已完成（1/1）`；展示简短文字/已有视觉反馈。
3. 建议奖励：**随身生命力 +10（SAMPLE）**，通过现有 `economy.credit` 与奖励去重机制，仅入账一次；不直接变成永久仓库入账，也不暗中结算副本。
4. 玩家可中途合法离区、继续当前世界，任务接取/完成状态与奖励记录应保持。提前离开不默认失败，也**不新增出区前必须完成任务的门槛**。确认开始新测试世界后，任务回到未接取，奖励可在新世界重新获得。
5. 完成一次便收口。当前不加入任务链、第二个任务、分支、对话树、NPC关系、自动寻路/传送、全图地图标记、每日任务或长线存档。

**位置策略：**前厅与储藏室是已知场景语义，不把坐标当已验证落点。Codex 须使用实际地图与路线/障碍/同层/可见性检查选择两处有效事件点；优先选择可通过真实玩家操作完成的短路线。无法合理到达则改为最近的可达调查点，并记录实际落点与原因；不得修改整张地图为本任务让路。保留既有空间、雾区与敌人行为。

## 2. 规则边界（AI 建议，非永久玩法定稿）

- **一个任务、一条有限状态线。** 建议 ID：`sample-warehouse-investigation`；状态 `notStarted | active | completed`。只有两类事件行为：接受、调查完成。进度显示由状态派生，不多造平行真假标记。
- **单一权威。** 正式当前世界的任务状态建议附着在 `WorldSession.places[placeId]` 或经代码核对更适合的现有地点持久状态中；不能只藏于 DOM，也不能跨世界泄漏。`ExplorationMemory.objective/cleared` 仍属于旧探索机制，本轮不静默改写其既有意义。
- **唯一事务。** 查询应纯读；真正接受/完成校验 `worldId / visit / placeId / pointId / revision / actor` 及存活可行动、同层、可见、接近、阶段与输入所有权。旧访问、重放、死亡/模态/暂停/失焦触发的无效动作纯拒绝。完成与奖励一次性原子处理；付款失败不得显示成功任务。
- **奖励与领取。** 优先复用 `worldRewardKey`、`economy.rewards` 和 `credit`；不新增第二个奖励账户。已有击杀、资源、篝火、物品、农田、升级与 Y 瓶各自权威保持不变。
- **任务与出口关系。** 任务是当前正式测试世界的可选样板，**完成不等于必须打通整个 144×120 地图**；不更改 `queryExplorationExit` 或本来已有的离区资格。
- **事件登记。** 优先复用 `ExplorationPoint` 和既有场景事件选择/交互链。若需增加 `quest` 类型，应在 `interactExploration` 中显式分派，绝不能落入旧 `resource` 或 `objective` 分支而产生免费资源/假主目标。不要重画正式地图或添加正式场景美术。

## 3. UI 与实际操作

- 复用现有 `#exploration-objective` 折叠区，不新增任务菜单、日志界面、主 HUD 区域或永久图标。
- 一行显示 **未接取 / 进行中 0/1 / 已完成 1/1**；附近事件点允许真正鼠标点击/现有点位按钮交互，不仅是控制台 command。
- 未发现的远处物体不越过现有迷雾/可见性规则显露；可用任务文字提示目标房间，但不需要立即开发导航系统。
- 失败时给简短、准确的理由（太远、不可见、角色不可行动、任务未接取、已经完成、访问过期），不能吃掉玩家 LMB 普攻、F 选路、G 战术轮盘或其它 UI 输入。
- 避免与起点篝火、FARM-01 两田、现有探险点/点击优先级重叠，保留 1920/1280 的六区 HUD 几何。
