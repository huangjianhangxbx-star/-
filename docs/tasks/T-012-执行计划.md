# T-012 波次与节点衔接实施计划

**目标：**同一调度器实现3波短关与12波长关、多批预告/清波/整备，以及独立节点放弃。
**批准：**用户执行指令及R6-B1/B2/B3全部采用推荐；内容参数由执行者配置。附件 [输入计划](T-012-第六轮输入计划.md) 为规格，用户本次授权覆盖其中历史未授权描述。
**架构：**地图几何保留。`waves.ts` 独占调度、进度及预告查询；内容定义与运行计数分离；engine负责单位生成与唯一整场终结，scene/HUD消费同一查询。波间不初始化节点。
**技术：**现有Three.js/TypeScript/Vitest/Playwright，不更新依赖。writing-plans的superpowers执行子技能环境未提供，按用户授权在本会话直接执行，不声称使用。
