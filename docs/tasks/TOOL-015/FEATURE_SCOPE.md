## 必须保持的区分

- 体素格 ≠ 贴图像素；1格0.25m在当前密度下是16像素宽。
- 体素画布 ≠ 手绘图层；新增手绘层不要求新建体素画布。
- 资产Root ≠ 对称中心；屏幕轴 ≠ 资产作者轴。
- 无光照原色 ≠ 屏幕最终照明；作者色吸色不吸入灯光。
- 当前同面填充 ≠ 对整面墙的连通填充。
- 既有建模像素完美 ≠ 新贴图像素完美。
- 视口结构边线 ≠ 能随PNG导出的作者边带。
