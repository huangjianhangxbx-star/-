# TOOL-009 交接

第一轮仅 P1/P2。使用方法：打开 v2 项目后，在“项目与资产”浏览项目根目录；双击文件夹进入、双击原生模型编辑，右键模型定位/改名/另存/导出/回收；右键顶部资源标签管理分屏，Alt+滚轮调整当前画布卡片大小。模块编辑底栏和试摆右侧使用同一浏览器。试摆时打开 `assets` 内分类，拖模型图卡至中间视口，释放后保存草稿。

后续请先让用户做 Gate A 手感验收，再决定是否执行 P3/P4/P5。当前实现仍使用 v2 项目内登记目录结构；未提供任意普通文件编辑或旧项目原位迁移。不要误认为已有“一个模型一个便携 `.xhasset`”或步进建模。

2026-10-19 更新：用户认可修正后的 Gate A 操作并要求继续，P3 现已接入。模块编辑中先选体素，按 S 进入整体步进预览；默认 XY，按 X/Y 锁轴，方向键或面板 +/- 改每端整数步数，Enter 提交，Esc 取消。颜色和 0.25 米体素规格保持；冲突阻止覆盖。B 算法为用户选择，形状对照见 `p3-shape-comparison.md`。P4/P5 尚未实施；P3 实际手感仍待 Gate B。

P3 操作补正：按 S 后在绘制视口左右移动鼠标（也可按住左键拖动）调每端整数步数，向左可缩到各选中轴至少 1 格。X/Y/Z 键锁单轴，XY/XYZ 面板按钮联动；起始 0 步，方向键和 +/- 保留，Enter 提交、Esc 取消。用户已确认缩放形状，但新鼠标与 Z/XYZ 手感尚待 Gate B 复验。

最新验收：用户确认鼠标缩放手感及表现。按 S 现在默认 XYZ；按 X/Y/Z 锁单轴，XY 等组合用面板按钮。视口左键单击或 Enter 确认；按住左键移动并松开只调整预览。与未选中体素冲突时保持阻止提交并提示，不能误覆盖。此轮不启动 P4/P5。

后续缩小/视角补正：XYZ 缩小时各轴独立到最少 1 格，不再被已有的单层 Z 阻断；右键拖动在预览中正常旋转视角，中键继续平移，且不会改变缩放步数。用户截图的红条为目标覆盖未选中体素的冲突保护，减小步数或重新选择源体素即可避开；不会自动覆盖。P4/P5 仍未开始。

## 2026-10-20 多画布入口
模块编辑左侧顶部「建模画布」→「另存为多画布模型」，再选择规格新增画布。不同于资产浏览器标签。当前三档 .25/.125/.0625 m，位置匹配两次点表面再确认，整体导出FBX。主页/面板可导入便携 .xhasset 源。技术验证、兼容边界及用户待验内容见 p5-validation.md；先前P4/P5未开始条目是历史状态。
