# 未确认操作同步搭建场景预览

2026-11-01；基线 cd893d4。用户要求建模中尚未确认的缩放、变色等变化，也实时显示在右侧“搭建场景”预览。

## 行为与约束

- 当前资产的临时形状/外观替代其所有场景引用，其他资产、实例位置/旋转、模型单位与原点保持；同资产多实例一致。
- 覆盖物体 S、编辑选区 S、物体/体素操作轴变换、自动上色、岩体塑形、Ctrl+U 调色与旧随机工具中已有的预览。取消/退出恢复实际资产，确认后的结果与预览相同。
- 临时预览不写资产、搭建场景、保存队列或历史；操作仍由原事务确认/撤销。资产、画布或项目切换后不残留旧草稿，异步旧请求不能覆盖最新变化。
- 复用现有右侧视口和场景几何，不新增渲染器，不跳动相机。模型视图/场景视图切换时保持对应显示和坐标空间。

## 实施顺序

1. 实际隐藏工坊复现右场景未随缩放变化，并保留 Ctrl+U 已同步的正对照。
2. 将颜色专用临时资产通道推广为统一草稿通道，区分来源并阻止过期取消；编辑局部预览通过独立会话合成为完整资产。
3. 接入各预览产生/取消/确认点；场景消费者按帧处理最新草稿，保留对象来源缓存，防止同 revision 草稿被忽略和异步请求逆序覆盖。
4. 核心/类型/构建、真实双视口 GPU 检查多实例、取消/确认/撤销和文件原样；同步本地便携资源前备份并验证哈希。选择性提交、核对远端后正常推送 GitHub main，不改 Gitee。

全程只用后台临时项目和独立测试配置，不操作当前用户窗口或真实资产。

## 完成与验证

统一 AssetPreviewChannel 与完整 native AssetDocument 草稿已接入上述来源；旧 onColorPreview 仍为兼容别名。编辑代理、物体/体素变换走独立会话合成，右场景保持实际米坐标/画布单位和全部同源实例变换。消费者用独立 contentKey 识别同 revision 的新草稿，合并同轮同步通知；每次新请求立即作废旧 I/O，防止延迟 binary 或读取完成后重挂旧模型。几何缓存按资产快照复用，排除参考 PNG/绘画原稿；隐藏的搭建工作区不重复重建。
