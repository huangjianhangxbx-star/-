# 桥梁／阶梯固定接口族 v1｜独立母件制作输入

此文件保留 schema1 历史作品的固定接口约定。schema2 随笔迹绘制采用独立的[结构适配契约 v2](bridge-freehand-adaptation-v2.md)；不得把v2的受控弧长适配解释为旧版已经支持任意变形。

这是本轮有限折线路线的**专用接口族**，不是所有建筑的统一格度。生成器验收前以本文件与实际源件认证冻结；如规则变更须修订版本并重新测试。

## 工坊通用部分

使用现有 voxel_workbench 共享API、原生Blender源、真实FBX和palette PNG导出；不安装Addon，不改旧文件或用户默认配置。新文件单独profile。色彩可自由设计，palette导出后必须有完整UV与实色贴图。

作者坐标为X沿路、Y向上、Z横路；每件底部中心为枢轴，轮廓位于约定包络内。下表单位均为米。制作细节单元0.125m；这个数仅约束本族。所有源件保持原尺寸，不允许整件非均匀缩放或未经认证镜像，允许绕Y旋转0/90/180/270度。

共享FBX导出器必须由导入检查适配轴向。SB03兼容源采用“实际FBX子矩阵后绕Y180度”适配；这是格式适配配置，不可把源的错误朝向藏进桥梁布局代码。请在契约写 `unityAdapterYaw` 并验证实际导出尺寸。源沿BlenderZ向上，鼻口源-X；源Y方向对称，适配后鼻口仍在作者-X。

## 角色与接口

| 角色键 | 包络 X×Y×Z | 重复与连接基准 | 保护和制作自由度 |
|---|---|---|---|
| tread | 0.5×0.25×0.5 | 沿X每0.5，横向每0.5，最大单阶0.25；底部Y0、顶面Y0.25 | 顶面要可走；朝-X下行鼻口保留；可改变分层/凹槽/收缩但不穿出包络 |
| deck | 0.5×0.25×0.5 | 四边平接，顶面Y0.25，不留下不可走孔洞 | 可分层、刻缝、改石块组合；不能使步进高度变化 |
| coping | 0.5×0.25×0.25 | 长轴X，顶部连续，转角由平台对应边及固定端部配置处理 | 帽沿、底座与层次可变，保留端面高度基准 |
| rail | 0.5×1×0.125 | 直段沿X，从Y0至1；端部位于X±0.25；桥族向内半厚度偏置避开柱面共面 | 可做双横杆/框格/斜格等真实几何；不做整块不透明填满所有缝隙的墙 |
| post | 0.25×1.25×0.25 | 栏杆与端头节点，底部Y0、帽顶Y1.25 | 底脚、柱身、柱头可重新设计；固定包络和枢轴 |
| arch-stone | 0.25×0.25×0.25 | 阶梯拱圈重复石，X/Y每0.25，不侵入受保护开口 | 双层石/削肩/色带可变；保持需要承接的顶部和左右边界 |
| arch-foot | 0.5×0.5×0.25 | 起拱节点，底部Y0，左右配对旋转 | 可改底座和帽沿；不能将造型伸入逻辑洞口 |
| keystone | 0.5×0.5×0.25 | 拱顶收口，按宽0.5替代中央两块 | 可阶梯收缩和换层次，保留对称接合界面 |
| abutment-cap | 0.5×0.25×0.5 | 引道／平台支承收口 | 底座、帽石轮廓可变，包络不变 |

各件除语义上要求的接触面外可内缩或做分层。端面美术不能依靠相邻源恰好遮住错误。固定/重复母件与规则生成区分别记录：本轮墙芯仍为明确的规则剖面，并不称为工坊模板；转角平台由deck/coping/rail/post组成。

## 本族组合限制

- 路线为有限正交折线，节点可移动、改变标高；不承诺平滑曲桥。
- 净宽按整数米1—6m，平台半宽按0.5m对齐。本轮不认证任意接口尺寸变化；尺寸不匹配应报错，不能改生成器来迁就第二套。
- 直段由固定0.5m步进安排，0.25m高度步进；过短、过陡、自交、走廊重叠或缺件拒绝并保留旧结果。
- 转角节点形成平平台，与相连直段留出端口；端口上不得有栏杆挡路。
- 桥下洞只在合法水平直段，不能跨角。洞口贯穿显示与碰撞，不挖A地形。

## 套件登记要求

本轮登记完整9个角色。尚未实现部分角色自动继承；未改造的角色可在供给步骤中显式复制获准自有源，并登记完整文件，不能静默补灰方块。第二套至少真实改变tread/deck、post等节点、rail/coping三类角色，颜色变化不算几何变化。

提供每件 `.blend`、recipe、palette FBX/PNG、中性预览，登记角色、显示名、逻辑尺寸、适配旋转、原始文件路径。来源SHA由登记工具计算，制作人不手填。文件保持独立版本，预览替换后明确采用或取消。

合格例：0.5m铺面内增加一圈内缩基座和不同表面层次，顶面与四边接口仍正确。不合格例：将顶面抬至0.375m而仍登记0.25m；把rail导出长0.6m却登记0.5m；用整体缩放修正枢轴错误。

制作中遇到本文歧义请记录，不读取生成器内部代码来反推答案。只有实际换件、接缝、洞口与重开编辑通过后，本族才能标记认证通过。
