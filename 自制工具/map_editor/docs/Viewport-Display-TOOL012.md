# 视口显示与光照

每个视口顶部的“显示：…”打开紧凑菜单。左编辑视口默认清晰灰模，右预览和试摆默认材质柔光；各自记住上次设置。

- **清晰灰模**：忽略原色观察形体，彩绘暂时隐藏。
- **原色检查**：检查色板和笔触原色，不受灯光、亮度、凹槽增强影响。
- **材质柔光**：以相同的哑光受光方式显示基础面和彩绘。
- **结构侧光**：固定方向的斜光观察错台和凹槽，可拖动光向滑条或开启灯光随视角。

菜单还包含视口亮度、背景、凹槽增强，以及折叠的结构边线、体素格线、地面参考网格。原“无光照校色”和“体素清晰”入口已移入此处。

“同步模块双视口”默认关闭。勾选后，以正在操作的视口为准同步显示参数，不同步相机、选区、工作平面或选取穿透。恢复默认只影响当前视口（开启同步时也会同步）。

灰模进入材质绘制会暂时切为原色检查，退出后恢复；绘制过程中手动选用柔光等预设会保留该选择。吸管仍读取模型颜色数据。正在落笔或拖操作轴时，显示控件暂不可调整。

切显示可保留岩体塑形预览。菜单打开时，第一次 Esc 只关闭菜单；随后 Esc 继续原有取消操作。右键旋转、中键平移、滚轮缩放不变。

显示只影响观察，不改模型、色板、Root、贴图、撤销记录或导出。缩略图保持独立的固定有色配方。

凹槽增强使用深度与法线的 SSAO，支持正交与透视，独立于格线。透明/X-Ray 或裁切透明材质视图暂停增强并在菜单说明；硬件启用失败会明确显示“凹槽增强未启用”。基础四预设仍可用。外部特殊 PBR 材质按基础色哑光显示，保留基础贴图、Alpha 和面向，不作为完整 PBR 渲染器。

便携包“示例/视口显示/project”含深色岩壁、层阶平台、六面校色与局部彩绘三个资产，可用“打开项目”载入。独立岩体查看器使用同一套显示预设，离线运行。

本轮为技术交付，最终形体辨识和灯光手感等待用户 Gate V。TOOL-010/011 既有待验收事项不因本轮自动完成。
