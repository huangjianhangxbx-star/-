# 绘图图层与局部粘贴

独立贴图窗口右侧上方是当前画布的图层列表。左侧复选框控制显隐，右侧锁按钮控制可编辑状态；单击名称选层，下面输入框改名。新建、复制层、上移、下移、向下合并、删除位于列表下方。缩略图展示该层首个有笔迹的体素面，供快速识色，不代表全部模型展开图。

画笔、形状、填充、擦除只写入当前层；擦除会露出下层或模型基色。向下合并保留两层可见结果，隐藏或锁定层需先显示、解锁。图层操作与笔触均进入撤销。上方“绘画目标”切换同一资产内物体及其建模画布；画布各自的图层保持独立。

M进入选区，拖框后选择“当前图层”或“可见绘图”，Ctrl+C复制。切换目标后Ctrl+V，移动鼠标预览，先调整比例（12.5%至800%）和90度旋转，再左键单击直接落地，无需额外确认。方向键微移后也可Enter落地，Esc取消。连续粘贴保留上次的比例与旋转。透明部分不覆盖；只复制绘图像素，不复制模型基色或实时光照。

“仅当前平面”在目标平面裁剪；“沿表面延展”沿连续体素表面绕棱角，复杂分叉/回折处以预览为准，不等同外部任意网格的自动UV展开。粘贴保持64像素/米，不因目标画布体素精度不同而改变物理尺寸。贴片在当前绘图窗口内保留，可跨目标画布；关闭窗口后需重新复制。

工具栏“笔迹轮廓”默认关闭。关闭时绘制及粘贴显示实际笔色，选区轮廓仍显示；本机记住该选项。

技术：图层原稿与可见合成都保存在原生资产；GLB/FBX使用可见合成。隐藏原稿计入原有262144像素/16384面资产预算；每画布最多32层。已有原稿按需无损迁移，保持唯一写入会话、笔触差量队列和局部纹理更新。

验证：504项核心测试、类型检查、构建；真实窗口显隐/合并撤销、跨画布缩放旋转粘贴、取消、撤销重做、关闭重开及进程重启回读；原工具完整故事与800ms确认延迟连续显示通过。测试使用独立生成项目和隔离用户目录。
