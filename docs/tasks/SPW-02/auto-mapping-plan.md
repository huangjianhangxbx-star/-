# 本地自动分析与映射

用户反馈当前只能手工映射且方向备注空值阻止生成。修复方向备注的验证，并增加本地自动分析入口：官方 runtime 采样、层级/长度/位置/名称/左右侧匹配，自动添加确定候选，歧义集中显示且不覆盖已有人工映射。已验证角色对可按骨架指纹复用本地映射，清楚区分历史映射与推断。对新动作仍执行完整通道审计，不将未匹配项静默跳过。

步骤：先复现空方向备注失败；新增采样/歧义/侧别/人工映射保护测试；实现分析模块及 UI；用 rhiny/rozeul 无配置动作验证自动匹配数量和审计状态；打包并同步 GitHub。骨架采样和匹配算法不联网，不上传素材。不宣称任意角色/任意动作完全自动匹配。

完成情况：上述入口、空备注修复、离线采样/歧义/侧别/人工保护测试、最终 EXE 自动分析与旧配置导回回归完成；结果和未完成的通用迁移能力见 auto-mapping-handoff.md。
