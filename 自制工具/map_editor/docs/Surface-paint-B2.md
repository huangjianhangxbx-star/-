# 三维表面材质绘制 · Gate B 试玩

本轮交付 B0–B2。已验证自动 UV、可编辑源、实际 FBX＋PNG 和 Blender 回读；B3/B4 的团结引擎接收与性能/发布收口尚未验收。

1. 在模块编辑中选中物体，按 **Tab** 进入编辑模式。
2. 顶部选择 **材质绘制**。选择画笔、擦除、吸色或填充；尺寸滑条单位为贴图像素。沿用左侧固定色板或色轮选择颜色。
3. 左键在可见模型表面绘制，右键旋转、中键平移。松开一次提交；Ctrl+Z / Ctrl+Y 撤销重做整笔。Esc、失焦、保存和切换对象会取消未提交笔画。
4. 保存草稿，关闭重开仍可继续编辑。项目资产可导出 `.xhasset`，导入另一工程后继续绘制。
5. 保存后按原有单件“导出 FBX”导出。请一起保留 `.fbx`、`.xhmaterials.json` 和 `.xhtextures` 文件夹；贴图已自动生成 UV，不需手工展开。

示例位于便携包 `示例/材质绘制/`：导入 **三精度彩绘石块.xhasset** 后，选中任一石块进入编辑模式，即可继续画。`FBX/` 内是已生成的普通美术文件组，能直接在 Blender 导入。

## 当前边界

- 首版支持工坊原生不透明体素表面 Base Color；不支持给任意外部 GLB 或透明材质绘画。画笔不改变体素数量或原色板。
- 首版密度样例为 64 px/米：0.25、0.125、0.0625 米体素面分别为16、8、4像素。密度不是最终美术规格；尺寸滑条为1–32像素。
- 填充处理单个体素面内四邻接同色区域。画笔范围裁切于当前命中面；持续拖动按实际可见表面采样，不穿透背面，越过空处不凭空连线。
- 物体模式的移动、90°旋转、复制，同画布 Ctrl+J、分离所选及画布合并会保留绘画；场景 Ctrl+J 也会映射表面及像素方向。相邻面暂被遮挡时保留源，重新露出后恢复显示。
- 已绘制模型的**体素选区级**移动/复制/旋转和 S 步进缩放暂时阻止执行，避免无声丢失贴图；请改用物体模式操作。普通增删体素仍可用，删除所属体素同时移除其绘画源，可撤销恢复。
- 每资产最多262144个覆盖像素、16384个绘画面；超限明确拒绝，保留此前内容。现有文件体积和便携包预算继续生效。
- 绘画源使用版本化、严格校验的稀疏数据，直接嵌入原生 JSON；整份源参与现有原子保存与便携包 SHA-256 校验。没有新增外置 paint blob 路径或依赖，项目复制/回收沿用原有资源事务。
- 团结引擎接收尚未执行，不能把 Blender 验证视为目标引擎验收。请先试玩 Gate B 的绘画手感和保存/编辑流程，再进行 B3/B4 收口。
