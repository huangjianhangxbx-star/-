# 地图工坊 M1.1 执行记录与计划

> 基准：`main@52de84aea94fc32867dd1b3f4d8c3ffcf9c91035`。依据：用户提供的《星骸回廊_地图编辑器_M1.1修正与塔防验证计划_v0.1.md》与交接包。2026-10-02 获用户“执行”及随后将此版本上传 GitHub 的授权；Gitee 不更新。

**目标：** 修正 M1 编辑语义和反馈，接入真实资产，并以同一体素源制作独立可玩的塔防验证图。

**架构：** `core` 是体素/表面及文档校验的唯一权威；桌面视口只负责拾取和即时预览；游戏与团结分别消费同一地图 JSON 的明确派生结果。独立入口不覆盖现有关卡。

**技术：** Electron 44.5.1、TypeScript、Three.js 0.186.1、团结 2022.3.62t13 Built-in、现有游戏依赖不升级。地形体素 0.25 米；首张地图 1 米 = 1 游戏 U（仅本样本适配，不改旧图单位）。

**保护：** `design/开发细则.md`、`design/用户维护/` 与原始截图不改；T-009、`voxel_workbench`、`art` 现有未提交工作不覆盖；真实资产改名/Blender 回流只在副本。D1 按用户确认六面法线增减；D2 的新全局光照部署机制不进入本图。

## 限制与发布状态

图仍是供程序和美术路线验证的小型塔防，不代表正式关卡、平衡、性能或完整地图格式。可玩场景只支持一个水平位置对应一个可站立面；混合高度单元明确拒绝。M2、实时资产监听、桥上下同时战斗和长期内存优化未实施。本次不改开发细则、用户维护区、原艺术资产，不同步 Gitee；GitHub main 只纳入本轮文件。工作区另有 T-009/资产任务的未提交内容，本轮不覆盖或混入。
