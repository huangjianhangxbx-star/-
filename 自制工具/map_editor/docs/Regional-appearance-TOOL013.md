# TOOL-013 区域色差与美术暗面 · 使用与边界

在模块编辑顶部工具栏点击 **上色**。物体模式先选同一画布的物体；编辑模式先框选要改变的体素。空选区不自动变为全模型。

- **区域色差**：作者物体分块、虚拟砖块、成片色斑三种分组。虚拟砖块支持 XY/XZ/YZ、米制尺寸、错缝、局部原点；幅度、变化比例、色阶独立。总种子和高级布局/范围/色阶种子可复现；高级种子 0 跟随总种子。物体只有一格时会提示改用虚拟砖块或色斑。
- **美术暗面**：上亮下暗、指定光向两种预设，2/3档、六向目标面。Z 向上，方向是表面指向光源。只压暗目标面，不制造高光；不计算遮挡阴影或烘焙 AO。
- **对照**：作者结果、原始模型、区域/面分档、仅底色。仅底色临时隐藏彩绘，不删除笔触。灰模隐藏作者色，请通过顶部“编辑显示 → 原色检查”观察；换显示不会重新抽种子。
- **应用与撤销**：打开时冻结源和范围，调参不写资产；取消/Esc/失焦丢弃预览。应用只产生一次修改，可整体撤销/重做。区域色差提交到底色，再次打开以当前底色为源；并非无限效果堆栈。暗面是独立相对数据，重复应用替换，清除不改底色。
- **手绘**：默认保留原笔触。显式“暗面同时影响手绘”只影响最终显示/导出，原始笔触仍不改，清除暗面即可恢复。完全涂满的面会遮住底色色差，面板有说明。材质绘制吸色区分“原始笔触”和“作者最终色”，都不采集视口实时灯光。

原有逐格色阶随机化保持旧入口。固定侧色保持原样并提示，不擅自切换所有侧面继承色。材质源最多64槽、按面数据每资产最多250000面，超出时整次拒绝。区域色差同时更新重叠源层，物理材质身份不混并。

物体级复制、移动、90°旋转、分离/合并、画布合并与场景合并保留归属和面方向；后操作覆盖完整目标表面。几何删除清理真实 owner，新露面默认中性。带彩绘/暗面的体素级选区变换与步进重采样暂不支持，会明确拒绝；请在物体模式变换。旧原生格式不能保存暗面，会拒绝降级；旧应用不能读取新字段，需使用本版工坊。

保存工坊源保留可编辑数据；GLB/FBX 输出作者最终颜色。未画的暗面使用普通材质；有笔触的面生成贴图并使用白色材质系数，避免二次变暗。FBX 与 `.xhmaterials.json`、`.xhtextures` 要一起交付，团结使用现有 NativeAssetMaterials 接收脚本。并未扩展旧发布系统的 native-cells 路由以支持多画布新源。

便携包 `示例/区域色差与美术暗面/project` 含两份原创模型、纯色/逐格对照/17、73、211种子/暗面/组合。参数为 SAMPLE，技术验证不代表用户美术验收。
