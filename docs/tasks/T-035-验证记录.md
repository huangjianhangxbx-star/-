## 调试与边界

历史测试的 Focus/Promote 标题保留来源，并在套件头部登记 T035 替代；没有删除或跳过整包安全断言。第一次核心命令从仓库根调用造成历史证据相对路径 ENOENT，改在 game cwd 全绿。页面首轮暴露旧 C 清焦点断言、零痛印按钮点击及短强制位移观测时序问题，分别改为绝对选择、合法痛印条件和在暂停夹具内推进正常 step 后观测 forced，保留原位移恢复断言。旧 D02 的危险已观察夹具改为正常 CompanionCombat 观察状态，不能继续用已退出的 CommandDefense 观察状态驱动避险。召影慢速与 Tower 3/4 保护先 RED 复现，再修正只限制探索入口的范围。实际技能测试须先结束领域再机动；切人本身保持领域，不能以机动成功为由取消它。

最终 B 用例改为模型内部多个邻点一致命中，等待镜头切换落稳；I 用例改以 stats.slowTime 判定模态慢速而非软件渲染壁钟速度。

自动回归不等于人工长时间试玩、音画品味或战斗手感验收。正式即时/模式技能仍不重制；Direction/Point/Unit 仅受控框架，不新增内容。用户试玩通过后回 EC10 战术轮盘；XC08、XC12/13 与旧 XC10 Command UI 不冒充完成。
