## 接受、命中、取消

queryRightSkill 只读检查右手身份、职业/实例、本体/当前控制、生命、动作/瞄准锁、CD/次数、体力和有限非零方向。拒绝不扣费/不改配置/不开始动作。Q/R 在实际 Accept 通过 CB02 单一支付序号扣一次，启动自己的 CD，清未接受 Basic/自身移动订单，建立独立 action、Release event；缓存本体+主武器实例+技能/参数/武器/原点/方向/形态。E 在原生 Accept 缓存右手武器，并将来源传给 charge/爆炸派生；不在 Release 重新读已变化装备。

Q/R 用真实扇区、目标规则和墙遮挡筛选，唯一 resolveHit 处理 HP/架势/护甲/受击/敌人生死；每次 Release 对每个目标至多调用一次。trace 关闭仍有独立运行时 action/event，不把可选日志当支付或伤害前提。普通命中去重、CB支付、技能CD、装备磨损、生命恢复/收益是不同事务。

样板执行中不叠加普攻、RMB、E、机动或 C；RMB 松开事件仍必须消费。Z、失能/受伤/死亡、暂停/帮助/失焦及卸载清该动作，不退款、不补资源、不排队下一次施法。已经产生的真实伤害不回滚。Q/R 的 CD 随存活本体模拟时间推进，与原生 E 同一时间域，Z 不免费刷新，离区和暂停冻结，死亡期间停止；同世界复活保配置/实例/CD及支付 ID。新建世界回默认；刷新没有存档。没有 AI 样板施法。
