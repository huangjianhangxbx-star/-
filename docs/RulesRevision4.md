# 第四轮战斗表现修订

用户要求：独立普攻/技能范围，左侧详情技能悬停预览；技能期间停止普攻；修敌我重合不攻击；增强守卫；优先接入角色已有FX；击杀碎片飘向HUD。

沿用writing-plans分工：核心query/执行/减伤/重合/击杀事件由engine处理；真实Spine FX副本与场景由scene处理；root处理技能悬停、碎片飞行和集成回归。先写红测试再实现。UI继续使用frontend-design的现有色板，motion-design反馈采用弧线0.9秒飞行和终点轻脉冲，不阻塞操作，尊重减少动画。

范围查询与技能执行共享同源函数。猎人旧“强化普攻”改为施法期间独立技能射击，不消耗普攻耐久。原素材不改写，不生成替代素材，实际可用动画表须运行时验证。效果事件只由真实释放或击杀触发，不从每帧闪光重复生成。
