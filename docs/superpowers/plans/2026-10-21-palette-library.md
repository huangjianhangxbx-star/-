# 工坊固定色板实施与验收

用户授权按推荐方案实现。保持现有深色和金色选中反馈，色板为8列紧凑网格，固定色板/色轮切换，不添加重复HEX输入。

- desktop/palette-library.cjs：独立解析JSON/GPL，项目palettes目录默认32色，不覆盖已有文件。
- main/preload/store：会话校验后读取项目目录，通过原生对话框选择外部色板文件夹。
- renderer/workshop：文件夹及色板选择、固定/色轮模式、8条最近色；显示历史与模型索引分离。
- core/color-adjust：加入色相旋转，保留原调色范围和非破坏预览。
- UI：剖切进视口顶部，窄视口工具栏水平滚动防重叠。
- 验证：颜色变换和色板解析先失败后实现；类型检查、完整核心测试、开发及打包Electron回归。
