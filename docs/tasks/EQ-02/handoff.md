# EQ-02 试玩交接

普通探索默认两人均 I。进入后按 **C** 切当前主控右手形态，**Z**换人；两人的形态各自保留。**LMB**按住连击，I猎人四段/阿尔三段，II分别a3/a4和a2/a3两段。动作/受击/整套恢复/瞄准/模态中C拒绝，不排队；右手槽显示I/II，点击装备面板可用真实形态按钮切换。

RMB仍是当前左手盾/射击器/炸弹，E保持原盾冲/火箭；与右手形态独立。II更大范围、更强架势、较慢衔接均SAMPLE，请实际比较两人的手感与动作组合。当前无新武器外观，不声称已形成永久规则。普通页面可试玩，最终回复提供含提交版本的链接。
