# 工坊根点定位

顶部“根点”菜单用于设置整个资产的装配/导出定位点。它与当前选中物体的拖拽轴中心分别维护。

门洞、墙体等落地资产推荐“底面中心”；“包围盒中心”适合按外部尺寸居中。六个面各有九个锚点，空心面也能使用。预设按所有画布实际体素外边界计算，隐藏或锁定画布仍计入，参考PNG与空画布不计入。既有根点不会随模型几何变化自动移动。

选择一个面后进入“面上选点”，辅助面与网格显示定位范围；移动鼠标预览，左键确认，Esc取消。吸附可选“网格交点”“体素中心”“自由”，按当前画布精度及原点计算，面所在轴保持不变。手动坐标以资产空间米为单位，也允许不对齐网格的根点。

设置根点可撤销和重做，保存后重开保留；不会改变体素或各物体原点。使用中的场景实例通过原有联合根点事务补偿位置，保持已有几何位置。
