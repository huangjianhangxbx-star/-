## 2. 问题诊断与重整原则

| 现状问题 | 本次证据/观察 | 改造方向 |

### 4.1 三个主工作区

保留现有内部 workspace ID，先改显示组织，不为改名迁移资产格式：

### 4.2 模型制作里的任务入口

资产文档工具行明确分为：**建模｜自动上色｜贴图绘制 ↗**。

- 建模：启用几何工具及对象/画布管理，岩体塑形归属这里。
- 自动上色：在右栏切换区域色差/美术暗面，沿用现有计算与提交。
- 贴图绘制 ↗：明确标为打开专用窗口，不把它伪装成已有第三种内部选择模式；已打开时用于聚焦该窗口。

“物体模式/编辑模式”仍保留为建模上下文，Tab 语义不变。**它不只是显示粒度：两种模式的新格归属也不同，不能偷偷改成一个普通选择过滤器。**

“清晰灰模/原色检查/材质柔光/结构侧光”只在显示菜单；不列入编辑任务页签。

### 4.3 对象、画布与选区的表达

当前对象身份与画布分离。左侧提供“物体与集合 / 画布”两个视图，共享真实选择与画布上下文，但不更改数据归属。

- 物体视图显示单层集合及成员，物体行可带所属画布/精度徽标；集合分组不等于合并物体。
- 画布视图显示精度、位置、显隐与锁定；不把画布画成一个隐含的合并物体。
- 大量独立单格物体用虚拟列表、折叠或过滤，不自动 Ctrl+J、不删除、不擅自改成员。
- 模型制作右栏顶部固定简短范围条：资产名 → 当前画布 → 对象/选区，注明“整件/内部选区”。
- 无目标时显示“选择一个物体”“进入该物体编辑”等可执行说明；不把能力入口隐藏。
- 取消选择不能使“当前绘制画布”不明，也不能因为缩起层级面板而改变选择。

### 5.2 推荐尺寸（CSS 像素，待真实界面确认）

- 常见 1500×940：层级栏约 210、工具条约 40、属性栏约 296；中央剩余为主视口，默认不展开资产抽屉。

- 右栏是当前工具参数与对象属性的固定位置，不再每个功能各开一个浮框。删除/另存/覆盖等真正确认仍可使用小型对话框。

## 6. 两种面板状态与预览生命周期

### 6.1 普通工具

选中画笔后右栏显示尺寸、形状、厚度/方向、工作平面、颜色；选中物体后显示变换、所在画布与允许命令。选择层级和当前绘制目标持续可见。

同一参数只有一个主要编辑控件，必要的顶栏摘要是只读。控件“不可用”给出原因；不因条件暂不满足而在用户找入口时整体消失。

### 6.2 带应用/取消的工具

岩体塑形、区域色差、美术暗面继续使用冻结源＋草稿预览＋一次提交，不改算法或源格式。

- 切换右栏折叠项、调整面板宽度、旋转镜头、切换显示、打开帮助、显示/隐藏资产抽屉，不取消当前草稿。
- 新工具或改变目标：若草稿有变化，显示就地“应用后切换 / 放弃后切换 / 返回”；无变化可直接切换。
- Esc 有优先级：先取消当前未提交笔画/变换/工具草稿，再关闭临时菜单；不能一键连续清掉对象与选区。
- 点空白位置不等于应用。零变化和失败不产生历史。
- 保存遇到待应用草稿时，明确提示“应用并保存 / 放弃草稿并保存 / 取消”；不能保存屏幕上并未提交的结果，也不静默丢掉用户参数。
- 以上保存/切换确认是对现有“某些操作直接取消预览”的推荐 UX 调整，需在本任务批准后记录为变更，不能伪装成旧行为完全不变。
- 活跃鼠标笔画失焦仍取消未提交部分。对于已结束交互的参数预览，系统失焦可保留草稿并暂停输入；返回先验证来源修订，失效则提示重算，不能用旧快照覆盖新源。
- 预览可观测、可比较原形与结果；切换显示不改变种子、选区或资产修订。

## 7. 独立贴图绘制窗口（首轮必须真实可用）

### 7.1 产品入口与布局

“贴图绘制…”常驻模型制作文档栏，也可从资产右键进入。同资产已打开则聚焦，不重复创建写入者。第一次进入允许自动完成旧的 editObjectId 上下文准备，不要求用户先记住 Tab 和隐藏下拉；准备动作不能制造新资产或改变几何归属。

目标不明确时提供小型目标选择：只显示当前原生资产内可绘制的对象/画布。锁定/隐藏时说明原因。当前首版仍一次绘制一个既有可编辑对象/画布，不以“独立窗口”为由放宽跨对象写入。

```text
贴图绘制 — 古工坊·墙壁入口1        保存当前资产 | 返回建模
目标：墙体A / 主体画布 / 0.25m     原色检查 ▾ | 辅助 ▾
┌──────┬────────────────────────────────┬──────────────────────┐
│画笔   │                                │ 画笔尺寸：1 px        │
│擦除   │       专用三维绘画视口          │ 颜色 / 色板 / 最近色   │
│吸色   │                                │ 当前作用域             │
│填充   │                                │ 高级（折叠）           │
└──────┴────────────────────────────────┴──────────────────────┘
已提交笔画/未保存状态 | Esc取消当前笔 | 当前画布规格
```

能最大化、缩放、移动至另一屏幕；第一版无需再做可任意停靠的通用窗口框架。窗口使用本地打包资源，不依赖 CDN。默认原色检查，可切材质柔光；灰模下明确“不显示绘画颜色”，不得悄悄改用户保存的显示偏好。

主窗口原位显示“该资产正在贴图绘制中 · 聚焦绘画窗口”；同资产几何、自动上色及会改变绘画目标的动作临时锁定，但主视口查看/相机/显示仍可用。锁范围覆盖原生菜单、快捷键、右键和自动操作，不只置灰一个按钮。

### 7.2 首轮迁移内容

迁移现有画笔、擦除、原始笔触吸色、作者最终色吸色、填充、尺寸滑条、色板/选色、笔画预览、Esc、Undo/Redo、保存和重开。

保留当前画笔/填充范围限制并写入交接：现有笔刷足迹在单面内部裁切，填充也是单面内连通填充。不能迁移时顺手改变它，却用旧测试宣称无行为变化；跨同平面笔刷改进在 P1/P2。

已有“原始笔触吸色/作者最终色吸色”必须保持区别，作者色不包括视口灯光。区分底色、手绘像素、faceTone；不新增任意多图层承诺。

### 7.3 单一会话权威和消息流

当前 `WorkshopSession` 和 `CanvasSession` 在主窗口 renderer 维护。推荐最小改造：保留这个权威，绘画子窗口只是快照＋命令客户端；Electron 主进程负责验证路由和窗口生命周期。不要趁机迁移整个项目会话到主进程。

```text
绘画窗口：本笔局部草稿 → 受限 paint 命令
          ↓（经主进程验证窗口、资产租约、消息大小）
主窗口权威：验证对象/画布/源修订 → 现有 CanvasSession.paint → 统一历史
          ↓ 回执：命令ID、新修订、当前快照或增量
绘画窗口确认 + 主窗口/试摆更新；磁盘保存仍走原受管事务
```

建议契约字段：`leaseId / sessionId / assetId / canvasId / objectId / baseRevision / sequence / commandId / patch`。字段名是拟定，不是声称已有 API。

- 一笔松开为一次命令；提交等待期间只允许一个在途写请求，避免乱序。重复 commandId 返回同一结果，不再写一次。
- 允许权威端通过现有画布 paint API 生成新源；来自子窗口的内容仍需核对允许的 owner keys、六面、像素范围、预算、来源修订。
- 若现有 paint API 接收整张 paintSource，也须验证本次修改仅落在租约目标，并基于当前权威源重建，不直接接受子窗口整份 AssetDocument。
- 子窗口不得创建另一份项目 store、直接落盘或用旧资产 JSON 全量覆盖主窗口。它没有任意文件/目录读写权。
- 草稿预览可节流同步到主窗口的临时显示层；已提交结果必须同步。草稿不递增正式 revision，不进入保存与正式导出。
- Undo/Redo 走同一权威序列。绘画窗口不得同时维护一套会与主资产冲突的长期撤销历史。
- 工具颜色/尺寸与相机是本窗口偏好；它们不使资产变脏。原生“颜色调整”不能在绘画期间误改几何底色。
- 贴图会话使用单一资产写锁。首版父窗口可查看，不同时在其他入口编辑同资产；不同资产的并行编辑也不必作为首轮目标。

### 7.4 IPC 与安全不能降级

当前 `main.cjs` 的 guarded 检查 sender、mainFrame 和固定主页面 URL；新子窗口不能直接复用成“允许所有 renderer 调用”。

为绘画窗口增加精确注册、固定本地页面、独立最小 preload 和受限通道；保留 `contextIsolation:true`、`sandbox:true`、`nodeIntegration:false`、导航限制。每次校验 sender/主 frame/租约目标；主窗口回执也须验证真实来源。不得暴露原始 ipcRenderer、通用 fs、任意 shell 或通配代理。官方技术依据见 §15。

原生菜单现在存在直接发给主窗口的动作，须按焦点窗口/文本输入/资产上下文路由；不能在子窗口 Ctrl+Z 时撤销主窗口另一个选择，也不能吞掉数值框的正常文本撤销。

### 7.5 保存、关闭、失败规则

- 绘画窗口关闭：取消正在拖动的未提交笔；已提交未保存笔触留在主窗口权威，不自动丢弃。界面明确“返回建模，修改仍未保存”。
- 绘画窗口“保存当前资产”：等待在途提交回执，再通过原资产保存事务；失败保留脏状态并显示错误。若现有保存会保存整个项目，要明示并封装正确范围，不能按钮写“当前”却悄悄保存别的文档。
- 主窗口关闭/切换项目：先结束子窗口在途请求，统一提示保存/放弃/取消；取消则两个窗口继续可用。不产生双重重复弹窗。
- 主窗口 renderer 重载、崩溃或失去权威：立即停止子窗口写入，明确主会话失效，禁止把残存子快照硬写回磁盘。不得宣称未保存的权威数据有磁盘级崩溃恢复。
- 子窗口崩溃：取消其未提交草稿并回收租约；权威端已确认的笔触仍在主窗口，可重新打开接续。
- 多显示器断开时窗口自动回到可见工作区；最小化/隐藏暂停非必要绘制；反复开关释放 listeners、WebGL、纹理及 IPC 订阅。

## 12. P1–P3：此前绘画需求的后续功能包（不假装首轮已有）

### P1｜跨同平面笔刷与贴图像素完美

在独立绘画窗口稳定后另行执行。区分建模体素格与贴图像素：首版像素完美只针对1px连续笔画，按本笔有序采样修整多余短折角，保护长直角、交叉点、原笔触。被修正位置恢复本笔起始快照颜色，不是直接清成底色。

同画布、同对象、同朝向且同几何平面的相邻体素面，转换到连续整数texel坐标后处理，再映射回faceKey；不依赖图集位置。不同平面、遮挡、空洞或对象边界断开，不能把笔画拉到背面。

预览实时、抬笔一次提交、Esc整笔取消。纹理模式开关与已有建模像素完美分开；尺寸>1px时明确暂停该算法，不宣称所有粗笔刷智能修形。

### P2｜一体素笔刷复位

按钮“重置为当前体素大小”：按真实密度和当前画布规格计算，现密度64px/m时0.25m=16px、0.125m=8px、0.0625m=4px。

单位必须同时显示px和米；这不是把贴图分辨率改成体素分辨率。自由画笔要跨同平面相邻面正确覆盖；若仍在单面裁切，就不能宣称已完成一格宽自由笔刷。

“画笔宽度一格”和“每次吸附涂满一个体素面”是两个操作，后者需单独命名和批准。尺寸变化后1px像素完美状态不误报。可将P1/P2同轮实施，不需要两次数据架构重写。

### P3｜可导出的自动结构边带

目标为参考岩台的台阶边带/顶面内描边，不是模型选择轮廓线。以几何邻接/法线/台阶边界识别，忽略同平面的体素缝、三角缝、颜色缝和UV岛缝。

首版建议只做两种：侧面上沿向下的暗带；顶面外轮廓向内的暗带。可调宽度、强度、颜色策略、目标朝向与保护手绘。真光照阴影/屏幕AO不混入它。

独立可清除效果数据或经明确确认的烘焙结果，不能无声覆写手绘。合成次序、faceTone是否影响边带、重复应用不加深、几何变更后的失效/重算、复制旋转、保存及FBX+PNG必须完整定义后再实现。

不要把自动结果粗暴铺满稀疏手绘faces，瞬间打穿既有像素/图集预算。先估算每面/像素/派生材质成本；超限明确失败或采用批准的紧凑源表示，不暗中裁掉。

这三项本轮只保留扩展位置和功能说明，不展示成可用工具。后续用户明确要求合并实施时，单列变更范围与验收，不能由执行者擅自扩张首轮。
