# EC03 闪避与普攻参数

范围仅独立暗牢的同行伙伴本体。当前主控按Shift：猎人仍瞬影，阿尔侧步、菲奥蕾滑步、伊内丝踏步。伙伴机制相同，未赋予职业额外收益。优先使用WASD方向，否则取战场鼠标方向；鼠标在UI或无方向时拒绝。个人栏机动按钮也可点选战场方向。

| 参数 | 首轮值 |
|---|---|
| 储层 / 顺序恢复 | 2 / 每3模拟秒恢复1层 |
| 最大距离 | 1.20U |
| 动作时间 / 最短再次发动间隔 | 0.18s / 0.18s |
| 主动未命中窗口 | 发动后前0.10s，不含右边界 |
| 路径采样 / 最小有效距离 | 0.025U / 0.05U |
| 普攻前摇 | 0.25s |

连续移动，起点不瞬移；全路径及运行中均检查地形、同层和敌人占位，可穿另一本体。墙边截短，无有效距离不消耗；动态障碍提前停下也不绕过再次发动间隔。受眩晕/硬直/破势或失能时停下。开始拒绝技能、SkillRun、跨层、落位、换装、收纳、救援、队伍命令和失能；动作中不启动普攻或接受冲突命令。疾行牌仍存在，但不能打断闪避，也不会因此扣牌。

闪避取消未出手前摇与普通移动，不退攻击计时；切人不会改变其既定路线，结束处建立玩家锚点。影庭冻结恢复，返回保留进度，新探索初始化满层，篝火补满。暂停/后台不恢复，0.1×/2×使用既有模拟时钟。原概率dodge独立；主动窗口从resolveHit早退，HP、架势、灰血、痛印、夺血及命中型附加状态不结算。已附着持续伤害仍按原规则处理，不是清除异常的无敌。

普攻进入前摇时锁目标并确定朝向、支付完整攻击周期。独立暗牢出手时检查目标存活、射程、LOS和朝向：保留进入前摇的朝向，目标不可越到该朝向后半平面；失效不退周期。圆形寻找目标不改成锁定或攻击键。出手后可立即移动；独立暗牢普通移动/闪避期间继续冷却。技能/落位/换装的原暂停计时不扩改，塔防/旧庭院保持原节奏。

反馈沿用现有暗青与黄铜个人栏：动作名称、2格储层、下一层倒计时。复用run/move与0.18秒轻残影，减少动态时不显示残影。不新增资产、重写Spine或做AI自主闪避。当前三伙伴资源未提供独立闪避动作时使用上述fallback。

统计：evadeUses、activeEvades、windupsCancelledByMove（含猎人瞬影）、windupsCancelledByEvade、basicAttacksReleased（全场实际普攻出手）；可在独立探索摘要actions读取。数值仍为首轮原型参数，用户试玩后再决定后续阶段。
