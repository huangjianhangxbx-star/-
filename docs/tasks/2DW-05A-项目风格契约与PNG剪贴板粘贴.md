# 2DW-05A 项目风格契约与 PNG 剪贴板粘贴

状态：实现、样本与本地验证已完成；GitHub 发布结果以本轮最终交接的远端 SHA 为准。自动测试、Windows 桌面烟测和样包检查见 [`VALIDATION-2DW05A.md`](../../自制工具/asset_workshop_2d/docs/VALIDATION-2DW05A.md)。依据是用户于 2026-10-10 授权的《星骸 2D 素材任务工坊｜2DW-05A …执行计划 v0.1》和仓库内的[实施计划](../superpowers/plans/2026-10-10-2dw05a-style-clipboard.md)。

## 范围与目标

本轮在独立离线 2D 工坊中增加两层风格数据：长期默认的项目风格契约 `projectStyleContract`，以及只描述本次局部目标的 `taskStyleDelta`。参考图区增加粘贴 PNG 的入口，同时保留“添加 PNG”文件选择。砖块案例用关联对话的两张真实参考图验证任务 ZIP 能分别表达内容位置、局部画法、项目约束和待外部执行的步骤。

改动范围限 `自制工具/asset_workshop_2d/` 和本任务、验证及工程记录。`design/开发细则.md`、`design/用户维护/`、3D 工坊、游戏源码和无关并行修改不在本轮范围内。Unity 默认 100 PPU 未改变；某个具体图块任务的 512×512 四边要求也未被提升为项目通用规则。

## 实际交付

- 核心规格 `1.1.0` 在 `spec/asset-spec.json` 内分别存储项目契约与任务偏移。内置“星骸回廊手绘块面风格”是新任务默认项目契约；用户可在桌面端明确选择空基线、编辑任务专用版本，或显式保存本机项目默认值。新建任务恢复默认契约并清空偏移；复制任务保留当前两层风格。
- 项目契约包含正向规则、禁令、暗/亮层级预算、形状语言、纹理控制和渲染提醒。本次偏移包含焦点、必须保留/改变、局部参考说明、避免事项及可选层级预算。结构化校验拒绝未知字段和越界预算。空契约可以导出，但会标记“无项目基线保护”。冲突提示覆盖预算放宽、空基线，以及偏移中部分明确要求违背项目禁令的措辞；它不是完整的语义或看图判断。局部偏移不能自动覆盖长期约束；疑似矛盾由外部执行端记录、请用户裁定。[字段与优先级说明](../../自制工具/asset_workshop_2d/docs/STYLE-CONTRACT.md)。
- 新任务包使用 `2dw-zip/3`。`spec/asset-spec.json` 是唯一权威规格；新增 `style/project-style-contract.json`、`style/project-style-contract.md`、`style/task-style-delta.md` 是可读镜像。`workflow/` 和 Codex 适配文本要求先核对风格与硬规格，再按参考角色分析、处理冲突、规划制作。旧 `/1`、`/2` 的读取与各自结构仍保留。
- 粘贴入口接受 PNG 位图，以及剪贴板中的本地 PNG 文件 URI 或单个绝对路径。位图先暂存在会话缓存，再与文件选择流程共用 PNG 完整性、尺寸、字节预算和哈希核验；参考项显示缩略图、尺寸、体积，并可修改内容/风格角色与说明。编辑或参考变化使旧预览失效，导出前重新读取原件。会话结束或移除参考时清理受管的位图暂存文件。
- Windows Electron 44 实机烟测已分别用剪贴板 `image/png` 位图与复制文件的 `text/uri-list` 导入 32×24 PNG，界面显示缩略图且参考项可编辑；完整回执由验证记录保存。
- [砖块样本](../../自制工具/asset_workshop_2d/samples/2dw05a/README.md)包含图 2 内容参考、图 1 手改画法风格参考及两层风格约束。其任务只要求重绘图 2 中间大砖，保留周边关系。样本 ZIP 已按 `2dw-zip/3` 解包核对；源 PNG 与包内字节相同。

## 执行与验收边界

工坊只生成规范、可追溯的原始参考 PNG、工作流配方与待执行指令；它没有在本轮调用外部 AI 看图、分析视觉规律或制作目标 PNG。ZIP 中的 `reports/` 路径是未来预期产物，实际包内没有报告或 `output/asset.png`。`style/` 的可读文本也不是已完成的图像观察。

本机项目默认契约保存在工坊 `.cache/asset-task-2d-profile/project-style-contract.json`，不与某次任务偏移混为同一份持久配置。配置损坏或无法读取时，工坊保留原文件，临时回退到内置示例并显示警告。剪贴板路径不下载网络 URL；无效或超预算 PNG 会拒绝并给出错误。自动回归、旧包兼容及本轮桌面实测见[验证记录](../../自制工具/asset_workshop_2d/docs/VALIDATION-2DW05A.md)；保护哈希与 GitHub 推送 SHA 在最终交接核对。用户本人对交互手感与外部 AI 成图效果仍需另行验收。
