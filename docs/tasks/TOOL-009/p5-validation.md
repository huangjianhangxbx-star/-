# P5 多画布与便携源：契约、验证与交接

## 入口
打开模块后左侧顶部「建模画布」。旧资产点「另存为多画布模型」，自动先保存当前修改，再生成新 assetId；原资产仍保留。选择新画布规格后新增，通过画布下拉选择当前编辑层。每层支持命名、复制、顺序、显示、锁定、删除和精确位置；至少保留一层，最多32层。默认仍为点选/刷选。

「位置匹配」依次点当前画布和另一可见画布表面，在 0.03125m tick 网格拾取；Ghost 预览后确认/Enter，Esc取消；源锁定/隐藏时不能操作。另一层半透明显示，右侧显示完整模型。「查看全部画布」把可见层纳入视野。

导出 FBX 包含全部画布（包括编辑时隐藏的层）。同层重叠副本沿用既有可见表面合并；跨画布保留独立命名 Mesh，不作布尔融合，界面明示。

## 数据与兼容
- 新 `xinghai-workshop-asset-2`：canvases 是几何唯一来源；每层 cells/baseCells/voxelCopies/protectedColumns/editor/voxelStepM/originTicks 独立。共享 palette/materialProfile 与 model anchorM。
- 旧外壳 voxelSize/gridStep 固定 .25 仅供历史色板及字段兼容，不用于新几何计算；顶层 cells/protectedColumns 必须为空且不得有副本/编辑参考，校验拒绝双重几何来源。旧 schema 校验保持严格，不能在旧 schema 塞 canvases。
- 画布规格 .25/.125/.0625 m，原点整数 tick=.03125m。编辑引擎在画布整数局部格工作，其他层渲染变换到该参考帧，源文件没有扁平重采样。Root 作为导出偏移，联合场景历史仍维护世界几何位置。
- 编辑会话维护整模型历史（40次/百万格快照预算）；切换画布不修改源，画笔/缩放/复制仅作用当前层。锁定/隐藏层禁止编辑。
- 旧模型自愿另存升级；不自动升级或批量改写。旧 PNG 参考与重叠副本随源画布保存；旧 GLB/FBX 适配器保持独立路径。

## P4 依赖的实现范围
提供 `.xhasset` 便携源导入/导出，JSON 容器携带版本、源字符串、PNG及两项 SHA256；没有压缩目录解包。读取有96MB总量/4MB预览预算、PNG完整性与模型校验；导入总是新 assetId，通过原有受管事务写项目。不替换默认 JSON+PNG 项目存储。导出写临时文件并 fsync 后用排他硬链接发布，不截断已有文件；磁盘不支持硬链接会明确失败。
项目主页和模型画布区都有导入按钮。保留原有超过20000格不生成缩略图的限制；该情况下便携源导出会要求有效已保存预览，不宣称支持大模型预览性能。
