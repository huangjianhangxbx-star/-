# T-020 / EC02 控制与相机参数

适用范围：独立暗牢。塔防与旧庭院保留原选择、领队和镜头行为；EC01数值、地图、敌群与召影规则保持现状。

## 操作

- 出发默认控制猎人；C 在猎人与本次选定伙伴之间切换，1 接管猎人、2 接管伙伴。3/4 不扩展暗牢本体名单。
- 点击在场本体或头像同时接管并查看。复制体只查看，WASD、E、世界技能按钮和镜头仍服务当前主控。
- WASD 控制当前主控；Shift 仅主控猎人可用。H/B 仍为猎人的队伍能力，Q 沿用查看对象的收纳/救援/影体销毁操作。
- 切换时旧 WASD 停止；按住方向切换后需松开再按，避免继承旧按键覆盖新角色正在完成的动作。已提交的鼠标目的地继续执行。
- 战术暂停允许 C/1/2，不推进模拟；瞄准、拖动、经济/退出确认、构筑、背包等独占操作期间拒绝切换并提示先完成或取消。

## 核心交接

`controlledBodyId` 独立于 `selectedBodyId`/前端查看对象。`queryControlBody` 只读检查，`switchControlledBody` 负责交接，`ensureControlledBody` 在命令后及模拟步前后维护生命周期；`controlledBody` 提供只读合法角色查询。

合法对象仅当前双人队伍的 active 非影庭本体。破势或硬直仍可接管，但不会解除其移动锁。濒死、死亡、撤退、复生等待或进入影庭时移交另一本体；无人合法则为 null，恢复一人可重新接管，有合法主控时复生者不抢回。

接管撤销纯 AI approach/Return/follow 路径与局部任务；已开始的攻击、SkillRun、换装、跨层和技能落点继续。切走无命令者以当前位置建锚点；鼠标路径保留至完成并更新锚点；尚在执行生命周期者延后 AI 交接。切换本身不刷新生命、虚血、架势、CD、攻击计时、武器耐久或敌人仇恨。

非战斗主控领队、另一本体自然跟随；沿用软槽位、本体互穿和远距1.15赶队。入战建立当前位置锚点，脱战恢复跟随，均不改变主控；脱战不撤销已提交鼠标路径。

## 镜头与UI

`focus = primary + clampLength((secondary - primary) × 0.35, 3U)`，只考虑另一名 active 非影庭本体。无另一人时跟主控，无主控时保留最后焦点。沿用指数平滑 `1-exp(-8×dt)`；页面启动时读取 prefers-reduced-motion，减少动态模式直接对齐。不改变投影和 zoom。

名单黄铜边框与“◆ 当前操控 / AI”区分角色；详情明确“查看 / 当前操控”。猎人个人区仅在主控猎人时出现，世界技能按钮跟主控。没有新增模型、材质或控制环。

下一阶段尚未实施：闪避、走A、三技能、AI2和仇恨重做。参数可供试玩评估，不代表最终手感验收。
