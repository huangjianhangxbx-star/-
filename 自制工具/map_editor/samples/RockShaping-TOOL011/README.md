# 岩体塑形练习项目

便携程序中使用“打开项目”，选择旁边的 `project` 文件夹。源码检出后在 map_editor 运行 `npm run build` 和 `node scripts/build-rock-sample.mjs` 生成。

这是原创的两个未塑形体块：柱状岩壁24×18×30格、层阶平台32×28×20格，均已作为单个物体归属在独立画布。

进入场景装配，选实例→编辑模块；或从项目资产打开模型。选中物体，在视窗左侧“建模→岩体塑形”选择相应预设。可调参数、种子、影响侧面及保护，右键旋转观察，应用或取消。应用后可一次撤销，保存后可重开继续编辑。

两种形态的较大参考尺寸对比仍在独立原型。工具操作与限制见 `docs/Rock-shaping.md`；练习项目不含第三方截图、生产模型或绘画依赖。
