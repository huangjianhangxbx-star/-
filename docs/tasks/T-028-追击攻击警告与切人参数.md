# T-028 / EC09.5 追击、攻击警告与切人参数

依据：[批准的原始计划](T-028-EC09.5-原始计划.md)。仅 Standalone；EC09 的职业站位、控制权/前台优先、卡牌、复制体、篝火及旧模式仍保留。以下是本轮首轮校准值，工程通过不等于手感已经验收。

## 同行与追击

| 项目 | 行为 |
| --- | --- |
| 非战斗 Follow | 与 DirectActor 距离 ≤2.2U ×1，2.2–3.5U ×1.20，3.5–5.5U ×1.45，>5.5U ×1.70；仍乘重量与 Slow |
| 追赶迟滞 | >3.5U 优先追领队附近 1.2U 落点；≤2.5U 恢复软阵型，远距每 .18 模拟秒重评估 |
| 普通敌人政策 | Standalone melee/ranged/heavy 为 chaser；territorial 保留旧 home 8U 边界，未新增精英或 Boss |
| 感知/追击 | 初次感知 5U + LOS；已追击目标有 LOS 时持续追击，敌人与目标相隔 >18U 才释放，出生点不再硬截断 |
| 失视 | 沿 lastSeen 寻路，连续 4.5 模拟秒未找回目标后 return；附近另一名可见本体仍可成为目标 |
| 动态战术域 | 原活动组圆域 + 活动 chaser 周围 3U + DirectActor 周围 3U；全路径 .15U 检查及 Inactive 5U+.2/LOS 禁入保留 |

Follow 不瞬移，不抢玩家移动、技能、强制位移、Broken 或跨层。敌人 return 仍回 home 后进入巡逻。动态域不是把所有已见过的房间永久打开，也不解除主动拉未交战组的限制。

## Basic、接近节奏与 Ability

| Basic | total / lock |
| --- | --- |
| melee | .22 / .10 秒 |
| ranged | .30 / .14 秒 |
| heavy | .36 / .18 秒 |

Basic 保留内部 AttackIntent、Lock、Geometry、Resolve、Break；不进入世界 Telegraph Renderer，也不作为 AI Emergency Hazard。攻击周期至少 total+.10 秒，保留武器/模板较长周期。

melee/heavy 在 1.8–3.2U、普通攻击可用时，可有横向 Probe 然后 Burst，或直接 Burst。以 enemy identity + Basic attack serial + 地图 seed 确定，Probe .20–.45 秒、Burst .20–.40 秒/×1.45–1.70。横移连续检查墙、层及其他身体；不替换寻路，不穿墙或瞬移。Ability、Reaction、ForcedMotion、stun/Break、return 优先，ranged 不使用。

Ability 原数据未变。最终完整边界始终可见，Tracking 虚线可转，Locked 实线冻结；progress=(time-startedAt)/(resolveAt-startedAt)，Circle 半径、Sector range、Capsule 长度由 origin 向外推进。填充透明度 .08→.38，同时增强红色；Reduced Motion 保留这些传达真实结算进度的信息。

## AI 机动取舍

只 Ability 进入紧急规避，保留 .18 模拟秒观测延迟。能及时到达安全点时先走，走不及时才评估资源机动。实际 HP/架势比例、预计防御/盾后损失、直接 Broken、致死与多个 Area 共同形成确定性评分；阈值 avoid .35、preserve .65（直接 Broken 时 .35）、default .8、rescue .9、aggressive 1.25。实际 Evade/Blink 仍检查 charge、CD、行动锁和完整安全终点/路径。

评分是风险估计，不是完美预测命中的 oracle；不预测未来转向或全路径多次 Resolve。低威胁可以保留资源并受击，机动资源不足也不新增免疫。前台技能不被应急走位抢走，不加入 Manual 技能 AI。

## 伤害数字与判断窗口

普通命中数字消费结算后的 HP loss，包含防御、方向、护盾等结果，0/Miss 不显示普通 0。同目标 + 来源 + cast 在 .12 模拟秒内聚合；没有 cast 的独立命中用事件 ID 区分，不能把不同攻击混成一击。数字使用缓存文本贴图，.65 秒淡出并释放资源，最多保留 128 项；Reduced Motion 固定位置只淡出。Weakpoint 的独立反馈保留。

真正成功的主动 C/1/2/点击其他本体切换，创建 1.5 **真实秒**的 Tactical Switch Focus，时间倍率 .20 经 smoothstep 回到 1。点击当前本体、失败切换、自动死亡移交、重生和 Tower 不触发。暂停、帮助页、隐藏页和退出确认不消耗判断时间。

DirectActor 成功的 WASD/direct、mouse move、Blink 或 Evade 立即取消；失败命令不取消，E/R/T 不自动取消。帧宿主显式传数值 timeScale，与 Build/Card/背包等 .1× Slow 取更慢值；simulationDelta 保留旧 boolean 调用兼容。相机继续用真实 visual dt。节点/副本结束与模式切换清除临时窗口和数字。

## 待用户试玩

建议实测长廊折返同行、近战压迫节奏、成群追击搜索、低血/低架势及不同倾向的机动取舍、切人后使用技能和立即移动。没有启用 EC10 轮盘、EC11 卡牌改造、新敌人、正式 Boss、怪物知识或新瞄准系统。

补充边界：数字读取回收/致死保护后的最终 HP 差值；持续毒伤以同 Status 来源聚合，盾完全抵消不生成普通数字。Probe 转 Burst 立即重评估寻路，成功 Reaction 撤销未完成接近阶段。
