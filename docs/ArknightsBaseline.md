# ArknightsBaseline

## 明日方舟原有规则：本轮可确认范围

发行方说明明确将其定义为即时部署干员阻止敌人突破防线的塔防，站位、角色特征和职业组合会影响战况。来源：[Yostar 官方商店介绍](https://play.google.com/store/apps/details?hl=en_IN&id=com.YoStarJP.Arknights)。
用户提供视频直接展示部署费用、地格高低差、部署方向、方向性范围、自动战斗表现、技能 READY 按钮、顶部敌人计数和速度/暂停控件。具体观察证据见 ReferenceVideo_001.md，不把单段视频当作所有角色的通用规则。

## 本项目准备沿用

斜视角格子战场、部署与朝向预览、路线推进、自动普攻、主动技能、阻挡职责、保护目标及波次胜负、速度/暂停和战斗信息反馈。这些属于设计选择，其中未由本视频单独证明的细则仍由本项目计划决定。

## 本项目准备改变

个人始动替代全局部署费用；不限高台/地面职业部署；部署后可移动且无移动 CD；自动转向与默认方向分离；远程标签决定跨层；猎人动态部署/救援/影庭；濒死与跨节点损耗；失败不回档；卡牌道具装备与逻辑黑暗。
这些规则不借明日方舟名义背书，以用户确认基线为准。

已打开官方全球站，但文本抓取无可用规则正文。发行方商店简介未给出职业部署限制的完整例外、索敌排序、阻挡超额行为、技能充能分类、基地扣血公式、重试结算和撤退再部署完整细节。当前视频也未覆盖完整胜败流程。不猜攻略数值，不把本项目高台遮挡规则误写为明日方舟规则。
