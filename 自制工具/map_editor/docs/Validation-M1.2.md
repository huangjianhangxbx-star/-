# 地图工坊 M1.2：绘制与资产互通

本轮依据：`docs/tasks/TOOL-003-原始计划-v0.1.md`。用户于2026-10-02明确要求读取并执行；本轮不含提交/推送。开发基准main@7ec8a315，实际受测包含本轮未提交源码，不能把旧提交号当作新包版本。

## 新操作

- 方形/圆形面积笔刷1—33格。工作层+厚度+向上/向下生成真实体素；表面工具沿选定六面法线。同笔固定参数，增加保留已有体素颜色，重染只改已有体素。
- 跨受保护三维列的二维绘制/擦除跳过该列，其余落点继续；松手一次提交，撤销整笔。无变化不增加修订。
- 属性只有普通地面、高台、阻挡；普通地面/高台只写在真实外露顶面。旧deploy/ground通过明确另存迁移，不新增独立部署开关。
- 工具区底部“PNG比例参考”可导入、设有效上下界/脚底、输入米坐标、一次性放置及取消。PNG嵌入编辑源，普通绘制不拾取，游戏与模型导出排除。
- “原生资产与模型交换”中拖框选择XY，Z范围由最低/最高层决定；也可选择全部体素。指定局部锚点后保存新资产，生成`.xhasset.json`母版和标准带色GLB，自动登记资产库。
- 重复放置沿用模型模式。修改母版须先“打开原生资产编辑”，然后“更新当前原生资产”；不会把整张地图的世界坐标错当资产局部坐标。更新稳定ID，实例位置保持。
- 地图GLB包含按块地形、共享模型与事件预览、水平PNG贴花；不会导出PNG比例参考、网格与编辑辅助。游戏逻辑仍来自地图JSON，GLB事件节点只是视觉与标识。
- FBX按钮调用已安装Blender，使用独立后台进程，不覆盖原blend、不安装依赖。FBX材料旁车必须随文件一起导入新版团结适配器，保色/方向验证见最终报告。

PNG的9项真实界面检查见`validation/m12/reference/result.json`；包括透明留白、坐标/脚底、参考与绘制隔离、取消、保存/重开及游戏导出剥离。

## 数据与限制

地图继续使用v1兼容源；编辑元数据在`editor`字段。原生资产使用`xinghai-native-asset-1`，共享材质使用`xinghai-palette-1`，区分profile/palette/color身份与修订。旧色保留，重复RGB不合并不同材质族。

单模块25万体素、64色；矩形4096列且总体积预算预检。参考PNG≤32MiB、单边≤8192、总像素≤32Mi；地图保存总量≤64MiB。大图快照仍有成本，不声称长期制作或固定FPS已验收。

GLB仅支持自包含静态模型；骨骼动画、外部依赖及未支持扩展明确报错。Blender原生改网格后作为外部模型回工坊，不保证反体素化。团结目标为既有2022.3.62t13 Built-in；URP/HDRP未验证。

用户操作手感和美术定稿独立于自动验证。
