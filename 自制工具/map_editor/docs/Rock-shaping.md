# 岩体塑形 · 工坊试用

选中一个已合并的体素物体，打开建模视窗左侧 **建模 → 岩体塑形**。多个独立体素先按 Ctrl+J 合为物体；不同画布先按原规则合并画布。也可进入某个物体的编辑模式后打开工具，当前体素选区可作为保护区。

- **柱状岩壁**：适合厚矩形体、厚墙。选择+X/−X/+Y/−Y侧面，调整岩柱宽度、削切深度和竖向断阶。
- **层阶崖岸**：适合平顶、平底、每个XY位置为连续实体的平台；支持矩形、L形和带孔轮廓。只处理完整外缘带，保留中心顶面，内孔不会发起新一圈削切。
- **高级随机**：按结构类别单独输入种子或重抽。0保持默认，与总种子共同决定结果。可保留岩柱布局只换断阶，或保留层高只换边缘轮廓。

滑条以格数为主，同时显示当前画布的米数。预览从打开工具时的原模型重算，不会在拖动参数时累积侵蚀；右键旋转、中键平移仍可使用。查看原形可对照。“应用”一次提交，Ctrl+Z整次恢复，Ctrl+Shift+Z重做。

默认每次打开都保护已有彩绘及当前体素选区。面板显示削除体素、消失/新露表面、受影响绘画面计数。关闭彩绘保护时，真实受影响的笔触会随削切清理，新露面使用基础色；撤销会同时恢复几何、归属和笔触，未受影响绘画保持原样。

Esc、取消、保存、失焦、切换物体/画布/模式或开始其他编辑会清理未应用预览；原模型不变。无有效变化时不能应用。画布锁定/隐藏、单格目标、过期源或不支持的几何会保持模型并说明原因。

当前竖向固定画布局部Z；柱状按轴向外侧首个连续实体段工作，空气/其他物体/保护区域会阻断削切。层阶暂不支持悬挑、上下重叠层或变底平台，已塑形成不同列高的崖岸也不能直接再次当平顶输入。局部面点选、部分岸段和任意高度轴尚未实现；侧面快捷项及完整外缘带可用。首版只削不增，保留厚度和原始连通关系。

应用结果沿现有原生资产保存、便携源、GLB/FBX+PNG流程；不会另建资产、改变Root或重采样精度。需要先确认预览，再保存。包内 `示例/岩体塑形/project` 提供两个原创练习体块。

这是工坊试用接入，实际建模手感待用户Gate R-B。没有引入真实侵蚀、洞穴/碎石生成或自动玩法通路保证。
