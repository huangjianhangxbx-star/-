# 星骸 Spine 动画工坊

默认打开 Spine → Spine：选择来源和目标 .spine，自动分析对应骨骼，先看目标新增动画的草稿，边修改映射边刷新。满意后确认迁移，再在 Spine 中完成动画导入并继续改键。GLB 模式仍可从右上角进入。

## 0.2.4 的使用流程

1. 本机安装并授权 Spine 4.3.26，保留工程原有图片目录。点“载入源 .spine”“载入目标 .spine”；旧 JSON 输入也兼容，多骨架工程会提示选择骨架。
2. 选择来源动画。工坊自动采样并建立可靠对应，默认“身体骨骼优先”，生成右侧新增动画草稿。胸、头、手脚等骨骼对上即可先试；没有映射的头发衣服不写入新键，保持目标原绑定，仍会随父骨运动。
3. 两侧用同一时间轴播放、暂停、拖动和逐帧查看。未匹配、重复目标、附件拓扑不同等只略过相关通道，报告说明原因，其他身体动作正常预览。空映射也能显示空动画草稿，界面会明确显示尚无可迁移通道。
4. 在对象映射中修改源/目标、驱动或选择“不迁移”。“定位”会标出两侧骨骼；更多未匹配骨骼默认收起，需要时补充。可添加当前动作的局部旋转/平移修正。默认修改后自动刷新，也能关闭自动刷新后手动点“刷新预览”。过期预览不能确认，最新预览完成后恢复确认。
5. 新增动画是默认操作，填写名称即可。重名会自动编号，反复刷新以原目标为基础重算同一条工坊草稿，不会不断增加动画。若已在 Spine 新建并保存空动画，重新载入后，可在“动画目的地”选择该空动画。只有没有任何内容的动画才出现在列表中，零秒但已有关键帧的动画不会当作空动画。
6. 满意后点“确认迁移到 Spine”。无需为预览先选输出文件夹；首次确认时再选择完整工程的保存位置，也可提前更改。工坊准备可编辑的完整目标工程副本，自动打开 Spine，并准备本次动画的导入来源。
7. 在 Spine 菜单选择 Import Project / 导入项目 → Animation / 动画，点工坊“复制导入文件地址”后粘贴，选择提示的骨架和动画，确认导入并保存。默认新增；如果工坊选择了已有空动画，则按提示勾选 Replace existing animations / 替换现有动画，将内容填入该空动画。
8. 回工坊点“校验导回结果”。通过后使用界面中目标完整工程地址，继续在 Spine 修改动画。可保存映射配置，下次载入同一角色对复用。

确认前所有试调都在工坊内。确认后的最终文件位于 target-project 中，是完整 .spine 工程。_internal/animation.spine 是自动准备的导入载体，不是最终交付的单动画工程；无需手动导出 JSON 或解包。当前官方接口仍需用户在 Spine 确认这一次动画导入，工坊不会把“已准备”标成“已导入”。

## 草稿怎样处理不兼容内容

默认只尝试已映射骨骼，槽、网格 deform、层序、事件和来源约束不要求对应。需要时切到“全部已映射通道”再尝试这些内容；不兼容的通道仍略过。默认范围不是自动识别所有人体语义，若误把装饰骨映射进去，可在该行选择“不迁移”或删掉对应。

目标 IK 可能覆盖胳膊/腿的 FK 键。草稿会为实际采用的 FK 骨链在本次新动画中加入零时刻 IK mix=0，且保留目标骨架设置和旧动画。报告会列出被关闭的 IK，供最终在 Spine 里调手脚轨迹。这一步保证草稿能显示已迁移的骨骼键，不等于自动生成自然运动。

未兼容内容不阻止预览或确认；每份报告区分已迁移、需调整和略过。损坏工程、缺失贴图、非法时间和未实现的精确裁切仍需修正，不能生成具有错误时间范围的预览。当前完整动作保留原关键时间/曲线，并支持局部数值修正；没有实现通用世界轨迹重定向或不同拓扑网格的转换。

## 自动采样和目录记忆

采样与匹配在本机运行，不调用网络服务，不上传角色。Spine 首次授权、安装或版本下载另依赖官方启动器。runtime 在完整动作上取 25 帧，零时长取 1 帧；运动幅度用于审阅排序，匹配依据名称、侧别、父链、设置姿势的归一化位置与长度。唯一名称和严格单一子链的高分对应可自动加入，模糊分支保留候选，评分不是正确率。

rhiny → rozeul 内置历史人工校准对应，只有两端骨架指纹与皮肤一致才复用，界面说明来源；不套用旧动作的跳过策略或修正。已有配置、人工映射保留。方向仅为可选备注，不转换角色视角。

来源 .spine、目标 .spine、GLB、配置和保存位置分别记住最近确认目录，退出重开及换便携包仍保留。取消不清空；旧目录丢失时回到存在的上级目录。打开/保存映射配置共用配置目录。

## 验证与源码
