# 工坊集合、根设置与临时物体画笔

2026-11-01，用户明确要求执行本轮交互修正；框选问题已说明符合编辑模式预期，移出本轮。

## 目标与约束

- “根设置”直接位于模型制作上方左半边，替换“资产定位”；模型管理与导出分开。
- 集合只组织物体：成员可以单独点选，点标题可选整组；Ctrl+J 才合并体素归属。
- 集合与子元素有明确缩进和图标。解散仅在集合右键菜单，保留成员和几何。
- 右键物体可设为临时画笔，界面明确显示来源名称；随时替换或恢复体素格。
- 画笔快照保留源形状、精度、颜色与绘图；落笔生成独立物体，不能暗中覆盖其他物体。
- 临时状态不写入资产文档；切换资产清理状态，项目与历史数据继续兼容。
- 后台/隔离测试，不修改用户正在编辑的模型，不操作现有桌面窗口。

## 实施顺序

1. 为集合成员选择、根设置入口位置、物体快照/落笔及撤销补回归测试，先观察失败。
2. 调整 WorkshopShell 的入口名称与左侧布局，保留原有根点行为。
3. ModelObjectTools 取消成员点选的自动集合扩展，增加分层树和右键菜单。
4. 核心 captureTemporaryObjectBrush / stampTemporaryObjectBrush 以画布 tick 保存坐标；CanvasSession 负责单次提交与历史。
5. renderer 提供临时画笔预览与左键落笔，右键点按选物体菜单与旋转拖动分开；顶部状态支持恢复体素格。
6. 执行核心回归、类型检查和构建；用隔离后台工坊检查成员单选/整组选取、解散、入口及画笔替换/恢复/落笔/撤销。
7. 更新工具文档与任务验证记录；仅提交本轮源码、测试和记录，不纳入私人参考图或用户模型。

## 模块边界

- `workshop-shell.ts/.css`：名称和布局。
- `model-object-tools.ts` 与树样式：选择和菜单、临时画笔状态 UI。
- `core/temporary-object-brush.ts`：独立快照和无损落笔计划。
- `core/workshop-canvases.ts`：历史和画布提交。
- `renderer.ts` 与 `temporary-object-brush-tool.ts`：视口坐标、预览、输入路由。

本件由现有交互的明确修正需求推进，不改变正式游戏设计规则或图片先行 Skill。
