# 工坊轴向操作与双视口实施计划

2026-11-01；用户直接要求改进既有工坊，并确认粘贴应按鼠标拖动锁定最近 X/Y/Z 轴，只移动、不旋转。沿用后台开发和独立隐藏测试，不操作当前窗口或用户项目。

## 行为约定

- 场景试摆显示与模型制作相同的方向导航，上下/前后/左右均可切正交视角。
- 体素粘贴从复制源位置开始，鼠标越过小门槛后按投影方向选择最近轴，直到该次放置完成均保持该轴。左键完成当前位移，Esc 忽略预览偏移、原位完成并选中新副本。右/中键视角操作不隐式改变粘贴位置。
- Shift 拖动进入直线建模，搭积木从起笔面沿最近切向轴连续延伸，保持另外两坐标和起笔面；松 Shift 回到正常建模，单次按住鼠标的操作仍一次撤销。
- 双视口右侧可选择当前模型或项目试摆场景；场景只读，复用已有 WebGL 视口，编辑和场景数据互不写入。
- 建模模式菜单显示图标与文字；默认表面搭积木，用户主动选择的模式会被记住。刷新、物体/编辑切换、恢复体素笔、新画布不擅自恢复三维。

## 边界与分工

1. `core/axis-line-stroke.ts`：公共屏幕投影轴锁定与直线格点；先测试再实现。
2. `renderer.ts`：粘贴与 Shift 输入接入、预览场景桥接；保留 Esc 与副本历史修复。
3. `renderer.ts` 的模式状态局部、`tool-icons.ts` 和样式：默认/记忆/菜单图标，独立隐藏回归。
4. 场景 view、`workshop-shell.ts`、`workshop.ts` 与独立预览模块：导航和右视口场景，资源释放/更新和选择验证。
