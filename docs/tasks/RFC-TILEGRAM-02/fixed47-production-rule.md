# 固定47槽位绘制规范 v1

用户纠正目标：需要一份永恒固定的模板，逐格对应原始47张素材；不需要组合变体或绘画教程。之前A/B/C、20格局部观察和单画布组合提案不满足这一要求，不作为本规范。

## 固定规矩

- 对当前已核对的目标墙族，固定槽1..47绑定原素材索引1..47。排列8列×6行，从左到右、从上到下，第48槽不输出。源数组索引0未被该47态映射使用，不混入47张。源索引绑定来自本机实际数据，不由素材名字猜测。
- 画布3072×3072px，每容器384×512px；原片左上对齐，实际输出矩形保留各片原宽高。余量不输出，不能拉伸填满或在此处绘制有效内容。
- 绘画底板、原图参照板和刀线层完全同坐标。每格绘制一张完整替换片，不拆接角、不组合前板、不任意旋转或移动格子。
- 每格永久绑定相应连接状态。点格子看八邻条件与同格原图；邻域有墙/无墙决定收口和连接，不能任选变体。墙沿、前面板和内凹位置以真实原片为参照，各格共边及高度需协调。黑色不自动视为透明，空状态不因缺少可见墙沿而删除。
- 保存隐藏参照与刀线后的自己的PNG，必须保持整个画布尺寸。程序直接裁47矩形，逐片保留原PPU/Pivot、原索引和状态绑定；不改为100PPU。
- v1以contractSha256冻结，已有文件遇到定义变化会拒绝覆盖。同一绑定下更换画风不改变格位；改变墙族、尺寸或绑定另立版本，不能无声修改v1。

## 验证和边界

冻结顺序不随输入数组顺序改变；缺项、重复、错尺寸拒绝。14项模块测试通过。浏览器47格逐一索引匹配，载入作品/指定像素直接进入第08输出片；ZIP CRC、47PNG数量、逐片原尺寸/PPU/Pivot核对通过。153受保护输入SHA未变；旧观察页12项浏览器回归通过。
