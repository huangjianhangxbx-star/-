# EQ-01 v0.2 · 冻结试玩合同

2026-10-11。用户明确新增可装备的左手炸弹；装盾才能举盾及 Hunter E 需盾是本轮推荐 **SAMPLE**，待试玩，不登记为永久设计。原作动态消费者、正式道具定义不因此闭合。

## 权威与实例
正式 standalone 的 hunter/ranger 各有 `equipment.equipped.right/left`；右手引用原武器对象，职业与普攻周期读取 mainWeapon，旧索引只保留兼容桥。旧主武器合法损坏回退仍把同职业影武器接为右手，绝非左手。原生黄金 LMB 原先没有新增耐久消费者，本轮保留其既有行为；不凭空新设普攻损耗。

world-1:hunter:right:golden / world-1:hunter:left:guard / world-1:hunter:left:bomb；阿尔使用 ranger 对应的 right:golden / left:shot / left:bomb。下一世界以实际 world id 生成；同世界不重建。只有所属角色的已拥有副手可装，存活、battle、explorationIdle 且动作结束才可切；交战/举盾/盾冲/射击/投弹前摇/失衡等拒绝。无跨人物互转或免费维修。

每人默认盾/射击器和候选炸弹独立耐久100。成功方向格挡同一开盾动作最多磨损1；射击器真实 Hit/Release磨损1；炸弹真实Release磨损1。独立单调wear token不依赖可关闭trace，0耐久不能接受动作；最后一次合法格挡耗尽盾后解除旧举盾。主武器原损耗不受左手影响。migrationLoad保留接手构筑总负重，不新增候选负重或重平衡。

## 玩法与事务（全部炸弹参数 SAMPLE）
- 原盾RMB和盾冲E保留原Clip/窗口/成本；换炸弹时旧核心guard/E拒绝且无付款，E灰显并提示需可用盾。
- 原射击器RMB四发、Hit .0333扣枪弹、.5333动作及原装弹保持；换炸弹不扣枪弹，阿尔E原火箭保留。
- 炸弹RMB一次物理down：合法才Accept，CB唯一账本扣20、登记CD5；持键过CD不重投，松开再按才新请求。无背包弹数/制作消耗。
- 有效落点、4.5射程、同空间可见路径；墙/非法点拒绝，不截断、不吸敌、不改成隐形目标。Accept缓存原位置、落点、source、instance、上下文、45基础HP及25架势。
- Accept后 .05模拟秒Release，磨损1并生成一颗实际在途实体；Release之前取消不退款但不磨损。Release后 .45模拟秒飞行；抛物线仅显示。落地半径1.25，主resolveHit逐合法敌人最多一次，同一attackEvent；实际护甲/架势/奖励继续主链。友方不命中。
- CD仅存活且主控时推进。Z后已Release实体可完成且仍归原source，未Release取消；离手CD冻结。死亡/全灭/区域卸载清派生，复活/同世界继续保留gear/耐久/CD/接受序号。暂停/面板/离区不推进模拟钟。失焦/死亡epoch/暂停/G/F/modal清持键；不得转发旧物理按键。
