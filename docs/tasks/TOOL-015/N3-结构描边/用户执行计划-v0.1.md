## 3. 用户流程与界面

### 3.1 正常流程

打开资产的贴图窗口 → 选择绘画目标 → 自动处理/结构描边 → 确认作用域 → 选择预设、颜色、宽度 → 旋转查看预览 → 应用 → 在图层列表查看、擦除或隐藏结果 → 保存项目/导出。

不能要求用户去 UV 窗口选边；不能先导出 Blender，再手工处理后导回才能完成。

### 3.2 参数区建议

使用现有右侧工具区的专用页或折叠区；不新增遮住模型的大模态浮框，不重做整个工坊外壳。

```text

目标：入口主体 / 画布 4 / 0.25 m
范围：当前目标全部表面 ▾

预设：侧面上沿 / 顶面内描边 / 顶面+侧面 / 通用凸棱
几何判断：完整资产（默认） / 独立目标（明确提示）

接收面方向：按预设；高级可筛选六个方向

图层位置：手绘下方（保护） / 置顶生成
```

仅显示当前预设有关的参数。“指定颜色”使用既有色轮/HEX；点“取当前画笔色”只是复制颜色，之后改主画笔色不应悄悄改变已冻结的描边预览。

### 3.3 预览所有权

进入工具前结束或取消当前笔画/粘贴草稿，排空已结束笔触队列；失败队列先由用户重试或放弃，不得绕过。

## 4. 边缘与作用域的确定语义

### 4.1 必须区分三个集合

- **判断几何：**用来判断是否相接、是否外露、是否真实转折的体素实体；可以包含只读的其他物体/画布。
- **可写目标：**当前绘画租约允许写的物体、画布及其原生表面；其他物体只参与判断，不因此获得写权限。
- **用户掩码：**贴图选区/面方向对结果的进一步限制；不是边缘来源。

先在完整判断几何中识别结构，再裁到可写目标和掩码。不得先删去选区外几何，再把选区裁切边当作模型外轮廓。

### 4.2 真边与假边

| 场景 | 期望 |
|---|---|
| 一块平顶由多个体素/不同颜色组成 | 顶面内部不描小方格，不沿色差接缝描 |
| 网格合面或三角形划分改变 | 结果不变，不依赖渲染面序号 |
| 真正的顶面→外侧壁、阶梯落差 | 能识别并生成对应边带 |
| 侧面中间的上下两层体素共面 | 不在接格处重复生成水平条纹 |
| 环形平台/门洞的空洞边缘 | 有实体承载的真实凸棱可处理；不跨空洞向后墙投射 |
| 凹角底部、墙与地面接合 | 首版凸棱模式排除凹棱，不误变成全部黑缝 |
| 两物体/两画布共面紧密接合 | 默认完整资产判断下不描假的接缝 |
| UV 分块、手绘图层边界、矩形选区边界 | 都不是模型结构边 |
| 只在镜头方向下出现的轮廓 | 不作为自动源；旋转相机不改变已算结果 |

### 4.3 两个参考预设和通用模式

**侧面上沿：**识别 +Z 顶面与轴向侧面之间的凸边；接收面为侧面，从该边向 −Z 延伸。宽度跨过相邻共面体素面时连续，不在每格重新起一条带；遇到侧面终止/台阶转折停止，不绕到下方地面。

**顶面内描边：**使用相同的顶缘，但只在 +Z 接收面向实体顶面内部铺色；洞口边缘按照同样的真实几何判断处理。相邻条带相交时取并集，不重复压暗。

**顶面+侧面：**分别运行两种接收规则；两种颜色与宽度独立，分别生成可编辑层，一次应用一起撤销。

**通用凸棱：**用于墙体竖边、柱子和其他六向轴面转折。默认向凸棱相邻的合法接收面内铺色，可以筛选接收面朝向。不是只有 +Z 顶缘才叫模型边缘；但首版不处理任意曲面法线阈值或凹棱。

### 4.4 多画布和邻接

默认“完整资产”读取同一模型内所有原生画布几何（包括隐藏/锁定），与现有“隐藏画布仍参与导出”语义一致；被隐藏的目标本身仍不可写。辅助参考图、选区框、操作轴、视口地面网格不参与判断。

“独立目标”是作者明确选择的隔离语义：其他物体不参与接触判断，可能显露原本的接触边；面板须提示，不能在计算失败时自动切到此模式。

不同精度/非零原点的邻接必须以统一作者空间处理，至少覆盖平齐接合、上下遮盖、T 形接合和部分覆盖。**只读分析可以细分边段/面矩形，不能把原资产重采样成统一体素尺寸。**

完全重合且归属不唯一的复杂表面、非流形对角接触或超过分析预算时，标出无法可靠处理的范围并阻止对应应用；不得在不提示的情况下生成接缝。简单多精度拼接是必测项，不能全部以“不支持多画布”回避。

### 4.5 选区和对称

默认整个当前目标，明确包含其背向相机但几何外露的表面；这不是普通画笔穿透。

选择“当前贴图选区”后，空选区表示零范围并禁用应用，不回退全部物体；只写掩码内的像素。若选区只有顶面而预设只写侧面，提示无接收范围，不擅自扩展到侧面。

结构描边不自动继承画笔镜像开关。它已经遍历目标的合法边缘，不应再额外镜像一遍；选择局部范围时也不能因此越界复制到另一侧。

## 5. 宽度与颜色

### 5.1 尺寸

主单位为整数贴图像素，界面显示 `宽度米 = widthPx / 64`。本轮建议 1–64 px，独立于手工笔刷原来的尺寸范围；预算不允许时明确拒绝，不截掉一部分。

| 体素边长 | 单个体素面宽 | 2 px 色带的实际宽度 |
|---|---:|---:|
| 0.25 m | 16 px | 0.03125 m |
| 0.125 m | 8 px | 0.03125 m |
| 0.0625 m | 4 px | 0.03125 m |

不要把 2 px 解释为 2 体素格；不要改变画布尺寸或贴图密度。窄小面可能被边带铺满，预览应如实显示，不为避免“太粗”秘密缩小宽度。

条带为硬边栅格，不新增抗锯齿、渐变 alpha 或模糊。拐角采用可预测的方角/并集，凹口裁剪，不产生超长尖角或同格多次着色。

### 5.2 指定颜色

取用户选定的合法 `#RRGGBB` 作为生成层源像素色。不是固定黑线，也不是只能调明暗强度。

既有 `faceTone` 和视口光照继续按现有规则合成。输入色不保证在受光视口每个角度都以相同屏幕 RGB 出现；当作者设置“暗面影响手绘”时，普通生成层同样会受其影响。

必须显示相关提示，不得为“颜色看起来一样”偷偷清除 faceTone、换底色或把生成层当发光材质。测试在无 faceTone 的原色样本中核验精确源色与 PNG；有 faceTone 时核验现有合成公式只执行一次。

### 5.3 相对底色压暗

作为另一种可选颜色模式，取冻结源的体素 `color`/合法 `sideColor` 对应原始底色，在现有线性颜色工具基础上施加相对增益，再编码为绘画像素。

不得采样屏幕受光色、现有生成层或不断变化的最终合成色；每次参数预览从同一冻结底色计算，避免累积压黑。既有按面暗面最后仍按普通绘画合成规则处理，不在生成器内重复烘一次。

## 6. 生成层、保护手绘与重新生成

### 6.1 复用当前原稿格式

使用当前 `SurfacePaint.layers` 的普通不透明 `PaintLayer`，不建立新材质通道、不把描边存成 viewport preference。

新建名称建议 `结构描边 · 侧边`、`结构描边 · 顶面`、`结构描边 · 凸棱`；真实身份必须是唯一 layer ID，不能按名字查找并覆盖用户同名图层。

只有应用成功才进行旧单层格式的按需迁移；预览/取消不产生空层或修改源格式。生成两层、写入像素、更新可见合成，属于一个主会话原子命令。

### 6.2 默认保护手绘

默认将生成层放在已有绘图层下方、模型底色上方。已有层内容、层序关系、显隐和锁定保持不变。已有不透明手绘会遮住下面的边带；这是保护规则，不是生成失败。

提示有多少候选像素被上层手绘遮盖（可按脏区域统计），并允许显式选择“置顶生成”。置顶也不改手绘原稿，只改变叠加结果；不得解锁、清空或合并用户层。

选区仍严格限制生成写入，不因为“放在下方”就写满整个画布。

### 6.3 调参不累积，替换不误删

在一次工具会话中记住本次新建的 layer IDs、来源几何/范围、生成原稿摘要。再次“调整本次结果”时替换这一组生成内容；缩小宽度时必须移除旧的多余像素，而不是只加新像素。

相同参数、同一源重复应用应无变化或禁用按钮，不多建重复层、不增加无意义历史。明确点击“新建一组”才允许生成另一个结果。

如果该层被手绘、粘贴、排序合并、删除、锁定等改变过：不能继续当成安全缓存直接覆盖。提示新建一组／明确替换／返回；默认保留已有内容。替换共享层时尤其不能清掉其他物体或画布的像素。

### 6.4 重要边界：本轮是一次性作者工具，不是实时修改器

旧 TOOL-015 N3 对“独立参数+派生缓存”的描述是架构建议。针对现在已经实际加入的图层，本计划改为**普通图层保存像素，生成会话负责预览与安全替换**，不再为此引入第二套持久化叠层结构。

关闭窗口后像素、层名、显隐、手修内容完整保存；不承诺从 PNG 或普通层反推出原始算法参数。常用参数可作为本机偏好记忆，但不是原稿权威来源。

重新打开时默认新建；显式选择已有层替换必须说明清除范围并确认，不能仅因名称含“结构描边”就自动认领。界面始终说明“已生成像素；修改造型后需重新生成”。

本次会话几何指纹变化立即使旧预览失效。离开绘画后，移动/旋转/复制等沿用既有普通绘画的坐标映射；增删体素不会自动生成新边带。不得声称已提供持续跟随几何的非破坏修改器。

若后续确实需要可跨机器重开调参、自动标记/重算过期边带，再专项扩展版本化生成元数据及所有复制/变换映射；本包不以隐藏 sidecar、无验证私有字段临时实现。

## 7. 核心算法建议

以下是可落地的推荐算法与测试合同，不是仓库已有 API。执行者可换等价实现，但必须满足相同输出与边界条件。

### 7.1 坐标与索引

统一在作者空间处理，保留 `face` 的既有六方向编码、每面 UV 轴序及负坐标 floor 规则。

当前原点 tick 是 1/32 m，贴图网格是 1/64 m，可选用 1/64 m 整数单位：`globalTexel = 2 * originTicks + localCell * (voxelStepM * 64)`。它只用于分析，不修改模型存储。

对象的成员 keys 建立 Set；画布 cells 建立占用索引；跨画布查询先按空间块/AABB 粗筛。不得每条边/每个像素重新 `filter(...includes(...))` 扫整个资产。

### 7.2 外露表面与边段

从原生体素占用获取外露面，不从 `EdgesGeometry`、贪心合并 quad 的序号或贴图岛取得权威边界。

同画布邻格占用可直接查询；跨画布按统一坐标求相接/覆盖的面区域。出现不同格尺寸时，在相关面/边局部细分到邻接断点，不能把整块模型膨胀成最小体素阵列。

为候选轴向边建立标准化标识（边方向、固定坐标、半开区间端点）；需要时在邻接端点分割长边，使 T 接合与不同精度的短边能与长边匹配。

### 7.3 凸棱分类

对一条基本轴向边段，在垂直于边的截面上查询四个相邻空间扇区的实体占用：

| 占用 | 分类 |
|---|---|
| 1 个扇区有实体 | 凸棱候选，继续检查接收面和所有者 |
| 2 个相邻扇区有实体 | 平直连续表面，不描 |
| 3 个扇区有实体 | 凹棱；本轮默认排除 |
| 0 或 4 个扇区有实体 | 非外露结构边，不描 |
| 2 个对角扇区有实体 | 非流形/接触歧义；诊断，不任意连接轮廓 |

对分段后的连续区间处理，不靠浮点 epsilon 随机偏移猜哪一侧。接收面法线与实体内部方向必须一起确定，避免把顶面内描边生成到外部空气。

本轮针对轴向体素面，无需给用户一个无实际意义的连续“法线夹角阈值”滑条。

### 7.4 从边生成像素带

将边段映射到接收面的二维全局贴图坐标，向该面的实体区域生成 widthPx 行/列候选像素。像素中心到边的距离用一致规则，1 px 恰好一行，宽度不随观察角度变化。

沿相邻共面小面连续延展；遇到几何转折、空洞、无实体或非目标归属，停止或裁剪，不绕到另一个平面，除非它本来也是另一条合法凸棱的接收面。

同一接收像素由多个边生成时按 `(canvasId, faceKey, texelIndex)` 去重；颜色不累乘，内部边角不出现加深结块。先 union，再裁 scope/mask，最后写颜色。

不要先枚举整个顶面的所有像素再寻找细边；优先围绕识别出的边生成有限窄条，并在扩展前检查预算。复杂覆盖可以按行区间或稀疏块表示。

### 7.5 可验证的输出

拟定纯计划器输出应至少包含：源/目标身份与版本、规范化参数、拓扑诊断、结果层的稀疏 faces、触及的 face keys、像素/层数预算及需要替换的精确范围。

相同输入应得到确定结果；排序只为稳定比较，不改变图层上下关系。输入与原图层对象应保持不可变，取消后能证明原稿字节或规范化内容未变化。

## 8. 主会话、历史与计算生命周期

### 8.1 不用两个普通命令拼成“假原子操作”

当前新增 layer 与绘画是分开的命令。若先建层再逐笔填色，失败会留下空层、多次 Undo 或半成品，不能满足本包要求。

建议在现有租约协议中加入一个**严格限域的复合命令**（名称如 `outline`，仅拟定）：由参数、目标、范围与替换预条件驱动，主会话生成/核验计划，全部通过后一次提交一组普通绘图层。

不得新增“执行任意函数”“覆盖任意 model”“放行任意 layer JSON”的通用 IPC。主窗口仍唯一拥有作者源、历史和文件保存。

### 8.2 权威校验

主端必须验证 sender/本地窗口、协议版本、lease、commandId、baseRevision、当前 object/canvas、读写锁、颜色/宽度/枚举、掩码合法性、目标层身份及替换摘要。

仅比较可见合成 faces 不够：隐藏图层原稿也需保护，不能把越权像素藏在隐藏层里。必须断言非目标物体像素、已有层原稿、几何、底色、faceTone、Root 与原点未被非法修改。

完整结果通过既有原稿/完整资产预算；组合生成需要 2 个层位时，不能只创建第 1 层就报成功。超预算整次拒绝，不自动裁短轮廓、降低分辨率或丢弃隐藏层。

### 8.3 冻结源和队列

开始计算前等待普通队列 drain；计算期保持模型写入所有权和冻结版本。不允许一边手绘同一层、一边靠过期预览覆盖回去。

每次参数变化分配 job generation/cancel token，旧任务晚到不得覆盖新任务。取消丢弃临时结果，不提交部分像素；应用后等待确认时保留结果预览。

应用成功一次 revision/一次历史项（无变化不提交）；ACK 丢失按同 commandId 同内容重试，不重复创建层。保存、撤销、切目标和返回建模仍按现有队列顺序处理。

发送后、主端已经提交的操作不能宣称被 Esc 撤回；收到回执后可一次撤销。关闭窗口保留已确认结果，失败清楚提示，不把等待确认当已保存。

### 8.4 显示更新

纯生成层提交应携带合法 paint 类型更新，继续使用 `paintOnly` 快路径，不重建模型网格/owner 查询域。只更新合成变化的纹理面；生成层被上层完全遮盖时，允许没有纹理上传但仍正确记录原稿。

相机、光照、布局变化只重绘视图，不重跑边缘识别。关工具清理临时掩码/辅助线；不能遗留监听器、worker 或逐帧扫描。

## 9. 性能保护

### 9.1 分级失效

| 改动 | 应重新做的工作 | 不应重复做 |
|---|---|---|
| 镜头、灯光、窗口大小 | 视口重绘 | 几何边识别、作者写入 |
| 指定色/压暗强度 | 当前候选像素着色、脏面预览 | 全模型边界扫描 |
| 宽度/接收面方向 | 复用边集生成覆盖带 | 重新建模或全场景 raycast |
| 掩码变化 | 重裁已有候选或重算局部覆盖 | 把掩码边界当几何边 |
| 目标/画布/几何判断模式变化 | 重建必要几何上下文 | 直接沿用过期结果 |
| 真实几何/原点/归属改变 | 失效边集和派生覆盖 | 基于总 revision 无差别每笔重建 |

### 9.2 预算与响应

识别是批量几何运算，不应对每个候选像素再次走普通鼠标拾取；几何外露与相机可见性是两种概念。本功能默认不依赖相机，因此不需要逐像素相机 raycast。

大任务合作式分片或 worker 运行；推荐单片主线程工作不持续超过一帧量级，提供处理状态和 Esc 取消。具体调度数值在 E0 测试机记录，不能用每帧刷新整个模型冒充分片。

复用 SurfacePaintLayer 的持久纹理/材质/几何，更新变化面；对每面 canvas 更新可能上传整张小纹理，不声称只上传单像素。颜色预览更新合并到每显示帧一次，应用/取消/确认边界允许完整 flush。

新增缓存必须有上限并随目标/资产关闭释放。跨画布分析设置面片/边段预算，先预检；不可一次分配覆盖全世界包围盒的密集数组。

### 9.3 定向对比

使用当前优化版本与 N3 新版的真实可见 EXE、同机器、同窗口/DPR、同模型副本、同相机/光照对比。旧报告是参考，不是本轮成绩。

至少覆盖：中型门洞、三层阶梯岩台、已有大量手绘的多精度组合。记录格数、原稿像素/面数、生成边数/像素、识别时间、调色更新时间、应用确认耗时、最大主线程任务与资源计数。

建议每例预热一次、重复三次并逐次记值；少量样本不标成可靠 p95。普通画笔/选区/对称至少做一组同条件前后对比，不能通过关闭旧质量设置、美化平均 FPS 或换小模型掩盖退化。

硬性结构指标：稳定几何下改颜色的边识别重跑次数为 0；纯 paint 应用的模型网格重建次数为 0；取消写入次数为 0；重复修改同批面后资源不线性增长。

## 10. E0–E7 实施包

### E0｜基线与样例

核对本地 dirty、最新 HEAD、适用 AGENTS、TOOL-015 图层/性能交接和正式包指纹。原版完整保留，不覆盖用户唯一可用 EXE。

建立隔离样例：平板、两级/三级台阶、环形平台、门洞与后墙、凸/凹角、小跨度侧壁、不同物体接合、三精度混合。用户生产资产只能读后复制到测试目录，不直接改原件。

给出需求→实际入口→测试对应表。复用 `paint-performance.ts` 的合适测量点，不启用永久高频日志。确认当前无 N3 实现；若远端已有同功能，基于差异补齐，不平行造第二个工具。

### E1｜只读边缘识别器

建立完整几何与可写 owner 两层索引、整型坐标、外露面/边段分割和凸棱分类。先写纯逻辑测试，再展示诊断边。

判据：大平板内部无格线；颜色、渲染合面和相机改变不影响结果；接触边正确消除；不同精度/非零原点能判断简单邻接；凹棱/歧义分开报告。此阶段不视为整个 N3 完成。

### E2｜覆盖带与颜色

实现侧面上沿、顶面内描边、组合与通用凸棱；宽度跨小面连续；裁接收面和选区；指定色与相对底色压暗；完整预算预检。

判据：1/2/4 px 宽度和三精度物理尺寸准确；边角去重，空洞不写；深侧壁不是每格一条；通用凸棱能处理墙块竖边。

### E3｜正式窗口预览

在贴图窗口接入可发现的“自动处理→结构描边”，参数分组，范围/接收面可读，原始/结果/诊断切换，真实着色预览和取消。

判据：相机/灯光变化保留草稿；旧计算不覆盖新参数；窄窗口操作区不遮挡模型；空选区、不合法目标和无边结果有明确反馈，不用假按钮或测试页交付。

### E4｜图层事务与主端防护

实现有限复合命令、原稿预检、一次新增/替换一组图层、保护手绘、同次结果安全替换、队列与 ACK 幂等、失败原子回滚。

判据：一次 Undo 恢复原图层和像素；取消/超预算/过期/锁定零写入；保存失败可恢复；隐藏层越权数据被拒绝；既有图层和其他 owner 不被改。

### E5｜保存、变换与导出

验证源与 `.xhasset` 便携包保留生成层；新旧单层原稿可读；复制、物体移动/90°旋转、画布/场景合法合并等沿用当前映射且不丢颜色。几何改变后的“普通像素、需重新生成”边界明确。

通过既有 GLB/FBX+PNG 发布链路；实际 Blender 回读纹理、UV、指定色、各面方向。不要只检查 FBX 文件存在或大小。描边可能使导出面按材质细分，允许表达所需的网格划分变化，但作者体素与世界几何形状不得改变。

### E6｜性能与定向回归

完成第 9 节比较；普通画笔、形状、贴图/建模对称、图层合并、复制粘贴与当前租约生命周期不回退。对受影响模块采用 B 级验证，必要时扩大真实影响范围，不重跑无关游戏/Spine/二维工坊全集。

若确认/导出有已知慢项，保留真实数据与原因；不能通过删范围、关闭遮挡判断、降精度/预算、放宽校验来通过。

### E7｜打包与用户验收

交付可运行便携 EXE、commit/sourceFingerprint、源码和包一致性回执、原创样例、三步操作说明、必要截图、失败/未测/边界清单。按授权选择性推 GitHub main，Gitee 不动。

最终测试使用重新启动的正式 EXE，不只测开发服务。最后停在用户 Gate N3：图像效果、粗细/色调、手绘保护与操作流畅度由用户确认，不能代填。
