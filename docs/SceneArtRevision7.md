# 雨后灰钟街区：3D 美术样板

用户已批准上轮分析与先做完整样板的方案。保持地图规则、角色资源和旧维多利亚哥特主题。

实现顺序：
1. scene.ts 调整镜头、主光/环境光比例，启用真实投影，验证可操作地格仍可命中。
2. 独立场景细节模块：高台石砌侧壁、倒角压顶、墙脚接触暗部、排水沟和煤气灯局部光晕。
3. 石材与金属材质分离；保留道路统一材质。样板元素应用于现有关卡对应区域。
4. 实际浏览器截图检查，部署/疾行回归、构建，记录性能与限制。
