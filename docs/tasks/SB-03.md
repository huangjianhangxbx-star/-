# SB-03｜阶梯石拱桥

2026-11-03。用户批准从楼梯、桥和桥底洞开始建立 B 专用搭建线。首轮已在原有团结研究工程完成直线单孔石桥，不占用桌面，也未重复启动 Tiny Glade。

输入路线与尺寸，规则协调台阶、桥面、栏杆、桥台、阶梯拱圈和真实洞口。9类原创 FBX 按原比例消费；墙芯是明确授权的生成区域，A地貌与独立物件保持独立。

默认14m×2.5m、两端各8阶，352构件合并10显示块/10556三角面。规则、实际FBX/UV、原生撤销、SceneView合成事件、洞口MeshCollider、普通保存、多桥身份隔离、独立进程重开和无脚本烘焙均有通过证据。

当前限定直线单孔与水平支承基准，不包含曲桥、多孔、自动复杂地形支承或完整建筑编辑器。来源与研究详情见源包内notes。
