## 实现

`exploration-hud.ts`拆六个身份/屏幕集群；`geometry-hud.css`用1920×1080单一设计单位和四角/底部锚点缩放。顶部主角没有头像；左下伙伴采用大圆头像，条在上、三被动/上下武器/自由槽在右。Tab独立位+一行十格；Q上右/E中左/R下右，V及真实随身生命力贴底边。设置、动作提示、通知单独低权重显示。

Y/武器/被动/自由道具/Tab/十格/Q/R/V均是不可触发预留；体力、天气/日历明确空值，不造假CD/物品数/日历。E、HP/虚血/架势和随身生命力只读既有权威；原键盘路由及黄金动作不变。对显示集群的鼠标测试确认不透传战场，中央空白仍是scene。

头像源1122×1402 RGB、SHA `5a1662d8410eab9b87a0cf23edd4391a3703814b033445d8d99d54ddcb22b962`。连通白底蒙版，人工确认外部白隙种子(820,1080)，相邻中性边缘修整；只裁面部/缩放，未绘制另一张人脸，眼睛和肤色内部样点保留alpha255。衍生768×768 RGBA、SHA `719c06fb1c1c641d84fe093628784c962bc67252271c5633042f334914c6849c`，来源/参数见public/assets/ui/portraits/al-user.source.json。原件本地保留，只有用户授权用于项目的衍生图接入。

首轮实屏暴露`exploration-app.ts`每帧旧头像更新会覆盖新用户头像。最小修改仅将`data-portrait-source=user`排除出快照替换/隐藏循环；没有改变Unit.asset、模型或动作。Z往返仍保留固定阿尔头像；换伊内丝时为其合法旧头像。浏览器currentSrc真实指向al-user.png、naturalWidth/Height均768、脸部已实屏观察。相同动作条markup以专属显示缓存比较，不再每帧重建；DOM同节点回归先红后绿，避免innerHTML属性序列化差异导致比较失效。最后三档/Z/xx/不穿透6项再次通过，类型与双构建复测通过。
