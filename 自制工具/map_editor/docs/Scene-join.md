# 场景合并物体

多选场景中的体素模型，按 **Ctrl+J**，或在视窗顶部“更多”中选择“合并物体”。

所选模型会被一个新实例替代，并生成独立可编辑资产。原始资产保持不变；新实例可以整体移动、旋转、复制。选中它并点击“编辑模块”，可以进入内部体素编辑和分离所选。

相同精度且网格对齐的内容归入一个画布；不同精度和不同网格相位保留画布，不重采样。后选内容覆盖同网格的重叠格子。根点、位置与旋转会换算进新资产，外形的世界位置不变。

Ctrl+Z 一次恢复原实例，重做恢复合并实例。新资产在撤销后仍保留在资产库，避免丢失后续编辑或其他引用。使用正常“保存草稿”保存合并资产与场景。

首版只合并工坊原生体素模型，不合并外部 GLB 或 PNG 贴花。无法在现有颜色、画布、体素预算及材质表示范围内无损合并时，会保留原场景并提示原因。
