## 定位与消除证据

旧版单个长pointer事件重复预览350次的红测试已复现；新实现同一事件最多一次发布，浏览器再合并到一显示帧一次，结束/取消/ACK交接可额外flush。CPU trace的命名函数self samples显示paintVisible、paintGuides和target为明显热点；匿名回调占比很高，因此不把命名函数排序冒充全部CPU排名。

- R1：目标成员Set/坐标索引只建立一次；queue.source借用稳定只读乐观源，悬停不clone、不重放队列。所有写入走copy-on-write。各场景每次悬停sourceCOW、资源创建、纹理更新为0；目标/域/几何重建计数为0。
- R2：普通笔触仅扩展新候选及镜像，变化面写时复制；形状撤回恢复笔前值，像素完美撤回已着色拐点的差分测试通过。按帧合并预览，pointerup/Enter先flush，不漏终点；ACK不覆盖活动草稿。
- R3：同一面的CanvasTexture/Material/BufferGeometry保持身份，只重新绘制变化面的画布；20次重复落笔资源恒定，擦除最后像素才释放。仍使用每个小面整张纹理上传，未声称GPU只上传单个像素。独立窗口空闲按需渲染；父窗租约期间也按确认/相机/显示变化渲染，未以失焦当隐藏。
- R4：权威回执携带运行时paint分类；普通确认保留两端几何和子窗域。实际门洞父窗旧版发出4个mesh worker job，新版为0，改走4次纯paint refresh。测量触发内部版本化稀疏入站协议；旧完整source协议兼容。租约/修订/owner/外露面/颜色/整资产预算/命令摘要去重继续校验；丢失ACK重试同ID同内容且历史只增加一次。全历史快照和完整权威回执保留。
- R5：可拾取网格列表、投影/相机代际复用；仍逐像素精确遮挡。选区掩码按revision缓存，轮廓独立复用BufferGeometry；固定大选区悬停轮廓不重算。可见性和共面缓存有预算上限。共面填充/连通选区合作分片，Esc取消只丢计算，不写部分资产。

## 条件分支与剩余限制

已采用稀疏入站协议；未采用大图集合批、精简ACK或历史压缩。代表高面数样本约1350 draw calls，持久资源后的render CPU处于个位毫秒，输入/预览已达到本轮参考目标，未观察到必须通过图集重构才能解决的瓶颈。renderer.info仅作资源/调用诊断，不是GPU时间或显存字节。

大量满面手绘的确认仍约147–151ms，高于100ms建议；主要剩余成本是完整校验、完整历史安全快照及ACK序列化。标准和用户门洞达到建议确认目标。像素完美的已批准reference路径算法保留，极长反复回描没有宣称与普通增量画笔同样的复杂度；形状/刷迹完整轮廓仍可能随覆盖规模增加计算。绘画层仍遍历面键做轻量身份判定，未将其冒充完全零遍历。

大填充取消、旋转、20笔和开关窗口为功能/生命周期验证，未提供它们全部的三次p95性能矩阵。未做极限16K面、长时JS堆趋势、物理DPI/多显示器拔插、屏幕出光或GPU计时。以上不填虚构指标，不用平均FPS掩盖未测项。
