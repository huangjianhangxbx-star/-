# 2DW-TILE-01｜联通母版生产线

工坊 **0.3.0**；原创模板 **0.1.0 / candidate**；任务规范 **1.3.0 / ZIP v5**。这是一条可运行的本地 PNG 生产与诊断流程。程序结构通过不代表手绘美术通过，也没有恢复原作者 PSD。

## 启动和操作

双击本目录上一层的 `启动工坊.cmd`，或已安装依赖后 `pnpm start`。开发重建使用 `pnpm run build`。本机 Node 24、Electron 44.5.1；没有新增联网生图接口，没有便携 EXE。

1. 首页选“场景地块/墙体联通”，选择草地或石质边界候选。默认分层方式、逻辑格128px、PPU100、母版1254px。128/100=1.28世界单位；母版边长与逻辑占位不是同一尺寸。
2. 生成锁定母版。先展开两张绘制说明图，再看空画板、独立导引和工程字段。导引的橙线只供解释，不能画进成品。绘画输入、47格 atlas、地图组合分别展示。
3. 可通过原有参考区添加PNG或Ctrl+V，指定内容/风格角色，再填写本次需求。只有选入的真实参考进入ZIP；批准的风格文字快照沿用2DW-05B。
4. 导出AI任务ZIP。交给有图像能力的执行端；没有该能力时只能审阅，不可宣称产图。先画结构母版，再做风格细化。
5. 用“导入返回PNG”或在返回图区域Ctrl+V。尺寸必须精确匹配，完全不透明，损坏图片或错误尺寸直接拒绝。工坊实际采样像素并合成47种状态，没有插值拉伸。
6. 检查3×3邻域、L/T/U、孔洞、孤岛、细线、5/8/16随机地图。底图、格线、Pivot、Alpha、越格外框、mask/索引、排序均可切换。Alpha显示的是当前组合的透明度；检查轮廓时关闭底图。点击格标签或问题项回看母版取样窗。
7. 导入“风格细化图”后重新编译和验证，不能沿用旧通过状态。修改模板/尺寸/PPU等参数也会清除旧产物。返回图可与原创空画板切换查看。
8. 导出真实47 PNG。包内包含原始母版、47张PNG、atlas、底层、逻辑映射、测试报告及SHA256。保存不覆盖同名文件；取消保留当前状态。

普通素材流程保留原入口。联通参考选择复用原面板，切回普通流程会恢复其位置。主进程负责文件对话框、剪贴板、PNG读取和写盘；网页不提供任意绝对路径接口。

## 绘制组织与裁切

推荐B方式是一张四区连续材质图：左上surface、右上edge、左下underlay/body、右下accent。默认每区627×627，程序从各区中心同相位128×128窗口采样（局部坐标249,249），按邻接生成轮廓。不要让AI分别设计47张散图。石材第四区为保留装饰位置，当前编译器不强制使用它；草地只在少量周边像素使用accent。

草地有独立叶缘轮廓及真实土色底层；石质边界采用更平整的顶部轮廓和暗面厚度。石材128格对应150×192可见画布、左右各11px和顶部64px越格；逻辑格仍128×128，Pivot(.5,1/3)。这些是原创候选参数，不是对原作层级的认定。

A方式为28×28连续占据画板，覆盖47个真实邻域取样窗；同格距下比前序48×48画板减少约66%面积。它是保底诊断方式，自制像素夹具通过；两类真实AI补测均返回错误尺寸，不能称为真实AI创作验收通过。连续方式格边长最多144px，保证画布≤4096px。

邻接位为NW1/N2/NE4/W8/E16/SW32/S64/SE128；对角仅在两条相邻正交都存在时有效，共47态。输出ID为稳定的`mask-NNN`，逻辑映射不依赖atlas位置。3×3输入拒绝非法角组合。没有对应PNG时报告格坐标、mask、输出ID及母版区域，不替代成别的图块。

## 格式和保护

ZIP v5中`spec/asset-spec.json`是唯一硬权威；grammar、cut-map、风格和提示词均由它生成并校验镜像。包内有blank-master、guide、shape-mask、测试场景、三段提示词、风格快照、选入参考和SHA256清单。未来的目标PNG不伪装为已完成结果。

旧ZIP v1–v4的解释没有改变。实际编译结果是独立`2dw-tile-output/1`归档，不冒充任务ZIP；原样保留Sprite外框及Pivot，不按透明边界偷偷裁小。

L0/L1与正式石材规则沿用批准版本；草地没有新增正式L2，木材仍是实验候选。原作图、图集、完整索引及可还原映射只留本机研究区，本工具运行不依赖该区或3D工坊。

## 限制及人工终修优先级

- P1：查看重复相位、连接边的大面积色差及内角。当前中央同相位重复明显；“47/47”和Alpha正确不是无缝美术保证。
- P1：人工判断石沿亮度、厚度、前后遮挡和是否像可用墙/高差边。现为stone-edge候选，未做Unity实机层级核验。
- P2：草叶过于机械的轮廓、偶发装饰点和整体块面组织。明暗各最多三阶针对主要块面，不限制整图总色数；不得为材质细节填满纹理。
- 检查器严格检查尺寸、状态和像素Alpha；草地连接边仅做中央三分之一的Alpha及色差启发式。石材不宣称完成感知接缝检查。高亮黑边、视觉重复与所有跨层遮挡仍需人看图。
- PNG≤32MB、画布≤4096、预览≤16MP；超预算明确拒绝，不偷偷缩小。参考图沿用最多8张/单张4MB边界。
- 没有拖入文件或手绘画笔；使用系统文件选择或Ctrl+V。没有自动修图、联网聊天、Unity导入、性能基准、自动批准美术。
