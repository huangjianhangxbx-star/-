# 交易 PPT 对照实施
来源：用户提供《交易系统基础.ppt》，PowerPoint 只读导出两页 1600×900 PNG 并提取文本。未修改原稿。

第1页：左侧背包、中央交易卡；由上至下为交易标题、道具名、库存、重量、简介、图片/分类/能力标签、效果、操作与价格。第2页：右侧商人名称、刷新时间、五列独立货架，每件标名字/价格。本轮使用现有10种已定价样本道具，不复制参考游戏道具或扩展背包容量；保留既有背包红色边框，交易详情采用深色底、商人货架青色底、绿色买卖按钮。安全与装备操作在普通背包中保留，交易布局隐藏以匹配PPT。


## 2026-10-16 交易 PPT 与芙萝蕾茜娅（覆盖旧待售流程）
用户明确确认按《交易系统基础.ppt》两页替换待售批量出售，新增购买与刷新。交易布局：左己方背包、中交易详情、右商人独立库存；不自动把玩家库存当货架。点击己方物品出售、商人物品购买，按钮/F 执行；编辑数量时 F 不交易。交易时 F 优先交易，非交易时沿用附近掉落拾取/选路。
商人样板：5种食物各5件、5种贵重品各2件；买价为卖价2倍，卖价仍沿用物品定义；魔素占位瓶不新增效果/价格。游戏模拟时间每300秒刷新，暂停不走时；库存属于当前世界，关闭窗口不重置，新世界重新初始化。购买从团队、安全、后备持有钱币支付，所得入团队包；资金/空间/身份/报价/库存校验失败整笔不发生。出售针对选中实例及指定数量，库存栏显示己方同定义合计。默认交易数量1，可修改；出售不自动加入固定商人货架。
原阿尔游戏内显示名统一为“芙萝蕾茜娅”，用户新头像原文件接入；内部 ranger/al 标识保留以兼容既有战斗与库存，不更换战斗模型。历史记录保留原称呼。
