# AL-ITEM-01B-LITE｜试玩交接

用最终回复的带提交版本链接进入主探索。新测试世界团队有2个“实验消耗型炸弹”，阿尔起始没有。

1. Tab选炸弹→“交给阿尔并设优先 ×1”；也可交付后在后备选中“设为优先”。右键原自由槽清意图，物品仍在后备。
2. Z控制猎人，带阿尔进入已交战敌人附近。她在动作与危险区允许、4.5米内同层通路合法时投弹，飞行/爆炸真实结算，后备只减少1。控制阿尔时不自动投。
3. 没设炸弹优先时须能覆盖两敌；设优先可单敌。她不会专门走位追投，条件不足会等待。成功一次后等待5模拟秒。
4. 同时交一瓶缓回药；有合法低血量需求时先治疗，即使自由槽仍选炸弹。

这是有限技术样板，非正式道具数值或完整战术AI；缓存落点可能被移动敌人躲开。没有用户认可投弹时机/数值/观感的记录，停在本轮试玩 Gate。完成即冻结该AI纵深，不自动开始附件后续候选。FARM/Y瓶和玩家左手装备炸弹仍走原规则。
