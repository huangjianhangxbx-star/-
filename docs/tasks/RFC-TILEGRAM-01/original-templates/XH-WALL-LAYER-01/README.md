# XH-WALL-LAYER-01｜原创结构候选

状态：draft_layer_binding_required。默认100PPU/1单位可覆盖。没有原作像素或原作索引，尚非正式美术规范。

打开blank-master.png作为共享绘画工作台；[asset-grammar.json](asset-grammar.json)定义整数像素cutRegions与pivot/alpha/越格。存在cut-windows.png时只作为独立刀线图；structural-demo.png是自写几何结构示范，不是成品美术。先连续区域作画，统一相位/边界，再按矩形无缩放裁切回拼。不按alpha包围盒trim。

条件八邻47态工作台包含连续满块、边角、洞、孤岛的取样区域，程序几何19回拼通过；随机3片只有中心变化、共用8px边，四回拼通过。墙候选是draft，body单片不代表cap/underlay联通已通过。具体仅适用本契约assetKind；不支持条件在unsupportedCases，不强套其他机制。

两个技术可执行候选仍待实际绘画便利性、接缝与风格人工审阅；墙额外等待层绑定。Schema文件附于ZIP根目录，公开目录的总说明提供完整指南。
