# 第五轮战斗设计与实现记录

## 目标与已确认决定
本轮将短促双路强压改成较长的逐步构筑关卡，完成角色差异、可读地图和复制体系统。

grill-with-docs 的三个结论均已由用户确认：技能开局和节点重入从空条充能；复制体拥有独立完整能力、部署耗20碎片；毒素计量挂在敌人身上，由本体与复制体共享，满条爆炸后清零。

## 已实现规则

- 22×12地图，双出口；北路绕高台一整圈，再与南路汇流至水晶。所有地面同材质，高台通过高度/边沿表现。点选先命中真实地格，再判定同格角色。
- 45名敌人分8波，分别于18、45、65、85、105、125、145、165秒开启；每波2、3、4、5、6、7、8、10名，波间陆续出现。生命倍率从0.45递进到1.5，攻击倍率从0.45递进到1.22。
- 猎人360HP/32基础攻击：技能从空条18秒充能，持续8秒，每秒50伤害并使命中目标眩晕0.2秒。
- 菲奥蕾280HP/35近战攻击、普攻1格；技能18秒充能，对自身半径3格内队友恢复160生命。
- 游侠260HP/30攻击、普攻7格；技能切换无时限狙击，攻击间隔2.5倍、每发伤害3.5倍，再点击切回。
- 守卫800HP、35%基础减伤、28攻击的5格飞刀；毒刃默认开启，每次命中累积25，满100时目标周围1.5格造成80伤害并清空。技能按钮可关闭/开启自动毒刃。
- 始动量分别为猎人0、菲奥蕾8、守卫10、游侠6秒，给波次到达前的部署留出时间。
- 复制体由本体头像指令部署于同层3格内，花费20碎片。复制完整角色能力，各自拥有生命、技能充能、武器耐久、攻击节奏和卡牌状态；可以被治疗。禁止移动、救援与影庭撤离；手动撤退、死亡、节点结束或战斗结算时消失。
- 疾行卡按“选卡—选角色—悬停预览周围合法方向—确认方向”执行，确认前不消耗。真实按钮紧邻已选角色血条，左侧立绘旁只展示介绍；技能就绪以柔金光提示。
- 原型音效按猎人枪、游侠弓、守卫飞刀与毒爆、菲奥蕾、敌袭、充能完成及波次提示区分，继续采用本地WebAudio合成。

## 验收与限制
- `npm run build`（TypeScript + Vite production build）通过。
- `启动原型.cmd -NoBrowser`启动服务并收到HTTP 200；默认页面已在本机浏览器打开。
- 本轮未运行自动化测试或整场战斗；波次倍率与战斗时长仍需实战试玩校准。
- Vite提示JS主包约624KB，超过建议500KB拆包线，不影响构建和本地运行。
- 参数集中在 `game/src/core/combat-config.ts` 与 `game/src/core/map.ts`，无须改其他代码即可继续调节。
