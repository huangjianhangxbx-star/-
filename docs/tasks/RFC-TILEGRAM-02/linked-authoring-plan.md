# 单画布联动绘制工作台

用户批准制作“完整母版区域→切窗→输出片→地图位置”的真实联动内容。沿用writing-plans、TDD、frontend-design；既有外观与来源观察页保留进阶入口，不继续把原作观察窗配成通用零件。

1. 失败测试：单画布47态应与现有A分层裁切逐RGBA相同，改变指定源窗应确实改变对应输出。
2. single_master.py将A顶形/前板并排写成一张原创PNG，改写整数窗为统一坐标；生成透明blank、独立辅助层、示范母版、47片、14场景、模板ZIP、独立联动数据。
3. linked-authoring.js/css建立默认工作台：场景点击→所需源窗/图层顺序/实际片/所有落格同步；母版地图点击反查；局部放大显示实际绘画区域。不是把完整原作截成四块的教学替代。
4. 用户本地PNG载入，严格校验规格，实际按固定cut-map重切并刷新预览；不联网上传、不自动保存覆盖。提供当前47PNG的ZIP导出。
5. Python像素/错尺寸/覆盖测试，真实浏览器47覆盖/点击/载入/导出/反查；旧页与源SHA保护适度回归。
6. 操作指南、限制、工程记录与白名单GitHub发布。原作数据只留本机；不改工坊或Unity。用户艺术认可仍待验。

限制：A仍有23连续设计区、尚未优化为最小画板；同一画布内顶形与前板分区绘制，不能承诺一笔画出全部方向。唯一用于裁切的窗必须标清，同类重复草稿不自动共享；上传后技术可切47片不代表艺术接边自动正确。
