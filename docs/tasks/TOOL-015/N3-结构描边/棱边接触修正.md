# 棱边接触导致整件描边被禁用的修正

2026-10-25。用户反馈「结构描边存在归属重叠或非流形接触歧义」且不能应用。旧策略把可分离的对角接触也当成致命歧义，门洞模型因此整个被阻止，限制不合适。

## 原因与结果

对用户门洞资产只读分析：5256 格、0 归属重叠、19 处沿棱边对角接触。旧版两种几何判断都报错；在旧正式 EXE 的工作副本上先复现到 `error !== ready`。

现在分别沿接触两侧各自实体的外表面生成凸棱，色带停止于自己的表面边界，不跨空气、不写其他目标。19 处接触显示为信息，不再禁用应用；重复外表面归属歧义、无法区分的接触及预算超限仍整体拒绝。算法指纹升级，旧分类结果不能混入新提交。

- 几何测试覆盖三个方向、两种对角占用、混合精度与其他 owner；独立微网格 oracle 按法向对逐边匹配。
- 另行只读审查以独立微占用/截面/带栅格 oracle 检查32个随机组合、四预设及1/2/6px，共384次逐像素一致。预存诊断仅覆盖外表面归属歧义，不能据此声称检测所有非共面的体积相交；本次未扩展到通用体积相交分析。
- 计划器对三轴 × 两种对角 × 四预设 × 2/20px 宽度，结果逐像素等于两个独立立方体之和；超宽条带不跨空域。
