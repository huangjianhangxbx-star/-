## 浏览器实机范围与证据

`记录/验证/T-024/` 保存 front-back.json、manual-back.json、back-break-wall-pin.json 与截图；同 Heavy/同 Build 单击基准：正面65 HP/10.5 Posture，背面125 HP/20.25 Posture。普通 melee/ranged 的两方向均为100/15；基准100伤害和15架势用于隔离倍率，不是改游戏武器参数。

真实 C 切阿尔、真实 A/W 输入绕到锁定 Heavy 后方，之后通过正常 step → 普攻前摇 → 出手产生 WeakpointHit，显示“弱点”，0.65模拟秒后消失。局部移动验证暂清地形并延长 Locked fixture 窗口，用于隔离方向与输入；不是自然100秒锁定行为或完整通关。默认 Debug 无分区，点击现有 Debug 才显示朝向、分区和后核心；减少动态文字仍可读。

独立链路保留原地图墙体：背部两次有效命中将40.5架势归零，不立即 Break；真实 C/技能按钮启用阿尔强化箭，正常 step 释放主箭，随后产生 Break / WallImpact / WallPin 各1次，CombatEvent 记录 back/rear-core/snipe，Heavy heading 未转动。两次预置命中用于稳定测试 Broken 状态，主强化箭为实际普攻管线。未声称自然 AI 包夹或完整流程手感验收。

初次浏览器失败：测试误读 direct.x（实际 direct.direction.x）；钉墙 fixture 选到地图远端且未进入有效攻击状态。修正输入字段、选近处原生墙、显式稳定交战/Locked/可见窗口后通过，没有放宽玩法断言或修改 AI 规则。
