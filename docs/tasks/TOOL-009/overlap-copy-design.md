# 工坊原位副本与轴向移动设计

用户决定：Ctrl+C/V 后允许与源体素完全重叠，按 Esc 完成原位粘贴；粘贴结果仍是同一个模型的可编辑体素。工坊源可记录重叠的历史层，FBX 只导出合成后的可见表面。

现有编辑文档、网格和 FBX 使用每坐标一个体素的 `cells`。保持该合成视图，新增可选的 `baseCells` 与 `voxelCopies`：前者是常规绘制层，后者是有 ID 的独立体素组。加载旧源时 `cells` 即 base；首次创建副本时才写扩展字段。合成按 base、复制创建顺序覆盖同坐标颜色；预算约束同时考虑独立源格数和合成格数。验证时重算合成并拒绝不一致文件。

Ctrl+V 从源位置进入放置预览；按 Esc 在源位置提交，左键可在目标处提交。粘贴后保持选中，视口显示 X/Y/Z 轴手柄；立即拖动粘贴组时保留原位内容，按 0.25 米吸附。之后用户按可见体素选区进行缩放、移动、擦除或改色时，所选坐标上全部历史层一起被消费并写回同一模型，预览与确认结果一致。历史层是内部的重叠记录，不呈现为另一种用户可见模型；输出端只读取 `cells` 合成结果，不产生重复面。

场景试摆、项目索引、Unity/FBX 交换协议及 Legacy 语义不变。旧版本程序不能读取带扩展字段的新源，项目保存不做降级或静默丢弃。
