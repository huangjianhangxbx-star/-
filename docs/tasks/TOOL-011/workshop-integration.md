## 已实现

- “建模→岩体塑形”紧凑非模态面板；两预设、格/米滑条、最小厚度、轴向侧面、原形对照、总/分项种子和重抽。视口不遮暗，右键/中键保留，左键编辑在预览期间阻断。
- 单个合并物体/当前画布；编辑模式支持当前体素选区作为保护掩码，其他物体/画布保持。临时选区与永久保护列优先于削切。
- 冻结源规划，80ms合并输入事件；应用时刷新最新参数，校验完整源修订与目标上下文。取消/保存/失焦/切换/其他编辑清理草稿。无变化或不合法结果不产生历史。
- 原子CanvasSession事务：几何、对象成员、baseCells/voxelCopies同键删除，避免旧源复活；Root/原点、身份、色板、其他成员保持。一次撤销/重做恢复源与彩绘。
- 每次打开默认保护所有已绘画owner及影响其显隐的邻域。关闭保护时清理真正变化面，未变化面逐项保留，新露面回基础色；面板显示影响数。公开预览对象的修改不能注入任意模型，提交采用已校验的内部快照。
- 修复编辑代理只读sync误覆盖完整画布的问题：没有作者内容变化时不合并简化代理，从而保留与塑形无关的重叠源层。普通实际建模编辑仍使用既有路径，本轮没有重写旧层源制度。
- 现有原生保存/重开、便携导入与GLB/FBX沿原权威；发行脚本生成并附两个原创练习项目体块和操作说明。

## 明确限制

此次是现有原型能力的工坊试用接入，未把原计划全部扩展交互冒充完成。竖向固定Z；柱状用轴向侧面快捷项，层阶用完整外缘带。任意局部连通面点选、部分岸段及渐弱端点、任意高度轴、受影响体积的专用高亮仍未实施。层阶要求共同平顶/平底、每柱连续实体；悬挑、多层重叠、变底拒绝，已塑形平台通常不能再次作为平顶输入。

首版只削不增，无跨画布重采样、无全场景批量处理。计划R4基本入口、R5事务/彩绘、R6现有存储导出及R7定向验证/打包按本轮范围落实；完整R4高级选面仍是待续项。用户实际手感Gate R-B待验，Unity/团结接收未重复执行。

## 2026-10-24 向外增生与双向起伏

用户确认只削减造成选区/原体积限制，并授权增加三种方式与向外最大格数。本轮现行方式默认向内，新增向外/双向。削切仍只写选中的原格；增生由选中露出面逐格向外延伸，允许超出原模型及选区，但不扩大增生起点，也不覆盖已有格子。新增格采用起点基色，加入当前物体成员与baseCells源层；不复制笔触，不改变Root、画布原点、精度或其他物体几何/归属。

两预设共享原有结构场：岩柱可形成相关的外凸/内凹带，层阶增生下宽上窄、双向低层展开高层退让。向外最大格数独立控制外扩，0关闭；纯增生不删原格、不依赖输入厚度。单层表面可长出多格体积。双向保留增生根部，避免另一侧削切使新增部分脱离。外部障碍后的空气间隔不再阻止源面先长到障碍前；默认彩绘保护增加空邻格屏障，防止新体素遮住已有绘画。颜色与碰撞/预算均按冻结源重算，超预算不提交部分结果。

面板新增塑形方式、独立向外上限及明确向内上限。绿色新增、橙色削切可一起关掉看造型，原形对照继续可用；显示新增/削切/保护计数。新增也可应用为一次原子事务、撤销重做、原生重开、便携与GLB/FBX导出。仍为四个轴向侧面、Z竖向，没有上下面或任意轴扩展。
