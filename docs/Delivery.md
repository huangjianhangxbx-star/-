# 原型交付与验收

日期：2026-09-27。当前是本地可玩的验证切片，不代表原计划全部产品功能完成。

## 运行与已实现

根目录双击启动原型.cmd，访问 http://127.0.0.1:5173 。源码在 game/src，构建在 game/dist，操作见根目录运行说明.md。

- Three.js 14×8斜视战场，地面/高台、路径/方向/攻击范围提示，真实Spine 3.8角色，煤黑/骨白/铜色HUD。
- 完整点击移动需方向确认；快捷拖动松手直接移动；无移动CD；右键取消并回到1倍正常时间。选中、定向和背包交互为0.1倍速。
- 部署始动、自动攻击、远程跨层与高台遮挡、阻挡、路径偏移回原路线、救援、影庭和出口撤离、技能、双武器与耐久。
- 三类卡牌、碎片刷新、道具快捷栏、路障通路检查、负重与精神的可调原型逻辑、黑暗共享光照。
- 两个战斗节点与一个休息节点；失败退出节点，角色损耗不回档，重新进入水晶满血，次数控制能否继续副本。
- 项目持续记忆由 AGENTS.md、CONTEXT.md、设计基线、状态与日期日志组成。UI应用frontend-design；没有套用无关Unity项目记忆。

- 已加载真实角色主骨骼；独立FX骨骼尚未全部接入。攻击释放采用逻辑时间点，不声称绑定全部原素材事件帧。

- 原始素材未改写。应用原生聊天日志存储没有迁移；项目目录保留的是人工工作记录、设计决定、代码与测试产物。

后续从试玩反馈调整操作手感与数值；继续开发前先读取AGENTS.md和本交付说明，避免将历史“尚未实现”状态误当成当前状态。
