## 离手目标

同一 `CompanionCombatState.targetId` 贯穿排序、站位/路线及原生 Basic 起手。实际攻击记录的 target/angle 是接受时的已选目标；已释放几何仍可波及旁人，不能以波及对象误认转火。G 合法集火优先，猎人和阿尔同一查询；无合法出手则重规划/有限 Hold，没有背后的“最近敌人”回退。实际 Basic ID 是只读回报，不是第二份选择权威。

本轮 SAMPLE：首次选择软承诺 **1.5 模拟秒**；承诺后普通候选优势 **2** 连续 **0.35 模拟秒**才转火，不逐帧续租。无安全攻击位累计 **2 模拟秒**后才找合法替代。死亡、Return、域/知识失效可及时改选；G 仍按原记忆、合法性与超时合同。真正即将落下且已知的危险区覆盖 DirectActor/自身，可作为紧急转火证据；远处准备动作或普通排名领先均不能伪装紧急。危险规避先行但不强制转火，显式 MoveOrder/Reservation/PathAim/集合及手动 RMB/E 权限未改。

排序沿用原权重、确定性 ID 决胜；新增策略限定两原生包。其攻击位搜索复用有界导航预算 128，不增加随机消费。不把软件浏览器技术回归称为物理 GPU 性能认证。
