Heavy 用例实际解析同一 EC04 攻击，猎人位移 .675U、伊内丝 .36U，控制结束架势恢复，再真实 C 切人并接受直接移动。该局部用例清理地面仅用于隔离重量差异，地形阻挡另由原地图墙浏览器与纯逻辑矩阵验证。

反馈沿用现有世界环形效果并区分 Break/WallImpact/WallPin 颜色、角色条钉墙标签及统计，没有新增正式动画素材。普通 WallImpact 无额外 HP；跨层/身体停止不算 Pin。
