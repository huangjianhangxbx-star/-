# 随笔迹桥结构适配契约 v2

本契约只在 RouteDocument.SchemaVersion=2 的自由路线生成中生效。选用自由路线意味着采用此适配方式；schema1继续使用[固定接口族 v1](bridge-orthogonal-family-v1.md)，源件登记及旧作品不被改写。v2不是原作内部规则的声明。

作者节点是路线的唯一权威。XZ不吸附格点；0.25m派生截面按中心线弧长产生，两侧分别累计实际边界长度。净宽0.5—6m，总长0.5—256m；过急、自交或过近的走廊明确拒绝。代表验收固定净宽2m、半径6m，中心误差上限0.1m。

| 职责 | v2允许的适配 | 保留条件 |
|---|---|---|
| deck / tread | 每约0.5m弧长单元、横向约0.5m车道，把真实源件顶点映射到共享截面；末端余量均匀分配，曲面横向按净宽分配 | 原索引、UV0及颜色保留，重算法线；可走顶面不留洞；单阶0.25m；下行踏步绕Y180°使鼻口朝下 |
| coping / rail | 按左右实际边界各自的弧长重复，沿该侧曲线适配；扶手高度随路线连续变化 | 两侧不能共用中心线数量硬挤；相邻单元使用同一边界端点；rail不拉成满墙 |
| post | 按侧边弧长约1m间隔、切线朝向刚性放置 | 不拉伸、不弯曲；端柱保留 |
| arch-stone / arch-foot / keystone | 仅合法水平直段，沿明确拱洞规则刚性放置 | 保留原部件局部旋转，左右拱脚配对；不挤入受保护洞口 |
| 规则支撑 | 沿实际内外边界构建剖面，四分之一米拱底与可见网格一致 | 明示来源 recipe:swept-stone-core-v2；同一显示网格直接用于碰撞；不拿轴对齐盒子替代曲面 |

本版适配针对上述结构职责；它不把任意装饰模型当可无限变形的积木。曲线剖面只支持水平走向及受限台阶标高，不支持任意尖角、自交、自由三维扭转或曲线拱洞。贴图的原UV仍随顶点；不承诺所有细节在任意拉伸下都具有同等艺术质量，用户试玩负责美感验收。

研究源件的包围盒归一化、轴映射及附加通道分别留档，属于我方配置的角色适配，不证明原作物理尺寸或真实消费职责。生成网格使用真实源件索引/顶点/UV0/颜色，重新计算形变法线；源Mesh附加通道与原始字节仍在私有归档，兼容材质不执行原着色器语义。研究套件当前三件来自原作，其余六职责明确继承原创A。

每次生成记录套件版本、源件哈希、弧长区段、使用方式、局部旋转以及实际批次中的顶点/三角范围。原作研究产物只存ResearchPrivate，禁止公开Bake；公开打包必须执行实际AssetDatabase依赖闭包白名单检查，连同间接依赖研究产物的场景一起排除。
