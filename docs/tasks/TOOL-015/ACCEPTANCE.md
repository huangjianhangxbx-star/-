# TOOL-015 第一包试玩检查单

状态：以下均未由本次计划编制代为验收。使用资产副本或随包原创练习项目。

## 入口与选色

- [ ] 从主工坊明确入口打开独立贴图窗口，当前物体/画布/精度可见。
- [ ] 色轮、HEX、色板、上一色和最近色互相同步；选色不改模型本身。
- [ ] 临时吸色松开后回到原工具；作者最终色不混入视口光照。
- [ ] 在HEX/数量输入框按键不会触发画笔、镜像或模型命令。

## 在门洞墙上实际绘画

- [ ] 宽笔刷经过多个体素面的接缝，没有明显裁切或空缝。
- [ ] 笔刷显示的实际轮廓与落笔一致；旋转/缩放后尺寸仍是表面尺寸。
- [ ] 在三种画布中“一体素大小”分别为16/8/4px，不改变模型精度。
- [ ] 1px像素完美整理短折角；切大笔刷时明确显示不适用。
- [ ] 像素完美调整掉的新候选恢复旧笔触，不直接擦到底色。
- [ ] 直线、折线、矩形、椭圆能预览/取消/提交；反向拖动正常。
- [ ] 经过门洞不会染到后墙；锁平面图案不跟着镜头歪到另一面。
- [ ] 框选门框并填充，选区外无变化；空选区不会填全模型。
- [ ] 擦除选区露出当前底色/暗面，不删除任何体素。

## 对称

- [ ] 中心放到门洞中央，左画右同步；转动相机不改变中心。
- [ ] X/Y/Z单轴、双轴/三轴组合都能看见正确预览。
- [ ] 中线不重复写；偶数尺寸笔头左右没有一像素偏移。
- [ ] 对应位置没有表面时提示跳过，不补体素、不涂邻近其他物体。
- [ ] 开关“镜像到不可见外表面”确有区别；不把几何内面当成目标。
- [ ] 贴图选区限制镜像；只选左边时不会悄悄扩展到右边。
- [ ] 返回建模后，同一空间中心可用于对称增/删/重染。
- [ ] 编辑模式只影响当前物体；物体模式不因对称自动合并新格身份。
- [ ] 一次撤销同时恢复左右；有paintSource/faceTone的删除也能完整恢复。

## 连笔、保存与交付

- [ ] 快速连续画20笔，后续确认没有漏笔或重复笔触；队列满有明确反馈。
- [ ] 等待主会话确认时预览不闪回；失败有明确提示，不假称成功。
- [ ] 保存、返回、关闭与撤销按照序列处理，不丢确认过的笔触。
- [ ] 关闭窗口后主会话仍保留已确认但未保存修改；保存失败不清dirty。
- [ ] 保存项目，完全退出再打开，贴图、暗面、模型和对象归属一致。
- [ ] 实际导出FBX+PNG并用Blender重读，纹样方向/颜色/位置与工坊相符。
- [ ] 最新便携EXE可运行，功能SHA/指纹和回执一致，不只提供开发截图。
- [ ] 主工坊的常驻画布列表、合并选中、顶层菜单和点对点对齐未回退。
