本轮按用户提交的2026-11-04执行计划扩展SB-03，工具部分已在后台验证：真正保留中间路线、节点与局部标高，第二套独立母件只换素材/合法配置接入。**原作受控几何替换、原作参考消费模式和真实桌面键鼠仍须单独完成；当前不能称整轮素材使用复刻已完成。**

## 从哪里打开

使用原研究工程 `Origin/work/procedural-world-editor/LE-01/project`，新增入口：**星骸 → 专用搭建 → 打开折线桥样例**，编辑窗口为 **星骸 → 专用搭建 → 折线桥与套件**。旧SB-03入口与原作品保留。

样机是独立 `Assets/BridgeReplica` 后续切片，依赖原工程已有的SB03基础类型/配方；不是第二套长期Unity工程。交付覆盖安装只加入此目录，不替换A地貌、旧桥或用户工作场景。

## 最短操作

1. 点“转折样例”，或选“连续绘制路线”，按住左键沿X/Z画出足够长的转折，松手生成一个线路作者。默认抬高2m并生成两端台阶，中间折线真实保存。
2. 选中路线，黄色方柄调整节点标高；在节点列表选中拐点，青色方向柄平移内部直段的两个拐点。起终点保持。也可在节点坐标栏精确输入，非法斜段会被拒绝。
3. “沿末段续接4米”与“删除最后一段”调整连接，相关端头和栏杆重新安排。可在合法水平直段打开拱洞；斜段和转角不能放洞。
4. “素材套件”选择 `workshop.bridge.B / 1` 预览；点“采用候选”提交，或Esc取消。两套不需要改C#或手填哈希。新套件用“登记工坊套件…”选择 `kits/B/kit-manifest.json`。
5. 窗口底部可以查看每个职责的实际FBX、原尺寸和源预览，并在工程中定位源件。
6. Ctrl+S保存原生场景；“保存路线文件”保存完整节点、标高和套件身份；“烘焙独立预制体”只输出显示/碰撞。普通场景保存会先取消未采用候选，路线文件保存则明确要求先采用或取消。

一次提交对应一次Undo/Redo；关闭窗口与Esc取消候选，右/中键或Alt导航保留已提交结果。

## 本轮认证范围

- 有限正交折线，最多32节点；平滑曲桥、任意交叉网与复杂地形支承未包含。
- 母件尺寸固定，净宽按整数米1—6m；长度0.5m、标高0.25m。第二套验证只认证同接口不同造型，不承诺任意尺寸或任意源格式。
- 旧SB-03的2.5m样例继续由旧编辑器读取，不静默改宽。新接口族限制不是所有建筑的统一单位。
- 转角平台由真实铺面/收边/栏杆/端柱构成，桥底墙芯仍是明确的规则生成区域，未冒称工坊模板。
- A地貌与独立物件保留所有权，B不自动挖A；地形挡住洞口需要另行调整地形或抬桥。
