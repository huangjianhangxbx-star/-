## 一、任务目标

让正式双人探索中的每个在场本体拥有真实、独立的 **Stamina（体力）**，对现有可执行动作形成合理的费用与恢复约束，并把当前 PPT **左上猎人/左下伙伴原位绿色体力条**由占位改成真实消费者。

达到的玩家体验：

1. 普通 **WASD 移动免费**；攻击、方向格挡、闪避/翻滚、现有主动技能有明确体力消耗。
2. 猎人和阿尔体力各自独立；Z 切换主控只换可见主控和输入权威，**不交换、不重置**各人体力。
3. 即使 HP 与架势未空，体力不足也会使对应动作合法拒绝，并有明确、简短反馈；恢复后即可再次使用。
4. 自动伙伴普攻通过与玩家相同的体力资格与支付逻辑，不得 AI 无限免单；**玩家动作与 AI 不能对同一接受事件重复收费**。
5. 暂定体力成本不追求最终平衡；使用 **SAMPLE 配置**方便用户下一轮调参，不能以临时数据定义永久设计。

## 三、SAMPLE 初始参数（本轮允许试验，不构成玩家永久决定）

| 项目 | 第一版候选值 | 权威与约束 |
|---|---:|---|
| 在场本体最大体力 | 100/人 | 独立资源、与最大 HP/架势无耦合 |
| 普通 WASD | 0 | 战斗和非战斗均免费 |
| LMB 每段实际接受的普攻 | 10 | 持续按住/排队不多扣；下一段真正接受才支付 |
| 阿尔 RMB 单次成功开枪 | 15 | 弹药仍在原本 Hit 时刻消耗；不改变 4 发/装弹 |
| 猎人 RMB 举盾成功 | 8 | 持续举盾每模拟秒另扣 6，真实格挡保留已有霜寒与方向判定 |
| Shift 闪避/翻滚 | 22 | 不改原无敌时窗、位移与 CD |
| E 现有主动 | 28 | 已有次数/霜寒/冷却与动作资格仍必须满足 |
| 被动自然恢复 | 20/模拟秒 | 实际动作期间停止，付费后等待约 0.5 模拟秒再开始恢复 |
| 合法篝火 | **候选：恢复满体力** | 作为 SAMPLE，需记录；不影响篝火次数、HP/架势/技能原规则 |
| 离开/继续当前世界 | 保持当前值，停止时间推进 | 不能白嫖体力；重开一个测试世界才真正重建初值 |

这些值默认仅对**正式探索的真实在场友方本体**生效；历史 Legacy、独立 Action Lab、敌人和旧测试环境不自动移植体力费用。其他合法伙伴（菲奥蕾、伊内丝）必须拥有独立体力数据并覆盖它们确实可执行的旧动作路径；不在本轮重新开发技能或职业体系。

## 四、S1：唯一体力权威与状态机

建议新增一个轻量核心模块，例如 `game/src/core/stamina.ts`（真实命名以现有工程风格为准）。

- 角色本体携带 `current/max` 与恢复延迟状态；资源只由核心维护，HUD 只读。
- 提供 `queryActionStamina(s,u,kind)` 只读资格接口和由**动作真正接受点**调用的 `spendAcceptedAction(s,u,kind,acceptedId)`；同一接受身份不得重复收费。
- 处理 `0≤current≤max`、小数误差、非法值、体力不足、连续扣费与恢复上限。无敌/格挡/攻击时序不因新增支付层漂移。
- 恢复使用 `GameState` 模拟时间/模拟 `dt`；`Space` 暂停、战术观察慢速、窗口失焦、合法离区都不能按墙钟额外恢复或消耗。
- 被攻击而取消已合法接受的动作：**首版 SAMPLE 不退还体力**；取消前仅缓冲或被拒绝的请求不得扣费。
- 不能通过 UI 重绘、选择同一角色、卸载场景、切人或 G/F 指令初始化体力。

## 五、S2：接入现有唯一动作接受链

### 5.1 LMB 普攻

- 在 `basic-chain` 到 `startBasicAction` 的真实接受界限消费，而不是在每次 mouse/key 事件上消费。
- 猎人四段、阿尔三段、离手伙伴 Basic、F MoveOrder 允许的自动 Basic，都必须沿用同一个资格与扣费入口。
- 实际缓冲/重发/失焦/拒绝/取消/攻击尚未 Accept 时不扣；已接收的一段在 Release/Hit/Finish/下段缓冲时不重复扣。
- 费用不足时不能悄悄起手也不能进入错误的续击阶段；合法恢复后可重新请求。

### 5.2 RMB / Shift / E

- `hunterInput` 原格挡、闪避、主动：**先验证全部现存动作条件与新体力**，再在唯一 Accept 处支付。不拆改 `hunterDefense` 盾判或霜寒结算。
- 持续举盾真实按模拟时钟递减；体力耗尽应安全解除当前盾，并拒绝继续举盾，避免持有 RMB 时每帧重新开盾刷屏。相关解除行为首版 SAMPLE，交付列待玩家验收。
- `alInput` 的 shot/roll/rocket 仍保留原本弹药、装弹、无敌、Hit/MoveReady/Finish；增加体力不应改变发射时间。按住 RMB 连射：每个真正接收的开枪动作扣一次，原每次 Hit 才扣一发弹药。
- 如果已有某种能力实际不可用，UI 不得为它造“可以使用”的状态；未来 Q/R/V 尚未实施，本轮禁止创造假消费者。
- 目标优先覆盖猎人+阿尔黄金动作；其他当前可选伙伴通过现有合法执行通路补齐有意义的资源消费，不改变其职业技能设计。

### 5.3 AI 与输入权威

- 离手伙伴普通攻击不得规避费用；若不足体力，可保留移动/寻找位置/保守避险等合法行为，但不能造空弹或无限拒绝事件。
- Z 交换 DirectActor 时清理无效 held 输入，**不移动另一人体力数值**；G 自由/集合/集火/保守，F 路径命令不收费。
- 不引入新的体力专属快捷键，不占用已预留的 `Y`、`1～0`、`C`、`V` 或 Q/R。

## 六、S3：生命周期与世界边界

- `NR-01` 同一世界合法离区与继续保留当前体力；模拟钟冻结且不偷偷恢复。
- 世界重新开始测试时初始化每个合法角色的体力，不继承旧世界的费用记录。
- 死亡、濒死、Z 自动切换的后续大系统留待 **LT-01**；当前基本不能重复初始化、负值或因倒地扣费。不得改变已有死亡/救援行为。
- 如果采纳篝火满体力的临时策略，只在**真实合法且尚未使用**篝火事件中执行一次；取消、失败、重复使用不得恢复或复制收益。
- `high-pressure-v1` 默认仍开启，可使用 `?enemyPressure=baseline` 对比；**本轮不改变三箭伤害、敌人攻击频率、HP/架势、护盾或闪避黄金参数**。体力使困难上升可作为主观反馈单列，而不是自动削弱敌人。

## 七、S4：把已有 PPT 绿色体力条变为真实 HUD

- 复用 `exploration-hud.ts` 的 `.duo-stamina`，只增加真实填充、数字与可用/不足简短反馈；按已选几何素材绘制，不要求生成新的美术包。
- 严守 **UI-01C 六区域布局合同**；不改变 `geometry-hud.css` 的主角/搭档锚点、尺寸、QER 位置、Tab/十格、右上世界信息或底部 V/生命力位置。
- 阿尔用户头像 `/assets/ui/portraits/al-user.png` 始终真实绑定；Z 切换只改变控制高亮和当前动作信息，不交换身份区块。
- 角色本体各自体力/最大值需要与当前 `GameState` 完全一致；不能用静态 100%、CSS 假绿条、HP/架势字段代替。
- 体力不足时优先使用现有 notice/动作 hint，错误提示需限频，避免按住输入每帧重写 DOM 或把屏幕中心挡住。
- 两个常用桌面尺寸（建议 1920×1080、1280×720）进行快速真实截图，确认左上/左下条不溢出、不与 HP/架势遮挡；**无需每轮重做 UI-01C 三档长篇像素测量和商业图标复刻。**

### 8.1 定向核心测试——必须

先 RED→GREEN，覆盖：

1. 体力初始化/上限/精度/模拟恢复延迟，暂停与慢速；
2. 普攻每个真正 Accept 只扣一次，缓存/拒绝不扣，结束恢复门仍有效；
3. 猎人 RMB 格挡与持续耗费、耗尽自动解除；格挡 HP=0、减半架势不变；
4. 猎人 Shift/E：体力及霜寒/CD/动作门同时约束，拒绝零副作用；
5. 阿尔 RMB 连射四发/原装弹、Shift/E 仍按原真实时序；
6. 离手 AI 不能绕体力消费，F/G/Z 无不该发生的扣费；
7. 角色 A/B 数据独立，反复 Z 切人保持值；
8. 世界离区/继续体力不变、重开重置，合法篝火仅一次恢复；
9. 高压试验与 baseline 双模式的受击、打断、格挡、闪避与扣费独立；
10. 选用正确资源来源，trace 开/关不影响实际消费，拒绝反馈不无限刷。

可按风险加 1～2 个关联回归，例如 `EN06-G01` 普攻收尾、原阿尔四次射击、`NR-01` 状态延续。**不默认执行全部历史塔防/所有 1511+ 核心与所有过时浏览器脚本。**

### 8.2 构建与实际操作——必须

- 当前 `game` 工作目录 TypeScript/主构建（实际脚本 `npm run build`）。若 Action Lab 完全没触及且已有隔离保护，可不重新完整构建 Lab；若有共享类型/执行器改动影响它，补对应构建或定向烟测。
- 真实 Playwright / 浏览器 **3～5 个不同关键场景**：
  1. 1920 正式探索：猎人连续普攻 → 耗体力 → 拒绝与恢复；
  2. 切阿尔：独立体力、RMB 真射击/装弹和 Shift 或 E；
  3. 猎人举盾保持至耗尽 → 自动解除、下次可用；
  4. `?enemyPressure=baseline` 与默认高压：一次真实伤害、格挡/闪避不会因体力适配改变伤害权威；
  5. 一次合法离区继续或篝火操作，体力保持/补充符合本轮 SAMPLE。
- 1280 做一次 HUD 条无溢出+点击不穿透检查；若 1920 已通过且业务逻辑相同，不必把完整长世界路线重复执行两三个分辨率。
