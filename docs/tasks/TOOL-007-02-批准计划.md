==================================================
一、本轮目标
==================================================

在现有四 Workspace 和 TOOL-007-01 编辑操作基础设施上，
为“模块编辑”增加真正适合体素逐块制作的创造建造模式。

不替代现有：
- 地台
- 三维
- 大笔刷
- 矩形

而是增加另一种局部制作方式：

【搭积木 / Creative Build】

同时解决用户实际反馈：

大量相邻同色体素目前很难区分单格和命中面，
必须增加编辑辅助可视化，否则创造建造难以可靠使用。

==================================================
二、编辑辅助可视化
==================================================

新增仅供编辑器使用的显示模式：

【体素清晰】

要求：

1. 可见体素单元之间具有明确但不过度刺眼的边界。
2. 不修改：
   - 源体素颜色
   - palette
   - 材质
   - GLB/FBX
   - Unity发布结果
3. 这是纯编辑视图辅助。
4. 可以随时开关。
5. 暗色Workshop下视觉清晰。
6. 大面积模型不能因为轮廓线导致严重视觉噪声或明显性能倒退。

同时增加三级指示：

A. 当前命中体素：
整个命中Cube轮廓明显高亮。

B. 当前命中面：
命中face有轻微透明覆盖或等价视觉反馈。

C. 当前目标放置格：
显示Ghost Cube。

Ghost必须与真实Commit目标一致，
复用TOOL-007-01的Plan/Candidate纪律，
不能视图算一套、执行算另一套。

建议UI：

显示
[ 美术预览 ]
[ 体素清晰 ]

具体命名/位置可按当前Workshop UI合理安排，
不要新增Workspace。

==================================================
三、创造建造模式
==================================================

模块编辑中增加：

【搭积木】

它与现有stack功能不是简单改名。

目标行为学习Minecraft Creative：

1. 鼠标命中真实外露体素面。
2. 添加时：
   在命中face法线方向的相邻格添加体素。
3. 六个面全部支持：
   +X / -X / +Y / -Y / +Z / -Z。
4. 删除：
   删除实际命中的体素，而不是目标相邻格。
5. 添加/删除均使用当前色板/合法体素规则。
6. 负坐标必须正确。
7. 0.25m规则不变。
8. 不能写入Gameplay属性。

==================================================
四、连续搭建
==================================================

按住添加并移动鼠标：

持续生成合法放置计划。

要求：

- 快速移动时不能出现明显随机漏格。
- 重复采样同一目标不得重复写入。
- 整次按下→拖动→松开：
  一次Undo。
- 一笔期间配置冻结。
- Esc / pointercancel / window blur：
  完整取消整笔。
- 超预算或真正致命错误：
  按007-01事务规则完整回滚。

不要为创造模式建立第二套history。

==================================================
五、锁定工作面
==================================================

增加临时“工作面锁定”。

目的：

例如从墙面开始横向搭建时，
连续绘制不能因为刚创建的新表面而自动爬到其它方向，
造成模型越画越厚、越画越高。

进入锁面后应冻结：

- 起始face方向；
- 合法工作平面/法线；
- 该笔的放置逻辑。

预览必须明确显示当前锁定状态。

具体快捷键属于原型键位，可调整，
不写入永久规则。

==================================================
六、Pick Block / 吸取
==================================================

允许直接从已有体素吸取：

至少：
- 当前palette颜色。

吸取后：
- 当前画笔色更新；
- 原体素不变化；
- 不创建Undo记录。

本轮不建立复杂“预设系统”。

未来资产/Clipboard预设属于后续任务。

七、输入冲突与候选键位
==================================================

候选操作：

添加

删除

中键单击：
Pick Block

中键拖动：
平移相机

右键拖动：
旋转相机

Shift：
临时锁定工作面

但这些只是候选。

实施时必须验证当前Three.js相机操作，

mouseDown
↓
移动小于阈值
→ Pick

移动超过阈值
→ Camera Pan

如果实际冲突严重，
允许采用等价键位，
但必须在交付时说明理由。
只有涉及明显用户体验取舍时才需要停下询问。
