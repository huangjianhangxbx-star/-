# M1.2 最终EXE制作示例

1. 在地图工坊资产库点击“选择目录”，选择本文件所在目录。
2. 打开 assembly.xhmap.json：这是从最终EXE真实绘制、导入PNG参考、放置三份资产并保存的编辑源。
3. 展开“原生资产与模型交换”，用“打开原生资产编辑”打开 Wall.xhasset.json。修改后使用“更新当前原生资产”。
4. 重开assembly.xhmap.json并点“重载”，三份共享资产均引用更新结果，摆放位置不变。
5. assembly.glb可直接由Blender导入；assembly.fbx与assembly.xhmaterials.json须一起导入团结，使用随包M1.2插件。地图JSON仍承载游戏属性/实例身份，视觉模型不替代源。

比例参考.png是本轮用于验证透明留白与脚底的示意人形，并非正式角色美术。源地图已嵌入它，移动或删除外部PNG不会使已保存的地图失去比例参考。

这些模型只用于尺度、编辑与互通验证，不是新的正式关卡或美术定稿。
