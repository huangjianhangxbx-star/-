# 集合、根设置、临时画笔与原位粘贴

2026-11-01；适用于模型制作，旧项目继续兼容。程序资源已同步至 `release/星骸地图工坊-Workshop-M2.0/`；保存当前工作后重开生效，不会自动重启正在编辑的窗口。

## 操作

- 左侧资产选择器旁直接打开“根设置”；“模型管理”集中改名、复制模块、另存等操作，保存/导出仍在右侧。
- 集合是组织目录。点成员选一件，Shift 加选、Ctrl 减选；点集合标题选整组，箭头只折叠/展开。集合与成员有文件夹/物体图标和缩进。
- 右键集合选择“解散集合”，只移除分类，不删除成员或合并几何。同画布 Ctrl+J 才合并物体；跨画布限制保持原有行为。
- 右键一个物体，选“设为临时画笔”。顶部显示来源名称；指针处出现真实形状的半透明预览，左键一次放置一个独立物体，无需 Enter。右键拖动仍旋转视角，右键点按物体可换画笔。
- 顶部“恢复体素格”、选择普通绘制工具或 Esc 都能退出临时画笔。切换资产/关闭资产清理临时状态；同资产刷新、撤销/重做后保留当前画笔。
- 临时画笔保留源体素精度、形状、颜色、材质、面色差及绘图图层。预览显示形状和基础颜色，实际落笔保留手绘贴图。放置不能覆盖已有体素；被占用的位置会提示，不产生半次操作。
- 编辑模式 Ctrl+C → Ctrl+V 后，Esc 在复制源位置完成并选中新副本，忽略鼠标预览偏移。接着可用轴移动；原件保持原位。左键仍可直接确认预览位置。“移动选区”的 Esc 仍取消。

## 修复与验证

原位粘贴失效的原因是编辑对象代理及画布同步删掉 `baseCells/voxelCopies`，使重叠副本身份消失。现保留当前物体的分层，并合并保留其他物体/共用副本层的内容。临时盖章也保留目标画布已有重叠层。临时画笔的表面预览复用几何射线缓存，不在每次鼠标移动时为整张模型逐体素生成选取包围盒。

新增核心/输入用例先失败后通过；真实 DOM 检查集合单选、分类解散与根设置在 2116/1440/960 三种宽度的入口。隐藏 Electron 使用临时项目、独立 profile，实测源位置粘贴→轴拖动→保存重读，以及临时画笔盖章、原件保留、换源、恢复、撤销/重做。源码版和便携 EXE 均通过，未操控用户窗口或修改用户模型。

类型检查及构建通过。全套核心测试 586 项中 585 通过；唯一失败为 `exchange.test.ts` 的 GLB 线性色精确浮点相等断言（约 3e-17 差异），在原 HEAD `c600598` 的独立基线同样复现。本轮没有改动该导出模块。

复测入口：`tests/canvas-geometry-hit.test.ts`、`tests/voxel-placement-escape.test.ts`、`tests/voxel-placement-escape-ui.mjs`、`tests/temporary-object-brush.test.ts`、`tests/temporary-object-brush-tool.test.ts`、`tests/collection-brush-ui.mjs`、`tests/root-settings-layout-ui.mjs`、`tests/temporary-brush-workshop-ui.mjs`。Node 24 直接运行 TS 测试；UI 测试必须保留 `--test-hidden` 与临时 profile。

## 第二轮：轴向建模与场景预览

- 试摆视口右上显示六方向导航。点“上/下/前/后/左/右”切对应正交视角，再点当前方向切对面；右键拖动仍自由旋转。
- 编辑模式粘贴预览从源位置开始，鼠标移动超过 6 px 后锁定屏幕投影最近的 X/Y/Z 轴，另外两坐标不漂移，不自动旋转模型。左键完成当前位移，Esc 仍忽略预览位移、原位完成。右/中键视角操作不改变粘贴位置，结束视角操作后重新确定拖动轴。
- 在三维、表面搭积木或搭积木·创造的笔刷中按住 Shift 拖动，沿起笔面最近切向轴连续延伸，保持另外两坐标及起笔面，不要求每一格下都有原模型支撑。松 Shift 恢复正常笔刷，整次按住鼠标仍一次撤销；Esc 撤销未完成笔画。擦除/重染沿同一规则处理已有格，原有对称与预算约束继续有效。
- 新工坊默认表面搭积木，空画布可从工作面画第一格。建模模式菜单显示图标和名称，仅显示工坊支持的三种方式。用户主动选择的方式保存在本机偏好中，复制刷新、物体/编辑切换、新画布、调整工作面与恢复体素笔不会再强制换三维。
- 开启“双视口”后，在右侧“预览内容”选择“试摆场景”，再选项目内场景。复用同一个预览画布，显示装配位置、模型颜色与绘图；未保存的当前模型修改同步到此预览。切回“当前模型”恢复原视角；场景只读，不切换试摆页的活动场景、不自动保存用户模型。空项目显示无场景提示。

修复细节：模式重置来自多处硬编码 volume；直线输入显式读取 PointerEvent 坐标，避免对象展开丢失原型 getter；外部预览隔离原生模型时保留视口灯组，避免黑模型。新预览复用原 WebGL，上下文/模型资源按切换生命周期清理。

验证：全套核心 601 项中 600 通过，唯一失败仍是前述在旧基线复现的 GLB 浮点精确相等断言。类型及构建通过；六条真实隐藏工坊流程通过（本轮四条及上一轮原位粘贴/临时画笔），另有场景导航与预览组件回归。场景预览以实际亮面像素验证渲染、未保存两格模型的双实例四格预览、原场景与资产 SHA 保持不变。所有测试使用隔离项目/profile，不操作用户现有窗口。

## 第三轮：分离、单位重采样与场景保存

编辑模式左上直接显示“将选区分离为新物体（N 格）”。分离保持位置和绘图，原物体继续处于编辑模式，分离件不再属于它的可编辑范围；新件在层级独立列出。空选、计算或提交中禁用按钮，分离/撤销/重做仍各一次操作。

模型始终有默认画布，最后一张不可删除。在画布列表展开“当前画布属性”，选择 0.25 / 0.125 / 0.0625 m，再点“保持尺寸重采样”。变细拆格保持世界尺寸；变粗按当前原点新网格重排，颜色/归属、贴图投影、体积量化差异会显示。保留对象 ID、绘图层、隐藏/锁定原稿、面暗色、保护列与重叠副本；可能吞掉整件或无法保留覆盖语义则明确拒绝。必要时将操作轴对齐新格，资产根不动；整体转换可撤销，单位切换/撤销不会改变模型在视口中的大小。

笔刷快捷键为 T，吸色 Q（兼容 I），擦除 E；菜单显示键位。输入名称、数值或使用 Ctrl/Alt/Shift 组合键时不触发这些工具。旧的选区自定义快捷键不能覆盖 T/Q/E。

“场景搭建”左上常驻“保存场景”、当前名称、未保存/正在保存/已保存状态和实际文件位置。Ctrl+S 与按钮共用保存；可以改名、保存后关闭重开继续搭建。双视口下拉也改称“搭建场景”，原有用户场景名称保持原样。整场景 FBX 导出是后续任务，本轮未增加。

坐标导航文字已居中；点击“上/下”再开始旋转时同步 OrbitControls 的 up 基底，避免只歪转而不正常绕模型旋转。模型/搭建两视口的六方向及 PNG 参考均已回归。

第三轮验证：622 项核心中 621 通过，唯一旧基线 GLB 浮点断言失败不变；类型/构建通过。真实隐藏工坊验证分离与隔离编辑、T/Q/E、单位转换和原稿往返、撤销视图、场景保存重开；另有 252 个文字测量和 36 组旋转输入回放。入口脚本为 `tests/edit-separate-workshop-ui.mjs`、`tests/modeling-tool-keys-workshop-ui.mjs`、`tests/canvas-resample-workshop-ui.mjs`、`tests/canvas-resample-view-ui.mjs`、`tests/scene-save-workshop-ui.mjs`、`tests/axis-navigation-alignment-ui.mjs`、`tests/orbit-axis-navigation-ui.mjs`。

双视口选择搭建场景时，右侧镜头独立使用世界坐标；左侧模型改单位、撤销/重做均不会缩放或移走右侧场景。模型与场景镜头快照不会互套。`tests/scene-resample-view-ui.mjs` 与 `tests/canvas-view-space-ui.mjs` 覆盖此边界。最终便携 EXE 的分离、快捷键、单位/原稿、两类视图历史、场景保存六条流程全部复测通过。
