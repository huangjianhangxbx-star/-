# 用户试玩与交接检查单

> 仅是待验清单；以下未打勾不代表已执行。

## 先确认打开了哪个程序

- [ ] 记录EXE实际路径、代码SHA/sourceFingerprint和构建时间，不拿GitHub文档提交号代替EXE版本。
- [ ] 用资产副本试玩；开始记录assetId和原有画布/对象数量。

## 1. 找入口与看模型

- [ ] 新开资产后直接看见建模、自动上色和贴图绘制入口。
- [ ] 默认主视口足够大；资产抽屉、副视口按需开启，不需要常年拖来拖去才能画。
- [ ] 当前对象、画布、尺寸和物体/编辑模式清楚；禁用按钮可知道原因。
- [ ] 1280×800下保存、取消、应用可达；参数栏滚动不遮挡这些按钮。

## 2. 实际建模

- [ ] 物体模式照旧可自由绘制；内部编辑只改变指定对象。
- [ ] 画一笔、撤销、重做；复制、合并、分离和画布切换保留当前语义。
- [ ] 根点仍能底面中心/六面选点，区别于物体操作轴。
- [ ] 旧随机工具、参考图和便携源入口仍能找到。

## 3. 塑形和自动上色

- [ ] 打开塑形/区域色差，模型仍可看清；滑条与数值可调，高级参数折叠。
- [ ] 旋转模型、换灯光、缩起侧栏不会把当前预览取消。
- [ ] 切目标或保存遇到草稿时，明确决定应用/放弃/返回，没有暗中丢失。
- [ ] 一次应用只占一个历史步；零变化不创建空步骤。

## 4. 独立贴图窗口

- [ ] 从常驻按钮打开窗口，无需先找隐藏的编辑模式下拉。
- [ ] 画、擦、原始吸色、作者最终色吸色、填充都真实工作。
- [ ] 主窗口能观察已提交绘画；同资产几何改动被保护，不会一边画一边删掉承载面。
- [ ] Ctrl+Z/菜单撤销作用到正确会话；在输入框中仍能正常编辑文字。
- [ ] 关闭子窗口后，已画但未保存内容仍在主窗口，不丢失。
- [ ] 保存→退出→重开后，底色、绘画和暗面一致。

## 5. 输出与边界

- [ ] 同一已提交源仅改变布局/显示后，导出内容不变。
- [ ] 实际FBX+PNG/材质旁车回读正常，不仅检查文件头。
- [ ] 图层、自动描边和贴图像素完美等未实施能力未伪装为可用。
- [ ] 记录最不顺手的三处操作，用户审美/易用性结论与AI测试分开。
