# RFC-TILEGRAM-02｜研究结论

2026-10-14。研究与程序验证完成；人工美术验收尚未完成，未接入2D工坊。推荐从B的功能分工开始：先以H/T连续草稿统一墙沿与前面板，分别画四方向接角，最后用C修正特殊端头、内凹和交汇。A保留为连续画板实验，不默认它是最佳生产尺寸。

## 实际证据与限制

目标墙与一个明显不同的有机材质墙族，均确认48数组槽、47合法条件八邻状态；多出的槽未被该映射使用，其原作用途未知。mask24确实引用索引8。全部登记片的尺寸、PPU、Pivot、Alpha与SHA可在本地页查询；实际Tile变换均为identity，未发现可据以宣称原作镜像绘制的证据。

主族多数片为341×512、PPU341、Pivot约(.5,.34)，两个方片为384×384、PPU384、中心Pivot。主族导出Alpha最低245，黑内部不是PNG透明区；对照族存在Alpha0。材质如何处理黑色、运行时图层及排序未证实。原像素合成不缩放；另提供按PPU/Pivot的世界尺寸SVG，不能把像素合成与精确世界比例混为一谈。Grid单位与(.5,.5)锚点只是比较框架。

14类源图重建覆盖31/47状态；在至少一个已生成合成窗口中，只有8态能逐RGBA复得原Sprite，16态未在这些场景出现。遮挡会破坏完整源窗口，因此这不等于39态必须重画，也不代表原作者没有连续母版。独立角色表仍覆盖全部47态。

相同角色中央前面板比较：一个横向状态与参考直线状态的指定中央矩形逐RGBA完全相等；其余同类片有程度不同的局部差异。支持共用前板设计的猜想，不能推出唯一PSD或作者历史。四象限SHA分类数不是画师实际部件数量。源直线共边差异小、交汇共边差异大，连续关系必须在相同可视角色下判断，不把整条边差值当作同一笔画证明。

## 可执行原创方案

所有示范笔画、空白画板和裁切布局由本轮程序原创，不描摹原作像素。A：23连续区域、两张3072×4608的分层画板，避免1.5格整片窗口混入邻片；画板成本高且未优化。B：四方向×五接角角色，共20部件，240×192顶形板与96×96前板；前板在半格处开始，保留一格高度。C：768×864受控47窗口，作修正通道。三套都使用96×144输出、100PPU、Pivot(.5,1/3)，与原作规格分开。

每套已有独立透明blank、annotation辅助层、整数cut-map、47张实际切片、14类真实程序回拼、5步图和原创模板ZIP。0/10/18/72/80/90列为端头/内凹/交汇的优先人工审阅任务，并非证据证明原作者必须额外画6片。B的角缝与双墨线、前板落点、不同方向视觉一致性仍需画师修正；程序覆盖不等于成熟美术通过。

## 尚不能证明

没有找回作者PSD；图集排布不代表制作画布。连续轨迹PNG是角色带候选高亮，可整体开关，未自动识别真实笔画骨架、未分别控制每条墙沿。原作真实TileMap场景、遮挡排序和Unity渲染未验收。模板尚未由用户认可为正式规范。后续需另立2DW-WALL47-01，不能自动改工坊编译器或双网格路线。
