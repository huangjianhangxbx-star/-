# TITLE-01 美术概念

- A：深蓝废墟与断裂星环包围中央原创标题，下方仅“点击屏幕开始”。
- B：同一背景与字标上移，出现开始游戏；读取游戏、画廊明显灰显并标记暂未开放。
- 主体设计：沉没的哥特回廊、破碎星环、冷蓝雾层。没有使用参考游戏的图像或标志。
- 背景由内置 imagegen 生成，原图 `game/public/title/starfall-corridor.png`，1672×941。生成提示要求原创、蓝色夜幕、西幻废墟回廊与星环、无文字、无角色，中央低细节用于叠加标题。
- 字标 `game/public/title/title-logo.svg` 为确定性 SVG，宋体粗字、冰银色阶与断星菱形线饰；未复制参考字标。
- 配色：夜色 #050e19，深蓝 #174256，冷银 #e4f7ff，星蓝 #70bdd2，灰显 #778896。
- 1600×900 基准：背景 cover / center；字标宽900，x350，A y220，B y140；A 提示 y690；B 菜单 x590 y490 宽420，间距16。字标容器宽 min(56.25vw,900px)，窄屏可适当放大至84vw；布局按视口比例缩放，菜单文字下限18px。
- 菜单项使用无实体大面板的居中横向光带，首项上下细线、左侧菱形，避免后台式卡片菜单。
- 右下角 F10 调试入口弱提示；底部原型版本标记。
- 复现：从仓库根运行 Node `docs/tasks/TITLE-01/render-concepts.cjs`。HTML 仅为概念板，不是生产运行代码。
- 未添加动画，避免视觉门槛前扩大实现；实现可保持静态。
