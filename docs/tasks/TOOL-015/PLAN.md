## 1. 用户要求、建议与实现事实分开

### 1.1 用户明确要求

- 贴图窗口增加色轮。
- 补齐类似 SAI2 工作习惯的基本绘制工具，特别是直线和对称。
- 建模模式也要对称。
- 此前要求的贴图像素完美、笔刷恢复为当前体素格大小、独立贴图窗口和自动描边不得遗失。
- 工坊用于低饱和、硬边、大色块、克制细节的体素／手绘资产，不需要复杂效果贴图生产线。

### 1.2 本计划推荐的默认值

- 首版以轴向原生体素表面为对象；一份绘画租约仍只写一个物体、一个画布。
- 自由笔刷保留现有“沿可见表面”习惯，另加“锁定起笔平面”；直线、形状、选区默认锁平面。
- 硬边、100%不透明是本轮画笔默认；不做没有数据支撑的透明度或图层假按钮。
- 对称默认关闭；初次中心取当前物体包围盒中心后固定，不随每次落笔重新计算。
- 默认只在当前可见、可编辑表面写入；镜像到视线不可见但几何外露的目标，必须显式开启。
- 初始笔刷范围推荐维持现有 1–32 px；先解决覆盖完整性，不以无限增大尺寸代替效率设计。

## 3. 总体结构：一个绘画内核，多个输入工具

建议处理顺序如下；模块名是职责描述，不要求生搬硬套类名：

```text
鼠标／快捷键 → 当前工具手势 → 表面全局像素候选
            → 本笔路径修整／形状栅格化
            → 对称映射与去重
            → 物体／画布／选区／外露面／可见性检查
            → 基于本笔开始前状态的临时预览
            → 一次手势形成一个像素差量
            → 客户端顺序队列 → 主会话校验与一次历史提交
            → 确认快照 → 显示／保存／既有导出
```

形状、笔刷、擦除、填充都使用同一份权限和像素映射。不能每增加一种工具，就复制一段直接改 `paintSource` 的代码。

四种状态分开：
- **作者数据：**体素、底色、paintSource、faceTone，保存与导出。
- **本次写入目标：**租约、物体、画布、源修订，不能由子窗随意扩大。
- **工具状态：**选色、尺寸、形状、对称中心、选区等；调整它们不使资产变脏。
- **显示状态：**相机、原色／柔光、网格、笔头、对称平面；不写入贴图。

工具偏好可以本机记忆；对称中心必须按资产+对象+画布隔离，重新打开时校验身份。首版不把偏好伪装成新的资产字段。

## 4. 颜色与绘画界面

### 4.1 色轮、色板与吸色

- 右栏“色轮／色板”直接切换，默认记住上次选择；色轮复用 `bindColorWheel()`，与 HEX、色板点击、吸色保持双向同步，不递归触发写操作。
- 保留当前模型色板；可复用现有项目色板的只读列表，但不为子窗开放任意路径访问。首版不强制新增色板文件管理系统。
- 显示当前色、上一色和最近色；最近色建议最多12个。颜色确认、色板点选、有效吸色时去重加入，不把拖色轮经过的每个颜色塞满列表。
- RGB/HSV 数值放折叠区；色值合法性明确。黑白灰调回有饱和度时保留用户最近色相，不突然跳红。
- 临时吸色建议 Alt 按住启用、松开返回；两种取样源明确命名“笔触／底色”和“作者最终色”。视口光照不属于取样源。
- 颜色选择只设画笔色；不自动重染色板槽、不改变底色、不增加作者历史。

### 4.2 窗口组织

沿用当前独立窗口，不重做主工坊外壳：

- 常用工具直接按钮：画笔、擦除、直线、折线、矩形、椭圆、填充、选区、吸色。可用图标配短标签/提示，不再全部藏于一个下拉框。

## 5. 共面像素坐标、笔刷与像素完美

### 5.1 统一坐标，不能跟着屏幕变化

作者源是 **Z向上**；Three.js 视口有坐标轴变换，且活动画布一格可能按0.25渲染单位显示。所有工具计算使用作者源／画布局部坐标，经现有转换函数显示，不直接拿渲染坐标当米数。[S7]

对于当前画布步长 `s`，每面边长像素数 `n = 64 × s`：0.25→16，0.125→8，0.0625→4。[S3]

用 `(canvasId, normalAxis, normalSign, plane)` 标识共面图表；正向面的 plane 为 owner法线轴坐标+1，负向为原坐标。面内 U/V 沿源码既有的“非法线轴升序”定义，不自行翻转负面 UV。

```text
U = cell[tangent0] * n + u
V = cell[tangent1] * n + v
cell[tangent0] = floor(U / n)
u = U - floor(U / n) * n       // 负坐标也必须得到 0..n-1
```

因此同平面相邻体素面共享连续像素格，不依赖贪心合面的三角面编号，也不依赖导出UV图集位置。

**测试必须包含 U=-1、U=0、U=n-1、U=n，六个面方向，三精度、非零画布原点。**

### 5.2 范围与遮挡

- 每个候选像素反查真实 owner cell、面方向和授权对象；不存在的格、空洞、其他物体与非目标画布不得写入。
- 几何外露判断必须参考完整画布占用，而非仅被编辑对象的裁剪几何；不能把被另一物体紧贴的内面当作可画外面。
- 直接绘画先取整个可见模型的最近命中；非目标物体挡在前面时阻挡画笔，不能跳过它去画后墙。
- 同平面笔刷足迹跨面时，按候选像素中心检查必要的可见性，或采用等价的有测试支持的可见性掩码；不能只验证笔刷中心就穿透遮挡。
- 可见性采样、表面邻接查询应缓存，不要求每次 pointermove 重建全资产 GLB。
- 悬空时停止段落。跨真正折面时重新起段；本轮不把折线拐角自动展开成无缝曲面。
- 锁平面只限制目标平面，不把门洞后的平行墙面拉到当前平面。

### 5.3 笔刷大小与足迹

- 方形／圆形硬边；尺寸始终表示表面贴图像素宽度，不是屏幕像素。
- 数字、滑条、快捷键同步；提示如“16 px · 0.25 m”。预览显示真实会写入的裁剪后足迹。
- “恢复为当前体素大小”仅令 size=n；切换画布后按新画布重新计算。不要修改模型或提高贴图分辨率。
- 偶数尺寸的中心偏置确定、预览与写入一致；镜像应映射已生成的完整像素足迹，避免在镜像点重新扩笔头造成左右偏一像素。
- “一格宽笔刷”不是“吸附填满该小面”。当前小面填充可从填充范围选择，不偷换按钮语义。
- 沿可见表面自由绘画，每个命中的面按自身法线生成局部足迹；不因鼠标走得快而越过无命中区域连线。

### 5.4 贴图像素完美

- 首版只对1 px硬边自由画笔有效。大笔刷、填充、形状和擦除不假称生效；界面显示“不适用于当前工具／尺寸”。建模开关独立。
- 在共面全局 U/V 上整理本次路径，跨体素边界不断笔；真正转角、遮挡、租约变化才断段。
- 基于笔画前的像素状态与本笔候选集合重建结果。移除冗余候选时恢复旧笔触或旧底色，不能一律删除该像素。
- 保留端点、交叉和明确长直角；对“多余一像素折角”的判断用固定正反向夹具确定，不承诺逐像素复制 Aseprite 算法。
- 单次笔画的原笔＋镜像一起修整／去重、一起撤销。不要先分别修整左右再出现不一致。
- 历史提交不包含临时修整过程，零变化不新增历史。

## 6. 直线、形状、选区与填充的行为合同

### 6.1 直线／折线／矩形／椭圆

- 在起笔真实面上锁定作者平面，终点由鼠标射线与该平面相交后转全局 U/V；相机与平面近平行时提示换角度，不生成巨大离屏候选。
- 形状以表面像素栅格化，不采用浏览器抗锯齿截图当源数据。矩形／椭圆有描边／填充，描边宽度为整数像素。
- 直线支持拖动起终点；折线逐点确定，Enter或双击完成，Esc取消整条。仅为折线累计待定节点，不提前逐段写作者源。
- Shift的角度约束和圆／正方形约束在面内坐标计算，不以透视变形后的屏幕长度判断。
- 调节端点／宽度仅重算当前预览，不累计叠画；一次确认一次历史。反向拖动、零长线、小于描边宽度的形状均定义一致结果。
- 一条线可以经过前景门洞空白；空白段无像素，后墙不落色。若同一平面另一段属于授权目标且可见，可继续生成图形候选；自由画笔的“空白断段”规则保持不变。
- 普通直线用确定性的整数栅格算法；像素完美不再次修整规则图形，避免无故缺角。
- 开始形状后临时旋转相机：保留固定起点／平面和草稿，暂停更新终点；回到左键后继续。窗口失焦取消尚未确认的绘画手势；已确认排队笔触按第8节处理。

### 6.2 贴图选区

**不是体素选择；Delete只能擦除当前贴图选区内的手绘像素，绝不能删除模型。**

- 第一包：矩形选区、当前共面连通表面全选、加选／减选、清除、反选；多边形套索留到下一包。
- 选区绑定当前目标与一张共面图表；初次矩形选区在命中面起笔。想在空白处起框，应先明确锁定目标平面，不依据任意后墙猜平面。
- 选区包含实际可编辑表面像素，不包括空洞，不默认透选。边界可显示虚线或等效高对比提示。
- 第一包多次加选限制在同一平面。转到其他平面时，提示重新建立选区或显式清除，不能把旧选区解释成新面的坐标。
- 反选的有限全集是当前目标、当前共面连通区域与可见性策略，不是无限二维平面，也不是全资产所有面。
- 选区建立／清除不改变作者数据与dirty；可有独立选择撤回，不混入现有绘画历史边界。原主建模选择历史规则不变。
- 显示、缩放、颜色和工具变化保留选区；源几何／对象改变或租约失效时清除并提示。窗口关闭无需把它写进资产。
- 画笔、擦除、形状、填充、对称的最终输出都受选区约束。只选左侧时，镜像到右侧会被裁掉，界面应说明；不能暗中自动扩大选区。

### 6.3 填充

提供明确范围：**当前体素面／同平面连通区域／当前选区**。空选区不回退整模型。

- 相似色连通填充默认4邻接，不跨斜角缝、不跨真实台阶、不跨物体。可见性和目标掩码先参与边界判断。
- 容差默认0，只匹配相同作者源颜色；可用0–255的最大RGB通道差作为第一版明确且可测试的阈值，不称感知色差。
- 比较源可选“笔触／底色”与“作者最终色”；均从操作开始前快照读取，不采样带光照屏幕，也不边填边改变比较依据。
- “选区填色”明确表示将当前选区统一填成画笔色，不必伪装成从一点扩展的魔棒填充。
- 写入的是当前画笔原始色，仍由 `appearanceColor()` 合成 faceTone；不为追求屏幕颜色相同而逆算并污染笔触。
- 擦除选区只删稀疏手绘覆盖，露出当前底色与暗面；不把背景颜色硬写一遍。
- 大范围填充必须先估计像素／面／消息体积；超限整次拒绝，或在有进度的可取消纯计算中规划。不能写到预算为止留半片填充。

## 7. 对称：共用空间规则，两套写入器

### 7.1 范围和中心

第一包要求 X、Y、Z 单轴及多轴组合；对组合结果去重。这里的轴是**资产作者空间轴，Z向上**，不是屏幕轴，也不是并不存在的物体旋转矩阵。

- 中心来源：当前物体实际包围盒中心、手动米坐标、从模型选点；空物体可用当前画布原点。
- 不默认使用资产 Root；Root可能是拼接点或门轴。改变对称中心不移动Root／物体原点。
- 中心设置后冻结。持续建模改变包围盒时不漂移；“重置到当前中心”才重算。
- 提供可见平面、方向标签、镜像笔头；小窗口收进对称分组，不遮挡视口。
- 作者空间中的“X对称”表示关于 `x=d` 的镜像。多轴由多个互相垂直平面组合，不是绕中心旋转。
- 工具设置不写入作者文档；本机记忆必须按目标身份隔离。主窗／子窗共享同一经过校验的对称规格或显式复制设置，不依靠两个窗口各自猜同一个中心。
- 第一包不跨画布、不同精度或不同对象匹配；不建立最近邻“找一个差不多的面”策略。

### 7.2 网格对齐公式（实现与测试依据）

设当前画布该轴原点为 `o` 米、体素边长 `s`、整数格坐标 `i`、对称面 `x=d`。格子中心 `x=o+(i+0.5)s`。

```text
镜像中心 x' = 2d-x
镜像格坐标 i' = 2(d-o)/s - i - 1
合法条件：K = 2(d-o)/s 为整数
```

- 对称面通过格边界 `d=o` 时，`i'=-i-1`。
- 对称面通过第0格中心 `d=o+s/2` 时，`i'=-i`。
- 不满足网格条件时明确提示，允许显式吸附到合法半格平面；不得偷偷round全部镜像格。
- 法线也镜像：被反射轴的法线分量变号，其他分量保留；面编号随之变化。
- 贴图像素应映射**像素中心**和面法线。再按目标面既有升序切向轴还原u/v，验证结果精确落于像素格；不简单把每个面都做 `u=n-1-u`。
- 共用合法体素半格平面可确保本轮三精度的贴图也对齐。未来需要半贴图像素中心时另扩展，不影响本轮默认。

测试覆盖奇／偶宽门洞、中线单格、负坐标、非零原点、X/Y/Z、双轴与三轴组合、六面与不同切向轴；同一像素／体素被多个镜像路径命中也只写一次。

### 7.3 贴图对称

- 源候选先完成路径／形状栅格化，再镜像完整足迹；与无对称时相同的尺寸、圆形、像素完美语义。
- 镜像目标必须有真实的授权owner和匹配方向的几何外露面。没有则跳过并计数，不补体素、不投射到邻近表面。
- 默认镜像位置也必须视线可见；提供“允许镜像到不可见外表面”显式选项。这不是穿透刷：它只访问精确的镜像目标，不能访问被实体占据的内面。
- 对称结果仍受当前贴图选区与保护范围约束；提示“右侧被选区排除”等原因。
- 画笔、擦除、直线、折线、矩形、椭圆支持对称；填充先计算原侧连通结果，再镜像其像素集合，不在对侧独立泛洪扩成另一大片。
- 取色不对称，只读取实际指针处；选区建立也不自动镜像。
- 原侧与各镜像作为同一次历史；任何预算或源版本错误整笔失败。合法但无对应面的候选允许跳过，预览与统计必须真实。

### 7.4 建模对称

- 作用于当前画布的基础画笔添加、擦除、重染；必须覆盖现有三维固定平面、表面搭积木和搭积木·创造的相关画笔路径。矩形体素工具只在复用候选事务可保证时接入，并明示支持状态。
- 先取得普通工具的实际候选格，再镜像候选及法线，最后重新执行原占用／保护／对象权限检查。不是把鼠标屏幕坐标翻到另一侧再点一次。
- 物体模式沿用当前“新格独立物体”的约定，不因对称自动合并；编辑模式新增格仍属于当前物体，其他物体不能被擦除或重染。
- 擦除需命中已有合法格；添加遇其他物体占用不覆盖；重染保留owner及原本非颜色参数。锁定、隐藏和受保护内容不因对称绕过。
- 中线不重复添加、重复扣预算或生成重复物体。镜像两侧预览与一次撤销一致；被跳过的一侧显式标记。
- 删除有绘画／暗面的格子沿既有几何清理逻辑维护paintSource/faceTone；恢复历史要恢复全部源，不能从baseCells/voxelCopies复活幽灵格。
- 第一包不把对称应用到S重采样、物体移动旋转、画布合并、岩体随机化；这些属于不同命令，不暗中获得新语义。
- 原建模像素完美在其既有适用范围内仍可用：先得到修整后的本笔候选，再镜像。与贴图像素完美设置完全分开。

## 8. 笔画事务与异步确认：不能新增丢笔问题

### 8.1 现有风险应先复现

`paint-workspace.ts` 在busy时将工具状态置空；`command()`在catch中显示错误但不向调用者传播失败。现有代码不能仅凭“commit Promise已结束”区分成功和失败。本轮要建立明确回执语义，不宣称现有EXE所有快速连笔都已通过。[S2][S4]

### 8.2 推荐的有限顺序队列

- 主会话继续只接收一个在途写命令；客户端允许少量尚未发送的完整笔画差量，建议初始上限4笔，并同时受像素与内存预算限制。
- `confirmedSource`、`inFlightDelta`、`queuedDeltas`、`activeDraft`分开。预览由已确认源顺序叠加，确认一笔后不闪回旧图。
- 下一笔在本地逻辑结果上开始；差量记录设置／删除哪些像素，不把两个旧全量快照并发覆盖主会话。
- 发下一笔前，以最近确认revision和顺序累积结果生成既有`paint`消息。可保留现有全量source协议；第一包不强制改成远端差量API。
- 全量source消息必须保留该画布中其他物体的全部原手绘键；只改本租约目标，不能用局部新对象覆盖整个paintSource。
- 每笔独立commandId且只提交一次；超时重试必须使用同ID及同内容先取得回执，不能换ID造成重复历史。
- 队列满时光标与状态明确阻止新手势，不允许用户画了而没反馈；禁止无限缓存、绕开32MiB或像素限额。
- 对待发送笔画的快速连点应可预见；实测20笔，确认源与预期逐笔一致，不能仅依据事件触发次数判定成功。

### 8.3 失败、保存、撤销与窗口生命周期

- commit返回明确成功回执或抛出失败；错误不能被catch后按成功消费。失败恢复最近确认源，冻结后续队列，说明未提交笔数，允许有界的显式重试或放弃。
- 不在租约失效、新对象或新画布上自动重放旧队列；不在关闭子窗时回写一个旧模型快照。
- 保存、返回、窗口关闭、切目标、Undo/Redo都必须与在途队列串行化。正常完成队列后再执行命令；未落定手势要求结束或取消，不偷偷丢弃已确认在主窗的笔触。
- 保存失败保留主会话修改与未保存标记；关闭子窗不代表已写磁盘。
- Esc取消当前draft；不撤回已发送且可能已提交的命令。已确认笔触用Undo撤销。
- 失焦取消活动手势；已经结束并进入队列的笔画不被普通失焦清空。显示与相机变化不重置确认状态。
- 子窗崩溃／关闭后释放租约；主窗不能永久写锁。已确认源继续在主窗，未确认数据的恢复能力按实际证据说明。
- 选色与切工具不必等待确认，但新作者命令必须遵守顺序。父子窗口之间只共享必要且验证过的状态。

## 10. 定向验证矩阵与验收故事

### 10.1 验证等级

采用**B级模块验证**：涉及绘画输入、共享历史、IPC确认与建模候选，但不改变游戏规则，也不默认跑全部工坊历史故事。共享生命周期发现回归时按证据扩测。

### 10.2 必测矩阵

| 项目 | 成功用例 | 失败／边界 |
|---|---|---|
| 表面坐标 | 三精度×六面；跨格线；负坐标；非零origin | 宽笔刷碰洞／遮挡／其他物体／退台 |
| 图形 | 水平、斜线、折线、反拖矩形、椭圆 | 极斜视角、零大小、超预算、起点无面 |
| 像素完美 | 本笔短折角清理，跨格不断 | 旧笔触恢复；交叉／端点；大笔刷状态不误报 |
| 范围 | 矩形加减选、反选、平面填充、容差0与非0 | 空选区不能全填；不越过洞；选区不写资产 |
| 贴图对称 | XYZ单轴/组合、奇偶宽、中线、镜像法线 | 不匹配表面、被选区裁剪、不可见镜像开关 |
| 建模对称 | 添加、擦除、重染、三工具路径 | 网格不兼容、别的owner、锁定/隐藏、预算 |
| 历史 | 一笔含镜像=一次Undo；Redo精确恢复 | Esc、失焦、重复确认、超时重试、未知command |
| 连笔 | 顺序20笔和排队时保存 | 队列满明确反馈；失败不按成功消费 |
| 显示 | 原色／柔光、辅助线、旋转、缩放 | 灯光不入吸色／源；切显示不丢确认中的预览 |
| 持久化 | 保存重开、便携源、复制物体后笔触跟随 | 老资产不强制迁移；不扩画布/Root/几何权限 |
| 导出 | 新绘图真实GLB/FBX+PNG与作者色一致 | 纹理预算拒绝；损坏依赖明确失败 |
| UI回归 | 画布列表、菜单顶层、独立窗口返回 | 禁止透点、误删体素、文本焦点抢键 |

### 10.3 门洞故事——用户判断“真的好用”的主用例

1. 打开原创带门洞厚墙，进入独立贴图窗口，选原色检查；旧底色、区域色差、暗面都保留。
2. 用色轮选两档深灰；当前色／上一色切换，不触发整槽重染。
3. 一格大小笔刷跨数个体素面横扫，没有格子裁切；改1px开启像素完美画一条转折线。
4. 用直线/矩形画门框饰条，经过空洞不染后墙；取消一次形状确认资产没变。
5. 框选门框正面，填充连通范围；选区外不改。清除选区后设置门洞中央X对称。
6. 左侧画纹样，右侧准确镜像；转相机仍在同一中心；一笔撤销两侧都恢复。
7. 保存项目、关闭子窗，在主窗进入物体编辑；对称增删两边凸块，未选物体不变。
8. 保存并完全退出重开，再导出FBX+PNG；Blender回读对照纹样与颜色，不只对照模型轮廓。

另外用L转角、遮挡墙、完全不对称物体验证拒绝／断段行为，不能只挑一个完美对称平面宣称通用。

## 12. 下一功能包：修改与复用（N1–N4，不自动开工）

这是后续实施的需求和设计底线，不是本轮代码授权。第一包不提前塞进假按钮。

### N1｜轻量手绘层与透明度

目标：底色／区域色差保留；手绘可按石面细节、纹样、磨损分层，至少新建、命名、显隐、锁定、透明度、顺序、删除、合并。

需要版本化新源与完整迁移。现有不透明paintSource作为保底层导入，保留旧可编辑源副本；旧程序不能静默丢字段。alpha混合语义、色彩空间、父会话权限、像素与图集预算必须先定合同。

建议合成方向：底色 → 可编辑手绘层 → 现有faceTone按原“是否影响手绘”策略合成 → 单独自动边带。该顺序仍需用兼容样例确认，不能改现有“保护手绘”的结果。只有普通混合一种也可以，不做全SAI混合模式。

验收：调磨损层透明度不改纹样；隐藏/清除可恢复底色；便携源与重新导入FBX颜色一致；旧单层样例迁移前后逐像素一致。画布列表不能被误当手绘层列表。

### N2｜多边形选区与图案复用

目标：多边形套索、同平面像素复制／粘贴、整数移动、镜像、90°旋转；明确剪贴源包含当前手绘层还是作者合成色。

不任意插值缩放，不自动跨曲面贴合。粘贴遵守选区、目标与遮挡；新几何不能凭空生成。后续可把复制片段保存为用户印章，导入图片权限另行登记。

验收：一段门框纹样复制到另一处不模糊，原纹样不损坏；撤销恢复；保存重开结果相同。

### N3｜作者自动结构边带（旧P3）

目标：台阶侧面上沿深色带、顶面向内收的边带；宽度以贴图像素／米表达，颜色相对基色或指定色；独立预览、替换、清除，默认保护手绘。

依据真实几何凸边、台阶、外轮廓，不依据体素格线、材质分块、UV岛或三角形缝。不是视口OutlinePass，也不是不随导出的黑线。

建议以独立生成参数和派生缓存保存；几何变更后重算或明确标过期。显示、保存、复制／变换、便携源及PNG烘焙必须统一接入。不能通过向每个小面永久填一圈黑色占满手绘预算来凑效果。

验收：一整块平顶内部无棋盘，真实台阶有连续边带；换种类/宽度不累积；手绘保持；FBX+PNG保留效果。

### N4｜手感增强候选

轻量防抖、压感、更多印章、径向对称、跨非共面表面连续铺展，按真实操作反馈选择。不是第一包的完成门槛；更不扩展成水彩模拟、AO/法线绘画或完整PSD互通。
