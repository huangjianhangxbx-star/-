基础线的完整操作闭环

落锚点，调范围，再改局部。

锚点、方向与范围示意。实色区对应真实允许修改区域；并非需要把整片场景重新“拆成方块”。

  1. 选择锚点固定参考位置与表面，不追着新预览越画越高。
  2. 调整范围用方向滑条／手柄调整左右、前后和高度带，看清实际影响范围。
  3. 局部解算与预览抬升、延伸、下压、削减或上色；相邻块只更新必要边界。
  4. 提交并合并表面体积与颜色数据保留，表面网格重新合并；一笔可撤销。

连续拖画仍保留为另一种输入方式，与定点塑形共用局部编辑能力。单独的参考强度、尺寸和颜色控制不等于针对每个源模型写一套专属规则。

上色怎样方便？

同一笔刷内直接涂色；锚点范围可一键填色，并可限制顶面／侧面和高度带。上色结果需要保存，重建地形不能把手涂颜色冲掉。具体可用选区与冲突处理以完整计划为准。
