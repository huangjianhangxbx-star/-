# ReferenceVideo_001

来源：视频图片参考/基本部署出怪攻击范围等参考.mp4。
ffprobe 实测：33.100 秒，1344×740，30 fps，H.264 + AAC。
核验方式：覆盖全片的每 3 秒抽帧，以及 12–20 秒每 0.5 秒抽帧；另查看 18 秒原尺寸帧。没有按实时连续播放或音频分析，不能据此认证精确动画时间与操作延迟。
证据：work/reference-frames/overview.jpg、interaction-12-20.jpg、range-18.jpg。时间为本地视频相对时间，抽帧概览有采样误差，不等同于 UI 内时间。

| 观察段 | 直接可见内容 | 结论边界 |
|---|---|---|
| 0–9 秒 | 编队、黑场与 1-12 标题过渡，随后战场 | 不能确认完整加载过程或可跳过规则 |

| 21–33 秒 | 敌人位置推进、攻击闪光、伤害数字与击杀计数增加 | 存在攻击反馈，不足以确认伤害公式或事件帧机制 |

镜头：固定斜俯视为主；选中交互有构图变化。地格边界清晰，高台具有可见侧面。Q 版人物脚底接近单格中心，身高约一格屏幕投影量级，武器与头发可超格；这只是视觉估计，不是比例测量值。
UI：顶部敌人/目标计数，右上速度与暂停，右下可部署角色与资源，选中时左侧详情。足底血条、轮廓、范围叠层提供独立反馈。

一致：斜视角、小地图、Q版与3D地形、方向性攻击范围、技能反馈。
差异：视频有全局部署费用；本项目使用个人始动量条。视频色调和现代 UI 不是项目最终美术风格。
无法确认：场上自由移动、自动转向、跨台、猎人救援、离场冻结、败退继承、光照、卡牌。视频未到完整胜利/失败结算。
