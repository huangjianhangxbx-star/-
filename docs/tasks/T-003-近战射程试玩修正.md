# T-003 近战射程试玩修正

用户截图反馈近战敌人攻击菲奥蕾但无法还击，并询问黄色三角预览来源。基准 017e393，接手工作树干净；开发细则／用户维护区不改。

确认原因：makeUnit 将除己方特例外的敌人射程统一设为 4；敌人能在接敌半径 1.5 内停止，而菲奥蕾射程只有 1。范围是圆形，不是扇形朝向限制。新增真实刷怪测试先复现失败，修正普通近战／重甲为 1，远程保留 4，集中配置于 combat-config.ts。127 项单元和构建通过，尚待用户再次试玩。

黄色碎片：scene.attackArea 的三角网格逐顶点贴合不同地形高度，跨边界形成斜面；仅表现层，不是攻击对象或伤害区域碎片。建议后续按地格表面裁剪范围覆盖层，让每块三角形处于同一表面，保留圆形外边界；本次用户询问原因，未修改预览。

技能沿用 diagnosing-bugs 与 test-driven-development；这是已批准数值范围内的纠错，不新增玩法范围。日志：work/melee-range-{red,green,build}.log。
