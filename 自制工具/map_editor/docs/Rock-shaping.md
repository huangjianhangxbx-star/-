# 岩体塑形 · 工坊试用

选中一个已合并的体素物体，打开建模视窗左侧 **建模 → 岩体塑形**。多个独立体素先按 Ctrl+J 合为物体；不同画布先按原规则合并画布。

**物体模式处理整个所选物体；编辑模式只处理当前体素选区。** 面板显示范围和格数。编辑模式没有选区时不能应用，不会自动扩大到整个物体。物体模式面板提供“进入编辑模式选择局部”入口；进入后框选，再打开工具。

选区限定原有体素的削切范围和增生起点，不是保护区。向内削切仍只能删除选中的格子；若需要切入更厚的体积，可开启选取穿透框选所需体素后再操作。未选中的同物体格子可提供厚度支撑，但不参与删除。

**塑形方式**提供“向内削切 / 向外增生 / 双向起伏”。默认向内削切保持已有操作。

- **向外增生**：从选中的露出表面长出新体素，不删除原格子，可超出原模型包围范围。单层表面也可作为起点，不需要提前堆出厚实体。
- **双向起伏**：围绕原表面同时形成凸起与凹陷。柱状以相关岩柱结构场分配增减；层阶让较低层向外展开、较高层向内退让。
- **向外最大格数**独立限制每个勾选侧面上的外扩距离，同时显示米数；0关闭外扩。向内上限另行调整。新增体素归入当前物体，沿用增生起点的基础色，不复制表面笔触。

增生可以超出体素选区，但必须从选中表面连续向外生长，不会把未选中的原有格子改成增生起点；遇到已有格子停止，不覆盖其他物体。默认彩绘保护还会阻止新增格遮住已有绘画面。双向塑形保留增生根部与必要连接。原模型不够厚只会限制削切，不会阻止单纯增生。

- **柱状岩壁**：选择+X/−X/+Y/−Y侧面，调整岩柱宽度、削切深度和竖向断阶。从局部露出的连续实体段向内计算，支持带洞口的墙。
- **层阶崖岸**：沿局部Z划分层段，从勾选的侧面形成相关退台；“层阶向内进深”控制最大向内范围，“向外最大格数”控制外扩。可处理拱门、变底和已经起伏的模型，不再要求整个物体平顶平底。仅一层高度的选区无法形成多个竖向层段，但仍能增生；需要更多层段时选择更多高度范围。
- **高级随机**：按结构类别单独输入种子或重抽。0保持默认，与总种子共同决定结果。可保留岩柱布局只换断阶，或保留层高只换边缘轮廓。

滑条以格数为主，同时显示当前画布的米数。预览从打开工具时的原模型重算，不会在拖动参数时累积侵蚀；右键旋转、中键平移仍可使用。查看原形可对照。“应用”一次提交，Ctrl+Z整次恢复，Ctrl+Shift+Z重做。

默认每次打开保护已有彩绘；“沿用旧保护柱”是独立开关，默认关闭，不会更改原有保护柱数据。面板显示削除体素、新露表面与受影响绘画面计数，悬停结果可查看消失表面、厚度/连接保留数与耗时。关闭彩绘保护时，真实受影响的笔触会随削切清理，新露面使用基础色；撤销会同时恢复几何、归属和笔触，未受影响绘画保持原样。

“标记变化”以绿色显示新增、橙色显示待削切体素，可关闭查看最终造型；“查看原形”临时对照输入。结果与原因固定在应用按钮上方，显示新增/削切/保护数量，参数区独立滚动。

Esc、取消、保存、失焦、切换物体/画布/模式或开始其他编辑会清理未应用预览；原模型不变。无有效变化时不能应用。画布锁定/隐藏、单格目标、过期源或不支持的几何会保持模型并说明原因。

当前竖向固定画布局部Z，处理四个轴向侧面；专用的任意面选取、上下面塑形、任意高度轴和岸段端点渐弱尚未实现。每条削切射线遇到其他物体或保护区即停止，不跨空气连续削穿；分离的露出实体段可独立处理。增生射线从实际露出面起算，允许在到达其他物体前的空隙中生长。最小厚度按削切方向的真实实体计算，薄处局部跳过，必要时保留连接格子，不再因整件形状把全部预览拒绝。总输入和结果占用上限为300,000格，超过时不提交部分结果。

应用结果沿现有原生资产保存、便携源、GLB/FBX+PNG流程；不会另建资产、改变Root或重采样精度。需要先确认预览，再保存。包内 `示例/岩体塑形/project` 提供两个原创练习体块。

这是工坊试用接入，实际建模手感待用户Gate R-B。没有引入真实侵蚀、洞穴/碎石生成或自动玩法通路保证。
