# EN-BAL-01｜普通探索新版敌人高压参数试验

状态：**待 Codex 执行的专项计划；完成工程与用户体感须分开记录**。
基准：`main@d8ab69a3fc08d1e5751f6ce0c2b62bff5673b9f2`，执行前应复核最新 HEAD。

## 1. 用户本次明确目标

> 现在己方太强、敌方太弱。试着让敌方**两下就能把己方的架势条打空**，**打中一下掉三分之一血**。

这属于**高压试验**，不是永久平衡承诺。建议将“一下”定义为**对角色的一个有效伤害接触**；未格挡/未闪避时，以目标 **maxHp** 为分母，而非当前剩余 HP。所谓两下是**架势尚未充分恢复期间**的两次真实有效接触，不能跨任意漫长间隔强制破势。用户未明确是否把骷髅弓整组 1+2 箭雨视为“一个攻击”，必须保留三箭真实独立实体并把其叠加危险单独列在验收里。

## 2. 实际代码与数字（供实施者再次核对）

- `game/src/core/enemy-profiles.ts`：僵尸 `ZOMBIE.power=5`，弓手 `ARCHER.power=3`；它们标记 `SOURCE + SAMPLE`，不能擅改原 Attack/Lock/Dash/Finish 事件时间。
- `game/src/core/engine.ts` `advanceEnemyEntities(...resolveHit...)` 当前给僵尸接触架势 15、弓手 10，仍通过主 `resolveHit` 一次性结算。
- `game/src/core/combat-config.ts` 猎人 `maxHp=360`，阿尔 `maxHp=260`。
- `game/src/core/pressure.ts` 普通猎人 `maxPosture=90`，阿尔 `maxPosture=70`；应以**实际 Unit.maxPosture** 为权威，因为职业和装备可能更改最大值。
- `game/src/core/enemy-posture.ts` 新架势：**第 1 次归零即控制**；格挡架势伤害系数 `0.5`，控制 0.6 s，恢复延迟 1.5 s、基础恢复率约 25%max/秒。保留它，禁止改回第二次才硬直。
- `resolveHit` 先读取阿尔无敌、猎人方向盾，再走 `damageAfterDefense`、格挡 HP=0、最后 `applyEnemyPosture`；按现有防御合法结算，不能绕过主入口写 `target.hp -= ...`。
- `enemy-ranged`/`enemy-attack-entity`：每套骷髅弓射击有 **1+2、三个可独立接触与落地的实体**，第三箭存在 .1 s 相对延迟；群体叠加危险必须实测。

## 3. 推荐可调试验方案（AI建议，不是已批准的长期参数）

### 3.1 两个显式试验预设

- `baseline`：当前 5/3 HP威力、15/10架势，作为历史对照与回退。
- `high-pressure-v1`：在**普通正式双人探索**的新版敌人接触结算中启用，建议**暂作普通入口默认试验预设**，以免用户打开普通游戏仍感受不到区别；允许 `?enemyPressure=baseline` 对照。具名动作夹具、Action Lab 应保留原基准，除非显式 opt-in。
- 显示极简“敌方高压试验”提示到**现有世界状态/帮助区域**，不要新增遮挡 HUD 的按钮、菜单或重排 PPT 布局；配置须真实进入 GameState/战斗结算，不能只是前端标签。
- 若新增预设影响大量历史核心测试，优先做清晰的 *session preset* 隔离；禁止用特定测试分支强制满血或重写黄金断言以制造绿测。

### 3.2 建议首版系数（试验值，Codex可通过实测局部校准并明记）

| 范围 | 高压试验目标 | 示例（仅正常无防御接触） |
|---|---|---|
| 生命 | 每有效接触造成约 `maxHp / 3` 的**真实 HP 损失** | 猎人约 120/360；阿尔约 86～87/260 |
| 架势 | 每有效接触约 `0.60 × target.maxPosture` 的原始架势冲击 | 猎人约 54/90；阿尔约 42/70 |
| 格挡 | 沿用现行防御：成功方向格挡 HP=0，架势依 EN04 `guard=0.5` | 例：猎人一次受挡架势约 27 而非 54 |
| 闪避/无敌/墙/未进入面积 | 0 HP、0 架势命中 | 不得因为试验模式绕过判定 |

为什么不简单给每次架势伤害设为 50%？因为两次攻击可能间隔略长于现行 1.5 s 恢复延迟；每下先用约60%，在近距离两次连续真实受击时更有机会破势。不要求隔十几秒仍两下必破；自然恢复必须继续生效。

**关于 1/3 HP 的精度：**建议由单一纯函数在正式 V2 伤害接触时按目标当前 maxHp、合法装甲 subtype/flat 估算 raw `power`，调用一次既有 `resolveHit`；普通无增减益/无格挡的实测结果目标落在 `maxHp × (1/3 ± 0.02)`，现有 Ward、背击、盾、无敌均保持合法偏移。该计算必须为临时 preset，绝不能在通用 `damageAfterDefense`、玩家对敌伤害或 Action Lab 原样板中全局改成百分比伤害。

### 3.3 必须处理危险观察者的一致性

若只是将实际 `resolveHit` 的威力升到约1/3，而 `visibleEnemyHazards`/`companion-combat.abilityThreat` 仍按旧 `power=3/5` 估算，AI 会错误判断为低威胁。让**只读危险观察、伙伴威胁权重与实际命中**读取同一高压 preset 的权威估算，不允许 AI 通过不可见目标位置或未来弹道结果作弊。

### 3.4 弓手 1+2 叠加风险——必须如实展示

本首版默认按**每个实际有效碰撞接触**调参，所以同一弓手的三处爆炸若都命中同一个角色，确实可能在一个攻击组中连续扣到接近全血并快速破势。这是高压试验的显性结果，**不是要重写三箭为一枚弹或暗中合并命中**。验收报告须记录“单箭 / 两箭 / 三箭同受击目标 / 两名弓手同时施放”四种结果。

如果三箭在常规试玩中形成不可读的瞬死，需在报告中提出独立 `archer-contact-scale` 或 `rootActionId` 组预算候选；**本任务不得为通过测试擅自添加未经确认的群攻伤害上限**。可让用户体验后决定是按每箭 1/3，还是按整套箭雨总额约 1/3。

## 4. 实施分段

- **E0 冻结基线**：普通世界与 EN06具名场记录两人物真实 HP/maxHp/posture/maxPosture/格挡、僵尸和弓手 contact/outcome/weapon/subtype；冻结当前全量测试与一对一、三箭、四/五怪真实浏览器轨迹。
- **E1 做试验配置**：单独模块管理 `baseline` / `high-pressure-v1`、只针对 `isStandaloneExploration && sessionMode=exploration && enemyV2` 生效；真正的单个高压命中由已有 release/contact/resolveHit 身份链驱动。不能同时保留旧威力消费者造成两次伤害。
- **E2 架势与生命**：接通标准暴露点；`postureDamage` 走现有 `applyEnemyPosture`，HP 走原 `damageAfterDefense`；不改 dodge/guard/CD/attack timelines，不增加假敌人攻击频率或额外 Hit。
- **E3 反馈一致性**：`visibleEnemyHazards`、`abilityThreat`、可见玩家伤害浮字、`combatTraceSnapshot`、EN/NR 离区代次；不放宽隐身信息约束。
- **E4 定向测试先红后绿**：猎人/阿尔各 1 次无防御命中约 1/3、2 次紧接触到0、1次+充分恢复不强制破势、盾正面成功/背后无效、闪避、墙体和落点圈外、不重击同一实体、三箭独立归属、死目标取消/离区旧实体失效、`baseline` 完整对照、trace启闭不改结果。
- **E5 真实试玩**：普通 `/`（高压）与 `/?enemyPressure=baseline` 两版本，各 1 僵尸、1 弓手、近远混合以及至少一次 G/Z 与盾/滚闪；无需让脚本靠开发接口改HP/位置“撑过”整张地图。统计实际 hpLost/maxHp、postureApplied/maxPosture、格挡/闪避次数及死亡原因。
- **E6 发布/交接**：对比表、参数模块与单元测试、失败和已知群攻失控风险、常规群体生存变化；只按有效授权选择性 GitHub main，停在用户体感测试 Gate。

## 5. 验收硬门槛

1. 无防御且真实接触后**实际**生命损失接近 maxHp/3（不是只改配置数字）；架势两次在未充分回满期间破势。
2. 不改变已经认可的猎人/阿尔动作事件、怪物 Source+Sample 事件时间与三箭子事件身份；不增加每次受击的额外隐藏生命/姿态结算。
3. 盾格挡、闪避、地形未命中无生命损失（现行盾挡减架势依旧）；低血量不会超过正常死亡/濒死生命周期。现有 `LT-01` 尚未实施，不能借调参改死者复活规则。
4. `baseline` 与 `high-pressure-v1` 同一个命中消费者，结果可核对，配置可回退；普通入口有可辨识试验标记。
5. 单/三箭群攻真实风险单独报告；若浏览器长流程因**本次难度大幅上升**无法无伤走到出口，不得修改角色 HP、降低怪物数量、篡改测试读取。应把行为改变与真正回归分别分类，并提供可完成的防御战术真实键鼠样本。
6. 用户试验观感未回报前，只能写“高压模式技术通过/待体验”，不能把 1/3/60% 标成永久平衡。
