## 1. 需求身份：哪些是用户要求，哪些是方案建议

### 1.1 用户明确要求

- 当前随机化像表面乱增删，实际造型价值不足。
- 希望从自己叠出的矩形体开始，选择四边等指定表面后，生成图 1 一类石壁。
- 希望生成图 2 那种不整齐、却具有规律和设计感的层阶边缘。
- 随机建模主要针对这两个用途，允许做专用工具而非追求泛用随机化。
- 当前讨论下一步计划，不中断正在执行的材质绘制阶段。

### 1.2 本计划的推荐默认值，尚不是用户永久确认的规则

- 共用一个「岩体塑形」入口，两个专用生成器；保留已有色阶随机化和旧边缘扰动，不顺带删除旧工具。
- 首版**只向内削切**，不增加体素，不生成悬空碎石或外长尖刺。
- 每次作用于**一个已选物体、一个画布**；保留三档画布精度，不跨画布重采样。大量独立体素可由用户先按已有命令合并为一个物体，工具不暗中代为合并。
- 轮廓和长条是主结构；局部缺损默认关闭或极低。所有样例参数标为 `SAMPLE`。
- 用原体素与结构规则生成真正可编辑的结果，不只是 shader 位移、屏幕假轮廓或替代源模型的不可编辑网格。
- 同种子支持重复生成；强度/深度微调不重新洗牌主结构。
- 以固定灰色、固定相机和普通均匀光的实际模型对比通过造型验收，再接入材质和正式 UI。

用户批准实施相应轮次后，可在本轮采用这些默认方案；需要改变作用对象、破坏源数据、增加外部依赖或突破范围时，另行报告，不以“AI 建议已写在计划里”冒充既有规则。

### 1.3 第一版不包含

真实水力/热力侵蚀、通用岩洞生成、任意轴向悬挑重建、跨画布布尔运算、全场景批量塑形、自动可行走性保证、自动修桥铺路、AI 自动绘贴图、岩体颜色噪声、节点编辑器，以及新的物体/集合身份制度。

## 2. 参考图与造型合同

### 2.1 本包包含的用户参考

- `references/01-columnar-wall.png`：用户图 1，优先观察左侧高大石壁的竖向条带，同时注意右下的层阶体量。
- `references/02-terraced-cliff.png`：用户图 2，优先观察顶面与边缘退台；中部高崖还有竖向条带，可作为后续组合方向。

图片原字节复制，尺寸与 SHA-256 见 `manifest.json`。只作用户提供的局部视觉参考；不得声称获得原游戏模型、解包成果或真实制作算法。**不把这些第三方游戏截图默认提交公共 GitHub、产品示例或发行包。**仓库只登记必要说明；实际图片留用户本地参考目录。

### 2.2 柱状岩壁的验收形态

必须同时看见：

1. 长条有主方向，纵向连续长度明显大于横向宽度。
2. 宽窄、深浅有成段变化，不是等距百叶窗，也不是满墙针刺。
3. 断阶少而明确；不同条带并非全部在同一高度断开，也不是逐高度重新抽签。
4. 主体体积完整，近看有细节，缩小后仍读成几组大结构。

失败示例：碎洞、蜂窝、随机棍棒、全高等宽栅栏、平滑鼓包、原大形被过度削薄。满足体素数量/连通性测试不等于造型通过。

### 2.3 层阶崖岸的验收形态

必须同时看见：

1. 平台中心完整且基本平整，变化集中在允许的边缘带。
2. 有真实高度层级和水平退台，不是只有外轮廓锯齿。
3. 层间继承同一主轮廓；突出的地方大致对应，不是每一层各画一张无关图。
4. 层高与退台宽度有节奏差异，避免等高等宽的“蛋糕/金字塔”。
5. 支持一个带凹角的不规则平台样例，而不只会给矩形切圆角。

图 2 的雪色/青色区域不属于本轮几何需求；不得用随机上色或强光暗影掩盖失败的几何。

### 2.4 两种“台阶”必须分清

- **网格锯齿**：轮廓落在体素格上自然产生的小级差。
- **结构台阶**：模型确实存在的岩台、分层退让和长条断面。

本轮主要生成后者；不得通过增加碎边频率，把前者冒充后者。

## 4. 作用范围与交互：先规定“改哪里”

### 4.1 选中的面，不等于可修改体积

新工具明确分开三个概念：

| 概念 | 含义 |
|---|---|
| **目标物体** | 本次允许改动的体素成员集合 |
| **表面区域** | 从哪几个外表面向内生成结构 |
| **影响深度/边缘带** | 从所选表面允许向内到达的范围 |

示例：选择石壁正面，深度 3 格，意味着可以削该物体正面往内最多 3 格的壳层；并非仅修改鼠标选中的最外一层，也不允许穿过空洞继续削后墙。

旧版普通体素选区的语义不改变。新工具用临时“塑形表面范围”明确显示扩展后的受影响体积；不能偷偷把旧选区放大。

### 4.2 柱状模式的最小选择方式

- 物体模式选一个已合并岩体，或在该物体编辑模式中进入工具。
- 侧面快捷项：`+X/-X/+Y/-Y` 与「四个侧面」。默认高度轴为工程局部 Z；需要时可选择 X/Y，算法仍使用当前画布局部坐标，不跟随相机方向乱转。
- 方向只是候选过滤，**不是把所有同法线内表面都选中**。首次支持从物体外包围区域沿该方向射入，取第一段属于目标物体的连续实心区间。
- 允许点选/追加单个连通的同向外表面区域；第一版限制平面/近似外侧表面，复杂内部洞壁不自动纳入。
- 预览高亮起始面和影响带，四边可同时预览和一次应用。

### 4.3 层阶模式的最小选择方式

- 选一个有厚度的平顶平台，自动提取平面外轮廓；允许矩形、L 形及预先绘制的不规则轮廓。
- 指定高度区间、向内影响带宽，预览将保留的平台核心。
- 默认只处理外轮廓；贯穿孔/中庭等内轮廓不自动视为第二圈“外岸”。首次支持内孔存在但不从孔边发起削切。
- 对局部边缘，允许选择外轮廓段；段端应有固定长度的影响渐弱过渡，不能突然切出一条不合理直槽。
- 受保护区域可由当前体素选区加入临时保护集合；它是操作掩码，不新增永久玩法属性。

### 4.4 平台中心保护与边缘变化

“保护顶面”在界面应改成**“保留中心顶面”**。要生成向内退台，必须允许边缘带的部分顶面变化。

内核保留范围外的体素逐项不变。保护区覆盖通道、门框、拼接端面、可行走平台时优先于生成器；保护造成效果减弱，界面要显示，不擅自扩大范围补偿。

### 4.5 原型适用几何边界

- 柱状：实心厚矩形体、普通厚墙、已粗建的简单外壁；各射入路径只改第一段实心区间。
- 层阶：单画布、轴向平台，适用区域每个平面坐标只有一个连续高度区间，并具可识别的主顶面。平面轮廓可以不规则或有孔。
- 对桥洞、悬挑、多层上下重叠、过薄结构等不满足条件的区域，先标出不支持并原子拒绝；不能强行压成单层高度图，更不能填平原洞。

这是首版专用工具的显式范围，不是宣称所有复杂岩体都已支持。

## 5. 公共生成内核与数据合同（拟新增设计）

### 5.1 纯计算与提交分开

推荐分层：

```text
冻结目标物体/画布/源修订与保护范围
    ↓
提取外表面或平台轮廓 + 建立局部坐标
    ↓
结构场：岩柱条带 / 相关层阶
    ↓
生成削切候选（不修改源模型）
    ↓
联合保护检查 + 新旧表面/纹理影响分析
    ↓
同一结果驱动预览和确认提交
```

建议接口如下，**只是拟新增合同，不代表现有 API**：

```ts
type RockShapeKind = 'columnar-wall' | 'terraced-rim';
type RockShapePlan = {
  sourceStamp: string;          // 几何、目标身份、画布、必要材质修订
  preset: RockShapeKind;
  seed: number;
  removedCellKeys: string[];    // 首版仅删除，不另造几何权威
  unchangedSurfaceKeys: string[];
  removedSurfaceKeys: string[];
  revealedSurfaceKeys: string[];
  diagnostics: {
    requested: number;
    applied: number;
    protected: number;
    unsupported: number;
    blockingReasons: string[];
  };
  recipe: unknown;              // 版本化参数与局部坐标锚点，字段在 R1 固定
};
```

新旧表面键应适配 B 阶段最终身份协议，不把这里的数组形式作为强制存储 schema。对大模型可流式/索引化表达，避免强制复制全部面列表。

### 5.2 参考帧、格尺寸与确定性

- 在当前画布**整数格坐标**执行；0.25/0.125/0.0625 米只影响参数换算与显示。
- UI 格数为主、旁边显示物理米数。不得用渲染器为了显示而使用的固定 0.25 单位推算真实模型深度。
- 本轮冻结一个结构场原点和方向，取物体局部参考框架，不使用相机坐标、当前可见三角面序号或修改后的包围盒持续重算。
- 相同几何、局部参考帧、参数和种子产生相同结果；体素数组/Set/Map 迭代顺序改变不得改变结果。
- 随机流按 `layout / vertical-breaks / terrace-levels / contour / chips` 分开，或使用坐标哈希；不要依赖遍历次数“顺手取下一个 random”。
- 调深度不换条带布局，调缺损不换主轮廓；调结构大小允许改变分段，但固定后仍可复现。
- 普通移动物体不应使已应用结果重新随机；无程序化修改器自动重算机制。

### 5.3 一次联合计算，不连续互相侵蚀

所有所选面从同一源快照计算候选，最后合并删除集合。

不得先削正面，拿被削过的模型再削右面，然后以最终顺序决定转角。四边顺序交换的结果必须一致。重复命中同一体素只删除一次，角落不按多个面深度相加。

取消、切换预设、调参、换种子都从本次原快照重算。只有确认应用后再次打开工具，才可能把上轮结果作为新的作者输入。

## 6. 生成器 A：柱状岩壁

### 6.1 推荐算法：成段条带 + 稀疏高度断阶 + 整数削切

不要从每格 Bernoulli 概率开始。先在所选面横向建立变宽条带：每条带有稳定编号、横向范围和归一化基准深度。

推荐步骤：

1. 用种子生成受最小/最大宽度约束的横向分段；宽度有变化但不出现大量一格细针。尾部不足最小宽度时合并，不能随手塞一条极窄碎片。
2. 邻段基准深度具有有限相关性和差异：不能每段完全一样，也不能最大/最小深度每格交替。可用分段值噪声或低频场采样，经限幅和离散化输出。
3. 沿高度复用条带身份和主深度；长段保持一致，仅在少数“断阶事件”处改变局部深度。
4. 事件间距大于常见条带宽度；只影响部分条带或相邻条带组，且改变后持续一段高度。不能在所有条带同一高度切出完整水平网格，也不能每层重新随机。
5. 原始深度场转为 `0..最大削切深度` 的整数格数；沿所选面向物体内部删除对应第一段实体。
6. 局部缺口最后处理，且默认关闭；不允许它破坏前面已经建立的主结构。

用于沟通的表达式：

```text
目标削深 D(u,z) = 整数量化[ A × clamp(条带主深度(u) + 稀疏断阶(u,z), 0, 1) ]
```

`u/z/A` 的精确端点和量化规则在 R1 单测固定。无需为了这条公式依赖 Houdini；它是本项目方案，不是原作逆向结论。方向性尺度控制可参照 [T1]，但“成段条带与稀疏断阶”的具体约束由本计划定义。

### 6.2 四侧连续与转角

对矩形体，可把四侧宽度连成一个闭合周长，按共同环向参数生成条带，并做周期接缝测试。这样有助于各侧共享尺度与节奏。

不能把独立平面编号当作无联系的四个随机种子。局部面可复用已冻结的环向/物体局部场，只用掩码限制应用。

第一轮允许矩形体用闭合周长、单面用平面坐标；对非矩形外壁的推广必须明确支持边界，不能悄悄改用四次独立随机。转角最终还须通过联合削切与厚度检查。

### 6.3 柱状预设的用户参数

| 参数 | 含义 | 初始 SAMPLE |
|---|---|---|
| 岩柱宽度 | 主条带宽度范围 | 2～6 格 |
| 起伏深度 | 最多向内削多少格 | 0～3 格；0 为完全不变 |
| 竖向延续 | 两次断阶间的大致距离 | 12～24 格 |
| 断阶变化 | 断阶密度和幅度，保持长段为主 | 低 |
| 规整程度 | 宽度/间距变化幅度，不是全局噪声强度 | 中 |
| 局部缺损 | 少量成片缺口 | 0 |

首个样例建议 `40×24×48` 格厚矩形体，四侧最大削深 3 格。数值仅用于首轮相对形态检查；不推断参考图真实尺寸。

## 7. 生成器 B：层阶崖岸

### 7.1 推荐算法：保留原占用 + 相关轮廓的嵌套退台

先选择“平台核心完整、上层向内收、下层相对更宽”的保守剖面，不提供任意无约束的轮廓编辑器。层阶与平台/陡壁区域分离可参考 [T2,T3]；下述体素削切、嵌套及保护合同是本项目方案。

1. 从合格平台源中提取真实平面占用与外轮廓，内孔保留。只把二维信息用于计算候选，**不拿二维高度图重新填充原模型**。
2. 在外轮廓内建立有限宽度的距离带；距离超出带宽的核心保持原样。
3. 按总高、最小层高与种子划分少量不等高层段，至少包含可见平坦退台与较长陡壁；避免全等高。
4. 为每层建立相关退让距离：共用主轮廓场，小幅变化可叠加，但从下往上的累计退让不能反向扩张，避免新悬挑。
5. 同一段凸出/凹进趋势在不同层大致继承；不得每层独立换一张随机图。
6. 以距离带和层段门槛决定保留/删除，最后与原体素占用取交集。没有新增体素，因此不会凭空封住旧孔洞。
7. 首轮缺损为零，先证明层阶结构；有必要时仅在局部边缘添加成片、小幅、低密度缺口。

### 7.2 可实现的数学约束（推荐，而非强制库依赖）

令 `V0` 为原物体体素；`d(x,y)` 为到被选外轮廓的向内距离；`k(z)` 为从底部向上编号的层段；`r_k(x,y)` 为该层需要的退让量。

```text
保留候选 V1 = V0 ∩ { (x,y,z) : d(x,y) ≥ r_k(x,y) }
```

该表达式只在影响带和高度区间中启用，范围外直接保留 `V0`。

建议构造：

```text
r_k(x,y) = r_base(x,y) + Σ[第 i 层的非负退台宽度(x,y)]，i=1..k
0 ≤ r_k ≤ 影响带宽
```

关键不是公式外观，而是同时满足：

- 同一 `(x,y)` 上层退让不小于下层，形成嵌套结构。
- `r_base` 与各层变化有共同低频骨架，不逐格独立抖动。
- 深层/核心不受影响；孔洞不填充；局部保护覆盖该判断。
- 距离计算使用有限影响带，避免为稀疏大包围盒分配完整三维数组。

初始距离度量建议近似欧氏/有界八邻域距离，避免默认四邻域距离产生明显菱形模板感。边界像素中心/格边约定须在 R1 固定。凹角最近边界身份切换处，优先使用同一物体局部二维低频场控制变化，避免随机相位突然翻转。

### 7.3 层阶预设的用户参数

| 参数 | 含义 | 初始 SAMPLE |
|---|---|---|
| 边缘带宽 | 从外轮廓最多向内影响 | 8～12 格 |
| 层数/层高 | 主层段数量与高度变化 | 3～4 个主层；层高不全等 |
| 退台宽度 | 相邻层横向退让量 | 2～4 格，累计不越带宽 |
| 轮廓段大小 | 边缘一次变化持续多长 | 大中段为主 |
| 层间错落 | 在共同轮廓上增加的有限变化 | 低 |
| 局部缺损 | 少量缺口，不改主轮廓 | 0 |

首个样例建议 `64×48×24` 格平台，并另做同高度 L 形平台。四周均可见的环形台阶不是唯一目标；同时要有一段明确陡崖与宽窄不一的退台。

### 7.4 与柱状模式组合

两者共用内核，但不是同一算法改方向。R3 可选做一份组合演示：先层阶，再仅在陡壁区域加弱柱状起伏；退台水平面仍保持干净。

首版**不要求一个全自动混合模式**。先使两个独立预设通过；组合演示不能取代任意一个单独预设的验收，也不能借机增加整套程序化地质系统。

## 8. 保护与失败处理：不能为了“出效果”破坏模型

### 8.1 修改权限最小化

所有删除必须同时满足：属于冻结的目标物体成员、在当前画布、位于批准的面/边缘带与深度内、不在保护集合。隐藏/锁定画布拒绝操作；同画布其他物体逐项不变；场景实例与原资产副本关系不改变。

### 8.2 最小厚度不是简单判断一次 depth

- 对每条向内路径只处理首个实心区间，不能越过空气、另一物体或受保护边界继续。
- 对面同时削切时，要按**合并后的结果**判断剩余厚度，不能两边分别认为“还有厚度”。
- 对合格厚体，可以用沿轴的原始实体区间限制削切，保留至少 `minThickness`；SAMPLE 可为 2 格，由对象尺寸合理约束。
- 凹角和窄连接不能仅靠轴向厚度担保；还须检查最终连通性与保护连接。

### 8.3 连通、附着与孔洞

以原目标物体的六邻接连通分量为参照：不得新增碎裂分量或清空受保护主体，不跨空隙连通别的物体。原本多个分量不因此自动合并。

关键接触/拼接处可纳入保护体素或固定边界带。连通性检查本身不能推断“这条路是否适合玩家行走”，不能宣称自动保证玩法。

超限可采用确定性的保守深度限制，并在预览显示请求/实际削切量；若限制后仍不合法，阻止应用。**禁止随机删完再清掉所有小碎块，也禁止填回体素掩盖失败。**保护导致无变化，应明确提示“范围过薄/受保护”，不造一个空历史步骤。

### 8.4 源数据及历史层

如果目标格存在 `baseCells/voxelCopies` 等多层源，必须遵循最新编辑契约同步处理对应坐标的历史源，否则只删合成格会在下次合成时复活。不能简单删除整个画布的历史副本字段来省事。

`objectId/cellKeys/collections`、颜色槽和材质身份按现有权威同步。未受影响成员和对象原点不变，不自动重设资产 Root，不把剩余碎片分成一堆新物体。

### 8.5 单次预览事务

- 开启工具后冻结源修订；调参/换种子仅更新派生结果。
- 新的预览请求使旧请求失效，旧 worker 回包不得覆盖最新结果。
- 确认时校验源几何、所有权及必要材质修订仍匹配；不匹配则提示重开，不套用过期删除列表。
- 应用为一次原子历史；Undo/Redo 几何、对象成员和受影响贴图同步恢复。
- Esc/取消关闭预览；切换资产/目标/画布/模式或保存前清理未提交预览。失焦按现有工坊生命周期取消，不遗留半次操作。
- 视角旋转/平移应能在预览期间使用；不要用全屏模态遮罩压暗结果或阻断审形。

## 9. 与 TOOL-010 B 材质绘制的兼容合同

**先塑形后绘画是推荐工作流，但不能以此为理由默认允许破坏已绘制资产。**

### 9.1 三种表面必须分开处理

| 表面状态 | 首版处理要求 |
|---|---|
| 原来存在且仍保持同一表面身份 | 绘画源逐字节/像素保持，不重采样、不漂移 |
| 因本次削切被移除的面 | 明确列出是否有已绘制内容；确认前提示；撤销后能恢复 |
| 削切后新露出的面 | 默认使用其体素现有基础色/材质；不把相邻图案强行拉伸过去 |

不要按整个资产“清空贴图重建 UV”，也不要按三角面编号猜笔触归属。最终 UV 重排由 B 的实际导出/表面映射处理，不在本任务创造第二套纹理权威。

### 9.2 已绘制区域的默认安全策略

默认勾选「保护已绘制区域」。对仍保留的 painted face，至少锁定承载体素，并保护其是否暴露的相关邻域；不仅要检查“被删的体素有没有贴图”，还要检查删除邻格导致的新旧表面状态。

预览必须给出：预计删除体素数、消失的已绘制面数、新露出面数、因保护被跳过的候选数。

用户显式关闭保护时，只允许通过现有可撤销材质事务处理真实受影响范围，未受影响笔触保持。若 B 实现还不能原子恢复被移除面的绘画源，**本版必须拒绝会损伤已绘制面的应用**，而不是只显示一句警告后继续删除。

保留与关闭保护的行为边界都须有测试和界面说明。是否支持“允许损失绘画”的进阶开关取决于实际 B 接口；不为了勾选验收表强行赶制不安全迁移。

### 9.3 未完成 B 时不得擅自接管

R0 读取 B 的实际基线、状态和未提交变更；未满足稳定衔接条件时，只可在已授权范围交付隔离造型原型，第二轮记为阻塞。不得替 B 重写 schema、提前重构它的材质文件，或以本任务名义覆盖并行成果。

## 10. 正式界面与最小作者流程

### 10.1 入口建议

沿用紧凑工具栏，在现有建模功能区加入「岩体塑形」。面板仅展开当前预设参数；“种子/高级保护/诊断”折叠显示，避免常驻说明堆满视口。

```text
岩体塑形
预设：柱状岩壁 | 层阶崖岸
目标：当前物体 / 当前画布规格
范围：四侧 / 指定面    或    外轮廓 / 轮廓段
主结构参数（当前预设）
保护：主体厚度、临时保护区、已绘制区域
[查看原形] [换一个种子] [应用] [取消]
```

第一次识别到只选了一个独立体素时，提示“当前目标只有 1 格；请选取并合并要塑形的体块”，不要自行扩选整个画布。

### 10.2 用户故事一：矩形体变岩壁

叠出厚矩形体 → 按现有操作合为一个物体 → 岩体塑形 → 柱状岩壁 → 四侧 → 选中喜欢的种子 → 调宽度与深度 → 看转角/背面 → 应用 → 继续逐格编辑 → 撤销/重做 → 保存重开。

### 10.3 用户故事二：平台变层阶崖岸

叠出平台或自绘不规则轮廓 → 选平台物体 → 层阶崖岸 → 设置边缘带与 3～4 主层 → 标保护通道 → 预览顶面/侧面/凹角 → 应用 → 材质绘制 → FBX+PNG 导出。

### 10.4 参数的职责分离

- “结构大小”决定条带/轮廓段的尺度。
- “深度/带宽”决定改动幅度，不随机更换结构布局。
- “层高/竖向延续”决定层级或长条长度。
- “规整程度”影响受约束的变异，不是所有参数同时乱动。
- “局部缺损”单独随机流，默认 0。

单独的“随机强度 0～100”不能成为唯一控制，也不允许只重命名旧增删工具。

### R0｜基线核对与第一轮边界

读取最新适用 AGENTS/细则、相关 CurrentRules/状态及本任务源码，不扫全部游戏或人工原稿。核对本地分支、未提交差异、GitHub 基准、TOOL-010 B 的真实进度和占用文件。

**通过条件：**明确可安全开展的范围；没有把讨论或旧计划当成本轮实施批准。

### R1｜公共结构内核、坐标与保护

新增纯计算模块，固定种子、源指纹、选面/影响带/保护集合与候选删除合同。先写以下测试，再接预览：

- 相同输入复现，打乱体素顺序与四侧顺序仍相同。
- 零深度无变化，空范围拒绝/无变化，不生成历史。
- 非目标物体、锁/隐藏画布、保护范围不变。
- 四边联合削切、厚度与连通检查，洞后实体不会被穿透削切。
- 三精度单位换算，以及旧层源不复活。

输出少量诊断数据即可，不引入长期全项目资源扫描、庞大通用生成框架或新第三方二进制工具。

### R2｜实现两个结构生成器

按 §6、§7 实现柱状和层阶模式，使用灰色原创夹具。两种算法都要有确定性、作用深度/嵌套关系、局部保护与异常拒绝测试。

首轮必须覆盖：单面墙、四侧长方体、矩形平台、L 形平台。不以外部截图或渲染图片替代真实体素结果；输出仍能由现有 mesher 和原生导出路线读取。

默认采用工程内独立验证页/开发入口，复用 Three.js 查看器，避免与 B 的主 UI 并行修改。说明实际启动命令；不把它冒充正式便携 EXE 新功能。R0 发现已可安全复用现有测试入口时可采用更小方案。

## 13. 造型与工程验收矩阵

### 13.1 最小模型夹具

| ID | 原创夹具 | 主要检查 |
|---|---|---|
| F1 | 厚长方体，SAMPLE `40×24×48` 格 | 四侧柱状连续、条带宽窄、转角无重复挖削 |
| F2 | 矩形平台，SAMPLE `64×48×24` 格 | 核心平顶、3～4 主层、不等宽退台 |
| F3 | L 形平台，同高、带一处凹角 | 轮廓继承、凹角不串噪声、不只适用矩形 |
| F4 | 薄墙/细颈/带孔厚体的小夹具 | 保护/拒绝、无断裂、无穿空气削后壁 |
| F5 | 同画布两物体、多画布三精度 | 目标所有权隔离、格/米换算、非活动画布不变 |
| F6 | 带局部文字或非对称图案的 painted 物体 | 保留面不变、失效面提示、新面回底色、Undo |

各夹具按影响阶段制作，不全都重复三套尺寸和所有种子。不得使用用户未授权改动的生产模型作为测试消耗品。

### 13.2 必须通过的技术检查

| 检查 | 通过标准 |
|---|---|
| 确定性 | 同源/参数/种子同结果；数组顺序及四侧选择顺序无关 |
| 控制独立 | 深度变化不重新分段；缺损变化不重排主结构 |
| 范围 | 删除是原目标成员的子集；非目标/保护内容不变 |
| 几何 | 零新增、无重复格、不填原孔、联合厚度及连通合法 |
| 层阶 | 适用区域层间嵌套；核心不变；主层数/尺寸有实际意义 |
| 所有权 | 剩余成员正确；旧复制源不复活；原点/资产身份保持 |
| 生命周期 | 调参不写源；取消无变化；过期请求不覆盖；应用一次历史 |
| 保存/导出 | 重开一致；便携源适用路径一致；真实 Blender 回读 |
| 材质保护 | 未变面笔触保持；受影响有绘画内容被保护或明确安全处理 |
| 失败透明 | 参数/几何不支持、超预算、保护限制、缺测都可见 |

### 13.3 美术验收必须独立记录

### 13.4 验证等级与成本

采用《开发细则》§7.1.1 的 **B 级模块验证**：当前内核相关单测、受影响 TypeScript/构建、少量真实 Electron 故事和必要 Blender 回读。仅在实际出现跨权威迁移等高风险时升级，不预先按整个项目 C 级做。

避免每次拖动复制全模型、每格全图 BFS、遍历整个稀疏大包围盒。使用局部范围缓存、有限距离带、必要节流/worker 与请求版本门；只有测到真实卡顿才扩大优化工作。
