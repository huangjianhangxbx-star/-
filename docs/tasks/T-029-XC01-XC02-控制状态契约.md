# XC01–XC02 控制状态契约

仅 Standalone battle 启用 ExplorationControl；Tower/旧庭院沿用 Legacy/Frozen。地图、敌人、技能与移动资源数据不变。

| 身份/操作 | 当前行为 |
| --- | --- |
| DirectActor | 当前实控原本体；controlledBodyId 仍是唯一持久控制权 |
| CommandFocus | 当前指令焦点；只允许另一名在场可控原本体，不暂停 AI |
| C | 有焦点时清除；无焦点时聚焦另一名原本体 |
| 1 / 2 | 聚焦猎人/所选同行者；点击当前实控者等价于清除焦点 |
| 3 / 4 | Standalone 无操作；Legacy 保持原逻辑 |
| 点击原本体/角色卡片 | 建立或清除指令焦点，不交接 AI |
| WASD / E R T / Shift | 同次按键先把焦点提升为 DirectActor、清除焦点/窗口，再执行动作；动作失败也不回滚控制权 |
| Escape | 无更高模态时只清除焦点；有模态时优先退出其当前操作 |
| CommandMode 普通地面点击 | 无 Aim 时不移动任一角色，也不显示移动路径 |
| DirectMode 地面点击 | 暂时保留旧点击移动，XC04 前的过渡行为 |
| 复制体查看 | 保留旧观察入口，不成为焦点或实控者 |
| 世界技能栏 / 相机 | 持续跟随 DirectActor；技能栏鼠标按钮不会提升 CommandFocus |

焦点、UI 查看、实控角色是不同职责。Standalone 原本体不再写入 Interaction.selectedId 或由逐帧 partySelection 镜像成为 AI 控制依据。HUD 的显示身份是只读投影，不能反写控制权。

## 生命周期

新合法焦点创建一次 1.5 真实秒 TacticalFocus，沿用 .20→1 恢复曲线，与其他 Slow 取更慢值；暂停/隐藏/互斥确认期间不推进。重复聚焦同一人不重启。自然到期只清除窗口，CommandFocus 仍保留。主动清除、提升、资格失效则清除窗口和焦点。自动回退及程序化 controlBody 不创建窗口。

失能、死亡、救援、撤离、进入影庭、脱离当前双人队伍、复制体身份变化或焦点成为实控者时清除焦点，不自动改焦点到其他人。退出 Standalone 或开始新远征删除运行时。暂停帧也检查失效身份，不推进模拟时间。

只有真实交接执行既有 release/acquire：撤销旧 Direct，保留已提交 mouse move/attack/skill/forced-motion/crossing 等生命周期，撤销新实控者的纯 AI 行走，交还离手者给原 AI2。聚焦本身不撤销路径、目标、companionCombat、Basic 或 Auto。

## 模块边界

`core/exploration-control.ts` 集中 Gate、查询、设置/清除、提升和 ensure。`commandFocus` 与 `promoteCommandFocus` 通过 engine Command 进入状态变更，main 不直接写运行时。`direct-control.ts` 仅持有交接与资格职责。

InputAuthority 为 modal / aim / direct / order / auto / ai 类型；当前输入入口由 modal 优先、未来 aim 次之、直接动作最后的统一查询保护。order/auto 保留类型，不引入订单执行器。Aim 仅有 path/skill/mobility 与 actorId 接口，本阶段不创建会话，不建设正式 Command 面板或 Mobility UI。

旧 T020 即时切人、T028 “切人启动窗口”的相关条款由本契约替代；其余 Follow/Pursuit/Ability/AI2/伤害、控制交接和资源规则继续有效。用户手感和后续 XC03+ 不由本轮自动验收推导。

## T-035 单一实控切换（2026-10-07）

用户批准以 controlledBodyId / DirectActor 为唯一实控身份。C 两位本体切换，1/2 绝对选择，头像及场内友方点击立即切人；有效持有 WASD 转交，新技能和机动只操作当前角色。当前角色选择 no-op，无效对象先拒绝。旧 Focus/Promote/CommandAim 与 CommandDefense 正常流程停用；离手交正常 AI，切回撤销普通 AI 路线。新 Aim 只属于 Direct，F 选路保留；切走作废未确认 Aim/token，但保留双方已确认订单和原子动作。成功身体动作只取消自身订单。主 HUD、技能和机动同绑 Direct；复制体查看只读，默认切人不自动慢速，其他模态规则保持。

此块替代历史 T029–T034 的双身份控制要求；资源、碰撞、订单、合法 Release/Hit 与真取消安全契约仍有效。专项入口：docs/tasks/T-035-单一实控输入与交接契约.md；执行与验证：docs/tasks/T-035-单一实控切换与控制简化.md、T-035-验证记录.md。用户试玩通过后直接回 EC10 战术轮盘；XC08/XC12/13 研究与演出不冒充完成，旧 XC10 Command UI 退出。发布仅 GitHub main，禁止 Gitee。
