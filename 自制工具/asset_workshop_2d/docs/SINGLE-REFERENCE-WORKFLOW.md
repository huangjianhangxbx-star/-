# 一张定稿图 → 正式联通（工坊 0.5.0）

双击 `启动工坊.cmd`，进入“样品到正式联通”，点击“我已有一张手修定稿图”的选择 PNG 或 Ctrl+V，选择平面石砖/草地/石质高差边界，确认四项用途后批准，再点击“导出扩展正式联通任务 ZIP”。不要求先有 AI 父图，不要求你绘制完整图集或数值控制图。

1. 原图作为唯一主要画法基准。检查实际原图、分辨率、Alpha、SHA；默认目标格128px、PPU100，原图不必128px。工坊不静默缩放、抠背景或把截图背景认成透明。
2. 四项检查是资产类型、固定视角、参考清晰、准确定稿身份。批准绑定准确原图和当前规格，不代表47态、美术或所有接缝已通过。平面石砖无侧面；高差石材使用独立的前暗面契约。
3. 把正式 ZIP 交给具有图像与文件能力的 Agent。它先理解原图，再扩展连续材料与边缘关系，返回艺术原稿和技术图层。工坊离线工作，本身不调用 AI。只有生图能力的 Chat 应如实停在绘画原稿。
4. 返回八区绘画原稿时，点击“导入艺术原稿并准备技术层”，阅读并确认显式编排政策。推荐画布4c×2c；不同尺寸必须由 Agent 提供精确窗口 JSON，不自动猜切或拉伸。艺术原稿和失败原件都保留。公共2px框由指定源像素重排，数值轮廓来自程序模板，艺术外轮廓未自动保留。
5. 编译后查看47态/188变体、3×3邻居、孔洞及8×8/16×16回拼。点击格点/诊断追到 mask、来源贴片和批准样品。明显重复、黑缝断裂、边角呆板等仍需看图。
6. 有问题，点“沿本次样品继续返工”，包自动带同一获批 PNG、失败原因与最近原稿SHA/取样记录，无须重填任务。换样品或硬规格会作废旧批准；可以明确复用原字节为新修订，再重新批准。

旧普通素材、经典母版和四形态 v7 仍有独立入口。新建时已有样品工程会先完整备份到本地 previous-projects；取消不覆盖原任务。每次 ZIP 写新文件，同名不覆盖。

本轮使用原创测试图演练，并非用户的最终石砖PNG。真实 AI 示例仍待人工美术认可，复杂石墙 Unity 排序未验证。首轮桌面测试未能确认恢复原剪贴板；使用粘贴入口前请重新复制自己的 PNG。
