## 实机方法与结果

使用 Edge 软件 WebGL、实际 Three.js 场景及 C/W/界面输入，fixture 固定近处高 HP 对手、合法地面和冷却以验证动作。真实 step/resolveHit 管线结算，不是自然通关或用户手感验收。t026 包含七个不同用例：近战、远程、重装、Tracking Break、Locked Break、四敌人多周期、reduced-motion/Debug/pick。

首轮五项通过，两项失败：W 移动前暂停会清空 held 输入，导致后撤/绕后测试失效。修正测试为真实 W keydown 后同步 step 再暂停，原玩法断言不放宽；远程与重装复查均通过。宽回归 63 项中 62 项通过，唯一失败仍为模拟暂停事件没有生效、异步时间耗尽后撤窗口。实拍复核发现 `e.target.matches is not a function` 横幅；新增 pageerror 断言后，单项真实 RED 捕获该错误（browser-runtime-red.log），再将模拟事件发送到 document.body，让事件冒泡进入真实处理器，正确暂停。最终 EC08 七项全部通过且 pageerror=[]，没有放宽短窗口或命中断言。

总计 63 个不同浏览器用例通过：56 项历史回归和最终 7 项 EC08；重复运行不重复计数。没有在测试运行期间修改服务端源码。历史测试生成的证据在全部完成后恢复到接手快照；EC08 保存最终截图/JSON与失败、复查、完整回归日志。

截图与 JSON 在 记录/验证/T-026；人工查看了近战重斩、重装护架与四敌人截图。能力双线和短名、侧移/后撤箭头和护架弧均存在，不只依赖颜色。稳定 fixture/软件渲染能证明功能与时序，不能代表目标设备性能或多人密集战斗的主观可读性。
