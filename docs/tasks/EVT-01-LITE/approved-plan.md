## 1. 本轮目标

玩家在当前正式探索世界中，能使用一个**临时事件入口**触发奇闻，看到 Galgame 风格的短叙述窗口，点击两个明确的剧情选项之一，看到各自不同的结果台词，且选择对应的**真实库存或经济状态**发生且仅发生一次变化。

这是**一个事件、两种选择、一次性结算、一个结果页**，不是建设剧情框架或任务链。2D TileMap 尚未进入此轮，不增建造、地块或场景交互物体；未来的场景触发器只需调用同一个事件触发请求即可。

### 1.1 玩家可见的样例内容（全部 SAMPLE）

- 事件 `sample-echo-event`，暂名《异常回响》。叙述：`石壁中传来断续的低语。一个破损的铁匣静静躺在角落，里面似乎还留有什么东西……`
- 选择 A：**打开铁匣，寻找补给** → 团队背包真实获得 `sample-al-regen`（实验缓回药）×1。此物品进入团队库存，**不**自动送给阿尔、不强制她使用。
- 选择 B：**回应神秘的低语** → 真实获得**随身生命力 +10**，复用现有 `economy.credit`。不进入永久账户、不绕过副本结算。
- 选择后进入同一个弹窗的**结果页**：A 展示找到药物的短句；B 展示回响消散与生命力增加的短句。均有“继续”关闭。UI 同时显示真实变更值。
- 两个结果互斥；同一当前世界只能选一次。关掉未选择的弹窗不奖励，能重新打开选择；已经结算不能二次领取。

### 1.2 触发入口（临时方式）

- 只在正式 Standalone 当前世界激活时，在原世界信息区 `#world-cluster` 的“事件”预留位置变成一个小按钮：`奇闻 · 异常回响`；“日历/天气”仍为未实现，不伪装成日历系统。
- 建议只允许在非交战 `explorationIdle`、未暂停、没有其他模态/瞄准/持有输入时打开。按钮触发后展示中央/下方对话框；不修改地图、不要求触发具体坐标。
- 已触发但未选择时，离区继续同世界仍可再次打开对话并完成。已选择则仅显示已处理的状态，不重新触发。
- 未来正式场景触发方式和事件出现条件**留接口**，不在此轮实现 TileMap、随机事件触发、NPC 或场景拾取。

## 2. Galgame 式窗口最低规格

一次固定叙述 + 两条竖排可点击选项 + 选后结果文字；建议布局：暗背景遮罩、清楚的事件名/说话者标签、较大的文字框、右侧或下方两项，沿用项目**黑底＋异色细边**设计风格。

无需立绘、CG、打字机动画、自动播放、语音、回看日志、多轮对话、随机分支、动态条件文本或专门 UI 设计器。

- 对话窗口打开时应**真正冻结模拟推进**（注意当前 `exploration-app.ts` 的 `simulationDelta`/`effectiveTimeScale` 使用显式模态条件，新增对话框不能只加进 `controlModal()` 就声称自动冻结）。不要将速度设置写回玩家选择。
- 打开前清理已持有的战斗鼠标/键盘输入；窗口内点击不穿透场景，不触发 LMB、WASD、Z、G/F/QER、Tab 或角色动作。选择通过按钮发送一次 Core 命令，不能只操作前端余额。
- `Escape`/关闭按钮在**未提交选择前**只关闭窗口，不改奖励/事件完成状态；再次打开仍可选。完成后“继续”关闭，玩家可返回正常探索。
- 小尺寸窗口不让选项被底栏遮挡；仅在真实布局修改有风险时再加第二尺寸检查。

## 3. 最小 Core 设计（不做通用剧情引擎）

优先新建小模块 `game/src/core/sample-event.ts`。世界中的状态附着到 `WorldSession.places[placeId]` 的唯一事件记录，例如：

```ts
// 示意，不强制固定字段名
sampleEvent?: {
  status: 'notStarted' | 'offered' | 'resolved';
  revision: number;
  choiceId: 'salvage' | 'listen' | null;
};
```

- `notStarted → offered` 在真正接受事件触发请求后发生；UI 可以关闭并在同世界重新打开 `offered`。`offered → resolved` 只能由合法选择触发。
- Core 资格与接受分开：`querySampleEventTrigger` / `triggerSampleEvent`、`querySampleEventChoice` / `acceptSampleEventChoice`（名称可按实际结构调整）。纯查询不可修改世界。当前世界的状态是权威，DOM 仅负责展示。
- 请求复核 `worldId`、`visit`、`placeId`、`eventId`、`choiceId`、`expectedRevision`、必要的控制身份；拒绝无效来源、已完成、旧访问、重复点击与恶意命令。真实模拟暂停与事件打开的 UI 资格不能取代 Core 防重校验。
- A：对唯一世界团队库存 `sample-al-regen` 安全 +1，检查重复/非法栈、非安全整数和溢出；不改阿尔后备或 Y 瓶。
- B：先确认 `economy.credit` 能成功，并使用稳定的事件奖励来源键防重；只记**随身**生命力。失败不改变事件状态或经济余额。
- 核对完成权益后再记录 `resolved / choiceId / revision`，保证失败无部分结算；同一事件只能产生一个结果。
- 同一世界离开/继续保留事件状态与领取结果；显式新测试世界重建 `notStarted`；刷新不承诺存档。不要污染旧 `ExplorationMemory.objective / mechanisms / cleared`、现有 QST 任务或旧塔防卡牌事件系统。
