# 双网格地形：一页操作（0.6.0）

双击工坊目录的「启动工坊.cmd」。若旧窗口已打开，请关闭后重开。开发机依赖已在本工具目录；更换机器需按 README 安装依赖并运行 build。

1. 在「样品到联通生产」导入你手修的**准确原始 PNG**，核对平面石砖形式，再明确批准这一版本。原有批准身份继续使用。
2. 正式制作选「双网格16态」，进入画板，沿用当前批准图。也可以直接点顶部「双网格地形」先试几何涂画。
3. 导出绘画任务 ZIP9，交给绘画 Agent。它包含准确参考原件、风格契约和连续 A/B 画布要求，**不要求你画16块或数值图**。默认4×4格母图，例如格128px时需要512×512px。
4. 导入或粘贴 A 连续母图。B 默认原创暗底，也可导入同尺寸不透明母图。尺寸不对保留原件并报告，不自动缩放；Agent 提供准确窗口且你明确同意时可原尺寸裁剪，覆盖至少25%，报告仍记录实际覆盖比例。
5. 编译后在地图涂 A、右键擦 B；支持直线、矩形、撤回/重做、3/8/16格与孔洞/棋盘等场景。Alt点显示格或选择检查工具可追踪四邻格、mask、相位、来源SHA。
6. 「检查当前地图」分别报告拓扑、像素边界、重复、美术和Unity状态；不满意时写返工说明，导出带原稿与诊断的任务。最后可另存工程、导出当前真实地图PNG或完整候选结果ZIP。

地图使用世界坐标相位，完整周期母图全部被取样。单独16张canonical只含一个相位，K4时仅占母图6.25%；Unity只用它会降级并增加重复，不能冒称全图继承。当前A/B必须不透明，边角由程序生成；没有保留AI自由边缘轮廓的保证。自然边线、裂缝节奏和大地图重复仍由你看图判断。

仅开放平面石砖，草地和高墙此轮未接入新生产批准；旧47态/188变体、草地和普通任务保留。旧路线在正式制作下拉框选择「旧47态」。同机工程恢复原稿与地图；异机导入需在原流程重新核对批准。撤回历史只在本次打开期间保留。

[可离线查看的原创技术样例](../samples/dualgrid01/index.html)全部是程序绘制的 test-only 夹具，**没有使用你的手稿冒充批准，也不是AI画风迁移成果**。真实手稿试产、最终美术认可、Unity实机仍待验。
