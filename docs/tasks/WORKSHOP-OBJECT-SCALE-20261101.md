# 物体模式 S 缩放

2026-11-01；与跨画布表面搭积木同轮，基线 392e15e。用户截图物体模式已选中物体，按 S 无法启动缩放。

## 复现和范围

真实隐藏工坊先 RED：下拉框失焦、焦点回到 BODY，单选 `body` 且体素选区为零时，S 仍无反应。编辑模式框选九格后，原 S 步进缩放可以启动。根因是 S 入口直接跳过物体模式，物体工具没有对应命令，不能只取消按键拦截就把对象当体素选区提交，否则新增格会变为独立物体。

本轮为单个物体增加 S 与常驻“缩放 · S”入口；保持物体模式，沿用体素步进缩放的中心扩缩和单位，不更改画布体素大小。默认 XYZ，X/Y/Z 约束、鼠标横移调整、左右键微调、左键确认、Esc 取消；缩放条持续显示对象及前后格数。文本/数值输入保留正常编辑，模式下拉选择后释放焦点。多物体不暗中合并，明确提示先只选一件。

## 数据与预览

纯计划生成预览模型，确认前不改源；提交走 CanvasSession 的对象事务，保持同一个 objectId、归属、原点/操作轴、其他对象/画布及一次历史。底色、贴图各图层和美术暗面随对象映射，base/copy 原稿结构保留。超预算、碰到其他物体、隐藏/锁定或不能保留描绘数据的有损收缩明确拒绝，不清空原稿。取消、切工具、失焦和对象变化退出预览。

## 验证安排

核心检查纯计划、所有轴向、坐标与预算、归属/ID、贴图图层/暗面/base-copy 保留、拒绝时原子性及撤销/重做。真实隐藏工坊回放对象模式 S、X 预览与 Esc、左键确认、一次撤销/重做、输入保护、模式下拉焦点、保存重开。与跨画布表面搭积木、原编辑选区缩放和矩形流程一同回归；统一构建、备份同步便携程序并核对资源哈希，最后选择性提交及正常推送 GitHub。
