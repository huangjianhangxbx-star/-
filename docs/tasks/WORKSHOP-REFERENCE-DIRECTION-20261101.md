# 工坊参考、显示、绘制方向与可靠操作

2026-11-01；依据用户本轮明确要求实施，不改游戏规则、人工表格与美术样件。后台临时项目验证，不控制当前窗口或写入用户项目。

## 约定与实现边界

- PNG 选择记忆上次目录，支持多张比例参考；比例参考使用世界米和固定 0.25 m 基准，画布改为 0.125/0.0625 m 时实际身高不变。旧单张参考元数据兼容读取。
- 建模参考是独立底层图像，随相机缩放而不遮挡几何；与用于体型比例的比例参考分别导入、选择、隐藏及移除。场景搭建支持比例参考并随项目保存。
- 编辑、模型预览、搭建场景三种显示档案独立；默认建模结构边线和体素格线开启。用户主动选择的显示设置保留。
- Ctrl+U 打开颜色调整；实时草稿同步到模型与搭建预览，取消恢复，不提前写入会话。吸色成功自动返回画笔。
- 物体粘贴覆盖此前遗漏的对象路径，按鼠标投影锁定 X/Y/Z，支持正负向。Esc 原地完成并选中新件，不再强制向右；同格独立副本用独立画布表示。
- 编辑朝向明确为上 +Z / 下 -Z / 右 +X / 左 -X / 后 +Y / 前 -Y；每个方向保存各自工作层。相机转向不改变绘制平面或工作层。
- 补充用户新报告：取景应按实际物体范围居中、合理占屏，支持快速聚焦；旋转以聚焦目标为轴，不把网格纳入模型取景。保存进行中问题需真实复现并保证完成或明确失败后可重试。
