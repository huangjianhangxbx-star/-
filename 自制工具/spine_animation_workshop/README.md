# 星骸 Spine 动画工坊 · SPW-01

将带骨骼动画的 GLB 中的一段动作，按一个目标方向映射到 Spine 4.3 角色。工坊生成**完整 Spine JSON 副本**；最终可编辑的 `.spine` 工程需要在 Spine 编辑器中导回。Windows 便携包的制作方法见 [packaging.md](packaging.md)。

## 准备与启动

1. 将便携包文件夹整体放在 Windows 电脑上，双击其中的 `星骸 Spine 动画工坊.exe`。若使用源码，在本目录执行 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm start`。
2. 准备一个**带骨骼动画**的 `.glb`。目标角色须先由 Spine 4.3 导出完整 `.json`；建议导出时包含 `Nonessential data`，供后续编辑器导入。把同名 `.atlas` 和它列出的所有贴图页放在 JSON 同一目录，例如 `rozeul.json`、`rozeul.atlas`、各页 `.png`。工坊不直接读取 `.spine` 作为目标输入。
3. 始终对目标 `.spine` **工作副本**操作；保留原工程和原贴图。便携包不包含角色素材或测试 GLB。

## 在工坊中制作

1. 点击 **载入 GLB 动作**，再点击 **载入 Spine JSON**。右侧可对照源三维模型或骨架与目标角色；两者共用时间轴。目标载入时会核对 Spine 4.3 版本、同名 atlas 和贴图页。
2. 在 **动作片段** 选择源动作，按需调整 **起点·秒 / 终点·秒**、**朝前轴 / 向上轴**。用播放、上一帧、下一帧和速度控制检查动作。
3. 在 **目标工程** 选择皮肤，填写本次 **方向标识**。**方向显示动作**用于预览该方向，生成的新动画会单独保存；方向标识并不会自动制作其他方向。
4. 在 **观察与对齐** 调水平角、俯角和镜像，选 **源脚点**、**目标脚骨**，再校准比例和横纵偏移。调整观察角会实时刷新目标当前帧预览。角度快捷按钮只是试角；默认俯角 5° 是可调整的起点。
5. 点击 **骨骼映射 + 添加**，逐行选择源关节、目标骨或控制骨、驱动方式与侧别。源关节分叉时可指定 **方向终点**。受 IK 或变换约束控制的链应映射其控制骨；不使用的行可设为 **跳过**。必要时通过 **局部修正 + 添加** 调整已映射目标的旋转和位移。
6. 填写 **新动画名称**、**采样频率·Hz**，点击 **选择输出目录**。采样频率允许 1–240 Hz，所选时间段最多生成 20,000 帧。状态栏会列出尚缺的脚点、映射或目录。就绪后点击 **生成动画**，检查目标预览，再点击 **保存完整副本**。每次保存会在所选目录新建 `SPW-01_<动画名>_<随机标识>/`，内含完整 JSON、atlas、贴图页与 `calibration.spw.json`；不会覆盖原输入。同名动画在 JSON 中会获得新编号。

可随时点击 **保存配置** 导出校准 JSON；之后用 **打开配置** 读取。损坏或不兼容的配置会报错，修正后仍可继续使用工坊；配置保存不会覆盖已载入的 GLB、目标 JSON、atlas 或贴图。重新载入 GLB 和目标 JSON 后，应核对动作、骨骼映射和局部修正，并**重新选择输出目录**。重选目标时旧生成会立即失效，新目标的 atlas 和贴图跟随新目标身份；必须重新生成才能保存。其他调参后也须重新生成完整片段，旧预览不再代表当前配置。

## 导回可编辑的 Spine 工程

1. 在 Spine **4.3** 主菜单使用 **Import Data**，选择输出文件夹中的完整 `.json`，导入到**新工程**，检查 atlas/贴图与新动画，然后将该临时工程保存为 `.spine`。JSON、atlas 与贴图页保持同目录。
2. 打开目标角色原 `.spine` 的**工作副本**。在主菜单使用 **Import Project**，选择刚保存的临时 `.spine`，选择 **Animation**，指定来源骨架、仅本次新动画和目标骨架。核对缺失对象警告及导入后的关键帧。
3. 将目标工作副本另存为新的 `.spine`，关闭重开，检查动画可编辑、贴图与方向显示正常。需要复核时从该副本再导出 JSON。不要用 **Import Data → existing skeleton** 替代第二步；该路径不导入动画。[Spine 官方导入说明](https://en.esotericsoftware.com/spine-import)

## 本轮范围

当前工程验证覆盖 `rozeul` 的一个可见方向和一条公开测试 GLB 动作。输入仅支持 GLB 与 Spine 4.3 JSON；不处理 FBX、视频、批量五方向或游戏事件。输出按映射骨链采样并采用地面原地化，复杂遮挡、手脚接触、发力姿态等仍需在 Spine 中检查与修整。技术导回已验证，最终动作观感仍由使用者审阅。
