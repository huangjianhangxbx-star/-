# 项目共用参考、对称中心与矩形

2026-11-01。保存后重开便携程序加载更新，不会自动关闭正在工作的窗口。

- 建模参考现在先绘制为背景，再绘模型、画笔和操作轴。开启凹槽增强也不会盖住模型。
- 每张比例/建模参考都有独立的透明度滑杆：0% 隐藏，100% 完全显示；建模图默认 50%，比例图默认 100%。拖动实时预览，释放一次提交；Esc 还原正在拖动的数值。
- 建模参考由同一个项目共用。切换资产或画布保留同一批图和设置，新图保存在 `project.xhproject.json`。旧资产和画布中的图首次兼容汇总，相同图去重，身份冲突的不同图保留，原资产文件不被重写。参考面板可独立“撤销参考 / 重做参考”，面板内 Ctrl+Z 同样有效。
- 场景比例参考仍归所属场景。建模右侧选择“搭建场景”时会显示同批场景参考，不影响场景物体、拾取、取景或导出。
- 对称面板可分别填写 X/Y/Z 米坐标，选择半格/整格并点各轴 −/+ 微调；“模型中心”“选区中心”可快速定位。“拖动中心”开启专用三色轴，半格吸附，只移动对称中心；点“完成拖动”或 Esc 返回建模。进入中心调整会退出参考图自由移动，避免拖错图片。
- 调整工作层或绘制朝向保留当前矩形、擦除等工具。**R** 选择矩形；三维、表面搭积木和创造模式都可画矩形。搭积木矩形固定起笔面，即使拖出原支撑面也不会攀爬漂移，整笔可一次撤销。

项目共享最多 256 张参考，单个资产/场景原有上限仍是 32 张；保存沿用 64 MiB 文档预算。旧项目汇总超限时保留原图、继续打开，并显示整理提示，不截断或写入空共享库。

验证：类型检查和构建通过；668 项核心回归中 667 通过，剩余一项为已在旧基线确认的 GLB 颜色浮点严格相等断言。真实 native GPU 40 组合检查背景不遮模型；隐藏工坊检查跨资产/细格画布共享、透明度与历史、40 张旧图保存重开、场景预览、对称拖动不改几何和矩形/工作层/R。全程使用隔离临时项目与配置。
