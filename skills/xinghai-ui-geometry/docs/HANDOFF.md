## 当前限制与未确认

1. 并非所有游戏 UI 截图都能自动识别所有元素。复杂图必须人工或视觉模型指出目标区域。
2. AI 可以依据技能说明检查视觉和确认策略，但本地 Python 分析器没有大模型视觉推理。
3. 还未实现从参考图自动提取矢量路径；素材由有限几何模板重新绘制，不是像素级复刻。
4. `validate_exports.py` 只验证结构、尺寸、透明、唯一性等技术指标，不证明美术质量。
5. 未测试 Photoshop CC 2018、分层 PSD、九宫格切片、游戏真实 HUD 运行时加载或用户试玩。
