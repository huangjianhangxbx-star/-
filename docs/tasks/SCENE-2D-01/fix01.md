## 交付参数与操作

默认地面400/341=1.173020527859U、有效341px/U。46片341×512/PPU341墙为1×1.501466U；**第46片384×384/PPU384为1×1U，继续保留原片例外，有效384px/U**，不把它覆盖成典型元数据。源PPU/pivot不改；墙统一适配系数1、源模数1U，偏移-0.45U保持旧实验基线。逻辑格、体型、速度、射程和黄金动作不变。实测站立非透明轮廓（Alpha>16/255）猎人1.203125U/阿尔1.3125U，脚点仍沿用已有画布定位；512画布的4U不是人体身高。

右上面板提供旧4U/统一密度、精确数值输入、逐片墙源像素/PPU/显示尺寸/实体占地，环境色/强度及三个灯独立启用、XY、颜色、强度、半径。源色为sRGB输入→线性照明→一次显示转换。默认环境色#b0bdcb、线性强度0.07；灯位置(11,12)/(26,16)/(37,13)，色#ffd9a2，强度3.2/3/3、半径9U；**均为本轮SAMPLE，无Unity强度换算承诺**。旧环境按钮仅恢复约(.43,.51,.60)的环境基线，不冒称重放旧所有Shader行为。复位完整还原新配置，JSON版本2包含灯配置/有效密度；冻结空气时间2供比较。

地面、墙、人物没有各自固定自亮，使用同一灯数组；墙面接收点约束在其逻辑格内，射线只忽略该接收墙格，其他墙仍截光。地面/角色不忽略墙。画面延伸区不是完整光照实体，红格=当前实体及光代理、青框=图片边界、黄线=排序，三者不混用。有限24采样非精确连续遮挡；薄墙/任意移动墙仍未全面认证。

|源功能|本轮状态|证据/差异|
|---|---|---|
|共享局部灯、弱冷环境、地墙受光|功能对齐（二维近似）|配置驱动真实GPU；人物同样受光，无固定+.16|

|消光、独立暖散射、暗边|近似|连续世界噪声/分角色密度；本轮空气不依赖Dust或邻域亮部，无原房间SDF/语义RT|
|原Normal/Data/Mask材质分家|未实现输入消费者|目标原图没有登记这些图；采用平面默认响应1，无假造法线、无离线修亮|
