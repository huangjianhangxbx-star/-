# SB-03 原创桥梁素材 v1

本套件是 B 专用搭建线首轮的 **9 件真实原创构件**。全部通过现有 `voxel_workbench/addon/api.py` 创建，保存原生 `.blend`、制作 recipe、palette FBX/GLB、PNG 色板和实际 Blender 中性预览。没有使用 Tiny Glade 模型；没有把整个桥作为一个预制体或把预制体重新解释成参考体素。

编号与角色见 [contracts.json](contracts.json)，图片见 [素材板](index.html)。工坊只负责构件造型，桥的联动布局与拱洞规则由 Unity 生成器负责。

## 契约

- 新源文件使用独立 `sb03.bridge.v1` profile，细节单元 **0.125 m**，结构接口步长 **0.25 m**。只在全新后台 Blender 场景内设置；没有安装插件或修改旧源/用户默认配置。
- 所有件为底部中心枢轴。登记尺寸按 Unity **X=桥长、Y=高、Z=桥宽**。所有美术造型位于逻辑包络内，未登记外扩。禁止整件缩放和未经认证的镜像。
- 实际源沿 Blender Z 向上；FBX采用共享导出器 `axis_forward=-Z / axis_up=Y`。独立 Blender 导入还原源的实际世界几何；Unity原始导入的轴向/子变换必须另由引擎 QA 核验，不能把包围盒对称视为方向验证。
- **Unity源坐标适配固定为180°绕Y旋转。** 先烘入实际导入FBX的root/child矩阵，再统一应用 `Quaternion.Euler(0,180,0)` 一次。旧引擎验证的raw映射是 `(-sourceX,sourceZ,-sourceY)`；适配后是 `(sourceX,sourceZ,sourceY)`。这是行列式为正的旋转，不是镜像或非均匀缩放。v1全部件在源Y／作者Z方向对称，因此桥宽轮廓保持设计。完整契约已写入顶层及各项 `unityAdapterYaw=180` 与 `adapterNote`。
- `tread` 源台阶跟部位于 Blender **+X**，源鼻口指向 **-X**。适配后鼻口仍指向作者 **-X**；它是唯一X非对称的定向验证件。引擎 QA 须检查适配后的实际包络、朝外绕序和鼻口朝楼梯下行侧。此适配记录没有重新生成或修改任何 `.blend`、FBX、PNG或GLB。
- 所有导出保留源的实际网格和 palette UV；内部接触面仍保留。这里只声明小型源构件，不宣称外壳合并或全桥渲染开销已达标。

## 实际验证

[native-validation.json](native-validation.json)：9/9 在共享 API 中合法；实际 Mesh 包围盒与契约尺寸一致。导出与预览前后模型指纹、原生文件 SHA256 均不变。

[roundtrip-validation.json](roundtrip-validation.json)：另起后台 Blender 5.1.2 进程逐件重新打开 `.blend` 并独立导入 FBX；9/9 通过网格数量、三角面数量、实际世界包围盒、全部UV合法且保留色板贴图检查。源/FBX/色板 SHA256 保持一致。

这不是 Unity 导入轴适配、碰撞、桥生成规则或交互体验的验收；这些必须由生成器的引擎验证单独提供。当前仅有 v1 源，没有所谓自由拉伸或任意弯曲素材认证。
