# T-036 / EC10 战术轮盘与伙伴策略契约

依据批准的 v0.1 计划，补充 T035 单一实控契约，只作用于 Standalone 双人探索。controlledBodyId 仍是唯一实控身份；轮盘不写 CommandFocus、Reservation、旧 Command Aim 或 CommandDefense。Tower/Legacy 不开放轮盘。

## 输入与时间

按住 G 在鼠标附近打开，四项为上集合、右集火、下保守、左自由；中心死区松开取消。打开时不自动选项，即使视口边缘钳制轮盘中心；实际移动鼠标后才选扇区。无有效目标时集火禁用。松 G 只提交一次，RMB/Esc 取消；取消后旧 G up 无效，键盘 repeat 不重开。

Session 固定打开时的发行者、离手接收本体、控制 revision、候选目标与递增请求身份；提交重新验证角色、目标和高层任务。复制体/敌人/失效对象不接收。成功请求保存每发行者单调序号，重放旧请求不替换新订单；失败请求无策略或资源副作用。

WASD 通道继续移动原主控。轮盘吞掉场景 LMB 完整按下/松开，不能漏出普攻或选人；F、E/R/T、Shift、C/1/2、明确 UI 操作先取消轮盘，同次输入再按既有契约执行。已有 Aim、模态、输入框或拖拽不接受 G。失焦、隐藏、resize、pointer cancel、暂停、接收者/实控身份失效都会清会话，不补发。

轮盘只在有效打开时贡献 0.1 倍率，与原模态/基础倍率取慢者，不改基础 1×/2×。暂停为零。UI 转场使用真实时间 120ms，减少动态时停用动画；移动、冷却、记忆、预算仍用模拟时间。

## 四项真实行为

- 集合：接收者向当前发行者的实时位置寻路，合法近点 1.2–2U；真实可达且近邻才完成。沿用碰撞/导航/inactive encounter 风险检查，不瞬移、不收纳、不切人。集合有效时 Follow 让路，阻止新的自主 Basic 和身体占用型 Rain/Reap Auto 起手；既有原子动作、Background、领域、费用/冷却继续正常。共用 Ability 防御优先，结束后再集合。每 .25 模拟秒重试，总就绪预算 8s，原子/硬直等待不消耗；预算结束明确反馈并自由。
- 集火：优先打开前鼠标指向的合法可见已激活敌人，否则当前主控最近 2 模拟秒内真正提交的手动 Basic 目标。没有就禁用，不猜最近敌人。既有 AI 安全贡献位置与实际自主 Basic 都绑定该敌人；保留职业/射程/防御和已有 AoE。丢视野只用最近已见旧位置，记忆 1.5s；死亡、return、退战、过期或贡献路径累计受阻 2s 后结束，不主动换下一只。
- 保守：只覆盖当前有效评分权重，risk≥2、flank≤.7、separation≥.25；不改永久 aiTendency/Profile/属性/资源，安全位仍输出。绑定实际角色，切为 Direct 后不驱动它，之后离手仍保留。
- 自由：移除轮盘临时策略并恢复原有 AI，不强写 default，也不删除精确订单。

集合/集火每次决策的新导航共享 128 个 A* 节点预算，耗尽按受阻处理并在下一次决策重试；直接可达路线仍保留精确端点。既有非战术导航默认无新增上限。它是本轮响应性边界，不等于所有复杂绕路都保证可达。

## 订单、原子动作与收尾

打开/hover/取消不改策略或订单。自由/保守保留原 MoveOrder；集合/集火成功后仅取代接收者订单，发行者订单保留，校验失败完整保留。成功的新 F 订单结束该角色集合/集火，保守偏好保留；旧 H/B 只在对象实际接受任务时收尾。

策略不得重置已提交攻击、领域、闪避、强制位移、跨层、落位、charge 或 CD；不可驱动时记为 pending-body，结束后重查实时世界，不存行动队列。路线受阻时撤掉自己持有的失效普通路线；收尾只清自己持有的普通路线；跨层保留当前原子边并撤掉旧路线尾部，不能清新玩家路径或技能落位路线。保守在失效/离场/新 Run 清除；集合/集火在被 Direct 接管时结束。

状态条显示真实接收者、策略、等待/受阻原因，集火使用合法可见目标标记；不引入长期管理面板。当前轮盘只指挥另一位在场本体；没有新增 Manual 技能 AI 权限或自动协同。

后续先由用户试玩四项与输入手感，必要问题在 T036 修正；EC11 技能标签/权限/协同、EC11.5 整合及既有 XC08/XC12/XC13 演出欠账仍未完成。
