# 像素完美 A1 使用说明

在物体模式选中需要编辑的物体，按 Tab 进入编辑模式。选择笔刷，范围1格、厚度1层；顶部“像素完美”默认关，点击开关后连续拖动绘制。

- 开启时清理本笔多余短折角；明确的长直角、旧体素和交叉点保留。
- 支持 XY/XZ/YZ 与 0.25/0.125/0.0625m 画布，按本地整数格处理。
- 鼠标按住可见独立预览，松开整笔提交；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
- Esc、窗口失焦、保存、切换物体或模式会取消未提交笔画。
- 物体模式、矩形、填充、擦除、大笔刷不执行折角清理。偏好仅本机记忆。

四组实际操作截图见 [开关对比](PixelPerfect-A1.html)。这轮为 Gate A 待试玩版本。三维表面 Base Color 绘制、自动 UV 和 FBX+PNG 属后续 B 阶段，尚未实施；当前普通 FBX 导出回归已通过。

物体与画布：物体模式新体素分别独立，同画布 Ctrl+J 合并；进入编辑模式的新体素归属当前物体。不同画布须先在折叠的“合并画布”入口合并，要求相同精度、网格对齐，保留物体身份，可撤销。
