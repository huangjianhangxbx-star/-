## 实际实现与键位

模块编辑新增独立“搭积木 · 创造”；保留地台、三维、表面搭积木及其既有工具。

| 输入 | 实际行为 |
| --- | --- |
| 左键单击/拖动 | 沿命中真实体素面的法线添加相邻格；空草稿可在地面起第一格 |
| Ctrl + 左键 | 删除命中格；状态文字和 Ghost 同步切换 |
| 擦除工具 + 左键 | 持续删除命中格 |
| 中键单击 | 吸取命中格的色板索引，不修改体素或产生历史 |
| 中键拖动 | 超过 5 像素后平移；一旦进入拖动，即使回到起点也不吸色 |
| 右键拖动 / 滚轮 | 旋转 / 缩放 |
| 起笔时按住 Shift | 锁定起始面的方向和工作平面，本笔不追随新创建表面 |
| Ctrl+Z / Ctrl+Shift+Z | 整笔撤销 / 重做（沿用模块历史） |
| Esc / pointercancel / 窗口失焦 | 取消整笔并恢复修改前状态 |

复用 EditOperationPlan / EditOperationSession。单笔冻结颜色与动作，采样去重，屏幕插值间隔不超过 4 像素（单事件最多 4096 次），一次历史。25 万预算在计划阶段拒绝新增。真实 DDA 命中用于六面操作；不以 Greedy Mesh 大面代替命中体素。

## 体素清晰与反馈

绘制视图操作条新增“体素清晰”开关。仅在编辑器材质 shader 中按 0.25m 坐标派生格线，使用导数抗锯齿及远处淡出；保留 Greedy Mesh，不创建逐体素对象。开关不改变源色板、材质身份或导出数据，保存前后源文件字节一致已验证。

命中格为青色立方体轮廓，命中面为半透明青色覆盖，实际目标为原计划 Ghost。侧面实测 Ghost 新增坐标与保存文件完全一致。状态提示显示添加/删除及自由/锁面，清晰开关沿用 active/pressed 金色反馈。
