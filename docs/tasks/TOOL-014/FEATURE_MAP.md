# 功能迁移表｜开工与收尾必须更新

2026-10-25：迁移入口已落地。下表将实际UI故事与仅由既有核心回归覆盖的入口分开；用户易用性验收仍待试玩。

| 功能 | 目标位置 | 保留约束 | 实际入口/测试/状态 |
|---|---|---|---|
| 项目/资产浏览 | 项目与资产；模型页资产抽屉 | 身份/分类/拖放/回收恢复 | 项目与资产原页；顶部资产抽屉；原浏览器复用，专项UI未逐项重跑 |
| 公共库/便携导入导出 | 资产页导入/文档导出菜单 | 原资产复制规则/哈希/范围 | 左侧画布页：导出/导入便携源；原公共库入口保持，便携与FBX实测回读通过 |
| 当前资产与改名 | 文档栏资产选择及标题 | 不改assetId/源文件身份 | 文档栏资产选择；资产更多→名称；assetId实测保存/重开保持 |
| 复制资产/另存新资产 | 文档更多 | 区别于物体复制 | 资产更多→复制模块/另存为新资产；原处理器保持，核心回归覆盖 |
| 保存/关闭/导出FBX | 文档栏及文件菜单 | 保存确认/重名备份/旁车PNG | 文档栏保存/导出FBX；资产更多→关闭；绘画窗口标明保存项目范围；UI与真实FBX通过 |
| 根点 | 资产属性→定位 | 六面九宫格/自由点/吸附/联合补偿 | 资产更多→资产定位→右栏根点；原处理器保持，根点核心回归覆盖 |
| 物体/编辑模式 | 建模上下文栏 | Tab/新增格归属/作用域 | 视口上下文模式；Tab原路径保持；物体模式建模/撤销与三精度绘画实测 |
| 物体与集合 | 左对象树/右键 | 集合不等于合并 | 左栏物体与集合页；原树控件，核心回归覆盖 |
| 物体合并/分离 | 对象命令/右键/快捷键 | 同画布规则/源可编辑性 | 建模命令→物体命令；Ctrl+J原路径；核心回归覆盖，未逐按钮UI重跑 |
| 多画布管理 | 左画布页/右属性 | 三精度/显隐锁定/原点/合并 | 左栏画布页；原列表与精度控件；三精度目标绘画实测 |
| 体素笔刷/擦除/矩形/填色/重染 | 建模工具条/右属性 | 现有笔画事务 | 窄工具条选工具，右栏当前参数/颜色；笔刷与擦除、撤销真实UI通过；矩形/重染核心回归 |
| 建模像素完美 | 建模画笔属性 | 原适用范围，非贴图能力 | 原视口建模像素完美保留；未增加贴图像素完美；核心回归覆盖 |
| 体素选择/穿透 | 选择工具属性 | 选择穿透非渲染透明 | 窄工具条框选；编辑模式选择属性/视口穿透；原选择合同核心回归覆盖 |
| 复制/粘贴/移动/90度旋转/S步进 | 命令/右键/快捷键 | 已有变换保护与拒绝规则 | 建模命令、窄工具条↔和原快捷键；核心回归覆盖，未全量UI重跑 |
| 点对点对齐 | 顶部操作栏常驻按钮 | 源点→目标点，沿用原变换/吸附 | 2026-10-25按反馈从辅助与参考移出；1500/1280/1000真实点击进入选源点通过 |
| 工作平面/厚度/方向/吸附 | 当前工具属性 | 坐标与单位正确 | 建模右栏绘制平面/厚度/方向；复用原控件；未改变坐标算法 |
| 岩体塑形 | 建模→岩体塑形/右属性 | 冻结源/种子/保护彩绘 | 建模命令→岩体塑形→右栏；保留原冻结计划/种子/保护逻辑 |
| 区域色差 | 自动上色→区域色差 | 对象/虚拟砖/色斑/稳定种子 | 文档栏自动上色→区域色差；真实应用/撤销、草稿保持/放弃/返回通过 |
| 美术暗面/清除 | 自动上色→美术暗面 | faceTone/保护手绘/非阴影 | 自动上色→功能选择美术暗面/清除；原计划器不变；核心与导出FBX回读通过 |
| 旧色阶随机/旧边缘随机 | 旧随机工具分组 | 仍可达，无声替换禁止 | 建模命令→旧随机工具；原按钮处理器，无声替换未发生 |
| 颜色与色板库 | 当前工具颜色/设置 | 固定色板/色环/原吸色 | 建模右栏颜色与色板；原库/色轮/吸色；独立绘画窗新增快取色板 |
| 贴图画笔/擦除/填充 | 独立贴图绘制窗口 | 单一会话/当前范围限制 | 文档栏贴图绘制↗→真实Electron窗口；六面三精度、擦除、历史、保存、重开通过 |
| 两种贴图吸色 | 绘画工具栏/属性 | 原笔触 vs 作者最终色 | 独立绘画窗工具选择：原始笔触/作者最终色；复用原合成，核心回归覆盖，未专项比较两者UI取样 |
| 四显示预设与灯光 | 每个视口显示菜单 | 不改源/不取消预览 | 顶部编辑显示/预览显示；绘画窗独立显示；显示/相机切换保持草稿真实UI通过 |
| 结构边线/体素格线 | 视口辅助 | 两者独立，非自动纹理描边 | 显示菜单的辅助显示；原控制器保持，无作者描边能力 |
| 三维副预览 | 视图→双视口 | 相机可独立，内容一致 | 顶部双视口；默认关闭，隐藏视口不绘帧；真实UI通过 |
| PNG比例参考/剖切/Z标签 | 辅助菜单/右属性 | 导出排除/非资产几何 | 建模命令→辅助与参考，剖切仍在上下文，Z显示在属性；原处理器保持 |
| 试摆集合/复制/变换/场景合并 | 场景试摆 | 实例身份与源资产明确 | 场景试摆工作区原结构；本轮未改场景数据/操作算法，核心回归覆盖 |
| 布局/UI缩放/快捷键 | 视图/设置 | 本机偏好不标资产dirty | 层级/属性/资产抽屉/双视口，右栏布局设置；1000/1280/1500及150%实测 |
| v1发布与Legacy | 兼容入口 | 不被新样式/菜单破坏 | v1代表链：独立绘画六面三精度/保存/重开通过；Legacy独立入口真实启动烟测通过 |

本表只跟踪首轮既有能力迁移。P1–P3是新增能力，不用于给首轮打虚假的完成勾。
