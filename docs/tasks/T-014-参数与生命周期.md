# T-014 参数与生命周期

2026-10-04。来源为本轮执行附件及用户对 Q1/Q2 的明确采用。全部数值为首版可调参数；不等同最终平衡。

## 承压与虚血

| 项目 | 当前实现 |
|---|---|
| 最大架势 | 猎人90；治疗/冰系辅助80；灵活近战/旧守卫110；盾卫/伊内丝140；阿尔70。敌人普通近战90、远程60、重甲150。 |
| 武器架势伤害 | 猎人15、治疗8、冰系12、旧守卫12、阿尔12、盾卫24、镰刀20；敌人普通14、远程10、重甲24。生命伤害增减不自动影响架势。 |
| 技能架势伤害 | 猎杀18、霜镜25、毒爆10、狙击30、箭雨每箭0.3、镰舞20、回镰25；纯治疗/领域0。各派生继承施放快照的配置；可与HP系数独立调整。 |
| 破势 | 从正值扣至0仅进入破势；下一次正架势伤害才硬直。零架势伤害、闪避、重复逻辑命中不触发。 |
| 硬直 | 0.6模拟秒，不叠加/刷新；其间仍受HP伤害；结束回50%架势，再等待1.5秒。 |
| 自然恢复 | 最后有效架势伤害后1.5秒开始，每秒最大架势25%。跨过等待边界只按余下时间恢复。 |
| 虚血 | 仅真实HP损失的100%生成；护盾承接和架势损失不生成。最后HP受伤后保留4秒，然后每秒最大HP10%衰减。始终不超过缺血量。 |
| 夺回 | 对敌人实际HP伤害的50%，不计算护盾承接或过量伤害。普通攻击每次最多自身最大HP5%；技能整次施放最多10%，包含AOE、侧箭与延迟派生。 |
| 启用对象 | 本体、复制体有虚血夺回；敌人有架势但无虚血夺回。不在场/濒死/死亡/已销毁来源不能被派生伤害救活。 |
| 治疗 | 保留现有治疗值；治疗后立刻将虚血限制到剩余缺血量，不额外再治疗一次。 |

## 动作与技能

- 普攻：取消尚未出手前摇；已结算的攻击不撤回，已发出的回声继续。
- 移动：已接受的路径和直接控制在硬直中暂停，恢复后可继续；硬直中新的移动/瞬影/主动技能/换装请求拒绝，松开直接控制仍可清除输入。
- 换装、主动回收/救援/集结读条：硬直取消；不会完成免费换装或瞬移收队。若同一击致死，已经按既有规则采样成立的回收保护优先保留。
- 生命祷告、伤势守护、霜镜钟声：接受施放后硬直中断，未完成部分取消，正常CD不退还。
- 猎杀：有限持续状态保留、窗口流逝，硬直中不产生新脉冲；错过的脉冲不补发。
- 箭雨：窗口继续流逝、丢弃硬直期间时隙，不补射；已经留下的箭迹继续。
- 镰舞、狙击、毒刃：开关保留，硬直中不攻击。无限模式按每次真实攻击及其派生共享本次预算，不能每个目标单独获得满额恢复。
- 回镰：中止未完成往返，不退已消费的普攻计数；重叠位置在硬直后通过既有合法落位机制处理。已生成留席月轮只因本次硬直而脱离动作，不延长原2秒寿命；原死亡/节点清理规则保留。
- 静钟：已生成领域在硬直中继续自身计时、治疗和范围效果；普通移动/换装/回收仍沿旧规则中断领域。本轮没有放宽其他退出条件。

## 生命周期

| 边界 | 架势/虚血 |
|---|---|
| 普通影庭 | 冻结时钟、保留数值；再部署不免费刷新。 |
| 菲奥蕾影庭 | 按模拟时间推进；现有2%/秒治疗后夹紧虚血。 |
| 复制体出生 | 独立满架势、0虚血，无本体硬直或恢复等待；保留既有满血与当前耐久快照规则。 |
| 换职业 | 架势按当前比例迁移到新职业上限，不借换装免费补满；HP/虚血按既有状态保留。 |
| 死亡/濒死 | 清虚血、硬直和等待，架势重置；不因此回血或解除禁用。 |
| 塔防结束、探索离开、节点进入/副本重启 | 清本轮临时状态和施放预算，不把虚血带出兑换成真实HP。原伤势、耐久、经济与死亡资格保留。 |
| 暂停/页面隐藏 | 没有模拟时间就不恢复、不衰减。0.1×/1×/2×只改变模拟秒推进。 |

## 界面

头像和场内条：青绿实际生命、灰白虚血拖尾、黄铜架势，护盾维持独立条。选中详情显示数值，破势/硬直附文字且技能按钮显示硬直不可用。敌方架势仅在当前选中目标、所选友军普攻目标、近期2秒受架势伤害、破势或硬直时显示；遵守探索可见性。

没有加入新动效、音效、职业、培养树、敌人虚血或队友AI。基础移速仍0.85、探索非战斗仍沿T-013；T-015尚未实施。
