# XC04 输入与确认契约

Standalone battle 的 AimSource 为 command/direct。Command 匹配当前离控焦点并沿用 T030 Reservation；Direct 匹配实控原本体且无指令预留。两者共用 Begin/Cancel/aimActor，旧 beginCommandAim/cancelCommandAim 保留兼容入口。

| 输入 | 行为 |
| --- | --- |
| F | 无更高模态时切换 PathAim；不会重启 TacticalFocus；暂停下允许 |
| 选路 [F] | 仅 CommandFocus 有效时显示，aria-pressed 表达已激活 |
| 场景 LMB | PathAim 激活时只确认当前角色路线；不聚焦、观察复制体或交互事件/出口 |
| RMB / F / Escape | 无模态时先只取消 Aim；Focus 与 Direct 不变；下一次 Escape 才清 Focus |
| C / 1 / 2 | 取消旧 PathAim，再走现有聚焦逻辑；新 Focus 不自动瞄准 |
| WASD / E R T / Shift | Direct 同键取消后行动；Command 同键取消、提升再执行；动作拒绝仍不恢复旧控制 |
| Build / 行囊 / 队伍 / Blink / 其他玩家功能按钮 | 先取消 PathAim，同次点击执行原功能；只读验证面板保留 Aim |
| 无 Aim 空地点击 / hover | Standalone 不移动、不显示被动路线；普通事件/聚焦功能仍有效 |
| Tower/Legacy | 保留原点击、拖动及路线逻辑 |

## 预览和确认

`queryPathAimPreview` 是纯查询：当前位置与 bodyRadius → positionKnown / canStop → navigate（含实际层与合法跨层边）→ Command 的全路径未交战感知区检查。Direct 不受该 AI 感知限制。失败没有有效路线，返回原因。

`PathAimPreviewCache` 是展示侧的一项缓存，按角色身份/位置/半径、Aim、地形/障碍/单位与目的地、可见记忆/灯光、活动交战组和实际鼠标落点失效；不存入 GameState。实际落点保留亚格精度，避免同格内身体碰撞误判。

`confirmPathAim` 始终绕过展示缓存：重新解析合法 AimActor，重新查询落点与路径，再检查 bodyActionReady。既有攻击、技能、强制位移、跨层、闪避、落位、换装、回收、队伍任务、救援、破势、眩晕或始动时间仍在时拒绝确认，Aim 保留，不排队、不取消既有动作。成功通过现有 `move` 命令入口，沿用 claimControl/completePlayerMove，然后只清 Aim。

路径预览属于 AimActor 而不是相机或 DirectActor；不因鼠标查看技能而换起点。无效角色/来源/队伍/阶段在 ensure 中清除，不转交 Aim 给替代角色。取消不保存或恢复旧 AI 路径。

## 边界

仅提交一次现有移动命令；途中自动战斗能否恢复原目标由未来 XC05 处理。本轮未构建持续 MoveOrder、Player Order suspend/resume、Command Skill/Mobility UI 或新减速。暂停按钮是玩家功能，取消 PathAim；Space 只切换暂停，保留 Aim。直接行动仍不能在暂停/模态下发起。

## T-035 单一实控切换（2026-10-07）

用户批准以 controlledBodyId / DirectActor 为唯一实控身份。C 两位本体切换，1/2 绝对选择，头像及场内友方点击立即切人；有效持有 WASD 转交，新技能和机动只操作当前角色。当前角色选择 no-op，无效对象先拒绝。旧 Focus/Promote/CommandAim 与 CommandDefense 正常流程停用；离手交正常 AI，切回撤销普通 AI 路线。新 Aim 只属于 Direct，F 选路保留；切走作废未确认 Aim/token，但保留双方已确认订单和原子动作。成功身体动作只取消自身订单。主 HUD、技能和机动同绑 Direct；复制体查看只读，默认切人不自动慢速，其他模态规则保持。

此块替代历史 T029–T034 的双身份控制要求；资源、碰撞、订单、合法 Release/Hit 与真取消安全契约仍有效。专项入口：docs/tasks/T-035-单一实控输入与交接契约.md；执行与验证：docs/tasks/T-035-单一实控切换与控制简化.md、T-035-验证记录.md。用户试玩通过后直接回 EC10 战术轮盘；XC08/XC12/13 研究与演出不冒充完成，旧 XC10 Command UI 退出。发布仅 GitHub main，禁止 Gitee。
