## 控制权与中断

| 状态/命令 | 已采用结果 |
|---|---|
| 自动跟随 | 最低优先级；不抢玩家路径、选定/直接控制、换装、救援、技能或群体任务 |
| 入战 | 停自动跟随；不取消用户已提交移动；不重置技能、瞬影、影体、价格 |
| 脱战 | 继续已有群体任务与原进度；不自动救援或回血 |
| 重复群体 | 相同任务不重开读条 |
| 新单体命令 | 只替换该对象群体任务；其他本体照常 |
| 群体开始 | 中断限时技能/普攻；保留持续模式但读条时不攻击 |
| 普通跨层/回镰 | 本轮新群体请求逐人拒绝，其他资格者继续 |
| 猎人失能 | 等待/取消未完成跟随与群体任务，不越权转移 |
| 集结濒死 | 取消集结，保留濒死；没有回收致死保护 |
| 召回有效致死 | 沿现有回收保护 |
| 出口 | 最终重查全部条件；濒死名单全量逐个确认后按身份死亡；健康本体收队，复制体清除 |
| 重入 | 敌人满血重布；培养/伤势/耐久/记忆/机关/奖励记录保留；需充能技能空条、瞬影满层、抽价初始 |
